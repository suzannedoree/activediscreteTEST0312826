    Subsection 2.1.B Sets of Digits

    Throughout this course, we use mathematical structures. One structure is a set, which is understood to be an unordered collection of elements. For example, the set \(\{1,4,5\}\) has three elements: 1, 4, and 5. The set \(\{4,1,5\}\) is the same as the set \(\{1,4,5\}\) because \(\{4,1,5\}\) has the same three elements: 1, 4, and 5. That is, the order in which we list the elements in a set does not matter. There is no need to repeat elements within a set because it does not change the set. For example, the set \(\{2,7,2\}\) is the same as the set \(\{2,7\}\) because each set has two elements: 2 and 7. Sets are very important in mathematics. In fact, we might say that
    🔗
    Sets are the most fundamental structure of mathematics because all of mathematics can be defined using sets.
    🔗
    🔗
    Since discrete mathematics comes from all areas of mathematics, it should not be surprising that this textbook uses a large mathematical vocabulary. Some words in that vocabulary are not defined. For example, the words “set” or “element” are not defined in the previous paragraph, although we hope that their meaning is clear from the narrative. It turns out that any vocabulary must be built on a set of undefined words because you have to start somewhere. We try to keep the list of undefined terms as short as possible.
    🔗
    When we can, we give a formal mathematical definition of a new word that states what the word means in mathematics. We sometimes add a quick example or note, but those additions are not officially part of the definition. Definitions in mathematics also serve another purpose. There might be several different, but equivalent, ways to explain the meaning of a word. In such situations, a definition establishes an agreement on which of those different explanations is the official mathematical definition of the word.

    Subsection 2.1.D Integer Algebra

    Often, the numbers we consider in this textbook are integers. For example, we might make a conjecture that involves an unknown integer. Historically, integers were commonly named using the letters \(i,j,k,l,m\text{,}\) or \(n\) because some computer programming languages, such as Fortran, used to reserve these letters for integer quantities (perhaps because the word “integer” begins with \(i\) and then \(n\)). In this textbook, we use a variety of letters for integers, although we tend to save the letters \(x\text{,}\) \(y\text{,}\) and \(z\) for real-valued (decimal) quantities.
    🔗
    When you studied algebra, you probably worked a lot with quantities named \(x\text{,}\) occasionally with quantities named \(y\text{,}\) \(z\text{,}\) or \(t\text{,}\) and rarely with quantities named \(n\text{,}\) \(m\text{,}\) \(k\text{,}\) or other common letters for integers. The rules of algebra remain the same for whatever letters we use, but it can take some practice to be comfortable working with a variety of letters. In this section, we discuss integer arithmetic. To start with, it is useful to name various arithmetic properties of the integers.
    🔗

    Definition 2.1.17. Integer algebra and the order of operations.

     
    1. When several operations are involved in a single calculation, we need to know the order of operations (PEMDAS), the priority ranking for arithmetic operations. The order is
      First, calculate anything inside Parentheses.
      Next, calculate Exponents \(\wedge\text{,}\) in order from left to right.
      Then, Multiply × and Divide \(\div\text{,}\) in order from left to right.
      Last, Add \(+\) and Subtract \(-\text{,}\) in order from left to right.
      🔗
      🔗
    2. The commutative properties of the integers tell us that
      \begin{equation*} n+s=s+n \ \ \text{ and } sn=ns\text{.} \end{equation*}
      We often use the commutative property to rewrite sums or products in standard order. For example, products are usually written alphabetically (\(ns\) is standard, not \(sn\)) and in products numbers come before letters (\(2k\) is standard, not \(k2\)). In sums, numbers often come after letters (\(n+1\) is common, although \(1+n\) is also acceptable).
      🔗
      🔗
    3. The associative properties of the integers tells us that
      \begin{equation*} (n+s)+t = n+(s+t) \ \ \text{ and } (ns)t = n(st)\text{.} \end{equation*}
      We often use the associative property to write an expression such as \(n+3k+2\) without parentheses, since the location of parentheses would not change the sum.
      🔗
      🔗
    4. We factor an integer by writing it as a product of two integers. For example, we can factor \(6\) as \(2 \times 3\) which we could write as \(6=2 \times 3\) or \(6=(2)(3)\text{.}\) Although it is correct to factor \(6\) as \(1 \times 6\text{,}\) if an activity or exercise asks you to “factor,” the answer should not use the factor \(1\text{.}\) Notice that “factor” can be a noun, which means the quantity we are multiplying, or a verb, which means write as a product.
      🔗
      🔗
    5. The distributive property of the integers tells us that
      \begin{equation*} n(s+t)=ns+nt\text{.} \end{equation*}
      Reading this equation from left to right tells us how to expand (or distribute or multiply out). For example,
      \begin{equation*} 2(n+4) = (2)(n) + (2)(4) = 2n + 8\text{.} \end{equation*}
      Equations tell us that two things are equal, so we can equally well read this equation from right to left
      \begin{equation*} ns+nt=n(s+t) \end{equation*}
      which tells us how to factor. For example,
      \begin{equation*} 5n-10 = (5)(n) + (5)(-2) = 5(n+(-2)) = 5(n-2)\text{.} \end{equation*}
      🔗
      🔗
    🔗

    Example 2.1.19. Combining like terms.

    Simplify the expression \(2n+3n\text{.}\)
    🔗
    Solution.
    You have seen \(2x+3x=5x\text{.}\) You might have learned that this equation is analogous to saying that if I have 2 apples plus another 3 apples, then I have a total of 5 apples. In the same way, \(2n+3n=5n\text{.}\)
    🔗
    Alternatively, we can use the definition of the product. Since \(2n = n+n\) and \(3n = n+n+n\text{,}\) together we have
    \begin{equation*} 2n + 3n = \underbrace{(n+n)}_{2 \text{ times } } +\underbrace{(n+n+n)}_{3 \text{ times } } = \underbrace{n+n+n+n+n}_{5 \text{ times } } = 5n \end{equation*}
    🔗
    Yet another way of thinking about this simplification is to use the distributive property to factor
    \begin{equation*} 2n+3n=(2+3)n=5n \end{equation*}
    🔗
    Each of these approaches is useful. So, even if you favor one approach, learn the other methods as well.
