    Example 8.1.3. First look at recursively-defined sequences.

     
    1. Consider the sequence \(a_n\) from Activity 6.5.A that was defined by \(a_n=10n+2\) for \(n\ge 0\text{.}\) The first few terms are
      \begin{equation*} 2, 12, 32, 42, 52, \ldots\text{.} \end{equation*}

      Solution.
      Each term (\(a_n\)) is ten more than the previous term (\(a_{n-1}\)) . That is,
      \begin{equation*} 2 \xrightarrow[+ 10]{} 12 \xrightarrow[+ 10]{} 22 \xrightarrow[+ 10]{} 32 \xrightarrow[+ 10]{} 42 \xrightarrow[+ 10]{} 52\text{.} \end{equation*}
      🔗
      Thus for \(n\ge 1\) we have
      \begin{equation*} a_n=a_{n-1}+10\text{.} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. Consider the sequence \(b_i\) from Activity 6.5.A that was defined by \(b_i=2\cdot10^i\) for \(i\ge 0\text{.}\) The first few terms are
      \begin{equation*} 2, 20,200,2000,20000, \ldots\text{.} \end{equation*}
      What do we notice about how each term is calculated from the previous term?
      Solution.
      Each term (\(b_i\)) is ten times the previous term (\(b_{i-1}\)). That is,
      \begin{equation*} 2 \xrightarrow[\times 10]{} 20 \xrightarrow[\times 10]{} 200 \xrightarrow[\times 10]{} 2000 \xrightarrow[\times 10]{} 20000\text{.} \end{equation*}
      🔗
      Thus for \(i\ge 1\) we have
      \begin{equation*} b_i=10b_{i-1} \end{equation*}
      🔗
      🔗
      🔗
      🔗

    Example 8.1.4. Double and add three.

    Consider the sequence \(c\) is defined by the \(c_0=1\) and
    \begin{equation*} c_k=2c_{k-1}+3 \end{equation*}
    for \(k \ge 1\text{.}\) Note that the rule for this sequence is actually piecewise-defined
    \begin{equation*} c_k = \left\{\begin{array}{cl} 1 \amp \text{ if } k=0 \\ 2c_{k-1}+3 \amp \text{ if } k\ge 1 \end{array} \right.\text{.} \end{equation*}
    Also notice that the second part of the rule gives an infinite list of equations:
    \begin{align*} (k=1) c_1\amp =2c_0+3\\ (k=2) c_2\amp =2c_1+3\\ (k=3) c_3\amp =2c_2+3\\ (k=4) c_4\amp =2c_3+3\\ \amp \vdots \end{align*}
    🔗
    It is often helpful to think of the rule in words To get each term, we double the previous term and then add 3.
    1. Evaluate \(c_4\text{.}\)
      Solution.
      First recall that \(c_0=1\text{.}\) When \(k=1\) the rule tells us
      \begin{equation*} c_1=2c_0+3=2(1)+3=5\text{.} \end{equation*}
      🔗
      Next, when \(k=2\) we get
      \begin{equation*} c_2=2c_1+3=2(5)+3=13\text{.} \end{equation*}
      🔗
      When \(k=3\) we have
      \begin{equation*} c_3=2c_2+3=2(13)+3 = 29\text{.} \end{equation*}
      🔗
      Finally, when \(k=4\) we find
      \begin{equation*} c_4=2c_3+3=2(29)+3=61\text{.} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. Write an explicit rule for \(c_k\text{.}\)
      Solution.
      Since we are multiplying the previous term by 2 each time, it is reasonable to suspect that an explicit formula involves a power of 2. Table 8.1.5 compares the first five terms of \(c\) to the powers of 2. Since there is no obvious pattern with \(2^k\) we have listed \(2^{k+1}\) and then \(2^{k+2}\) as well. It looks like \(c_k\) is 3 smaller than \(2^{k+2}\) and so we conjecture that \(c_k=2^{k+2}-3\text{.}\)
      🔗
      We can check that the definition gives \(c_5=2c_4+3=2(61)+3 = 125\) and our explicit formula gives \(c_5=2^{5+2}-3 = 128-3 = 125\text{.}\) We will see how to verify these conjectures in Section 8.2.
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    We state the formal definitions.
    🔗

    Definition 8.1.6. Recursively-defined sequence.

     
    1. The first term (or first few terms) of a sequence is the initial condition(s). If a sequence \(a\) starts at \(s\) for some nonnegative integer \(s\text{,}\) then the initial condition is \(a_s\) (and perhaps subsequent terms such as \(a_{s+1}\text{,}\) \(a_{s+2}\text{,}\) etc.) For example, the initial condition for the sequence \(c\) defined in Example 8.1.4 was \(c_0=1\text{.}\)
      🔗
      🔗
    2. A recursion (or recursive rule) for a sequence specifies how each term (\(a_n\)) can be calculated from the previous term(s) (\(a_{n-1}\) and perhaps \(a_{n-2}\text{,}\) \(a_{n-3}\text{,}\) and so on). For example, the recursion for the sequence \(c\) defined in Example 8.1.4 was \(c_n=2c_{n-1}+3\text{.}\) A recursion may involve the index \(n\) as well as previous term(s). A recursion should use the previous term(s) in a nontrivial way. We do not consider explicitly-defined rules (that use the index but not previous terms) to be recursive.
      🔗
      🔗
    3. A sequence is recursively-defined if we are given a recursion and enough initial conditions to evaluate the recursion at all values. For example, the recursion for the sequence \(c\) defined in Example 8.1.4 starts at \(k=1\text{,}\) so we needed the initial condition to provide the value of \(c_0\text{.}\)
      🔗
      🔗
    4. A recursive rule that involves only one previous term is first order. For example, the sequence \(c\) defined in Example 8.1.4 is first-order.
      🔗
      🔗
    🔗

    Example 8.1.8. Write the recursive rule for sequence from list.

     
    1. Write a simple recursive rule that generates a sequence \(a\) that begins
      \begin{equation*} 5, 6, 7, 8, 9, 10, \ldots \end{equation*}
      Solution.
      To get from each term to the next we add 1. That is,
      \begin{equation*} 5 \xrightarrow[+ 1]{} 6 \xrightarrow[+ 1]{} 7 \xrightarrow[+ 1]{} 8 \xrightarrow[+ 1]{} 9 \xrightarrow[+ 1]{} 10\text{.} \end{equation*}
      🔗
      Thus \(a_0=5\) and \(a_n=a_{n-1}+1\) for \(n \ge 1\text{.}\) By the way, an explicit rule for this sequence is \(a_n=n+5\) for \(n\ge 0\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Write a simple recursive rule that generates a sequence \(b_n\) defined by \(b_n=(n+1)(2n+1)\) for \(n \ge 0\text{.}\) Hint: The recursive definition depends on the index as well as the previous term.
      Solution.
      Let’s find the first few terms of \(b\text{.}\) We get \(b_0 = (1)(1) = 1\text{,}\) \(b_1 = (2)(3) = 6\text{,}\) \(b_3 = (4)(7) = 28\text{,}\) \(b_4 = (5)(9) = 45\text{,}\) and \(b_5 = (6)(11) = 66\text{.}\) That is, the sequence \(b\) begins
      \begin{equation*} 1, 6, 15, 28, 45, 66, \ldots \end{equation*}
      🔗
      Look at what we add to get each term from the previous term:
      \begin{equation*} 1 \xrightarrow[+ 5]{} 6 \xrightarrow[+ 9]{} 15 \xrightarrow[+ 13]{} 28 \xrightarrow[+ 17]{} 45 \xrightarrow[+ 21]{} 66\text{.} \end{equation*}
      🔗
      The values we are adding
      \begin{equation*} 5,9,13,17,21,\ldots \end{equation*}
      appear to depend on the index. An explicit rule for these terms we are adding is \(4n+1\) for \(n \ge 1\text{.}\) A recursive rule is \(b_0=1\) and
      \begin{equation*} b_n=b_{n-1}+4n+1 \end{equation*}
      for \(n \ge 1\text{.}\)
