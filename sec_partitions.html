    Section 7.3 Excursion: Partitions

    Whenever we subdivide a set into categories, we are using a partition of sets. For example, we might subdivide students at a university into three categories: full-time student, part-time student, or students who are not currently enrolled. Partitions are useful in counting because they give non-overlapping cases. For example, the total number of students at a university is the sum of the number of full-time students, the number of part-time students, and the number of students who are not currently enrolled.
    🔗
    In this section, we define the partition of a set and a related concept– the partition of a natural number. Partitions of natural numbers come up frequently in number theory and because listing or counting partitions is difficult, it is common in advanced computer science classes to work with algorithms to generate partitions.
    🔗

    Subsection 7.3.A The Definition of Partition

    Given a set, we might want to categorize its elements in such a way that each element of the set is in exactly one category. Let’s make this concept formal.
    🔗

    Definition 7.3.1. partition of a set.

    A partition of a set \(S\) is a collection of nonempty subsets \(T_1, T_2, \ldots, T_k\) such that each element of \(S\) is in exactly one of the subsets \(T_i\text{.}\) Notice that a partition satisfies two properties:
    1. \(\displaystyle S = T_1 \cup T_2 \cup \cdots \cup T_k\)
      🔗
      🔗
    2. \(T_i\) and \(T_j\) are disjoint when \(i \neq j\text{.}\)
      🔗
      🔗
    🔗
    For example,
    \begin{equation*} \{1,5\} \cup \{2,4,6\} \cup \{3\} \end{equation*}
    is a partition of the set \(S = \{1,2,3,4,5,6\}\text{.}\)
    🔗
    🔗
    Let’s look at another example of partitions of a set.
    🔗

    Example 7.3.2. Partitions of the set \(\{a,b,c\}\).

    List all partitions of the set \(\{a,b,c\}\text{.}\)
    🔗
    Solution.
    One partition is just the set \(\{a,b,c\}\text{.}\) If we group the elements into two sets we get three more partitions: \(\{a,b\} \cup \{c\}\text{,}\) \(\{a,c\} \cup \{b\}\text{,}\) and \(\{a\} \cup \{b,c\}\text{.}\) There is one final partition: \(\{a\} \cup \{b\} \cup \{c\}\text{.}\)
    🔗
    🔗
    🔗
    At times, we are only interested in the sizes of the sets in a partition. For example, in Definition 7.3.1 our set \(S\) had six elements and the subsets had two, three, and one element. Note that \(6 = 2 + 3 + 1\text{.}\) This example motivates our next definition.
    🔗

    Definition 7.3.3. Partition of an integer.

     
    1. A partition is a formal sum of positive integers listed in non-increasing order. For example, \(5+3+3+2\) is a partition since \(5 \ge 3 \ge 3 \ge 2\text{.}\)
      🔗
      🔗
    2. The parts of a partition are the numbers being added. For example, the partition \(5+3+3+2\) has four parts: 5, 3, 3, and 2. Notice that repeats are counted. A partition can have only one part. For example, the partition 13 has only one part: 13.
      🔗
      🔗
    3. For any positive integer \(n\text{,}\) a partition of the integer \(n\) is any partition where the sum of the positive integers in the partition is \(n\text{.}\) For example, \(5+3+3+2\) is a partition of 13 because \(5+3+3+2=13\) and 13 is also a partition of 13.
      🔗
      🔗
    4. The (Young) diagram of the partition \(a_1+ a_2+a_3+\ldots +a_m\) of the integer \(n\) is a drawing of \(n\) squares with \(a_1\) squares in the first row, \(a_2\) squares in the second row, through \(a_m\) squares in the \(m\)th row where the squares are drawn justified to the left. For example, the partition \(5+3+3+2\) has the diagram shown in Figure 7.3.4 which has five squares in the first row, three squares in the second row, three squares in the third row, and two squares in the fourth row.
      🔗
      🔗
    🔗
    🔗
    There is a connection between the partitions of a set and the partitions of a positive integer.
    🔗

    Remark 7.3.5. Partitions of sets and integers.

    If \(T_1 \cup T_2 \cup \cdots \cup T_k\) is a partition of a set \(S\) having \(n\) elements and if we order the sets \(T_i\) such that the number of elements in each set are nonincreasing, then \(|T_1|+|T_2|+ \ldots +|T_k|\) is a partition of \(n\text{.}\)
    🔗
    🔗
    Try working with partitions of an integer.

    Subsection 7.3.B Conjugate Partitions

    It can be difficult to know if you have found all partitions of an integer and there is no explicit formula for the number of partitions of an integer. One tool that can help check any list is the idea of conjugate partitions.
    🔗

    Definition 7.3.8. Conjugate of a partition.

    The conjugate of the partition \(\alpha\) is the partition \(\beta = b_1+b_2+ \ldots +b_k\) where \(b_1\) is the number of squares in the first column of the diagram for \(\alpha\text{,}\) \(b_2\) is the number of squares in the second column of the diagram for \(\alpha\text{,}\) and so on through \(b_k\) is the number of squares in the \(k^{\text{ th } }\) column of the diagram for \(\alpha\) and where \(k\) is the number of columns in the diagram for \(\alpha\text{.}\) For example, the conjugate of the partition \(3+1\) is the partition \(2+1+1\) as we see in Example 7.3.9.
    🔗
    🔗
    Let’s check the example from Definition 7.3.8.
    🔗

    Example 7.3.9. Calculating the conjugate of a partition.

     
    1. Calculate the conjugate of the partition \(3+1\text{.}\)
      Solution.
      The diagram for the partition \(3+1\) is shown on the left in Figure 7.3.10.
      🔗
      The diagram has two squares in the first column, one square in the second column, and one square in the third column. Therefore, the conjugate of \(3+1\) is the partition \(2+1+1\) shown on the right in Figure 7.3.10.
      🔗
      🔗
      🔗
      🔗
    2. Calculate the conjugate of the partition \(6+4+2+1+1\text{.}\)
      Solution.
      The conjugate of \(6+4+2+1+1\) is \(5+3+2+2+1+1\text{.}\) These partitions are drawn in Figure 7.3.11.
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    You might have noticed in Example 7.3.9 that there is a geometric relationship between the diagrams of a partition and its conjugate.
    🔗

    Remark 7.3.12. Calculating conjugate partitions geometrically.

    Given the diagram of a partition, when can reflect the squares across the line of slope -1 (\(\backslash\)) through the upper level corner of the diagram to get the diagram of the conjugate.
    🔗
    🔗
    It is possible that a partition equals its conjugate.
    🔗

    Definition 7.3.13. Self-conjugate partitions.

    A partition is self-conjugate if it equals its conjugate.

    Subsection 7.3.C Collecting Coins

    Here is a puzzle involving partitions of integers. You will need at least ten coins or other small objects.
    🔗

    Activity 7.3.C. Collecting Coins Puzzle.

    Take some coins and arrange them into piles. You may have any number of piles and any number of coins in each pile. A pile may have as few as one coin in it. Order them largest to smallest (in nonincreasing order). This ordered arrangement of coins in piles is a state of the system.
    🔗
    From that starting state, collect the top coin off each pile and make one new pile out of those collected coins. Notice that any pile that had just a single coin was eliminated. Again, order the piles in nonincreasing order by size. You now have a new state.
    🔗
    Repeat this process on the new state — collect the top coin from each new pile, make one new pile out of those collected coins, and arrange the piles in order. Keep repeating the process. Although we can repeat this process forever, we stop if we get back to a state that we had visited before.
    1. If you have five coins and you start with one pile of two coins and three piles of one coin each, then we denote that state \(2+1+1+1\text{.}\) Write down \(2+1+1+1\text{,}\) perform the process, and write down the resulting state. Then keep repeating the process, writing down each state each time, until you get to a state that you have visited before.
      🔗
      🔗
    2. Start with six coins in two piles of three, which is denoted \(3+3\text{.}\) Perform the process, write down the resulting state, and then repeat until you get to a state that you have visited before.
      🔗
      🔗
    3. Start with seven coins in piles of four, two, and one, which is denoted \(4+2+1\text{.}\) Perform the process, write down the resulting state, and then repeat until you get to a state that you have visited before.
      🔗
      🔗
    4. A state is a fixed point of the system if when we apply one step of the process to that state we get that state immediately again. Give an example of a fixed point that you have found and find another example.
      🔗
      🔗
    5. Conjecture which states are fixed points and which numbers of coins have a fixed point state.
      🔗
      🔗
    6. Thus far, we have been looking at one state at a time. For a given number of coins, \(n\text{,}\) we can visualize the entire system by drawing the directed state graph \(G_n\text{.}\) The vertices are all possible states and there is an arrow from each state to the state that follows from one step of the process. The state graph \(G_5\) is drawn in Figure 7.3.15. Draw the state graphs \(G_1\) (one coin) \(G_2\) (two coins), \(G_3\) (three coins), and \(G_4\) (four coins).
      🔗
      🔗
    7. Now draw the state graph \(G_6\) (six coins). Be sure that you have all possible states. Hint: Start with the state \(1+1+1+1+1+1\) and perform the process until you get a repeat. Then, find a state that is not yet included in your graph. Repeat this process until all eleven possible states in your graph.
      🔗
      🔗
    8. In your state graphs, how did you indicate a fixed point?
      🔗
      🔗
    🔗
    🔗
    We introduce a little more vocabulary that is used in the exercises.
    🔗

    Definition 7.3.16. Cycles and cyclic states.

    Let \(\mathbb{P}_n\) denote the partitions of the integer \(n\text{,}\) as defined in Definition 7.3.3. For a fixed positive integer \(n\text{,}\) the process introduced in Activity 7.3.C defines a function \(\beta:\mathbb{P}_n \to \mathbb{P}_n\text{.}\) When we repeat this process, we are iterating the function \(\beta\text{.}\) That is, we are calculating
    \begin{equation*} s, \beta(s), \beta^s(s), \beta^3(s), \ldots\text{.} \end{equation*}
    where \(\beta^k\) is the \(k\)th iterate of the function \(\beta\text{,}\) as defined in Definition 6.4.18.
    1. A state is cyclic if when we start at that state we eventually return to that state. That is, \(s\) is cyclic if \(\beta^k(s) = s\) for some positive integer \(k\text{.}\) For example, with five coins the cyclic states are \(3+2\text{,}\) \(2+2+1\text{,}\) and \(3+1+1\text{.}\)
      🔗
      🔗
    2. A \(k\)-cycle is a list of distinct states:
      \begin{equation*} s, \beta(s), \beta^2(s), \ldots, \beta^{k-1}(s) \end{equation*}
      where \(\beta^k(s) = s\text{.}\) The length of the cycle is \(k\text{.}\) For example, the three cyclic states in \(G_5\) form a 3-cycle. As another example, any fixed points are 1-cycles.
      🔗
      🔗
    🔗
    🔗
