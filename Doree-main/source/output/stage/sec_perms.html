    Section 6.4 Excursion: Permutations, Inverse Functions, and Uniqueness

    We start this section by looking at permutations, which are bijections between a set and itself, and discuss the composition of permutations. Next, building on our examples with permutations, we define function composition and function inverses, in general. Lastly, we explore how to prove that a function is one-to-one and, more generally, a proof format for uniqueness proofs as well as existence and uniqueness proofs.
    🔗

    Subsection 6.4.1 Permutations

    Permutations are used in many applications. For example, they are used to describe the shuffling of a deck of cards, analyze sorting algorithms, and model gene sequencing. They are used in encryption and error-correction algorithms and for games such as anagrams, the sliding 15 puzzle, and Rubik’s Cube{\texttrademark}. We start with the definition.
    🔗

    Definition 6.4.1. Permutation.

     
    1. A permutation is a function \(f:X \to X\) for some set \(X\) such that \(f\) is onto and one-to-one. In other words, a permutation is a bijection from a set to itself. Equivalently, a permutation is a function whose rule is a pairing of a set with itself. For example, the function \(h: \mathbb{R} \to \mathbb{R}\) defined by \(h(x) = 3x\) is a permutation, as we saw in Example 6.3.31.
      🔗
      🔗
    2. We are often interested in a permutation of the set \(\{1,2,\ldots,n\}\) for some positive integer \(n\text{.}\) We can describe such permutations by listing the values, drawing the standard dot diagram, or using 2-line notation
      \begin{equation*} \alpha = \left(\begin{array}{ccc cc} 1 \amp 2 \amp 3 \amp \ldots \amp n \\ \alpha(1) \amp \alpha(2) \amp \alpha(3) \amp \ldots \amp \alpha(n) \end{array} \right) \end{equation*}
      For example, if \(\sigma: \{1,2,3,4\} \to \{1,2,3,4\}\) is the permutation defined by \(\sigma(1)=2\text{,}\) \(\sigma(2)=3\text{,}\) \(\sigma(3)=4\text{,}\) and \(\sigma(4)=1\text{,}\) then we write
      \begin{equation*} \sigma = \left(\begin{array}{ccc c} 1 \amp 2 \amp 3 \amp 4 \\ 2 \amp 3 \amp 4 \amp 1 \end{array} \right)\text{.} \end{equation*}
      In the 2-line notation, the first line is always \(1 2 3 \ldots n\) and the second line contains each of \(1, 2, 3, \ldots, n\) exactly once.
      🔗
      🔗
    🔗
    🔗
    Permutations are often named with lowercase Greek letters.
    🔗

    Remark 6.4.2. Greek letters.

    Table 6.4.3 lists a few lowercase Greek letters commonly used for permutations.
    🔗
    🔗
    Let’s look more closely at permutations on \(\{1,2,3,4\}\text{.}\)
    🔗

    Example 6.4.4. Permutations on \(\{1,2,3,4\}\).

     
    1. Draw the dot diagram for the permutation \(\sigma = \left(\begin{array}{ccc c} 1 \amp 2 \amp 3 \amp 4 \\ 2 \amp 3 \amp 4 \amp 1 \end{array} \right)\text{.}\)
      Solution.
      Figure 6.4.5 shows two versions of the dot diagram — the standard version on the left and an unlabeled version on the right.
      🔗
      🔗
      🔗
      🔗
    2. Is the identity function a permutation on \(\{1,2,3,4\}\text{?}\)
      Solution.
      The identity permutation \(i: \{1,2,3,4\} \to \{1,2,3,4\}\) is defined by \(i(n)=n\text{.}\) ENDFigure 6.4.6 shows the dot diagram of \(i\text{.}\) Since the function \(i\) is both onto and one-to-one with domain and codomain of \(\{1,2,3,4\}\text{,}\) the identity function \(i\) is a permutation. We can write
      \begin{equation*} i = \left(\begin{array}{ccc c} 1 \amp 2 \amp 3 \amp 4 \\ 1 \amp 2 \amp 3 \amp 4 \end{array} \right) \end{equation*}
      🔗
      🔗
      🔗
      🔗
    3. How many permutations on \(\{1,2,3,4\}\) are there? Explain how you count.
      Solution.
      There are four choices for where the permutation maps one. Since permutations are one-to-one, there are three choices left for where the permutation maps two. Similarly, there are only two choices left for where the permutation maps three and then one choice for where the permutation maps four. Therefore there are \(4!\) permutations on the set \(\{1,2,3,4\}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    In Example 6.4.4, we drew an unlabeled version of the dot diagrams where we omitted the vertex labels (always 1, 2, … \(n\) from top to bottom) and the arrows (always left-to-right). The unlabeled version can save writing and so we use it in our examples, but feel free to stick with the standard dot diagram if you prefer.
    🔗
    There is a natural way to combine permutations.
    🔗

    Definition 6.4.7. Permutation composition.

     
    1. For any permutations \(\alpha\) and \(\beta\) on \(\{1,2,3, \ldots,n\}\text{,}\) their composite \(\gamma\) is defined by \(\gamma(x) = \alpha(\beta(x))\text{.}\) We often write \(\alpha \circ \beta\) instead of \(\gamma\text{;}\) that is, \((\alpha \circ \beta)(x) = \alpha(\beta(x))\text{.}\) Notice in the composite \(\alpha \circ \beta\) that \(\beta\) is applied first and \(\alpha\) is applied second, which feels backward but is correct. For example, let
      \begin{equation*} \sigma = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 2 \amp 3 \amp 4 \amp 1 \end{array} \right ) \text{ and } \tau= \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4\\ 2 \amp 1 \amp 4 \amp 3 \end{array} \right )\text{.} \end{equation*}
      Then
      \begin{equation*} \sigma \circ \tau = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 3 \amp 2 \amp 1 \amp 4 \end{array} \right )\text{,} \end{equation*}
      as we see in Example 6.4.8.
      🔗
      🔗
    2. For a permutation \(\alpha\text{,}\) the (\(n\)th) iterate of \(\alpha\) is the composite
      \begin{equation*} \alpha^n=\underbrace{\alpha \circ \alpha \circ \alpha \cdots \circ \alpha}_{n \text{ times } }\text{.} \end{equation*}
      For example, for that permutation \(\sigma\text{,}\) it turns out that
      \begin{equation*} \sigma^2=\sigma \circ \sigma = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 3 \amp 4 \amp 1 \amp 2 \end{array} \right )\text{,} \end{equation*}
      as we see in Example 6.4.8.
      🔗
      🔗
    🔗
    🔗
    Let’s check the examples from Definition 6.4.7.
    🔗

    Example 6.4.8. Composing permutations.

    Consider the permutations
    \begin{equation*} \sigma = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 2 \amp 3 \amp 4 \amp 1 \end{array} \right ) \text{ and } \tau= \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4\\ 2 \amp 1 \amp 4 \amp 3 \end{array} \right ) \end{equation*}
    1. Calculate \(\sigma \circ \tau\text{.}\)
      Solution.
      We have
      \begin{align*} (\sigma \circ \tau)(1) \amp = \sigma(\tau(1))=\sigma(2)=3\\ (\sigma \circ \tau)(2) \amp = \sigma(\tau(2))=\sigma(1)=2\\ (\sigma \circ \tau)(3) \amp = \sigma(\tau(3))=\sigma(4)=1\\ (\sigma \circ \tau)(4) \amp = \sigma(\tau(4))=\sigma(3)=4 \end{align*}
      🔗
      Thus
      \begin{equation*} \sigma \circ \tau = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 3 \amp 2 \amp 1 \amp 4 \end{array} \right )\text{.} \end{equation*}
      There is a quicker way to compute this composite using the unlabeled dot diagrams shown in Figure 6.4.9. To read this diagram, start with the uppermost dot on the left which represents 1. Moving right, follow the path to end on the third dot on the right which represents 3. Thus the composite maps 1 to 3. Repeat with each dot on the left following the path.
      🔗
      🔗
      🔗
      🔗
    2. Calculate \(\tau \circ \sigma\text{.}\)
      Solution.
      Following the paths in Figure 6.4.10 we get
      \begin{equation*} \tau \circ \sigma = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 1 \amp 4 \amp 3 \amp 2 \end{array} \right )\text{.} \end{equation*}
      Notice that the order mattered, in that \(\sigma \circ \tau \ne \tau \circ \sigma\text{.}\) That is, composition of permutations is not commutative.
      🔗
      🔗
      🔗
      🔗
    3. Calculate \(\sigma^2=\sigma \circ \sigma\text{.}\)
      Solution.
      Following the paths in Figure 6.4.11 we get
      \begin{equation*} \sigma^2=\sigma \circ \sigma = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 3 \amp 4 \amp 1 \amp 2 \end{array} \right ) \end{equation*}
      🔗
      🔗
      🔗
      🔗
    4. Calculate \(\tau^2=\tau \circ \tau\text{.}\)
      Solution.
      Following the paths in Figure 6.4.12 we get
      \begin{equation*} \tau^2=\tau \circ \tau = \left ( \begin{array}{cccc} 1 \amp 2 \amp 3 \amp 4 \\ 1 \amp 2 \amp 3 \amp 4 \end{array} \right ) = i\text{,} \end{equation*}
      the identity permutation.
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗

    Subsection 6.4.2 Inverse Functions

    How often have you done something on a computer, decided it was a mistake, and hit undo? As you may have learned (the hard way), some operations are invertible, meaning that they can be undone, and others are not. Let’s make this concept formal.
    🔗

    Definition 6.4.13. Inverse function.

     
    1. A function \(f: X \to Y\) is invertible if the equation \(f(x) = y\) has exactly one solution for each value of \(y\) in \(Y\text{.}\) For example, the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = n+1\) is invertible because the equation \(f(n) = m\) is really \(n+1=m\) which has one solution, namely \(n=m-1\text{.}\) On the other hand, the function \(\fn{trim}: \mathbb{B}^* \to \mathbb{B}\) defined by \(\fn{trim}(b) =\) the bit string \(b\) without its last bit is not invertible because, for example, \(\fn{trim}(b) = \bs{101}\) has two solutions, namely \(b\)=1011 and \(b\)=1010.
      🔗
      🔗
    2. For an invertible function \(f: X \to Y\text{,}\) the inverse function \(f^{-1}: Y \to X\) is defined by \(f^{-1}(y)\) is the unique solution of \(f(x)=y\text{.}\) That is, \(f^{-1}(y)=x\) exactly when \(f(x) = y\text{.}\) In this way, \(f^{-1}\) undoes \(f\text{.}\) Note that \(f^{-1}\) is pronounced as “\(f\) inverse”. For example, if \(f: \mathbb{Z} \to \mathbb{Z}\) is defined by \(f(n) = n+1\text{,}\) then \(f^{-1}: \mathbb{Z} \to \mathbb{Z}\) is defined by \(f^{-1}(m) = m-1\text{.}\) We can think of the function \(f\) as adding one, and so its inverse \(f^{-1}\) undoes that operation by subtracting one.
      🔗
      🔗
    🔗
    🔗
    A function \(f: X \to Y\) is invertible if the equation \(f(x) = y\) has exactly one solution for each value of \(y\) in \(Y\text{.}\) That is, if for each element \(y\) in \(Y\) there is exactly one element \(x\) in \(X\) such that \(f(x) = y\text{,}\) which means \(f\) is one-to-one and onto. Thus, \(f\) is invertible if (and only if) it is a bijection. We state this result as a theorem.
    🔗

    Theorem 6.4.14. Invertible Functions.

    For sets \(X\) and \(Y\text{,}\) a function \(f: X \to Y\) is invertible if and only if \(f\) is a bijection (one-to-one and onto) or, equivalently, if and only if the rule for \(f\text{,}\) \(x \leftrightarrow f(x)\text{,}\) is a pairing.
    🔗
    🔗

    It is not a coincidence that \(\sigma^{-1} \circ \sigma = i\text{,}\) the identity function. After all, the inverse function undoes the function. To state the general result, we first define the composition of the functions in general. (If you have seen calculus, the chain rule helped us take the derivative of the composite of functions.)
    🔗

    Definition 6.4.18. Function composition.

     
    1. Consider functions \(f: X \to Y\) and \(g: Y \to Z\text{.}\) Their composite function \(h: X \to Z\) is defined by \(h(x) = g(f(x))\text{.}\) We often write \(g \circ f\) instead of \(h\text{;}\) that is,
      \begin{equation*} (g \circ f)(x) = g(f(x))\text{.} \end{equation*}
      For example, if \(v: \mathbb{Z} \to \mathbb{Z}\) is defined by \(v(n) = n-1\) and \(w: \mathbb{Z} \to \mathbb{Z}\) is defined by \(w(n) = 2n\text{,}\) then
      \begin{equation*} (w \circ v)(n) = w(v(n)) = w(n-1) = 2(n-1) = 2n-2\text{.} \end{equation*}
      Note that
      \begin{equation*} (v \circ w)(n) = v(w(n)) = v(2n) = 2n-1\text{.} \end{equation*}
      🔗
      🔗
    2. If a function \(f:X \to X\) has the same set for its domain and codomain, then the (\(n\)th) iterate of \(f\) is the composite
      \begin{equation*} f^n=\underbrace{f \circ f \circ f \cdots \circ f}_{n \text{ times } }\text{.} \end{equation*}
      For example, if \(v: \mathbb{Z} \to \mathbb{Z}\) is defined by \(v(n) = n-1\text{,}\) then \(v^2: \mathbb{Z} \to \mathbb {Z}\) is defined by
      \begin{equation*} v^2(n) = v(v(n))=v(n-1) = (n-1)-1 = n-2 \end{equation*}
      and \(v^3: \mathbb{Z} \to \mathbb {Z}\) is defined by
      \begin{equation*} v^3(n) = v(v^2(n)) = v(n-2) = (n-2)-1 = n-3\text{.} \end{equation*}
      By the way, it is reasonable to conjecture that \(v^k: \mathbb{Z} \to \mathbb {Z}\) is defined by \(v^k(n) = n-k\) for any positive integer \(k\text{.}\)
      🔗
      🔗
    🔗
    🔗
    For any invertible function \(f\text{,}\) \(f^{-1} \circ f=i_X\) where \(i_X\) is the identity function on the set \(X\) because
    \begin{equation*} (f^{-1} \circ f)(x)=f^{-1}(f(x)) = f^{-1}(y) = x\text{.} \end{equation*}
    Similarly, \(f \circ f^{-1}=i_Y\text{,}\) where \(i_Y\) is the identity function on the set \(Y\text{,}\) because
    \begin{equation*} (f \circ f^{-1})(y) = f(f^{-1}(y)) = f(x) = y\text{.} \end{equation*}
    We state this result.
    🔗

    Theorem 6.4.19. Inverses and function composition.

    If \(f:X \to Y\) is an invertible function, then \(f^{-1} \circ f=i_X\text{,}\) where \(i_X\) is the identity function on \(X\text{,}\) and \(f \circ f^{-1}=i_Y\text{,}\) where \(i_Y\) is the identity function on \(Y\text{.}\)

    Subsection 6.4.3 Proof Format: Uniqueness

    How do we prove that a function \(f: X \to Y\) is one-to-one or that a function is invertible? In this section, we look at how to prove uniqueness and also how to prove existence and uniqueness.
    🔗
    Ironically, there are two different proof formats for proving uniqueness. The first is direct.
    🔗

    Proof.
    (Uniqueness, direct) Prove: There is at most one \(n\) with \(P(n)\text{.}\)
    🔗
    Proof. Assume \(P(n)\text{.}\)
    🔗
     (Explain why \(n = k\text{.}\))
    🔗
     Thus, if \(P(n)\text{,}\) then \(n = k\text{.}\) It follows that \(k\) is the only possible value of \(n\text{.}\)
    🔗
     Therefore, there is at most one \(n\) with \(P(n)\text{.}\)
    🔗
    🔗
    There is an indirect method to prove uniqueness that does not require us to find \(k\text{.}\) How can we do that? An intuitive approach would be a proof by contradiction Proof 5.1.2.3.1. That is, we would suppose that \(P(n_1)\) and \(P(n_2)\) with \(n_1 \neq n_2\) and derive a contradiction. However, such proofs typically do not use the assumption that \(n_1 \neq n_2\text{,}\) and therefore can be rewritten without using contradiction. That is, we can prove if \(P(n_1)\) and \(P(n_2)\text{,}\) then \(n_1=n_2\text{.}\)
    🔗

    Proof.
    (Uniqueness, indirect) Prove: There is at most one \(n\) with \(P(n)\text{.}\)
    🔗
    Proof. Assume \(P(n_1)\) and \(P(n_2)\text{.}\)
    🔗
     (Explain why \(n_1 = n_2\text{.}\))
    🔗
     Therefore, there is at most one \(n\) with \(P(n)\text{.}\)
    🔗
    🔗
    As usual, when we present new proof formats, we give you examples to copy and edit.
    🔗

    Activity 6.4.3. Uniqueness proofs.

     
    1. Copy the following direct proof. For a fixed integer \(a\text{,}\) prove that the equation \(2x+1 = a\) has at most one integer solution. Proof. Assume \(2x+1 = a\text{.}\) Subtract one from each side of the equation to get \(2x = a-1\text{.}\) Divide each side of the equation by two to get \(x = \frac{a-1}{2}\text{.}\) Thus, if \(x\) is a solution, then \(x = \frac{a-1}{2}\text{.}\) It follows that \(x = \frac{a-1}{2}\) is the only possible solution. Therefore, the equation \(2x+1=a\) has at most one integer solution. \(\Box\) Note: There will be one solution if \(a\) is odd and \(\frac{a-1}{2}\) is an integer. There will be no solutions if \(a\) is even and \(\frac{a-1}{2}\) is not an integer.
      🔗
      🔗
    2. Edit the proof from Item 1 to prove that the equation \(3x-4=b\) has at most one integer solution.
      🔗
      🔗
    3. Copy the following indirect proof. For a fixed integer \(a\text{,}\) prove that the equation \(2x+1 = a\) has at most one integer solution. Proof. Assume that the integers \(n_1\) and \(n_2\) are each a solution of \(2x+1=a\text{.}\) Then \(2n_1+1=a\) and \(2n_2+1=a\text{.}\) Equating these expressions we get \(2n_1+1 = 2n_2+1\text{.}\) Subtract one from each side of the equation to get \(2n_1 = 2n_2\text{.}\) Divide each side of the equation by two to get \(n_1 = n_2\text{.}\) Therefore, the equation \(2x+1=a\) has at most one integer solution. \(\Box\)

      🔗

    Recall that the one-to-one property was the uniqueness part of the definition of pairing Definition 6.3.12. Thus, we can use Proof 6.4.3.2 to prove that a function is one-to-one. Recall from Definition 6.3.26 that a function \(f: X \to Y\) is one-to-one if for each element \(y\) of \(Y\text{,}\) there is at most one element \(x \in X\) such that \(f(x) =y\text{.}\) Using the indirect approach from Proof 6.4.3.2, we can prove that a function is one-to-one by showing if \(f(x_1) = y\) and \(f(x_2)=y\text{,}\) then \(x_1=x_2\text{.}\) There is no reason to mention \(y\text{.}\) We can prove that a function is one-to-one by showing if \(f(x_1) = f(x_2)\text{,}\) then \(x_1=x_2\text{.}\) We can restate the definition of one-to-one using this observation.
    🔗

    Remark 6.4.20. Alternative definition of one-to-one.

    Let \(f: X \to Y\) be a function. Then \(f\) is one-to-one exactly when it satisfies the following condition. For all elements \(x_1\) and \(x_2\) in \(X\text{,}\) if \(f(x_1) = f(x_2)\text{,}\) then \(x_1 = x_2\text{.}\)
    🔗
    🔗

    Example 6.4.21. Prove function is one-to-one.

    Prove that the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = 2n+1\) is one-to-one, using Remark 6.4.20.
    🔗
    Solution.
    Proof. Let \(n_1\) and \(n_2\) be integers. Assume \(f(n_1) = f(n_2)\text{.}\) By the definition of \(f\text{,}\) it follows that \(2n_1+1=2n_2+1\text{.}\) Subtract one from each side of the equation to get
    \begin{equation*} 2n_1 = 2n_2\text{.} \end{equation*}
    🔗
    Divide each side of the equation by two to get
    \begin{equation*} n_1 = n_2\text{.} \end{equation*}
    🔗
    Therefore, the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = 2n+1\) is one-to-one.
    🔗
    🔗
    🔗
    We can combine proof formats for existence and uniqueness to prove that there exists a unique value of \(n\) such that \(P(n)\text{.}\) We begin with a quick notation.
    🔗

    Remark 6.4.22. Notation for uniqueness.

    There exists a unique value of \(n\) such that \(P(n)\) is denoted \(\exists ! n ~ P(n)\text{.}\)
    🔗
    🔗
    To prove that \(\exists ! n ~ P(n)\) we need to prove two things — first, that there is at least one \(n\) with \(P(n)\) and second, that there is at most one \(n\) with \(P(n)\text{.}\) The first proves existence, which we can do using Proof 5.2.3.1. The second proves uniqueness, which we can do directly using Proof 6.4.3.1.
    🔗

    Proof.
    Prove: \(\exists ! n ~ P(n)\)
    🔗
    Proof: First, consider \(n=\) (example).
    🔗
    (Explain why \(P(n)\text{.}\))
    🔗
    Therefore, \(P(n)\) is true for some (describe type of object), namely \(n=\) (example).
    🔗
    Next, assume \(P(n)\text{.}\)
    🔗
    (Explain why \(n=\) example.)
    🔗
    Thus, if \(P(n)\text{,}\) then \(n=\) example.
    🔗
    Therefore \(n=\) example is the unique (describe type of object) such that \(P(n)\text{,}\) namely \(n=\) example.
    🔗
    🔗
    Let’s look at an example.
    🔗

    Example 6.4.23. Proof that there exists a unique.

    Prove that there exists a unique graph with three vertices and three edges.
    🔗
    Proof. First, consider the cycle \(C_3\text{.}\) Note that \(C_3\) has three vertices and three edges.
    🔗
    Next, let \(G\) be a graph with three vertices and three edges. Say the vertices are \(u\text{,}\) \(v\text{,}\) and \(w\text{.}\) There are only three possible edges between these vertices: \(uv\text{,}\) \(uw\text{,}\) and \(vw\text{.}\) Since \(G\) has three edges, it must have exactly those edges. Thus \(G = C_3\text{.}\) Therefore, there is at most one graph with three vertices and three edges, namely \(C_3\text{.}\)
