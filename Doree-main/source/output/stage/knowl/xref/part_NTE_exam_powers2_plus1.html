Item 6.

The sequence \(f\) begins \(2, 3, 5, 9, 17, \ldots\text{.}\)
Solution.
To get from each term to the next we add two, then add four, then add eight, and then add 16 so perhaps the pattern involves powers of two again. Let’s make a table comparing \(n\text{,}\) \(2^n\text{,}\) and the terms of the sequence starting at \(n=0\text{,}\) in Table 6.5.12. We can get from \(2^n\) to the terms by adding one. A possible formula is \(f_n = 2^n+1\) for \(n \ge 0\text{.}\)
