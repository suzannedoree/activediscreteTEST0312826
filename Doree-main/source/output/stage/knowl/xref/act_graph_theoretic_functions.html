Activity 6.2.3. Graph-theoretic functions.

Throughout this activity, \(\mathbb{G}\) denotes the set of all graphs.
  1. The function \(\fn{comp}: \mathbb{G} \to \mathbb{G}\) is defined by \(\fn{comp}(G)=\overline{G}\text{,}\) the graph theoretic complement of the graph \(G\text{.}\) Evaluate (draw) \(\fn{comp}(W_4)\) for the wheel graph \(W_4\text{.}\)
    🔗
    🔗
  2. The function \(c: \mathbb{G} \to \mathbb{N}\) is defined by \(c(G)=\) the the number of edges in of the longest path in \(G\text{.}\) Evaluate \(c(C_5)\) for the cycle \(C_5\) and \(c(K_{1,4})\) for the complete bipartite graph (star) \(K_{1,4}\text{.}\)
    🔗
    🔗
  3. The function \(\fn{isplanar}: \mathbb{G} \to \{0,1\}\) is defined by
    \begin{equation*} \fn{isplanar}(G) = \left\{ \begin{array}{cl} 0 \amp \text{ if } G\text{ is planar } \\ 1 \amp \text{ if } G\text{ is not planar } \end{array} \right\text{.} \end{equation*}
    🔗
    🔗
  4. Evaluate \(\fn{isplanar}(C_5)\) and \(\fn{isplanar}{K_5}\) for the cycle \(C_5\) and the complete graph \(K_5\text{.}\) Hint: \(K_5\) is not planar.
