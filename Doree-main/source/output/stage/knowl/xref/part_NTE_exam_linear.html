Item 2.

The sequence \(b\) begins \(5,8,11,14,17,20,\ldots\text{.}\)
Solution.
We add three to get from each term to the next, so the answer likely involves \(3+3+\ldots +3 = 3n\text{.}\) Let’s make a table comparing \(n\text{,}\) \(3n\text{,}\) and the terms of the sequence starting at \(n=0\text{,}\) in Table 6.5.8. Notice that we can get from \(3n\) to \(b_n\) by adding five. A possible formula is \(b_n = 3n+5\) for \(n \ge 0\text{.}\)
