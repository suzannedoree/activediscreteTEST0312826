  3. Copy the following outline of a proof by mathematical induction that the complete graph \(K_n\) has \(f(n)\) edges for \(n \ge 1\) and fill in the missing details.

    Proof.
    First, when \(n=1\text{,}\) the graph \(K_1\) is one vertex which has 0 edges and \(f(1)=\underline{\hspace{1in}}\text{.}\) Thus, \(K_1\) has \(f(1)\) edges.
    🔗
    Next, assume \(\underline{\hspace{1in}}\) for some integer \(n > 1\text{.}\) The graph \(K_n\) can be built from \(K_{n-1}\) by adding one more vertex, \(v\text{,}\) and adding an edge from \(v\) to each of the vertices of \(K_{n-1}\text{.}\) Notice that we are adding \(n-1\) new edges. Thus, the number of edges in \(K_n\) equals the number of edges in \(K_{n-1}\) and \(n-1\) new edges. That is, the number of edges of \(K_n\) is
    \begin{equation*} f(n-1) + (n-1) = \underline{\hspace{.25in} \text{ (show algebra) } \hspace{.25in}} = f(n) \end{equation*}
