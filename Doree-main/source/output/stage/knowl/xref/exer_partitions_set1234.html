List all of the partitions of the set \(\{1,2,3,4\}\text{.}\) Hint: Organize your work by listing the partitions of the set corresponding to each partition of the integer four. For example, under \(2+2\) you would include the partitions \(\{1,2\} \cup \{3,4\}\text{,}\) \(\{1,3\} \cup \{2,4\}\text{,}\) and \(\{1,4\} \cup \{2,3\}\text{.}\)
