Activity 6.2.4. Functions on bit strings.

 
  1. The function \(l:\mathbb{B} \to \mathbb{Z}\) defined by \(l(b) =\) the length of the bit string \(b\text{.}\) Evaluate \(l(\bs{0})\) and \(l(\bs{1011})\text{.}\)
    🔗
    🔗
  2. The function \(\fn{lastbit}:\mathbb{B}^* \to \mathbb{B}\) defined by \(\fn{lastbit}(b) =\) the last bit in the bit string \(b\text{.}\) Evaluate \(\fn{lastbit}(\bs{0})\) and \(\fn{lastbit}(\bs{1011})\text{.}\)
    🔗
    🔗
  3. The function \(\fn{append}: \mathbb{B}\to \mathbb{B}^*\) defined by \(\fn{append}(b)=b\bs{1}\text{,}\) literally the string \(b\) with a 1 added to the right. Evaluate \(\fn{append}(\bs{0})\) and \(\fn{append}(\bs{1011})\text{.}\)
    🔗
    🔗
  4. The function \(\fn{reverse}:\mathbb{B}\to \mathbb{B}\) defined by \(\fn{reverse}(b)=\overleftarrow{b}\text{,}\) where \(\overleftarrow{b}\) means the bit string \(b\) written in reverse order. Evaluate \(\fn{reverse}(\bs{0})\) and \(\fn{reverse}(\bs{1011})\text{.}\)
    🔗
    🔗
  5. The function \(f:\mathbb{B}^*\to \mathbb{B}\) defined by
    \begin{equation*} f(b)= \left\{ \begin{array}{ll} b \amp \text{ if the last bit of the bit string } b \text{ is } \bs{0} \\ b \text{ without its last bit } \amp \text{ if the last bit of the bit string } b \text{ is } \bs{1} \end{array} \right\text{.} \end{equation*}
    Evaluate \(f(\bs{0})\) and \(f(\bs{1011})\text{.}\)
    🔗
    🔗
  6. Define a simple-to-describe function \(g:\mathbb{B}^*\to \mathbb{B}^*\) such that \(g(\bs{1011}) = \bs{0100}\text{,}\) \(g(\bs{110})= \bs{001}\text{,}\) and \(g(\bs{000011}) = \bs{111100}\text{.}\)
    🔗
    🔗
  7. Define a simple-to-describe function \(h:\mathbb{B}^*\to \mathbb{B}^*\) such that \(g(\bs{1011}) = \bs{10111}\text{,}\) \(g(\bs{110})= \bs{1100}\text{,}\) and \(g(\bs{000011}) = \bs{0000110}\text{.}\) Hint: even.
    🔗
    🔗
