Definition 7.1.1. Elements.

 
  1. If the object \(x\) is an element of the set \(S\text{,}\) then we use element notation and write \(x \in S\text{.}\) If \(x\) is not an element of \(S\text{,}\) then we write \(x \notin S\text{.}\) For example, if \(S=\{1,3,4\}\text{,}\) then \(3 \in S\) and then \(2 \notin S\text{.}\)
    🔗
    🔗
  2. An ellipsis is \(\ldots\) which is used to indicate missing items that follow a pattern. For an infinite set described using ellipses we need to recognize the pattern to know if an object is an element. For example, the set \(F = \{4,8,12,\ldots, 64\}\) is the set of multiples of 4 from 4 to 64. Thus, \(20 \in F\) because \(4 \mid 20\) and \(4 \le 20 \le 64\text{.}\) On the other hand, \(18 \notin F\) because \(4 \nmid 18\) and \(80 \notin F\) because \(80 >64\text{.}\) We see a more rigorous way to define such sets in Subsection 7.1.2.
    🔗
    🔗
  3. The cardinality of a finite set \(S\text{,}\) denoted \(|S|\text{,}\) is the number of (distinct) elements in \(S\text{.}\) For example, \(|\{1,3,4\}|=3\) because there are three elements in \(\{1,3,4\}\) namely 1, 3, and 4.
