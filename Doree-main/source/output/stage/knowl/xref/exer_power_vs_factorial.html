24. Explore.

 
  1. Without calculating values, decide which is larger: \(10!\) or \(2^{10}\text{.}\) Hint: Use the definitions of factorials and powers to write each of \(10!\) and \(2^{10}\) as a product. Then use those products to answer the question.
    🔗
    🔗
  2. Calculate \(10!\) and \(2^{10}\) using technology. Did you correctly determine which integer is larger?
    🔗
    🔗
  3. Make a table for \(n = 0, 1, 2, \ldots, 10\) showing the values of \(2^n\) and the values of \(n!\text{.}\) Challenge yourself to reciting the powers of two and as many factorials as you can from memory, but then you are welcome to use computing technology. Hint: Use three rows labeled \(n\text{,}\) \(2^n\text{,}\) and \(n!\text{.}\)
    🔗
    🔗
  4. Conjecture when \(n! \ge 2^n\text{.}\)
