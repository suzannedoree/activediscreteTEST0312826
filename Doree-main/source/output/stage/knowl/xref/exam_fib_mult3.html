Example 8.5.11. Fibonacci numbers that are multiples of three.

 
  1. When does \(3 \mid F_n\text{?}\) State your answer as a conjecture.
    Solution.
    The first few Fibonacci numbers that are divisible by 3 are \(F_4=3\text{,}\) \(F_8=21\text{,}\) \(F_{12}=144\text{,}\) and \(F_{16}=987\text{.}\) It appears that \(3 \mid F_n\) when \(4 \mid n\text{.}\) Notice that \(3=F_4\) so we can get fancy and rewrite our conjecture as \(F_4 \mid F_n\) when \(4 \mid n\text{.}\) We can also write our conjecture explicitly as \(3 \mid F_{4n}\text{.}\)
    🔗
    🔗
    🔗
    🔗
  2. Use the recursive rule and algebra to prove \(F_{4n} =5F_{4n-4} + 3F_{4n-5}\) for \(n \ge 0\text{.}\)
    Solution.
    The recursive rule for the Fibonacci sequence allows us to write any Fibonacci number as the sum of the two preceding Fibonacci numbers. We repeatedly use this idea, and simplify by collecting like terms, to get
    \begin{align*} F_{4n} \amp = F_{4n-1} + F_{4n-2}\\ \amp = \left(F_{4n-2}+F_{4n-3}\right) + F_{4n-2}\\ \amp = 2F_{4n-2} + F_{4n-3}\\ \amp = 2 \left(F_{4n-3}+F_{4n-4}\right) + F_{4n-3}\\ \amp = 3 F_{4n-3}+2F_{4n-4}\\ \amp = 3 \left(F_{4n-4} + F_{4n-5}\right) +2F_{4n-4}\\ \amp = 5 F_{4n-4} + 3F_{4n-5}\text{.} \end{align*}
    🔗
    Whew!
    🔗
    🔗
    🔗
    🔗
  3. Use the identity from Item 2 and mathematical induction to prove that \(3 \mid F_{4n}\) for \(n \ge 0\text{.}\)
    Solution.
    Proof First, when \(n=0\) we have \(F_{4(0)}=F_0=0\) and \(3 \mid 0\) so \(3 \mid F_{4(0)}\text{.}\)
    🔗
    Next, assume \(3 \mid F_{4(n-1)} = F_{4n-4}\) for some integer \(n > 0\text{.}\) By the definition of divides we can write \(F_{4n-4}=3k\) for some integer \(k\text{.}\) Then using the identity from Item 2 we have
    \begin{align*} F_{4n} \amp = 5 F_{4n-4} + 3F_{4n-5}\\ \amp = 5(3k) + 3F_{4n-5}\\ \amp = 3(5k+F_{4n-5})\text{.} \end{align*}
    🔗
    Thus \(3 \mid F_{4n}\text{.}\)
