Definition 6.4.18. Function composition.

 
  1. Consider functions \(f: X \to Y\) and \(g: Y \to Z\text{.}\) Their composite function \(h: X \to Z\) is defined by \(h(x) = g(f(x))\text{.}\) We often write \(g \circ f\) instead of \(h\text{;}\) that is,
    \begin{equation*} (g \circ f)(x) = g(f(x))\text{.} \end{equation*}
    For example, if \(v: \mathbb{Z} \to \mathbb{Z}\) is defined by \(v(n) = n-1\) and \(w: \mathbb{Z} \to \mathbb{Z}\) is defined by \(w(n) = 2n\text{,}\) then
    \begin{equation*} (w \circ v)(n) = w(v(n)) = w(n-1) = 2(n-1) = 2n-2\text{.} \end{equation*}
    Note that
    \begin{equation*} (v \circ w)(n) = v(w(n)) = v(2n) = 2n-1\text{.} \end{equation*}

  2. If a function \(f:X \to X\) has the same set for its domain and codomain, then the (\(n\)th) iterate of \(f\) is the composite
    \begin{equation*} f^n=\underbrace{f \circ f \circ f \cdots \circ f}_{n \text{ times } }\text{.} \end{equation*}
    For example, if \(v: \mathbb{Z} \to \mathbb{Z}\) is defined by \(v(n) = n-1\text{,}\) then \(v^2: \mathbb{Z} \to \mathbb {Z}\) is defined by
    \begin{equation*} v^2(n) = v(v(n))=v(n-1) = (n-1)-1 = n-2 \end{equation*}
    and \(v^3: \mathbb{Z} \to \mathbb {Z}\) is defined by
    \begin{equation*} v^3(n) = v(v^2(n)) = v(n-2) = (n-2)-1 = n-3\text{.} \end{equation*}
    By the way, it is reasonable to conjecture that \(v^k: \mathbb{Z} \to \mathbb {Z}\) is defined by \(v^k(n) = n-k\) for any positive integer \(k\text{.}\)
