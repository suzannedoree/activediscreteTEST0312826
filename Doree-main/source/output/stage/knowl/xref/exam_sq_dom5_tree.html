Example 2.1.15. Tiling a \(1 \times 5\) board with squares and dominoes.

Draw the possibility tree to list the ways to tile a \(1 \times 5\) board using squares (\(\bullet\)) and dominoes (\(\boldsymbol{-}\)) as in Activity 2.1.1.
🔗
Solution.
The tree in Figure 2.1.16 shows all eight possibilities. Notice that we changed the root symbol to \(\circ\) to avoid confusion with the square symbol (\(\bullet\)). Reading across the top row, for example, gives the all-square tiling \(\bullet\bullet\bullet\bullet\bullet\) and reading the next path from branch to leaf gives the tiling \(\bullet\bullet\bullet\boldsymbol{-}\text{.}\)
🔗
As we build a tiling of length five, we have to be careful. If we have a tiling of length four, then the only option to finish the tiling is a square because a domino would make length six. For example, the branch that begins \(\bullet\boldsymbol{-}\bullet\) can only be followed by \(\bullet\text{.}\) Once we have a tiling of length five, the branch ends. For example, the branch \(\boldsymbol{-}\bullet\boldsymbol{-}\) ends after three tiles.
