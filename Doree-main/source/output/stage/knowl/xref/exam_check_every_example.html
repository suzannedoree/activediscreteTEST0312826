Example 5.2.13. Checking every example.

In Section 4.3, we introduced the integers mod 5, \(\mathbb{Z}_5=\{0,1,2,3,4\}\text{.}\) In \(\mathbb{Z}_5\text{,}\) multiplication is defined by \(a \otimes b = ab \fn{ mod } 5\text{.}\) Prove that there is no solution to \(x^2=2\) in \(\mathbb{Z}_5\text{.}\) Note that \(x^2 = x \otimes x\text{.}\)
🔗
Solution.
We can check each element of \(\mathbb{Z}_5\) to see if it is a solution. Our work is displayed in Table 5.2.14. Since none of the elements of \(\mathbb{Z}_5\) is a solution, we can conclude that there is no solution to \(x^2=2\) in \(\mathbb{Z}_5\text{.}\)
