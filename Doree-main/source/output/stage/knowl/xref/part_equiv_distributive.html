Item 1.

Statements \(S\) and \(T\) are logically equivalent, denoted \(S \equiv T\text{,}\) if \(S\) and \(T\) always have the same truth value, either both statements are true or both statements are false. For example, we saw in Activity 5.1.2 that
\begin{equation*} (P \lor Q) \land R \equiv (P \land R) \lor (Q \land R)\text{.} \end{equation*}
