Use Proof Format Proof 5.1.2.3 to prove that for any integer \(n\) we have \(n^2 \fn{ mod } 5 = 0\text{,}\) \(n^2 \fn{ mod } 5 = 1\text{,}\) or \(n^2 \fn{ mod } 5 = 4\text{.}\) Hint: By the Division Algorithm \(n = 5q+r\) with \(0 \le r \lt 5\text{.}\) Break into five cases corresponding to \(r=0, 1, 2, 3\text{,}\) or \(4\text{.}\)
