Example 6.3.25. Proof that a function is onto.

Use the proof formats for universally and existentially quantified statements ( Theorem 5.2.16 and Theorem 5.2.12) to prove that the function \(h: \mathbb{R} \to \mathbb{R}\) defined by \(h(x) = 3x\) is onto.
🔗
Solution.
Proof. Let \(y\) be a real number. Consider \(x = \frac{y}{3}\) which is also a real number. Then
\begin{equation*} h(x) = 3x = 3\left(\frac{y}{3}\right) = y\text{.} \end{equation*}
Thus, there exists a real number \(x\) such that \(h(x) = y\text{,}\) namely \(x = \frac{y}{3}\text{.}\) \(\Box\)
🔗
Note that we nested Theorem 5.2.12 inside Theorem 5.2.16. For another example of a similar proof, see Activity 5.2.D in Section 5.2.
