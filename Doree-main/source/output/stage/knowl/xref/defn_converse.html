Definition 5.4.1. Converse and inverse.

 
  1. For statements \(P\) and \(Q\text{,}\) the converse of \(P \to Q\) is \(Q \to P\text{.}\) For example, for the statement For all integers \(s\text{,}\) if \(s\) is even, then \(s^2\) is even. the converse is For all integers \(s\text{,}\) if \(s^2\) is even, then \(s\) is even.
    🔗
    🔗
  2. In this context, we can translate the conditional \(P \to Q\) as “\(Q\) if \(P\)” and we can translate the converse \(Q \to P\) as “\(Q\) only if \(P\)”.
    🔗
    🔗
  3. For statements \(P\) and \(Q\text{,}\) the inverse of \(P \to Q\) is \(\neg P \to \neg Q\text{.}\) For example, for the statement For all integers \(m\text{,}\) if \(m\) is even, then \(m^2\) is even. the inverse is For all integers \(m\text{,}\) if \(m\) is odd, then \(m^2\) is odd.
