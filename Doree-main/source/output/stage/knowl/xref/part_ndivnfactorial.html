Item 3.

Copy the following proof. Note that the phrase “for any” indicates a universally quantified statement, so we use Proof 5.2.3.2. Prove \(n \mid n!\) for any integer \(n\text{.}\)

Proof.
Let \(n\) be an integer. Note that \(n!=n(n-1)!=nk\) where \(k=(n-1)!\) By the definition of divides, it follows that \(n \mid n!\) Therefore, \(n \mid n!\) for every integer \(n\text{.}\)
