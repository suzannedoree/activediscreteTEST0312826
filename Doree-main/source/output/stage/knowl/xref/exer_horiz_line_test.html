In this exercise, we introduce the horizontal line test. Consider a function \(f: \mathbb{R} \to \mathbb{R}\text{.}\)
  1. Suppose there is a horizontal line (\(y=t\)) that intersect the graph of \(f\) in two (or more) points. What does that tell you about the function \(f\text{?}\)
