Activity 7.5.2. Equivalence classes.

 
  1. Consider the relation \(R\) on \(\{1,2,3,4\}\) defined by \(R= \{(1,1),(1,2),(2,1),(2,2),(3,3),(4,4)\}\text{.}\) Identify the equivalence classes \([1]\text{,}\) \([2]\text{,}\) \([3]\text{,}\) and \([4]\text{.}\) How many distinct equivalence classes are there?
    🔗
    🔗
  2. Draw the directed graph of the equivalence relation on \(\{1,2,3,4,5,6\}\) with equivalence classes \(\{1,2,3\}\text{,}\) \(\{4\}\text{,}\) and \(\{5,6\}\text{.}\)
    🔗
    🔗
  3. Consider the equivalence relation \(R\) on \(\mathbb{Z}\) defined by
    \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } a^2 =b^2 \}\text{.} \end{equation*}
    Calculate \([2]\text{,}\) \([-4]\text{,}\) and \([0]\text{.}\)
    🔗
    🔗
  4. Consider the equivalence relation \(\sim\) on \(\mathbb{R}^2\) defined by \((x_1,y_1) \sim (x_2,y_2)\) if \(y_2-y_1=3(x_2-x_1)\text{.}\) Describe the equivalence class \([(0,2)]\text{.}\)
    🔗
    🔗
  5. Let \(\mathbb{B}_5\) be the set of all bit strings of length 5. Consider the equivalence relation on \(\mathbb{B}_5\) defined by \(b \sim c\) if the bit strings \(b\) and \(c\) start with the same three bits. For example, \(\bs{11111} \sim \bs{11100}\) and \(\bs{10111} \sim \bs{10110}\text{.}\) Calculate \([11111]\) and \([10111]\text{.}\)
    🔗
    🔗
  6. Continuing with the relation \(\sim\) on \(\mathbb{B}_5\) defined in Item 5. How many (distinct) equivalence classes are there and how many bit strings are in each equivalence class?
    🔗
    🔗
  7. Give an example of an equivalence relation on \(\mathbb{B}_5\text{,}\) the bit strings of length 5, that has exactly two equivalence classes. Now give a different one.
