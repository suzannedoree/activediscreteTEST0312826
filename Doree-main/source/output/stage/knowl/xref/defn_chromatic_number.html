Definition 3.3.4. Chromatic number.

 
  1. A (vertex) coloring of a graph is an assignment of a color to each vertex in such a way that adjacent vertices have different colors.
    🔗
    🔗
  2. A \(k\)-coloring of a graph is a vertex coloring using \(k\) colors. For example, the graph in Figure 3.3.13 has a 3-coloring.
    🔗
    🔗
  3. A graph is \(k\)-colorable if there exists a coloring using \(k\) or fewer colors.
    🔗
    🔗
  4. The chromatic number of a graph is the smallest number of colors needed to color the graph. For example, the complete bipartite graph, \(K_{6,3}\text{,}\) shown in Figure 3.2.9 has chromatic number two because it can be colored using two colors (black and white) and one color would not work because there are adjacent vertices.
