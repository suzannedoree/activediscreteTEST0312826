    Section 7.4 Cartesian Products and Relations

    All mathematics can be built from sets. A key step is to use sets to define relations. Functions and operations are examples of relations, but that is just the tip of the iceberg. Almost every mathematical symbol you know is either the name of a set or a relation. For example, each of the following mathematical symbols represents a relation
    \begin{equation*} + \times \sqrt{~} \mid = \neq \le > \land \lor \cap \cup \oplus \in \subseteq \sim \cong \equiv \| \perp \end{equation*}
    🔗
    Relations are built from the Cartesian product of sets, so we begin there.
    🔗

    Subsection 7.4.1 The Cartesian Product of Sets

    The Cartesian product of sets is another set operation that we can use to build new sets from known sets. The Cartesian product of two sets is defined using ordered pairs, which we define in Definition 6.3.1. It is useful to form the Cartesian product of any finite number of sets. For that, we need to extend the definition to ordered tuples of any finite length.
    🔗

    Definition 7.4.1. Ordered tuples.

     
    1. For sets \(X_1\text{,}\) \(X_2\text{,}\) \(X_3\text{,}\)…, \(X_n\) and elements \(x_1\in X_1\text{,}\) \(x_2\in X_2\text{,}\) \(x_3\in X_3\text{,}\) …, \(x_n\in X_n\text{,}\) the ordered \(n\) tuple \((x_1,x_2,x_3, \ldots, x_n)\) is defined by
      \begin{equation*} (x_1,x_2, x_3, \ldots, x_n) = \{\{x_1\}, \{x_1,x_2\}, \{x_1,x_2,x_3\}, \ldots, \{x_1,x_2,x_3,\ldots, x_n\}\} \end{equation*}
      For example, if \(X_1=X_2=X_3=\mathbb{Z}\text{,}\) then
      \begin{equation*} (1,5,2) = \{\{1\}, \{1,5\}, \{1,2,5\}\} \end{equation*}
      whereas
      \begin{equation*} (2,1,5) = \{\{2\}, \{1,2\}, \{1,2,5\}\}\text{.} \end{equation*}
      🔗
      🔗
    2. In the ordered tuple \((x_1,x_2,x_3, \ldots, x_n)\text{,}\) we say that \(x_1\) is the first coordinate, \(x_2\) is the second coordinate, \(x_3\) is the third coordinate, …, \(x_n\) is the \(n^{\text{ th } }\) coordinate. For example, in \((1,5,2)\text{,}\) the first coordinate is 1, the second coordiante is 5, and the third coordinate is 2.
      🔗
      🔗
    🔗
    🔗
    In applications to databases, the coordinates often come from different sets.
    🔗

    Example 7.4.2. Ordered tuples of data.

    Create 4-tuples to represent each student at a university where the first coordinate is the student’s first name, the second coordinate is that student’s family name, the third coordinate is the number of credit hours the student has completed, and the fourth coordinate indicates if the student lives on-campus or off-campus.
    🔗
    Solution.
    Let \(X_1=X_2\) be the set of all alphabetic strings of length up to ten (for the names), let \(X_3=\{0,1,2,3,\ldots, 999\}\) (for the completed credit hours), and \(X_4=\{\bs{0},\bs{1}\}\) (for off-campus and on-campus, in that order). For example, the student Elizabeth Anderson who has completed 48 credit hours and currently lives off-campus might be represented by the the 4-tuple
    \begin{equation*} (\str{Elizabeth}, \str{Anderson}, 48,\bs{0}) \end{equation*}
    🔗
    🔗
    🔗
    We are now ready to define the Cartesian product of sets.
    🔗

    Definition 7.4.3. Cartesian product of sets.

     
    1. Given sets \(X\) and \(Y\text{,}\) the Cartesian product, denoted \(X \times Y\text{,}\) is the set of all ordered pairs of the form \((x,y)\) where \(x \in X\) and \(y\in Y\text{.}\) That is,
      \begin{equation*} X \times Y = \{ (x,y) \mid x \in x \text{ and } y \in Y \}\text{.} \end{equation*}
      For example, if \(X = \{2,3,5\}\) and \(Y = \{0,1\}\text{,}\) then
      \begin{equation*} X \times Y = \{ (2,0), (2,1), (3,0), (3,1), (5,0), (5,1)\}\text{.} \end{equation*}
      🔗
      🔗
    2. Similarly, given sets \(X_1\text{,}\) \(X_2\text{,}\) \(X_3\text{,}\) …, \(X_n\text{,}\) the Cartesian product, denoted \(X_1 \times X_2 \times X_3 \times \cdots \times X_n\text{,}\) is the set of all ordered \(n\)-tuples of the form \((x_1, x_2, x_3,\ldots, x_n)\) where \(x_1 \in X_1\text{,}\) \(x_2 \in X_2\text{,}\) \(x_3 \in X_3\text{,}\) …, \(x_n \in X_n\text{.}\) That is,
      \begin{equation*} X_1 \times X_2 \times X_3 \times \cdots \times X_n = \{(x_1, x_2, x_3, \ldots, x_n) \mid x_1 \in X_1, x_2 \in X_2, x_3 \in X_3, \ldots, x_n \in X_n\}\text{.} \end{equation*}
      For example, if \(X_1=\{0,1\}\text{,}\) \(X_2=\{a,b\}\text{,}\) and \(X_3 = \{1,2\}\text{,}\) then
      \begin{equation*} X_1 \times X_2 \times X_3= \{ (0,a,1), (0,a,2), (0,b,1), (0,b,2), (1,a,1), (1,a,2), (1,b,1), (1,b,2)\}\text{.} \end{equation*}
      🔗
      🔗
    3. We are often interested in the Cartesian product of a set with itself. Given a set \(X\) we write
      \begin{equation*} X^n=\underbrace{X \times X \times X \times \cdots \times X}_{n \text{ times } }\text{.} \end{equation*}
      For example, \(\mathbb{R}^2\) is the usual \(xy\)-plane and \(\mathbb{R}^3\) is the usual \(xyz\)-space.
      🔗
      🔗
    🔗
    🔗
    If the elements of the sets \(X\) and \(Y\) are real numbers, then \(S \times T \subseteq \mathbb{R}^2\) and so we can draw \(X \times Y\) as points in the \(xy\)-plane.
    🔗

    Subsection 7.4.2 Functions Involving Cartesian Products

    Note that the domain and/or codomain of a function can be a Cartesian product. A quick note on notation when the domain is a Cartesian product
    🔗

    Remark 7.4.6. Notation for Functions on Cartesian products.

    For sets \(X_1\text{,}\) \(X_2\text{,}\) … \(X_n\text{,}\) if we have a function \(f\) with domain \(X_1 \times X_2 \times \cdots \times X_n\text{,}\) then we should write \(f((x_1,x_2, \ldots, x_n))\) where each \(x_i \in X_i\text{,}\) but the double parentheses look silly, so we often write \(f(x_1,x_2, \ldots, x_n)\) instead.
    🔗
    🔗
    Here are some examples of functions involving Cartesian products of sets.
    🔗

    Example 7.4.7. Functions involving Cartesian products of sets.

     
    1. Consider the function \(f: \mathbb{R}^2 \to \mathbb{R}\) defined by \(f(x,y) = x+y\text{.}\) Identify the domain and codomain of \(f\text{,}\) evaluate \(f(3,4)\text{,}\) and describe the set of all ordered pairs \((x,y)\) with \(f(x,y)=0\) as a set of points in the \(xy\)-plane.
      Solution.
      The domain of \(f\) is \(\mathbb{R}^2\) and the codomain is \(\mathbb{R}\text{.}\) Next, \(f(3,4) = 3+4 = 7\text{.}\) To find all points with \(f(x,y)=7\) we solve \(x+y=7\) to get \(y = 7-x\) which is the line with slope -1 and \(y\)-intercept 7.
      🔗
      🔗
      🔗
      🔗
    2. Consider the function \(g: \{0,1,2,3\} \to \{1,2,3,4\} \times \{0,1,2,\ldots,10\}\) defined by \(g(a) = (a+1,a^2)\text{.}\) Identify the domain and codomain of \(g\text{,}\) evaluate \(g(0)\) and \(g(3)\text{,}\) and describe the image of \(g\text{.}\)
      Solution.
      The domain is \(\{0,1,2,3\}\) and the codomain is \(\{1,2,3,4\} \times \{0,1,2,\ldots,10\}\text{.}\) We evaluate \(g(0) = (0+1,0^2)=(1,0)\) and \(g(3) = (3+1,3^2)=(4,9)\text{.}\) There are only finitely many integers in the domain so we can find the image by listing the values
      \begin{equation*} \{g(0), g(1), g(2), g(3) \} = \{ (1,0), (2,1), (3,4), (4,9)\}\text{.} \end{equation*}
      You can confirm each of these ordered pairs is in the codomain, as required.
      🔗
      🔗
      🔗
      🔗
    3.     Subsection 7.4.3 Relations and Their Representations

    We are now ready to define a relation.
    🔗

    Definition 7.4.9. Relation.

     
    1. For any sets \(X\) and \(Y\text{,}\) a relation (from X to Y) is a subset of \(X \times Y\text{.}\) For example, the set \(R=\{(a,0),(a,1),(b,1),(b,2)\}\) is a relation from \(\{a,b\}\) to \(\{0,1,2\}\text{.}\)
      🔗
      🔗
    2. In many of the important examples, \(X=Y\text{,}\) and we just say \(R\) is a relation on \(X\). For example, the set \(R=\{(0,0),(0,1),(0,2),(1,1),(1,2),(2,2)\}\) is relation on \(\{0,1,2\}\text{.}\) We could equivalently define \(R = \{(a,b) \mid a, b \in \{0,1,2\} \text{ and } a \le b\}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Note that the graph of any function is a relation.
    🔗

    Definition 7.4.10. Graph of a function.

    For sets \(X\) and \(Y\) and function \(f: X \to Y\text{,}\) the graph of the function \(f\) is the relation
    \begin{equation*} \{(x,y) \mid x \in X, y \in Y, \text{ and } y = f(x)\} \end{equation*}
    or, equivalently, the graph of \(f\) is
    \begin{equation*} \{(x,f(x)) \mid x \in X\}\text{.} \end{equation*}
    For example, if \(f: \mathbb{R} \to \mathbb{R}\) is the function defined by \(f(x) = 2x+1\text{,}\) then the graph of \(f\) is the line \(y=2x+1\) that has slope two and intercept one.
    🔗
    🔗
    More generally, any graph in the \(xy\)-plane is a relation on \(\mathbb{R}\text{.}\) For example, the unit circle \(U = \{ (x,y) \mid x^2+y^2=1\}\) shown in Figure 6.3.9 is a relation.
    🔗
    Although every function has a graph that is a relation, not every relation is the graph of a function. For example, we see in Example 6.3.5 that the unit circle is not the graph of a function.
    🔗
    Let’s look at another example of the graph of a function.
    🔗

    Example 7.4.11. The graph of a function on $\mathbb{Z}$.

    Consider the function \(s: \mathbb{Z} \to \mathbb{Z}\) defined by \(s(n) = n^2+1\) and let \(R\) be the graph of \(s\text{.}\)
    1. Is \((3,8) \in R\text{?}\) Is \((2,5) \in R\text{?}\)
      Solution.
      Since \(s(3) = 3^2+1=10 \neq 8\text{,}\) it follows that \((3,8)\) is not on the graph of \(s\) and so \((3,8) \notin R\text{.}\) On the other hand, since \(s(2) = 2^2+1=5\text{,}\) it follows that \((2,5)\) is on the graph of \(s\) and so \((2,5) \in R\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Find all integers \(m \in \mathbb{Z}\) such that \((2,m) \in R\) and find all integers \(n \in \mathbb{Z}\) such that \((n,5) \in R\text{.}\)
      Solution.
      First, if \((2,m) \in R\text{,}\) then \(m = s(2) = 5\text{.}\) No other value of \(m\) is possible because by the definition of function Definition 6.1.10 there is only one value for \(f(2)\text{.}\) Next, if \((n,5) \in R\text{,}\) then \(5 = f(n) = n^2 +1\text{.}\) Solving we get \(n^2=4\) and so \(n=2\) and \(n=-2\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    When \(X\) and \(Y\) are finite sets or subsets of \(\mathbb{Z}\text{,}\) we have two ways to visually represent a relation from \(X\) to \(Y\text{.}\)
    🔗

    Definition 7.4.12. Drawing relations on finite sets or subsets of \(\mathbb{Z}\) using dot diagrams.

      When \(X\) and \(Y\) are finite sets or subsets of \(\mathbb{Z}\text{,}\) we can represent a relation \(R\) from \(X\) to \(Y\) using a dot diagram where we draw a vertex for each element of \(X\) on the left and a vertex for each element of \(Y\) on the right. Then we draw an arrow from \(x\) to \(y\) if \((x,y) \in R\text{.}\) This is the same dot diagram we used to represent functions on a finite sets or subsets of \(\mathbb{Z}\text{.}\) For example, the relation \(R=\{(a,0),(a,1),(b,1),(b,2)\}\) from \(\{a,b\}\) to \(\{0,1,2\}\) can be represented using the dot diagram shown in Figure 7.4.13.
    🔗
    🔗
    When \(X=Y\text{,}\) there is another way we can represent the relation visually.
    🔗

    Definition 7.4.14. Drawing relations on a finite set or subset of \(\mathbb{Z}\) using a directed graph.

      When \(R\) is a relation on a finite set \(X\) or subset of \(\mathbb{Z}\text{,}\) we can also represent \(R\) using a (possibly infinite) directed graph. We draw a vertex for each element of \(X\) and an arrow from \(x\) to \(y\) for each pair \((x,y) \in R\text{.}\) If \((x,y) \in R\) and \((y,x) \in R\text{,}\) then we draw a double-headed arrow. If \((x,x) \in R\text{,}\) then we draw a loop — an arrow beginning and ending at \(x\text{.}\)
    🔗
    🔗
    Here are some examples.
    🔗

    🔗

    🔗

    Example 7.4.17. Directed graph of a relation on \(\mathbb{Z}\).

    Draw the directed graph of the relation on \(\mathbb{Z}\) defined by
    \begin{equation*} R= \{ (a,b) \mid |a-b|=1\} \end{equation*}
    where \(|~|\) denotes the absolute value.
    🔗
    Solution.
    Note that \(|a-b|=1\) is true in two cases. First, if \(a-b=1\text{,}\) then \(b=a-1\text{.}\) Second, if \(a-b=-1\text{,}\) then \(b=a+1\text{.}\) Therefore

    🔗
    There are several shorthands for relations.
    🔗

    Remark 7.4.19. Alternative notation for relations.

     
    1. It is sometimes convenient to write \(x \sim y\) instead of \((x,y) \in R\text{.}\) This notation is particularly helpful if \(X\) itself is a Cartesian product, so we can write \((a,b) \sim (c,d)\) instead of the potentially awkward ordered pair of ordered pairs \(((a,b),(c,d)) \in R\text{.}\)
      🔗
      🔗
    2. We often define a symbol for commonly-used relations. For example, if \(R = \{ (a,b) \mid a,b \in \mathbb{Z} \text{ and } a \le b\}\text{,}\) then instead of \((a,b) \in R\text{,}\) we might just write \(a \le b\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Let’s see an example of the \(\sim\) notation.
    🔗

    Example 7.4.20. A relation on a Cartesian product.

    Define a relation on \(X=\mathbb{Z} \times\mathbb{Z}^+\) by \((a_1,b_1) \sim (a_2,b_2)\) if \(a_1b_2 = a_2b_1\) or, equivalently, if \(\frac{a_1}{b_1}=\frac{a_2}{b_2}\text{.}\)
    1. Show that \((4,6) \sim (2,3)\text{.}\)
      Solution.
      We check that \(4 \cdot3 = 12 = 2 \cdot 6\) or, equivalently, \(\frac{4}{6}=\frac{2}{3}\text{,}\) and so \((4,6) \sim (2,3)\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Describe the set of ordered pairs \((a,b)\) such that \((a,b)\sim(1,2)\text{.}\)
      Solution.
      If \((a,b)\sim(1,2)\text{,}\) then \(a(1) = b(2)\) or, equivalently, \(a=2b\text{.}\) The set of ordered pairs related to \((1,2)\) is \(\{ (2b,b) \mid b \in \mathbb{Z}^+\}\text{.}\)
