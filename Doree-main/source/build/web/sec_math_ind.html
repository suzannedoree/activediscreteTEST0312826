    Section 8.2 Mathematical Induction

    In this section, we introduce mathematical induction, a powerful proof technique used throughout mathematics and theoretical computer science to prove a statement \(P(n)\) that depends on an integer \(n\text{.}\) For example, it is used in computer science to verify loop invariants. We practice using mathematical induction to prove some of our conjectures about explicit rules for recursively-defined sequences from Section 8.1.
    🔗

    Subsection 8.2.1 \subpffmathind

    Mathematical induction is used to prove a statement \(P(n)\) for all values of the integer \(n \ge s\) for some nonnegative integer \(s\text{.}\) That is, to prove the infinite list of statements \(P(s)\text{,}\) \(P(s+1)\text{,}\) \(P(s+2)\text{,}\) …. A proof by mathematical induction takes an inventive approach.
    🔗

    Definition 8.2.1. Proof by mathematical induction.

    A proof by mathematical induction that a statement \(P(n)\) is true for all integers \(n \ge s\text{,}\) where \(s\) is a nonnegative integer, consists of two parts.
    1. First, we prove the base case: \(P(s)\text{.}\)
      🔗
      🔗
    2. Next, we prove the inductive step: for any integer \(n\text{,}\) if \(n > s\) and \(P(n-1)\text{,}\) then \(P(n)\text{.}\)
      🔗
      🔗
    3. To prove the inductive step, we assume \(P(n-1)\) for some integer \(n > s\) and prove \(P(n)\) using a direct proof of the conditional [cross-reference to target(s) "pff_if_then_direct" missing or not unique]. The assumption of \(P(n-1)\) is the inductive hypothesis.
      🔗
      🔗
    🔗
    🔗
    Here is the official proof format.
    🔗

    Proof.
    Prove \(P(n)\) for \(n \ge s\text{.}\)
    🔗
    Proof.
    Induct on \(n\text{.}\) First, when \(n=s\) we have (explain why \(P(s)\) is true).
    🔗
    Next, assume \(P(n-1)\) for some integer \(n > s\text{.}\) That is, (restate \(P(n-1)\) more clearly, if needed). Then (explain why \(P(n)\) is true).
    🔗
    🔗
    🔗
    The phrase “induct on \(n\)” alerts the reader that we are using proof by mathematical induction. The key words in the proof are “First” (indicates the base case), “Assume” (indicates the inductive hypothesis), “for Some” (indicates the existential quantifier), and “Then” (indicates the end of the inductive step). A mnemonic is that a proof by mathematical induction is FAST.
    🔗
    Why does this proof format work? The result of the inductive step is \(P(n-1) \to P(n)\) whenever \(n > s\text{.}\) That is, if we know that \(P(n-1)\) is true for some integer \(n >s\text{,}\) then we can conclude that \(P(n)\) is true. Since we have proved \(P(s)\) in the base case, we can apply the result of the inductive step with \(n=s+1\) to get \(P(s) \to P(s+1)\text{,}\) from which it follows that \(P(s+1)\text{.}\) Officially we are using the logical inference modus ponens from Section 5.5. Then, since we know \(P(s+1)\text{,}\) we can apply the result of the inductive step with \(n=s+2\) to get \(P(s+1) \to P(s+2)\) from which it follows that \(P(s+2)\text{.}\) And so on.

      Proof Induct on \(n\text{.}\) First, when \(n=0\text{,}\) there is exactly one bit string of length zero, namely \(\lambda\text{,}\) the empty bit string. Since \(2^0=1\text{,}\) it follows that there are \(2^0\) bit strings of length zero.
      🔗
      Next, assume there are \(2^{n-1}\) bit strings of length \(n-1\) for some integer \(n > 0\text{.}\) Let \(b\) be a bit string of length \(n\text{.}\) Since the length of \(b\) is at least 1, we can consider two cases.
      🔗
      Case 1: \(b\) starts with 0. Then \(b=\bs{0}b_0\) where \(b_0\) is a bit string of length \(n-1\text{.}\) By the inductive hypothesis, there are \(2^{n-1}\) choices for the bit string \(b_0\text{.}\) Therefore, there are \(2^{n-1}\) choices for the bit string \(b\) in this case.
      🔗
      Case 2: \(b\) starts with 1. Then \(b=\bs{1}b_1\) where \(b_1\) is a bit string of length \(n-1\text{.}\) By the inductive hypothesis, there are \(2^{n-1}\) choices for the bit string \(b_1\text{.}\) Therefore, there are also \(2^{n-1}\) choices for the bit string \(b\) in this case.
      🔗
      Then, since cases add Theorem 2.2.6, there are
      \begin{equation*} 2^{n-1}+2^{n-1}=2\cdot2^{n-1}=2^n \end{equation*}
      bit strings of length \(n\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. What was the inductive hypothesis?
      Solution.
      The inductive hypothesis was that there are \(2^{n-1}\) bit strings of length \(n-1\) for some integer \(n > 0\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Explain step-by-step why the algebra in the final equation is correct.
      Solution.
      For any number \(x\) we have \(x+x=x(1+1)=2x\text{.}\) In particular,
      \begin{equation*} 2^{n-1}+2^{n-1}=2\cdot2^{n-1}\text{.} \end{equation*}
      Next, \(2\cdot2^{n-1}= 2 \cdot \underbrace{2 \times 2 \times \cdots \times 2}_{(n-1) \text{ times } }= \underbrace{2 \times 2 \times \cdots \times 2}_{n \text{ times } }=2^n\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗

    We conclude with an example of a proof by mathematical induction about trees. We use the fact that any tree with at least two vertices contains at least one leaf (degree one vertex).
    🔗

    Example 8.2.3. Tree with \(n\) vertices has exactly \(n-1\) edges.

    Use mathematical induction to prove that a tree with \(n\) vertices has exactly \(n-1\) edges.
    🔗
    Solution.
    Proof Induct on \(n\text{.}\)
    🔗
    First, when \(n=1\) the only tree is a single vertex which has zero edges, and \(1-1=0\text{.}\)
    🔗
    Next, assume that any tree with \((n-1)\) vertices has exactly \((n-1)-1 = n-2\) edges for some integer \(n \ge 2\text{.}\) Let \(T\) be a tree with \(n\) vertices. Since every tree with at least two vertices has at least one leaf, there exists a vertex \(v\) in \(T\) such that \(\fn{deg}(v)=1\text{.}\)
    🔗
    Consider the graph \(T'\) formed by removing \(v\) and the one edge ending at \(v\) from \(T\text{.}\) Since \(T\) was a tree, it does not contain any cycles so neither does \(T'\text{.}\) Since \(T\) is connected, any two vertices in \(T\) are connected by a path in \(T\text{.}\) Since \(\fn{deg}(v)=1\text{,}\) there is no path that includes \(v\) in the middle (because that would mean \(\fn{deg}(v)\ge2\)). Therefore any two vertices other than \(v\) are connected by a path in \(T\) that does not include \(v\) and so \(T'\) is still connected. Last, \(T'\) has \((n-1)\) vertices because we removed one vertex.
    🔗
    By our inductive hypothesis, it follows that \(T'\) has exactly \((n-2)\) edges. Since we only removed one edge from \(T\text{,}\) it follows that \(T\) has exactly \((n-2)+1=n-1\) edges.

    Subsection 8.2.3 \subpffindseq

    One special case where proof by mathematical induction is used is to prove an explicit rule for a recursively-defined sequence. We state this special case as its own proof format.
    🔗

    Proof.
    Given the sequence \(a\) defined recursively by \(a_s=\) (initial condition) and \(a_n=\) (recursive rule) for \(n \ge s+1\text{,}\) prove \(a_n=\) (explicit rule) for \(n \ge s\text{.}\)
    🔗
    Proof.
    Write \(f(n) =\)(explicit rule). Induct on \(n\text{.}\)
    🔗
    First, when \(n=s\) we know that \(a_s=\) (initial condition) and also \(f(s)=\) (evaluate and simplify to get the same answer).
    🔗
    Next, assume \(a_{n-1}=f(n-1)=\) (evaluate and simplify), for some integer \(n > s\text{.}\) Then
    \begin{align*} a_n \amp = \text{ (recursive rule) }\\ \amp = \cdots \text{ (use the inductive hypothesis to replace } a_{n-1} \text{ by } f(n-1)) \cdots\\ \amp = \cdots \text{ (use algebra) } \cdots\\ \amp = f(n)\text{.} \end{align*}
    🔗
    🔗
    🔗
    Note that in the base case we prove \(a_s=f(s)\text{.}\) The inductive hypothesis is \(a_{n-1}=f(n-1)\) for some integer \(n > s\text{.}\) In the inductive step, we prove \(a_n=f(n)\text{.}\) As usual, here is an example of the proof format for you to copy and edit.
