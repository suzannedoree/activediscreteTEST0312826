      🔗

    Example 4.1.2. Open lockers.

     
    1. What is the final state of locker 99? Explain.
      Solution.
      First note that the last student to touch locker 99 is the \(99^{\text{ th } }\) student. So to determine the final state of locker 99 we only need to know which students from 1-99 touched it. We can factor 99 in several ways: \(1 \times 99\text{,}\) \(3 \times 33\text{,}\) and \(9 \times 11\text{.}\) That is, the only students from 1-99 to touch locker 99 are students one, three, nine, 11, 33, and 99. Student one opens locker 99, student three closes it, student nine opens it, student 11 closes it, student 33 opens it, and student 99 closes it. The final state of locker 99 is that it is closed.
      🔗
      🔗
      🔗
      🔗
    2. Conjecture how the final state of a locker depends on the number of students who touch the locker.
      Solution.
      When the number of students who touch the locker is even, as was the case for locker 99, the final state of the locker is closed. When the number of students who touch the locker is odd, as was the case for locker 100, the final state of the locker is open. This conjecture is Conjecture A.
      🔗
      🔗
      🔗
      🔗
    3. Conjecture which lockers have an odd number of students that touch that locker.
      Solution.
      Notice that students who touch the locker tend to come in pairs. For example, locker 99 is touched by students one and 99, students three and 33, and students nine and 11. As another example, locker 100 is touched by students one and 100, students two and 50, students four and 25, and students five and 20. But there is one additional student who touches locker 100, student 10, which makes the total number of students touching locker 100 odd. Why is student 10 not in a pair? Because \(10 \times 10 = 100\) or, in other words, \(100 = 10^2\text{.}\) We conjecture that lockers touched by an odd number of students have locker numbers equal to the square of an integer, known as a perfect square. This conjecture is Conjecture B.
      🔗
      🔗
      🔗
      🔗

    Subsection 4.1.B Even and Odd Integers

    We have seen several situations in which it mattered whether an integer is even or odd. An odd number of bridges was problematic in solving the Bridges Puzzle in Activity 3.1.A. The chromatic number of the cycle \(C_s\) and the wheels \(W_s\) depended on whether \(s\) was even or odd. In each of those examples, we recognize that an even integer is the sum of twos: on-off, on-off, …, on-off in the Bridges Puzzle or black-white, black-white, …, black-white in coloring a cycle. That is, \(n\) is even if we can write
    \begin{equation*} n = \underbrace{2 + 2 + 2 + \ldots + 2}_{k \text{ times } } = 2k\text{.} \end{equation*}
    Equivalently, we can think of even integers as those that divide exactly in half. That is, \(n=k+k = 2k\text{.}\) We state the formal definition.
    🔗

    Definition 4.1.3. Even and odd.

     
    1. The integer \(n\) is even if \(n=2k\) for some integer \(k\text{.}\) For example, 18 is even because \(18=2(9)\text{.}\) If we wanted to be formal, we would say \(18=2k\) where \(k=9\text{.}\)
      🔗
      🔗
    2. The integer \(n\) is odd if \(n=2k+1\) for some integer \(k\text{.}\) For example, 19 is odd because \(19 = 2(9)+1\text{.}\) If we wanted to be formal, we would say \(19=2k+1\) where \(k=9\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Here are some more general examples.
    🔗

    Example 4.1.4. Even and odd, in general.

    You probably know many facts about even and odd integers. In this example, we use only the definitions.
    1. Use the definition of even to show that \(6t\) is even for any integer \(t\text{.}\)
      Solution.
      We want to write \(6t=2k\) for some integer \(k\text{.}\) We can solve to find \(k\text{.}\) We divide by two to get \(k=3t\text{,}\) which is an integer. Officially, we need to use that value of \(k\) to write
      \begin{equation*} 6t=2(3t)\text{,} \end{equation*}
      so \(6t\) is even.
      🔗
      Notice that we could have just factored out the two to write
      \begin{equation*} 6t=2(3t) \end{equation*}
      without any mention of \(k\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Use the definition of odd to show that \(2m-1\) is odd for any integer \(m\text{.}\)
      Solution.
      We want to write \(2m-1 = 2k+1\) for some integer \(k\text{.}\) We can solve to find \(k\text{.}\) First, we subtract and factor to get \(2k=(2m-1)-1=2m-2=2(m-1)\text{.}\) Next, we divide by two to get \(k=m-1\text{,}\) which is an integer. Officially, we need to use that value of \(k\) to write
      \begin{equation*} 2m-1= 2(m-1)+1\text{,} \end{equation*}
      so \(2m-1\) is odd.
      🔗
      Notice that we could have used algebra to write
      \begin{equation*} 2m-1 = 2m-2+1 = 2(m-1) + 1 \end{equation*}
      without any mention of \(k\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗

    1. Use the definition to show that zero is even.
      Solution.
      We can write \(0 = 2(0)\text{.}\) That is \(0 = 2k\) when \(k=0\text{.}\) Since \(k=0\) is an integer, it follows that zero is even.
      🔗

    Subsection 4.1.C Divisibility

    In the Lockers Puzzle Activity 4.1.A, the \(d^{\text{ th } }\) student touches locker \(d\text{,}\) locker \(d+d=2d\text{,}\) locker \(d+d+d=3d\text{,}\) etc. In general, the \(d^{\text{ th } }\) student touches locker \(n\) when we can write
    \begin{equation*} n=\underbrace{d+d+ \ldots+d}_{k \text{ times } } =dk \end{equation*}
    for some integer \(k\text{.}\) We make this concept formal with another definition.
    🔗

    Definition 4.1.6. Divides.

     
    1. The nonzero integer \(d\) divides integer \(n\text{,}\) denoted \(d \mid n\text{,}\) if \(n = dk\) for some integer \(k\text{.}\) For example, 3 divides 15, denoted \(3 \mid 15\) because \(15 = 3(5)\text{.}\) Note also that \(3 \mid -15\) because \(-15 = 3(-5)\) and \(-3 \mid 15\) because \(15 = -3(-5)\text{.}\)
      🔗
      🔗
    2. If \(d \mid n\text{,}\) then \(d\) is a divisor (or factor) of \(n\text{.}\) For example, the (positive) divisors of 15 are: 1, 3, 5, and 15 because \(1 \times 15 = 15\) and \(3 \times 5=15\text{.}\) (It is harder to know that we found all the positive divisors.) The complete list of 15 divisors is \(\pm\) 1, \(\pm\) 3, \(\pm\) 5 and \(\pm\) 15.
      🔗
      🔗
    3. If \(d \mid n\text{,}\) then \(n\) is a multiple of \(d\text{.}\) For example, 10, -35, and 65 are multiples of 5.
      🔗
      🔗
    4. If \(d\) does not divide \(n\text{,}\) we write \(d \nmid n\text{.}\) For example, \(4 \nmid 15\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Here are some more general examples.
    🔗

      🔗
      🔗
      🔗

      Solution.
      Factor to write \(5n-20 = 5(n-4)\text{,}\) so \(5 \mid (5n-20)\text{.}\) If we wanted to be formal, we could write \(5n-20 = 5k\) where \(k=n-4\text{.}\)

    Example 4.1.8. You cannot divide by zero.

     
    1. Can we divide by zero? That is, is zero a divisor of any integer? Explain.
      Solution.
      We are asking if \(0 \mid n\) for any integer \(n\text{.}\) In Definition 4.1.6 we did not allow the divisor \(d\) to be zero, so the answer is no. The reason we excluded zero is because if \(n = 0(k) =0\) for some integer \(k\text{,}\) then the only possibility is \(n=0\text{.}\) Therefore, it is impossible for zero to divide any nonzero integer. We also do not allow zero to divide itself either. The answer is no.
      🔗
      🔗
      🔗
      🔗
    2. Is zero a multiple of any integer?
      Solution.
      We are asking if \(n \mid 0\) for any integer \(n\text{.}\) That means we are looking for an integer \(k\) such that \(0 = (n)k\text{.}\) Since \(0 = (n)0\) and \(k=0\) is an integer, it follows that \(n \mid 0\) for all nonzero integers \(n\text{.}\) The answer is yes.
      🔗
      🔗
      🔗

    Subsection 4.1.D Algebra: Equivalent Fractions

    When we divide one integer by another (nonzero) integer, sometimes we get an integer, but sometimes we get a fraction (rational number) that is not an integer. Here is the formal definition.
    🔗

    Definition 4.1.9. Fraction (rational number).

     
    1. For integer \(n\) and nonzero integer \(d\text{,}\) the fraction (or rational number) is the number we get by dividing \(n\) by \(d\text{,}\) meaning
      \begin{equation*} \displaystyle \frac{n}{d} = n \div d\text{.} \end{equation*}
      We can think of the fraction \(\frac{n}{d}\) as representing an equal share of \(n\) objects among \(d\) places. For example, if we have 40 cucumber slices and five pickling jars, then we can put \(40 \div 5 = 8\) slices in each jar. Similarly, if we have four party-sized bags of candy to share equally among ten people, then each person gets \(\frac{4}{10} = 4 \div 10 = .4 = 40\%\) of a bag.
      🔗
      🔗
    2. Note that any integer is a fraction because
      \begin{equation*} \frac{n}{1} = n \div 1 = n\text{.} \end{equation*}
      For example, \(4 = \frac{4}{1}\text{.}\)
      🔗
      🔗
    3. In the fraction \(\frac{n}{d}\text{,}\) the integer on the top of the fraction \(n\) is the numerator and the integer on the bottom of the fraction \(d\) is the denominator. For example, in the fraction \(\frac{4}{10}\) the numerator is four and the denominator is ten.
      🔗
      🔗
    4. For integers \(n\text{,}\) \(m\text{,}\) \(a \neq 0\text{,}\) and \(b \neq 0\text{,}\) the fractions \(\frac{n}{a}\) and \(\frac{m}{b}\) are equal (or equivalent), which we write as
      \begin{equation*} \frac{n}{a}=\frac{m}{b}\text{,} \end{equation*}
      if \(nb=ma\text{.}\) For example, \(\frac{6}{15} = .4\) and so \(\frac{4}{10}=\frac{6}{15}\text{.}\) We can cross-multiply to confirm that \((4)(15) = 60 = (6)(10)\text{.}\)
      🔗
      🔗
    🔗
    🔗
    There is a connection between divides and fractions.
    🔗

    Remark 4.1.10. Fractions and divisibility.

    Let \(d\) and \(n\) be integers with \(d\neq 0\text{.}\) Then \(d \mid n\) exactly when \(\frac{n}{d}\) is an integer. Although we have this connection between fractions and divisibility, it is customary to avoid referencing fractions when working with divides.
    🔗
    🔗
    Every fraction has (infinitely) many different names. We often want to write a fraction in its simplest form. Other times, it is useful to write a fraction with a denominator such that the fraction is not in its simplest form– for example, to add, subtract, or compare fractions. The next theorem verifies both operations.
    🔗

    Theorem 4.1.11. Equal fractions.

    For integer \(n\) and nonzero integers \(d\) and \(c\text{,}\)
    1. If we multiply the numerator and denominator of a fraction by a nonzero integer, the resulting fraction is equal to the original fraction, namely
      \begin{equation*} \frac{n}{d} = \frac{c(n)}{c(d)}\text{.} \end{equation*}
      🔗
      🔗
    2. This equation holds in both directions. Specifically, we can cancel a common nonzero factor (or reduce the fraction) using the equation
      \begin{equation*} \frac{c(n)}{c(d)}= \frac{n}{d}\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Proof.
    Let \(n\text{,}\) \(d\text{,}\) and \(c \neq 0\) be integers. By the commutative and associative properties,
    \begin{equation*} n(c(d)) = n \times c \times d = c \times n \times d = (c(n))d \end{equation*}
    and so, by Definition 4.1.9 Item 4,
    \begin{equation*} \frac{n}{d} = \frac{c(n)}{c(d)}\text{,} \end{equation*}
    as in Item 1. Note that Item 2 is the same equation read right-to-left instead.
    🔗
    🔗
    Let’s see this theorem in action.
    🔗

    Example 4.1.12. Equal fractions.

     
    1. Write \(\frac{2}{5}\) as a fraction with denominator 15.
      Solution.
      Since \(15=3 \times 5\text{,}\) we can use Theorem 4.1.11 to multiply top and bottom of the fraction by three to get
      \begin{equation*} \frac{2}{5} =\frac{3(2)}{3(5)} =\frac{6}{15} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. Which fraction is larger: \(\frac{2}{5}\) or \(\frac{1}{3}\text{?}\)
      Solution.
      We can write each fraction with common denominator \(3 \times 5 = 15\text{.}\) In part Item 1, we found \(\frac{2}{5} =\frac{6}{15}\text{.}\) Similarly, we can use Theorem 4.1.11 to multiply top and bottom of the fraction \(\frac{1}{3}\) by five to get:
      \begin{equation*} \frac{1}{3} =\frac{5(1)}{5(3)} =\frac{5}{15}\text{.} \end{equation*}
      We can imagine \(\frac{6}{15}\) as the amount of pizza each person gets if we have six pizzas shared by 15 people. In that vein, we can imagine \(\frac{5}{15}\) as the amount of pizza each person gets if we have five pizzas shared by 15 people. Each person will get more pizza if we have six pizzas to share versus five pizzas to share, and so \(\frac{6}{15}> \frac{5}{15}\text{.}\) It follows that \(\frac{2}{5}>\frac{1}{3}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Reduce the fraction \(\frac{24}{100}\text{.}\)
      Solution.
      Notice that \(4 \mid 24\) and \(4 \mid 100\text{.}\) By Theorem 4.1.11 we have
      \begin{equation*} \frac{24}{100} = \frac{4(6)}{4(25)}= \frac{6}{25}\text{.} \end{equation*}
      Notice that 6 and 25 do not have any common divisors (other than the integers \(\pm\)1) and so we cannot further reduce the fraction \(\frac{6}{25}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    The concept of a fraction that cannot be further reduced has a formal name.
    🔗

    Definition 4.1.13. Lowest terms.

     
    1. The integers \(s\) and \(t\) are coprime (or relatively prime) if the only common positive divisor of \(s\) and \(t\) is the integer 1. For example, 6 has positive divisors 1, 2, 3, and 6 whereas 25 has positive divisors 1, 5, and 25 so their only common positive divisor is 1. Therefore, 6 and 25 are coprime.
      🔗
      🔗
    2. The fraction \(\frac{s}{t}\) is written in lowest terms if \(s\) and \(t\) are coprime. For example, since 6 and 25 are coprime, it follows that the fraction \(\frac{6}{25}\) is written in lowest tersm.
      🔗
      🔗
    🔗

    Example 4.1.14. Equivalent fractions.

     
    1. Reduce \(\displaystyle\frac{48!}{50!}\) to lowest terms.
      Solution.
      Let’s use the definition of factorial and cancel before multiplying to get
      \begin{equation*} \frac{48!}{50!} = \frac{(48)(47)\cdots(3)(2)(1)}{(50)(49)(48)(47)\cdots(3)(2)(1)} = \frac{48!}{(50)(49)(48!)} = \frac{1}{(50)(49)}\text{.} \end{equation*}
      Note that we cancel the common factor of \(c=48!=(48)(47)\cdots(3)(2)(1)\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. How many strings of three uppercase letters are there if we cannot repeat letters?
      Solution.
      Think of filling in three spaces with uppercase letters. The first space can be any of the 26 uppercase letters. Because repeats are not allowed, the second space can be any of the 25 remaining uppercase letters, and the third space can be any of the 24 remaining uppercase letters. Since steps multiply Theorem 2.2.2, the answer is \((26)(25)(24)\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Write your answer to Item 2 as a fraction whose numerator and denominator are each a single factorial.
      Solution.
      Notice that \((26)(25)(24)\) looks like the beginning of 26! We can multiply the numerator and denominator by \(c=23!\) to get
      \begin{equation*} (26)(25)(24)= \frac{(26)(25)(24)}{1} = \frac{(26)(25)(24)(23!)}{23!} = \frac{(26)(25)(24)(23)(22) \cdots (3)(2)(1)}{(23)(22) \cdots (3)(2)(1)} = \frac{26!}{23!} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    4. Reduce \(\displaystyle\frac{10^{20}}{10^{35}}\) to lowest terms.
      Solution.
      Let’s use the definition of exponential notation and cancel before multiplying to get
      \begin{equation*} \frac{10^{20}}{10^{35}} = \frac{\overbrace{10 \times 10 \times \ldots \times 10}^{20 \text{ times } }}{\underbrace{10 \times 10 \times \ldots \times 10}_{35 \text{ times } }} = \frac{1}{\underbrace{10 \times 10 \times \ldots \times 10}_{15 \text{ times } }} = \frac{1}{10^{15}}\text{.} \end{equation*}
      🔗
      Note that we canceled 20 factors of 10 to get \(35-20=15\) remaining factors of 10.
      🔗
      🔗
      🔗
      🔗
