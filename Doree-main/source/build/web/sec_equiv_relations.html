    Section 7.5 Equivalence Relations

    We have seen examples of equivalence in this textbook, including logical equivalence and isomorphic graphs. You may have seen geometric equivalences such as congruent or similar triangles. In this section, we formalize the notion of equivalence by defining an equivalence relation and equivalence classes.
    🔗

    Subsection 7.5.A Properties of Relations

    There are three properties that an relation needs to satisfy in order to be an equivalence relation.
    🔗

    Definition 7.5.1. Equivalence Relation.

    Consider a relation \(R\) on a set \(X\text{.}\)
    1. The relation \(R\) is reflexive if \((x,x) \in R\) for all \(x \in X\text{.}\) If the relation is defined by \(\sim\text{,}\) then we need \(x \sim x\) for all \(x \in X\text{.}\) For example, the relation
      \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } ab \ge 0\} \end{equation*}
      is reflexive on \(\mathbb{Z}\text{,}\) because for any \(a \in \mathbb{Z}\) we have \(aa=a^2 \ge 0\text{.}\) Thus \((a,a) \in R\text{.}\)
      🔗
      🔗
    2. The relation \(R\) is symmetric if whenever \((x,y) \in R\text{,}\) then also \((y,x)\in R\) for all \(x,y \in X\text{.}\) If the relation is defined by \(\sim\text{,}\) then we need if \(x \sim y\text{,}\) then \(y \sim x\) for all \(x,y \in X\text{.}\) For example, the relation
      \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } ab = 0\} \end{equation*}
      is symmetric on \(\mathbb{Z}\text{,}\) because for any \(a,b \in \mathbb{Z}\) with \((a,b) \in R\) we have \(ab=0\text{.}\) Thus \(ba=0\) and so \((b,a) \in R\text{.}\)
      🔗
      🔗
    3. The relation \(R\) is transitive if whenever \((x,y) \in R\) and \((y,z) \in R\text{,}\) then \((x,z)\in R\) for all \(x,y,z \in X\text{.}\) If the relation is defined by \(\sim\text{,}\) then we need if \(x \sim y\) and \(y \sim z\text{,}\) then \(x \sim z\) for all \(x,y,z \in X\text{.}\) For example, the relation
      \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } a \le b\} \end{equation*}
      is transitive on \(\mathbb{Z}\text{,}\) because for any \(a,b,c \in \mathbb{Z}\) with \((a,b) \in R\) and \((b,c) \in R\) we have \(a \le b\) and \(b \le c\text{.}\) Thus \(a \le c\) and so \((a,c) \in R\text{.}\)
      🔗
      🔗
    4. The relation \(R\) is an equivalence relation if it is reflexive, symmetric, and transitive. For example, The relation
      \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } a^2=b^2\} \end{equation*}
      is an equivalence relation.
      🔗
      🔗

    🔗

    Example 7.5.6. When is a relation on finite set transitive?

    We saw in Example 7.5.2 how to use the directed graph of a relation on a finite set to determine whether the relation is reflexive or symmetric. How can we use the directed graph of a relation on a finite set to determine whether the relation is transitive?
    🔗
    Solution.
    Suppose \(R\) is a relation on a finite set \(X\) and that \((x,y) \in R\) and \((y,z) \in R\text{.}\) There are four cases, as drawn in Figure 7.5.7.
    🔗
    Case 1: First, consider when \(x\text{,}\) \(y\text{,}\) and \(z\) are three distinct elements of \(X\text{.}\) Then the directed graph has arrows from \(x\) to \(y\) and from \(y\) to \(z\text{.}\) We need to check if \((x,z) \in R\text{,}\) indicated by the dashed arrow from \(x\) to \(z\) in our diagram. To be transitive, any time we have a two-step path in the directed graph, we must also have the shortcut (vector sum).
    🔗
    Case 2: Next, consider when \(x=y\) or \(y=z\text{.}\) If \(x=y\text{,}\) then \((x,z) =(y,z)\in R\text{.}\) If \(y=z\text{,}\) then \((x,z) =(x,y)\in R\text{.}\) In either case \((x,z)\) is automatically in \(R\) so we can ignore this case.
    🔗
    Case 3: The remaining case is when \(x = z\text{.}\) We need to check \((x,x)=(x,z) \in R\text{.}\) Swapping order, we also need to check \((z,z)=(z,x)\in R\text{.}\) That is, any time there is a double-headed arrow in the graph, we need to have a loop at each end, or barbells, which we draw in our diagram with dashed loops.

    Subsection 7.5.B Equivalence Relations and Equivalence Classes

    An important construction in advanced theoretical mathematics is to take a set \(X\) and an equivalence relation \(\sim\) on \(X\) and define a new set consisting of the equivalence classes of \(X\) under \(R\text{.}\) We begin with the definitions.
    🔗

    Definition 7.5.9. Equivalence classes.

    Consider a set \(X\) and an equivalence relation \(R\) (or \(\sim\)) on \(X\text{.}\)
    1. For any element \(a \in X\text{,}\) the equivalence class containing \(a\) is the set
      \begin{equation*} [a]=\{b \in X \mid (a,b) \in R\} = \{b \in X \mid a \sim b\}\text{.} \end{equation*}
      For example, for the relation
      \begin{equation*} R=\{ (a,b) \mid a, b\in \mathbb{Z} \text{ and } a^2 =b^2 \}\text{,} \end{equation*}
      the equivalence class of \(3\) is \([3] = \{3,-3\}\text{.}\) Note that \([-3]=\{3,-3\}\) is the same set.
      🔗
      🔗
    2. The quotient space, denoted \(X/R\) and pronounced “\(X\) mod \(R\)”, is the set of all equivalence classes. For example, for the relation \(R = \{(a,b) \mid a, b\in \mathbb{Z} \text{ and } a+b \text{ is even } \}\text{,}\) there are two equivalence classes: \([0]=\) the even integers and \([1]=\) the odd integers. Thus \(\mathbb{Z}/R = \{[0],[1]\}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Let’s look at an example.
    🔗

    Example 7.5.10. Equivalence classes for an equivalence relation on \(\{1,2,3,4,5\}\).

      🔗
      🔗
      🔗

      Solution.

      The quotient space consists of two equivalence classes: \(X/R=\{[1],[2]\}\text{.}\)

    Remark 7.5.12. Equivalence classes and partitions.

    Let \(X\) be a set.
    1. If \(R\) is an equivalence relation on \(X\text{,}\) then the distinct equivalence classes under \(R\) form a partition of the set \(X\text{.}\)
      🔗
      🔗
    2. Moreover, its equivalence classes are exactly \(T_1, T_2, \ldots, T_k\text{.}\)

    Subsection 7.5.C Congruence mod $n$

    An important equivalence relation on \(\mathbb{Z}\) is defined using \(\fn{mod}\text{.}\)
    🔗

    Definition 7.5.13. Congruence mod \(n\).

     
    1. For a positive integer \(n\text{,}\) the integers \(a\) and \(b\) are congruent modulo \(n\text{,}\) denoted \(a \equiv b ~(\fn{mod} ~n)\text{,}\) if \(a \fn{~mod~} n = b \fn{~mod~} n\text{,}\) that is, if \(a\) and \(b\) have the same remainder when divided by \(n\text{.}\) For example, \(73 \equiv 13 ~(\fn{mod} ~10)\) because \(73 \fn{~mod~} 10 = 3\) and \(73 \fn{~mod~} 10 = 3\text{.}\) As another example, for any integer \(a\text{,}\) if \(a ~\fn{mod}~ n=r\text{,}\) then that \(a \equiv r ~(\fn{mod} ~n)\text{.}\) For example, \(73 \equiv 3 ~(\fn{mod} ~10)\text{.}\) It turns out that congruence modulo \(n\) is an equivalence relation.
      🔗
      🔗
    2. For a positive integer \(n\text{,}\) the congruence class mod \(n\) of \(a\) is
      \begin{equation*} [a]_n = \{ b \in \mathbb{Z} \mid a \equiv b ~(\fn{mod} ~n)\}\text{.} \end{equation*}
      Note that the congruence class is the equivalence class under the congruence relation. For example,
      \begin{equation*} [3]_{10} = \{\ldots, -17, -7, 3, 13, 23, 33, 43, \ldots\}\text{.} \end{equation*}
      🔗
      🔗
    3. The integers mod \(n\) introduced in Section 4.3 is formally defined as
      \begin{equation*} \mathbb{Z}_n = \{[0]_n, [1]_n, \ldots, [n-1]_n\}\text{.} \end{equation*}
      For example, \(\mathbb{Z}_3 = \{[0]_3, [1]_3, [2]_3\}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Note that if \(a \fn{ mod } n = b \fn{ mod } n\text{,}\) then \(a\) and \(b\) end at the same number on the \(\fn{mod } n\) clock. Therefore, \(a\) and \(b\) differ by some number of complete rotations, which is multiple of \(n\text{.}\) We have the following result.
    🔗

    Theorem 7.5.14. Alternate characterization of congruence \fn{mod} \(n\).

    Let \(a\text{,}\) \(b\text{,}\) and \(n\) be integers with \(n > 1\text{.}\) Then \(a \equiv b ~(\fn{mod } n)\) if and only if \(n | (a-b)\text{.}\)
    🔗
    🔗
    Let’s look at some examples.
    🔗

    Example 7.5.15. Using the alternate characterization of congruence \fn{mod} \(n\).

     
    1. Use Theorem 7.5.14 to show that \(73 \equiv 13 ~(\fn{mod } 10)\text{.}\)
      Solution.
      We can check that \(73-13 = 60 = 10(6)\) and so \(10 \mid (73-13)\text{.}\) Thus \(73 \equiv 13 ~(\fn{mod } 10)\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Prove that if \(a \equiv b ~(\fn{mod } n)\text{,}\) then \(2a \equiv 2b ~(\fn{mod } n)\) for any integers \(a\text{,}\) \(b\text{,}\) and \(n\) with \(n > 1\text{.}\)
      Solution.
      Since we are proving a conditional statement, we use Proof 5.3.B.1.
      🔗
      Proof Let \(a\text{,}\) \(b\text{,}\) and \(n\) be integers with \(n > 1\text{.}\) Assume \(a \equiv b ~(\fn{mod } n)\text{.}\) By Theorem 7.5.14, it follows that \(n \mid (a-b)\text{.}\) By Definition 4.1.6, we can write \(a-b = nk\) for some integer \(k\text{.}\) Then
      \begin{equation*} 2a - 2b = 2(a-b) = 2(nk) = n(2k) = nk' \end{equation*}
      where \(k' = 2k\) is an integer. By Definition 4.1.6, it follows that \(n \mid (2a-2b)\text{.}\) By Theorem 7.5.14, it follows that \(2a \equiv 2b ~(\fn{mod } n)\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. State the converse of the statement from Item 2 and construct a counterexample to show that the converse is false.
      Solution.
      The converse is: if \(2a \equiv 2b ~(\fn{mod } n)\text{,}\) then \(a \equiv b ~(\fn{mod } n)\) for any integers \(a\text{,}\) \(b\text{,}\) and \(n\) with \(n > 1\text{.}\) For a counterexample we need integers \(a\text{,}\) \(b\text{,}\) and \(n\) with \(n > 1\) such that the promise is broken. That is, we want \(2a \equiv 2b ~(\fn{mod } n)\) but \(a \not\equiv b ~(\fn{mod } n)\text{.}\) A counterexample is \(a=2\) and \(b=7\) because \(4 \equiv 14 ~(\fn{mod } 10)\) but \(2 \not\equiv 7 ~(\fn{mod } 10)\text{.}\)
