    Subsection 3.1.B The Definition of a Graph

    In Activity 3.1.A, the essential information we needed to know about the city was the set of objects (the pieces of land) and the connections between them (the bridges). Any set of objects with connections between pairs of objects is a graph.
    🔗

    Definition 3.1.2. Graph.

     
    1. A vertex (or node) is an object. For example, a vertex could be a piece of land in the city from Activity 3.1.A or perhaps a student at the university. The plural of “vertex” is “vertices” and so we refer to one vertex, two vertices, three vertices, and so on.
      🔗
      🔗
    2. An edge is a set of two vertices. For example, if \(A\) and \(B\) are distinct vertices in a graph, then \(\{A,B\}\) is an example of a possible edge. When we model a situation using a graph, each edge represents a connection between two objects. For example, in the Bridges Puzzle Activity 3.1.A, we might want an edge between two vertices to indicate that those two pieces of land are connected by a bridge.
       1 
      We are ignoring, for the moment, that there are two bridges between the big island and the north shore. Technically we need a slightly more general definition of an edge and what we get is a multigraph, not a simple graph.
      As another example, in a graph where each vertex is a student at the university, we might want an edge between two vertices to indicate that those two students have a class together this semester.
      🔗
      🔗
    3. Two vertices are adjacent (or neighbors) if they are connected by an edge. That is, if \(A\) and \(B\) are distinct vertices and \(\{A,B\}\) is an edge, then the vertices \(A\) and \(B\) are adjacent. We also say that \(A\) is adjacent to \(B\) or that \(B\) is adjacent to \(A\text{.}\) So, for example, if Camilla and Quang are both in discrete mathematics class this semester, then Camilla is adjacent to Quang (and vice versa) in the student graph.
      🔗
      🔗
    4. A (simple) graph (or network) is a pair of sets: a vertex set of vertices and a edge set of edges where the elements of each edge are in the vertex set. For example, we might have the graph \(G\) with the vertex set \(\{1,2,3,4\}\) and the edge set
      \begin{equation*} \{\{1,2\},\{1,4\},\{2,3\},\{2,4\},\{3,4\}\}\text{.} \end{equation*}
      🔗
      🔗
    5. A graph drawing of a graph has a point for each vertex and a line (or curve) for each edge connecting its two vertices. In this textbook, we draw each vertex as a small, open circle instead of a point. The placement of the vertices and edges is at our convenience– none of the geometry such as position, length, or angle matters. For example, Figure 3.1.3 shows four different drawings of the graph \(G\) from (d).
      🔗
      🔗
    🔗
    🔗
    The city in the Bridges Puzzle can be modeled with a multigraph which is a graph where multiple edges are allowed between the same pair of vertices.

    Definition 3.1.8. Degree of vertex.

     
    1. The degree of a vertex \(v\) in a graph \(G\text{,}\) denoted \(\fn{deg}_G(v)\) or just \(\fn{deg}(v)\text{,}\) is the number of edges of \(G\) that contain the vertex \(v\text{.}\) For example, in the graph \(G\) from Definition 3.1.2 (d) with vertex set \(\{1,2,3,4\}\) and edge set
      \begin{equation*} \{\{1,2\}, \{1,4\},\{2,3\},\{2,4\},\{3,4\}\}\text{,} \end{equation*}
      vertex 1 has degree two because 1 is an element of two edges: \(\{1,2\}\) and \(\{1,4\}\text{.}\) Vertex 2 has degree three because 2 is an element of three edges: \(\{1,2\}\text{,}\) \(\{2,3\}\text{,}\) and \(\{2,4\}\text{.}\) In the drawings in Figure 3.1.3, we see two edges to vertex 1 and three edges to vertex 2.
      🔗
      🔗
    2. Equivalently, the degree of a vertex is the number of neighbors of the vertex. For example, in the graph \(G\) from Definition 3.1.2 (d), vertex 1 has degree two because it has two neighbors, 2 and 4. Similarly, vertex 2 has degree three because it has three neighbors, 1, 3, and 4.
      🔗
      🔗
    3. An isolated vertex is a vertex with degree zero. For example, \(F\) is an isolated vertex in the classmates graph in Example 3.1.6, because Felipe was not a classmate of anyone else in the group of new transfer students. In Figure 3.1.7 there are no edges to the vertex \(F\text{.}\)
      🔗
      🔗
    4. A end vertex (or leaf or pendant) is a vertex with degree 1. For example, in the classmates graph from Example 3.1.6, \(E\) is an end vertex because Elle was only in a class with Abdi. In Figure 3.1.7 we see one edge to the vertex \(E\text{.}\)
      🔗
      🔗

    Subsection 3.1.C Graph Complements

    When we first introduced graphs in Subsection 3.1.B, we explained that in a graph, \(G\text{,}\) an edge connecting two vertices, \(v\) and \(w\text{,}\) indicates that the two objects, \(v\) and \(w\text{,}\) are related in some way. For example, in Example 3.1.6, the objects were a group of new transfer students and an edge between two vertices indicated that the two students were in a class together this semester. That graph is helpful if we want to visualize who knows each other. Suppose instead that we wanted to set up one-on-one meetings for new transfer students who do not yet know each other. We might want to draw a new graph where the objects are the same group of new transfer students, but now an edge between two vertices indicates that the two students are not in a class together this semester. This new graph, \(\overline{G}\text{,}\) has the same vertices as \(G\text{,}\) but now an edge connecting two vertices, \(v\) and \(w\text{,}\) indicates that the two objects, \(v\) and \(w\) are related in the opposite way.
    🔗
    We formally define the graph complement.
    🔗

    Definition 3.1.9. Graph complement.

    For a graph, \(G\text{,}\) the (graph) complement, \(\overline{G}\text{,}\) has the same set of vertices but opposite edges in the sense that \(\{v,w\}\) is an edge of \(\overline{G}\) exactly when \(\{v,w\}\) is not an edge in \(G\text{.}\) Equivalently, \(v\) and \(w\) are adjacent in \(\overline{G}\) exactly when \(v\) and \(w\) are not adjacent in \(G\text{.}\)
    🔗
    🔗
    Let’s draw the complement of the classmates graph.
    🔗

    Example 3.1.10. Complement of the classmates graph.

    Solution.
    We draw the complement in Figure 3.1.11.
    🔗
    For example, \(A\) and \(D\) are not adjacent vertices in the classmates graph because Abdi and Drew are not in any of the same classes this semester. Therefore, \(A\) and \(D\) are adjacent vertices in the complement of the classmates graph. As another example, \(B\) and \(C\) are adjacent vertices in the classmates graph because Bhavika and Cara are in the algorithms class together this semester. Therefore, \(B\) and \(C\) are not adjacent vertices in the complement of the classmates graph.

    Example 3.1.13. Degree of a vertex in the complement.

    In the graph \(G\) drawn in Figure 3.1.12, what is the relationship between the degree of a vertex in the graph \(G\) and the degree of that same vertex in the complement \(\overline{G}\text{?}\)
    🔗
    Solution.
    As an example, the vertex \(v\) is adjacent to \(w\text{,}\) \(x\text{,}\) and \(z\) in \(G\) and \(v\) is adjacent to \(y\) in \(\overline{G}\text{.}\) Thus, \(\fn{deg}_G(v) = 3\) and \(\fn{deg}_{\overline{G}}(v) = 1\text{.}\) As another example, the vertex \(z\) is adjacent to \(v\) and \(y\) in \(G\) and \(z\) is adjacent to \(w\) and \(x\) in \(\overline{G}\text{.}\) Thus, \(\fn{deg}_G(z) = 2\) and \(\fn{deg}_{\overline{G}}(z) = 2\text{.}\) In general, if \(x\) is any vertex in \(G\text{,}\) then
    \begin{equation*} \fn{deg}_G(x) +\fn{deg}_{\overline{G}}(x) = 4\text{.} \end{equation*}
    🔗
    This equation holds for any vertex, \(x\text{,}\) because there are four other vertices in \(G\text{.}\) Some of those four vertices are adjacent to \(x\) in \(G\text{.}\) The remainder of those four vertices must be adjacent to \(x\) in \(\overline{G}\text{.}\) So, each of those other four vertices counts once in either \(\fn{deg}_G(x)\) or \(\fn{deg}_{\overline{G}}(x)\text{.}\)
