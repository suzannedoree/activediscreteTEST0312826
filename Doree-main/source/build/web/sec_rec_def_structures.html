    Many discrete objects, such as sets and graphs, can also be defined recursively. In this section, we look at a variety of examples of recursively-defined structures. While the recursively-defined sequences in Section 8.1 used only one previous term, recursions can involve any number of previous terms. In this section, we take a sneak peek at such higher order recursions, which we return to explore in more depth in Section 8.5.

    Subsection 8.4.A Proper Bit Strings

    We begin with a puzzle. For the sake of this puzzle, we classify each bit string as either proper or improper according to the following definition.

    Definition 8.4.1. Proper bit strings.

     
    1. A bit string is proper if it can be constructed from the initial condition B by applying the recursions R1 and/or R2 a finite number of times each in any order where
      • \textbf{~ B}:.
        The empty bit string \(\lambda\) is proper.
        🔗
        🔗
      • \textbf{~ R1}:.
        If the bit string \(b\) is proper, then the bit string \(b\bs{0}\) is also proper.
        🔗
        🔗
      • \textbf{~ R2}:.
        If the bit string \(b\) is proper, then the bit string \(\bs{1}b\bs{1}\) is also proper.
        🔗
        🔗
      🔗
      \(\bs{1100110}\)Example 8.4.2Item 1
      🔗
    2. All other bit strings are improper. For example, \(\bs{011}\) is improper, as we show in Example 8.4.2 Item 2.

    Example 8.4.2. Proper bit strings.

     
    1. Prove that the bit string \(\bs{1100110}\) is proper.
      Solution.
      To see why, we start with the initial condition B that tells us \(\lambda\) is proper. We can use R1 to show that \(\lambda\bs{0} = \bs{0}\) is proper, and then apply R1 again to show that \(\bs{00}\) is proper. Next, we apply R2 to show that \(\bs{1001}\) is proper, and then apply R2 again to show that \(\bs{110011}\) is proper. Finally, we apply R1 again to show that \(\bs{1100110}\) is proper.
      🔗
      We can summarize this series of steps in the diagram:
      \begin{equation*} \xrightarrow{\textbf{B}} \lambda \xrightarrow{\textbf{R1}} \bs{0} \xrightarrow{\textbf{R1}} \bs{00} \xrightarrow{\textbf{R2}} \bs{1001} \xrightarrow{\textbf{R2}} \bs{110011} \xrightarrow{\textbf{R1}} \bs{1100110} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. Prove that the bit string \(\bs{011}\) is improper.
      Solution.

    Definition 8.4.6. Language.

     
    1. An alphabet is a set of characters. For example, the usual English alphabet \(\{a,b,c, \ldots, z\}\) is an alphabet. The set of bits, \(\{\bs{0}, \bs{1}\}\text{,}\) is also an alphabet.
      🔗

      \begin{equation*} \mathbb{P} = \{ b \in \mathbb{B} \mid b \text{ is proper } \}\text{,} \end{equation*}

    Example 8.4.9. Multiplicative set.

    Consider the set of integers \(L\) constructed recursively as follows:
    • \textbf{~ B1}:.
      \(\displaystyle 1 \in L\)
      🔗
      🔗
    • \textbf{~ B2}:.
      \(\displaystyle 2 \in L\)
      🔗
      🔗
    • \textbf{~ B3}:.
      \(\displaystyle 3 \in L\)
      🔗
      🔗
    • \textbf{~ R}:.
      If \(k,m \in L\text{,}\) then their product \(km \in L\)
      🔗
      🔗
    🔗
    The \(L\) consists of all integers that can be formed using B1, B2, B3, and R a finite number of times.
    1. Is \(18 \in L\text{?}\) Is \(20 \in L\text{?}\) Is \(1 \in L\text{?}\) Justify your answers.
      Solution.
      First, by B2 \(2 \in L\) and by B3 \(3 \in L\text{.}\) Then, by R, it follows that \((2)(3) = 6 \in L\) and then it follows from R again that \((3)(6)=18 \in L\text{,}\) so yes.
      🔗
      Next, there is no combination of 2s and 3s that multiply to give 20 because the prime factorization of \(20=2^25\text{.}\) Therefore there is no way to construct 20, so no.
      🔗
      Last, \(1 \in L\) by B1.
      🔗
      🔗
      🔗
      🔗
    2. Give an explicit definition of \(L\text{.}\)
      Solution.
      Notice that \(L\) includes 1 and any integer we can build as a product of 2s and 3s. That is,
      \begin{equation*} L= \{2^a\cdot 3^b \mid a,b \in \mathbb{N}\} \end{equation*}
      🔗
      🔗
      🔗
      🔗

      \begin{equation*} L = \{ n \in \mathbb{N} \mid \text{ if } p \text{ is prime and } p \mid n \text{ , then } p=2 \text{ or } p=3\} \end{equation*}

    Example 8.4.10. Additive set.

    Consider the set \(M\) constructed recursively in Activity 8.4.B.
    1. Explain why \(M = \{n \in \mathbb{Z} \mid n \ge 2\}\text{.}\)
      Solution.
      We can show any even integer \(n \in M\) as follows. Write \(n = 2k\) for some integer \(k\text{.}\) By B1 we know \(2 \in M\text{.}\) Applying R \((k-1)\) times we get
      \begin{equation*} 2 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } \in M\text{.} \end{equation*}
      But
      \begin{equation*} 2 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } = 2+ 2(k-1) = 2k =n\text{.} \end{equation*}
      Thus \(n \in M\text{.}\)
      🔗
      We can show any odd integer \(n \in M\) for \(n \ge 3\) as follows. Write \(n = 2k+1\) for some integer \(k\text{.}\) Since \(n \ge 3\text{,}\) it follows that \(k \ge 1\text{.}\) By B2 we know \(3 \in M\text{.}\) Applying R \((k-1)\) times we get
      \begin{equation*} 3 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } \in M\text{.} \end{equation*}
      But
      \begin{equation*} 3 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } = 3 + 2(k-1) = 2k + 1=n\text{.} \end{equation*}
      Thus \(n \in M\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Use mathematical induction to verify that \(n \in M\) for any integer \(n \ge 2\text{.}\)
      Solution.
      Proof. Induct on \(n\text{.}\)
      🔗
      First, when \(n = 2\text{,}\) we know \(2 \in M\) by B.
      🔗
      Next, assume \(n-1 \in M\) for some \(n >1\text{.}\) We consider two cases.
      🔗
      Case 1: Somewhere in the process of constructing \(n-1\) we used B1. That is, \(n-1=2+m\) for some \(m \in M\text{.}\) Adding one to each side of the equation we get \(n = 3 + m\text{,}\) and so \(n\) can be constructed from \(m\) using B2 and R.
      🔗
      Case 2: Nowhere in the process of constructing \(n-1\) did we use B1. It follows that somewhere in the process of constructing \(n-1\) we used B2. That is, \(n-1 = 3+m\) for some \(m \in M\text{.}\) Adding one to each side of the equation we get \(n = 4 + m\text{,}\) and so \(n\) can be constructed from \(m\) using B1 twice and R.
