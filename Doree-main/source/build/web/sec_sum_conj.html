    Section 9.3 Conjectures of Explicit Formulas for Sums and Products

    Although we have a notation for sums and products, we still need to go through a process to evaluate a sum and product. First, we need to calculate each term. Next, we need to add or multiply. In some cases, we can find an explicit formula for a sum or a product, which allows us to evaluate using a formula. In this section, we introduce partial sums and partial products and use them to conjecture explicit formulas.
    🔗

    Subsection 9.3.A Sum Conjectures

    We start with sums.
    🔗

    Definition 9.3.1. Partial sums.

    Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\)
    1. For the sum
      \begin{equation*} \sum_{k=s}^n a_k =a_s + a_{s+1}+a_{s+2}+\ldots+a_n\text{,} \end{equation*}
      the partial sums are
      \begin{align*} \sum_{k=s}^s a_k \amp =a_s,\\ \sum_{k=s}^{s+1} a_k \amp =a_s+a_{s+1},\\ \sum_{k=s}^{s+2} a_k \amp =a_s+a_{s+1}+a_{s+2}\text{,} \end{align*}
      and so on. For example, for the sum
      \begin{equation*} \sum_{k=1}^n 2 =2 + 2 + 2 + \ldots + 2\text{,} \end{equation*}
      the partial sums are
      \begin{align*} \sum_{k=1}^1 2 \amp =2,\\ \sum_{k=1}^2 2 \amp =2+2=4,\\ \sum_{k=1}^3 2 \amp =2+2+2=6\text{,} \end{align*}
      and so on.
      🔗
      🔗
    2. The sequence of partial sums is
      \begin{equation*} a_s, a_s+a_{s+1},a_s+a_{s+1}+a_{s+2}, \ldots\text{.} \end{equation*}
      For example, the sequence of partial sums in our example begins
      \begin{equation*} 2, 4, 6, \ldots\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    We focus on finite sums, but we mention, for readers who have studied calculus, that these are the same partial sums used to define infinite series.
    🔗

    Remark 9.3.5. Recursive definition of partial sums.

    Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\) Then
    \begin{align*} \sum_{k=s}^n a_k \amp = a_s + a_{s+1} + \ldots + a_{n-1} + a_n\\ \amp = (a_s + a_{s+1} + \ldots + a_{n-1}) + a_n\\ \amp = \left(\sum_{k=s}^{n-1} a_k\right) + a_n \end{align*}
    🔗
    We can remember this recursion as
    \begin{equation*} \underbrace{\sum_{k=s}^n a_k}_{\text{ new sum } } = \underbrace{\sum_{k=s}^{n-1} a_k}_{\text{ previous sum } } + \underbrace{a_n}_{\text{ new term } } \end{equation*}

    Subsection 9.3.B Product Conjectures

    Next, we work with products.
    🔗

    Definition 9.3.13. Partial products.

    Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\)
    1. For the product
      \begin{equation*} \prod_{k=s}^n a_k =a_s \times a_{s+1} \times a_{s+2} \times \ldots \times a_n\text{,} \end{equation*}
      the partial products are
      \begin{align*} \prod_{k=s}^s a_k \amp =a_s,\\ \prod_{k=s}^{s+1} a_k \amp =a_s \times a_{s+1},\\ \prod_{k=s}^{s+2} a_k \amp =a_s \times a_{s+1} \times a_{s+2}\text{,} \end{align*}
      and so on. For example, for the product
      \begin{equation*} \prod_{k=1}^n 2 = 2 \times 2 \times \cdots \times 2\text{,} \end{equation*}
      the partial products are
      \begin{align*} \prod_{k=1}^1 2 \amp =2,\\ \prod_{k=1}^2 2 \amp =2 \times 2=4,\\ \prod_{k=1}^3 2 \amp =2 \times 2 \times 2=8\text{,} \end{align*}
      and so on.
      🔗
      🔗
    2. The sequence of partial products is
      \begin{equation*} a_s, a_sa_{s+1},a_sa_{s+1}a_{s+2}, \ldots\text{.} \end{equation*}
      For example, the sequence of partial products in our example begins
      \begin{equation*} 2, 4, 8, \ldots\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗

    Remark 9.3.17. Recursive definition of partial product.

    Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\) Then
    \begin{align*} \prod_{k=s}^n a_k \amp = a_s \times a_{s+1} \times \ldots \times a_{n-1} \times a_n\\ \amp = (a_s \times a_{s+1}\times \ldots \times a_{n-1}) \times a_n\\ \amp = \left(\prod_{k=s}^{n-1} a_k\right) \times a_n \end{align*}
    🔗
    We can remember this recursion as
    \begin{equation*} \underbrace{\prod_{k=s}^n a_k}_{\text{ new product } } = \underbrace{\prod_{k=s}^{n-1} a_k}_{\text{ previous product } } \times \underbrace{a_n}_{\text{ new term } } \end{equation*}

    Subsection 9.3.D Algebra: Factoring Polynomials

    In some of our conjectures about sums and products, our answer involved a factored polynomial. We would like to eventually prove these conjectures. For those proofs, it is helpful to be able to factor polynomials. As we saw in Subsection 4.2.B, we use the distributive rule to multiply polynomials. Let’s look at an example using the distributive rule to factor polynomials.
    🔗

    Example 9.3.25. Factoring polynomial.

     
    1. Multiply \((n+s)(n+t)\) and write the answer as a polynomial in the variable \(n\text{.}\)
      Solution.
      Using the distributive property (FOIL) as discussed in Subsection 4.2.B, we get
      🔗
      \((n+s)(n+t)\) = \(\underbrace{(n)(n)}_{\text{ First } } +\underbrace{(n)(t)}_{\text{ Outside } } + \underbrace{(s)(n)}_{\text{ Inside } } + \underbrace{(s)(t)}_{\text{ Last } }\)
      = \(n^2 + tn + sn + st\)
      = \(n^2+ (s+t)n + st\)
      Observe that the coefficient \(n\) is \(s+t\text{,}\) the sum of \(s\) and \(t\text{,}\) and the constant term is \(st\text{,}\) the product of \(s\) and \(t\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Factor \(n^2 -n-6\text{.}\)
      Solution.
      Based on our observation in (a), we might guess that
      \begin{equation*} n^2 -n-6 = (n+\underline{})(n+\underline{}) \end{equation*}
      where the sum of the integers in the blanks is \(-1\) and the product of the integers in the blanks is \(-6\text{.}\) We guess that the integers are \(-3\) and \(2\) and so
      \begin{equation*} \text{ answer: } n^2 -n-6 = (n-3)(n+2)\text{.} \end{equation*}
      This process of factoring is sometimes nicknamed unfoiling, since we FOIL to check.
      \begin{equation*} \text{ check: } (n-3)(n+2)=n^2 + 2n-3n-6 = n^2-n-6\text{.} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    3. Multiply \((n+s)(n-s)\) and write the answer as a polynomial in the variable \(n\text{.}\)
      Solution.
      Multiplying we get
      🔗
      \((n+s)(n-s)\) = \(\underbrace{(n)(n)}_{\text{ First } } +\underbrace{(n)(-s)}_{\text{ Outside } } + \underbrace{(s)(n)}_{\text{ Inside } } + \underbrace{(s)(-s)}_{\text{ Last } }\)
      = \(n^2 - sn + sn - s^2\)
      = \(n^2-s^2\)
      🔗
      🔗
      🔗
    4. Factor \(n^2 -4\text{.}\)
      Solution.
      We can use the result of (c),
      \begin{equation*} n^2-4 = n^2-2^2=(n+2)(n-2) \end{equation*}
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
