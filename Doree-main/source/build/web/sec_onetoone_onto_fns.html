    Section 6.3 One-to-one and Onto

    In this section, we look at the formal definition of a function and the properties of one-to-one and onto that make a function a pairing.
    🔗

    Subsection 6.3.1 \suborderedpair

    The formal definition of function uses the concept of an ordered pair. We have used ordered pairs, for example, in discussing points in the \(xy\)-plane. There is a clever way of defining an ordered pair using sets. We begin with that definition.
    🔗

    Definition 6.3.1. Ordered pairs.

     
    1. For sets \(X\) and \(Y\) and elements \(x\) in \(X\) and \(y\) in \(Y\text{,}\) the ordered pair \((x,y)\) is defined by
      \begin{equation*} (x,y) = \{\{x\}, \{x,y\}\}\text{.} \end{equation*}
      For example, if \(X = \mathbb{Z}\) and \(Y = \mathbb{Z}\text{,}\) then
      \begin{equation*} (3,7) = \{\{3\}, \{3,7\}\} \end{equation*}
      whereas
      \begin{equation*} (7,3) = \{\{7\}, \{3,7\}\} \end{equation*}
      which are different. Note that the same element may be used. For example,
      \begin{equation*} (5,5) = \{\{5\}, \{5,5\}\}=\{\{5\},\{5\}\}=\{\{5\}\}\text{.} \end{equation*}
      🔗
      🔗
    2. In the ordered pair \((x,y)\text{,}\) we say that \(x\) is the first coordinate and \(y\) is the second coordinate. For example, in \((3,7)\) the first coordinate is 3 and the second coordinate is 7.
      🔗
      🔗
    🔗
    🔗
    In 6.1.10, we define a function, \(f\text{,}\) as consisting of three parts: a domain set, a codomain set, and a rule that for each element \(x\) in the domain of \(f\) uniquely determines a corresponding element \(y\) in the codomain of \(f\text{.}\) In that definition, the term “rule” was undefined. As we have seen, examples of rules include formulas, piecewise-defined formulas, or even rules described in words. We are ready to provide a formal modern definition of a rule for a function.
    🔗

    Definition 6.3.2. Formal definition of rule for a function.

     
    1. Given a domain set \(X\) and a codomain set \(Y\text{,}\) a rule for a function \(f\) is a set of ordered pairs \((x,y)\) where the first coordinate of each ordered pair, \(x\text{,}\) is an element of the set \(X\text{,}\) the second coordinate of each ordered pair, \(y\text{,}\) is an element of the set \(Y\text{,}\) and the set satisfies the property that each element of the domain is the first coordinate of exactly one ordered pair in the set. For example, if \(X = \{1,2,3\}\) and \(Y=\{0,1,2,3,4\}\text{,}\) then the set
      \begin{equation*} \{(1,0),(2,3),(3,3)\} \end{equation*}
      is the rule for a function because \((1,0)\) is the unique ordered pair with first coordinate 1, \((2,3)\) is the unique ordered pair with first coordinate 2, and \((3,3)\) is the unique ordered pair with first coordinate 3. On the other hand, the set \(\{(2,1), (2,3), (3,2)\}\) is not the rule for a function for two reasons. First, there is no ordered pair with 1 as the first coordinate. Second, there are two different ordered pairs with 2 as the first coordinate. Either of these reasons justifies that the set is not the rule for a function.
      🔗
      🔗
    2. We use function notation and write \(f(x) =y\) to indicate that the ordered pair \((x,y)\) is in the rule for \(f\text{.}\) For example, if \((2,3)\) is in the rule for a function \(f\text{,}\) then we write \(f(2)= 3\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Example 6.3.3. Writing the rule for a function as a set of ordered pairs.

    For each function, describe the set of ordered pairs in the rule for the function.
    1. The function \(f: \{1,2,3,4,5\} \to {a,b,c,d}\) is defined by
      \begin{equation*} f(1)=a, f(2)=d, f(3)=a, f(4)=d, f(5)=c\text{.} \end{equation*}
      We saw this function in Example 6.1.18
      Solution.
      The rule is
      \begin{equation*} \{(1,a),(2,d),(3,a),(4,d),(5,c)\} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. The function \(\fn{alt}: \mathbb{N} \to \mathbb{Z}\) is defined by \(\fn{alt}(n) = (-1)^n\text{.}\) We saw this function first in Activity 6.1.2.
      Solution.
      The rule is
      \begin{equation*} \{(0,1),(1,-1),(2,1),(3,-1),(4,1),(5,-1), \ldots\} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    3. The function \(g: \mathbb{R} \to \mathbb{R}\) is defined by \(g(x) = x^2+1\text{.}\)
      Solution.
      The rule is the set of ordered pairs \((x,y)\) where \(y = g(x) = x^2+1\text{.}\) That is, the rule is the set of points on the parabola shown in Figure 6.3.4.
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    Let’s look at how to determine whether a set of ordered pairs is the rule for a function from a visual representation of the function.
    🔗

    Example 6.3.5. Determining whether a dot diagram or graph in the $xy$-plane is the rule for a function.

    Subsection 6.3.2 \subpairing

    How can we determine whether two sets are the same size? For finite sets, we can pair the elements, just as a child might count objects by pairing each object with one of their fingers. Consider the following example.
    🔗

    Example 6.3.11. Pairing finite sets.

    Give an example of a pairing of the sets \(X=\{1,2,3,4\}\) and \(Y=\{a,b,c,d\}\text{.}\)
    🔗
    Solution.
    A possible pairing is
    \begin{equation*} 1 \leftrightarrow a, 2 \leftrightarrow b, 3 \leftrightarrow c, 4 \leftrightarrow d\text{.} \end{equation*}
    Another pairing is
    \begin{equation*} 1 \leftrightarrow b, 2 \leftrightarrow c, 3 \leftrightarrow d, 4 \leftrightarrow a\text{.} \end{equation*}
    We verify this example satisfies the definition of a pairing in Definition 6.3.12.
    🔗
    🔗
    🔗
    In defining a pairing, we want to capture the idea that each element of the first set and each element of the second set are paired exactly once.
    🔗

    Definition 6.3.12. Pairing.

    A pairing, \(P\text{,}\) between sets \(X\) and \(Y\) is a set of ordered pairs \((x,y)\) where the first coordinate, \(x\text{,}\) is an element of the set \(X\text{,}\) the second coordinate, \(y\text{,}\) is an element of the set \(Y\) and the set \(P\) satisfies the following properties.
    1. Each element of \(X\) is the first coordinate of exactly one ordered pair in \(P\text{.}\)
      🔗
      🔗
    2. Each element of \(Y\) is the second coordinate of exactly one ordered pair in \(P\text{.}\)
      🔗
      🔗
    🔗
    When we have a pairing, we write \(x \leftrightarrow y\) to denote that \((x,y)\) is in the set.
    🔗
    For example, in Example 6.3.11 we saw that if \(X=\{1,2,3,4\}\) and \(Y=\{a,b,c,d\}\text{,}\) then the set
    \begin{equation*} \{(1,b),(2,c),(3,d),(4,a)\} \end{equation*}
    is a pairing because 1 is the first coordinate of exactly one ordered pair, namely \((1,b)\text{,}\) 2 is the first coordinate of exactly one ordered pair, namely \((2,c)\text{,}\) 3 is the first coordinate of exactly one ordered pair, namely \((3,d)\text{,}\) and 4 is the first coordinate of exactly one ordered pair, namely \((4,a)\text{.}\) Similarly, \(a\) is the second coordinate of exactly one ordered pair, namely \((4,a)\text{,}\) \(b\) is the second coordinate of exactly one ordered pair, namely \((1,b)\text{,}\) \(c\) is the second coordinate of exactly one ordered pair, namely \((2,c)\text{,}\) and \(d\) is the second coordinate of exactly one ordered pair, namely \((3,d)\text{.}\)

    Subsection 6.3.3 \subonetooneonto

    Every pairing defines a rule of a function because the definition of function Definition 6.3.2 includes the first property of the definition of a pairing ( Definition 6.3.12 Item 1). Therefore, we can describe pairings using function notation.
    🔗

    Remark 6.3.19. Function notation for pairings.

    For sets \(X\) and \(Y\text{,}\) a pairing, \(P\text{,}\) between \(X\) and \(Y\) defines a function \(f:X \to Y\) by \(f(x)=y\) when \((x,y)\) is in \(P\text{.}\) In this context, we write \(x \leftrightarrow f(x)\text{.}\)
    🔗
    🔗
    In this section, we explore the second property 6.3.12 Item 2, which the rule of a function needs to satisfy to be a pairing. For that purpose, it is helpful to separate 6.3.12 Item 2 into two parts.
    🔗

    Remark 6.3.20. When the rule of a function is a pairing.

    For sets \(X\) and \(Y\text{,}\) a rule, \(P\text{,}\) for a function \(f:X \to Y\) is a pairing if it satisfies the following properties.
    1. Existence: Each element of \(Y\) is the second coordinate of at least one ordered pair in \(P\text{.}\) That is, for each element \(y\) in \(Y\text{,}\) there is at least one element \(x\) in \(X\) such that \(f(x) = y\text{.}\) (Onto property)
      🔗
      🔗
    2. Uniqueness: Each element of \(Y\) is the second coordinate of at most one ordered pair in \(P\text{.}\) That is, or each element \(y \in Y\text{,}\) there is at most one element \(x \in X\) such that \(f(x)=y\text{.}\) (One-to-one property)
      🔗
      🔗
    🔗
    🔗
    Let’s take a closer look at the existence and uniqueness properties of a pairing. We start with existence.
    🔗

    Definition 6.3.21. Onto.

    A function \(f: X \to Y\) is onto (or surjective) if for each element \(y\) of \(Y\text{,}\) there is at least one element \(x \in X\) such that \(f(x) =y\text{.}\) That is, for each element \(y\) in \(Y\text{,}\) there is at least one ordered pair in the rule for \(f\) with second coordinate \(y\text{.}\) For example, the functions \(f\) and \(k\) defined by the dot diagrams in Figure 6.3.22 are onto, but the function \(g\) is not onto because nothing maps to \(b\) and the function \(h\) is not onto because nothing maps to \(a\text{.}\)
