    Section 6.1 Functions and Their Representations

    In this section, we introduce the formal definition of a function, look at examples of functions defined by formulas, and discuss how to visually represent functions. The definition of a function requires sets, so we begin with the names of some common infinite sets of numbers.
    🔗

    Subsection 6.1.A Infinite sets of numbers

    The definition of a function involves sets. Functions in discrete contexts often involve sets of integers, natural numbers, or rational numbers as defined in Definition 2.1.6 and Definition 4.1.9. It is convenient to have names for such sets.

    1. Which of the sets \(\mathbb{Z}\text{,}\) \(\mathbb{Z}^+\text{,}\) and \(\mathbb{N}\) have the integer 0 as an element?
      Solution.

    Functions in more continuous contexts, like algebra or calculus, often involve real numbers. A formal definition of real numbers requires mathematics beyond this textbook, but we start with a casual form of the definition.

    Definition 6.1.3. Real numbers.

     
    1. A real number is any number that can be represented in decimal notation. For example, each of the following numbers is a real number: 523.7, \(34 = 34.0\text{,}\) \(\frac{3}{8} = .375\text{,}\) \(-\sqrt{2} = -1.414213\ldots\text{,}\) and \(\pi = 3.141592\ldots\text{.}\) The … indicates that the decimal representation continues.
      🔗
      🔗
    2. When the decimal notation for a real number repeats forever, we use bar notation. For example,
      \begin{equation*} \frac{7}{11} = 0.636363\ldots = 0.\overline{63}\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    It is useful to have a notation for commonly used sets of real numbers.

    1. The set of all rational numbers

      🔗
      🔗
    2. The set of all real numbers is denoted \(\mathbb{R}\text{.}\) For example, each of the following real numbers is an element of \(\mathbb{R}\text{:}\) 523.7, \(34\text{,}\) \(\frac{3}{8}\text{,}\) \(^-\frac{7}{11}\text{,}\) \(-\sqrt{2}\text{,}\) and \(\pi\text{.}\)
      🔗
      🔗

      \begin{equation*} \mathbb{R}^+ = \text{ set of all positive real numbers } \end{equation*}

    Example 6.1.5. Sets of real numbers.

     
    1. Which of the sets \(\mathbb{Q}\text{,}\) \(\mathbb{R}\text{,}\) \(\mathbb{R}^+\text{,}\) and \(\mathbb{R}^*\) have the integer 0 as an element?
      Solution.
      The integer 0 can be written as a fraction, for example \(0 = \frac{0}{1}\text{.}\) Thus 0 is an element of \(\mathbb{Q}\text{.}\) The integer 0 can be written as 0.0 (or just 0). Thus 0 is an element of \(\mathbb{R}\text{.}\) Since the integer 0 is not positive, 0 is not an element of \(\mathbb{R}^+\text{.}\) Since the integer 0 is not nonzero, 0 is not an element of \(\mathbb{R}^*\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Which of the sets \(\mathbb{Z}\text{,}\) \(\mathbb{Q}\text{,}\) and \(\mathbb{R}\) are subsets of the others?
      Solution.
      Any integer \(n\) can be written as a fraction, for example \(n = \frac{n}{1}\text{.}\) Thus \(n\) is an element of \(\mathbb{Q}\) and so \(\mathbb{Z}\) is a subset of \(\mathbb{Q}\text{.}\) Any integer \(n\) can also be written as a real number, for example \(n = n.0\) (or just \(n\)). Thus \(n\) is an element of \(\mathbb{R}\) and so \(\mathbb{Z}\) is a subset of \(\mathbb{R}\text{.}\) Any rational number \(\frac{a}{b}\text{,}\) where \(a\) is an integer and \(b\) is a nonzero integer, can be written as a decimal by dividing \(a \div b\text{.}\) We might get a terminating decimal, like \(\frac{3}{8}=0.375\text{,}\) or we might get a repeating decimal, like \(\frac{7}{11} = 0.636363\ldots = 0.\overline{63}\text{.}\) (It turns out we cannot get a non-repeating decimal.) Thus \(\frac{a}{b}\) is an element of \(\mathbb{R}\) and so \(\mathbb{Q}\) is a subset of \(\mathbb{R}\text{.}\)

    There is a special notation for subsets of real numbers that are defined by inequalities.
    🔗

    Definition 6.1.6. Intervals.

     
    1. An interval is a set of all real numbers \(x\) between two real numbers known as bounds. For example, the set of all real numbers \(x\) such that \(11 \le x \lt 12\) is an interval bounded below by 11 and bounded above by 12. The integer 11 is an element of the interval, but the integer 12 is not an element of the interval.
      🔗
      🔗
    2. An unbounded interval (or ray) is a set of all real numbers greater than a real number or a set of all real numbers less than a real number. For example, the set of all real numbers \(x\) such that \(x\ge 4.32\) is an unbounded interval. The real number 4.32 is an element of that interval. The set of negative real numbers \(x\) is the unbounded interval defined by \(x\lt 0\text{.}\) The real number 0 is not an element of that interval.
      🔗
      🔗
    3. We can abbreviate an interval using interval notation where a square bracket indicates that the bound is included, whereas a round bracket indicates that the bound is excluded. When the interval is unbounded, we use \(\infty\) to indicate that the interval has no upper bound and \(-\infty\) to indicate that the interval has no lower bound. For example, the interval described by the inequality \(11 \le x \lt 12\) is denoted \([11,12)\) and the positive real numbers is denoted \((0,\infty)\text{.}\) Occasionally we write the full set of real numbers \(\mathbb{R}\) as the interval \((-\infty,\infty)\text{.}\) ENDTable 6.1.7 shows examples of each type of interval notation.
      🔗
      🔗
    🔗
    🔗
    Let’s work with interval notation.
    🔗

    Example 6.1.8. Interval notation.

     
    1. Write the interval \((12,14]\) using inequality notation.
      Solution.
      For an element \(x\) in the interval, the round bracket at 12 tells us that \(x > 12\) whereas the square bracket at 14 tells us that \(x \le 14\text{.}\) Together we have \(12 \lt x \le 14\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Which of the real numbers 13.7, 12, and 14 are elements of the interval \((12,14]\text{?}\)
      Solution.
      Since \(12 \lt 13.7 \le 14\text{,}\) the real number 13.7 is in the interval. The round bracket tells us that 12 is not in the interval. The square bracket tells us that 14 is in the interval.
      🔗
      🔗
      🔗
      🔗
    3. Write the interval \(x \le 2\) in interval notation.
      Solution.
      Since the inequality is bounded above by 2, and 2 is in the interval, we use a square bracket at 2. Since there is no lower bound on the interval, we use \(-\infty\) (always with a round bracket). In interval notation we have \((- \infty,2]\text{.}\)

    Subsection 6.1.B Function Notation and Vocabulary

    Before we give a rigorous definition of a function, let us look at an example.
    🔗

    Example 6.1.9. Garden.

    Each tomatillo plant in my garden produces about 100 tomatillos.
    1. One year I planted 3 plants. Approximately how many tomatillos grew?
      Solution.
      I grew around \(3 \times 100 = 300\) tomatillos, which made a lot of salsa verde!
      🔗
      🔗
      🔗
      🔗
    2. If I planted \(n\) plants, approximately how many tomatillos would grow?
      Solution.
      I would grow around \(100n\) tomatillos. In general, we say that the number of tomatillos is a function of the number of plants.
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    We are ready to define a function and related vocabulary.
    🔗

    Definition 6.1.10. Function.

    A function, \(f\text{,}\) consists of three parts: a domain set, a codomain set, and a rule. Specifically,
    1. The domain of the function \(f\) is the set of acceptable input values. For example, in Example 6.1.9, we could have any non-negative integer number of plants, so the domain was \(\mathbb{N}\text{.}\)
      🔗
      🔗
    2. The codomain of the function \(f\) is the set of acceptable output values. For example, in Example 6.1.9, we could have any non-negative integer number of tomatillos, so the codomain was also \(\mathbb{N}\text{.}\)
      🔗
      🔗
    3. To define a function, we need to say what the domain and codomain sets are. When \(f\) is a function with domain set \(X\) and codomain set \(Y\text{,}\) we use arrow notation to write
      \begin{equation*} f:X \to Y \end{equation*}
      which is pronounced “\(f\) maps from \(X\) to \(Y\)”. For example, in Example 6.1.9 we would write \(f: \mathbb{N} \to \mathbb{N}\text{.}\) If you want to know the domain of a function, look for the set before the arrow. Similarly, if you want to know the codomain of a function, look for the set after the arrow.
      🔗
      🔗
    4. The third part of a function is rule that, for each element \(x\) in the domain of \(f\text{,}\) uniquely determines a corresponding element \(y\) in the codomain of \(f\text{.}\) For example, in Example 6.1.9 for the input value of \(n\) plants, the rule for the output value is \(100n\) tomatillos.
      🔗
      🔗
    5. We use function notation \(f(x)\text{,}\) pronounced “\(f\) of \(x\text{,}\)” to denote the output \(y\) corresponding to the input \(x\text{.}\) We often write \(y=f(x)\text{.}\) For example, in Example 6.1.9, our rule was \(f(n)=100n\text{.}\)
      🔗
      🔗
    6. Given an input value \(x\) in the domain, we evaluate the function \(f\) at \(x\) to get the corresponding output value \(f(x)\) in the codomain. For example, in Example 6.1.9, when we evaluate \(f\) at 3 plants we get \(f(3) = 300\) tomatillos.
      🔗
      🔗
    7. There is one more set associated with a function. The image of the function \(f\) is the set of actual output values– the set of all elements \(y\) in the codomain such that there exists an element \(x\) in the codomain with \(f(x) = y\text{.}\) The image is a subset of the codomain. For example, in Example 6.1.9, we can only get multiples of 100, so the image of \(f\) is the set of nonnegative multiples of 100: \(\{0, 100, 200, 300, \ldots\}\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Many algebra and calculus textbooks do not make a distinction between the function \(f\) and its output value \(f(x)\text{,}\) but being careful to make this distinction is very helpful for advanced mathematics and computer science.

    Example 6.1.11. Function vocabulary with finite sets.

    Consider the function \(a: \{1,2,3,4\} \to \{0,1,2,3\}\) defined by \(a(n) = n-1\text{.}\) That is, \(a(1) = 0\text{,}\) \(a(2)=1\text{,}\) \(a(3) = 2\text{,}\) and \(a(4) = 3\text{.}\)
    1. What are the domain and codomain of the function \(a\text{?}\)
      Solution.
      The domain of \(a\) is \(\{1,2,3,4\}\) and the codomain is \(\{0,1,2,3\}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Find all values of \(n\) such that \(a(n) = 2\text{.}\) Is it unique?
      Solution.
      Note that \(a(3)=2\text{.}\) Yes, it is unique because no other value of \(n\) has \(a(n) = 2\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Does there exist a value of \(n\) such that \(a(n)=4\text{?}\) Explain.
      Solution.
      No, no value of \(n\) has \(a(n) = 4\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. Describe the image of \(a\text{.}\)
      Solution.
      The image of \(a\) is the set \(\{0,1,2,3\}\) which happens to be the codomain.

    Example 6.1.12. Function vocabulary with infinite sets.

    Consider the function \(f: \mathbb{Z} \to \mathbb{N}\) defined by \(f(n) = n^2\text{.}\)
    1. What are the domain and codomain of the function \(f\text{?}\)
      Solution.
      The domain of \(f\) is \(\mathbb{Z}\) and the codomain is \(\mathbb{N}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(f(5)\) and \(f(-6)\text{.}\)
      Solution.
      First, \(f(5) = 5^2=25\text{.}\) Next, \(f(-6) = (-6)^2=(-6)(-6)=36\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Find all values of \(n\) such that \(f(n) = 4\text{.}\)
      Solution.
      Note that \(f(2) = 2^2=4\) and \(f(-2) = (-2)^2=4\text{.}\) The values are \(2\) and \(-2\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. Does there exist a value of \(n\) such that \(f(n)=3\text{?}\) Explain.
      Solution.
      No, if \(f(n)=3\text{,}\) then we would have \(n = \sqrt{3}\) which is not an integer because 3 is not a perfect square.

      🔗
      🔗
      🔗
    5. Describe the image of \(f\text{.}\)
      Solution.
      The image of \(f\) is the set of perfect squares

    Although in mathematics functions usually have a single letter name, such as \(f\) or \(g\text{,}\) it is common practice in computer science and in work with databases to name a function with a string, often a word or abbreviation chosen to remind us of the rule of the function.     Example 6.1.13. Functions with multi-letter names.

    Consider the function \(\fn{half}: \mathbb{Z} \to \mathbb{Q}\) defined by \(\fn{half}(n) = \frac{n}{2}\text{.}\)
    1. What are the domain and codomain of the function half?
      Solution.
      The domain of half is \(\mathbb{Z}\) and the codomain is \(\mathbb{Q}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(\fn{half}(-6)\) and \(\fn{half}(5)\text{.}\)
      Solution.
      First, \(\fn{half}(-6) = \frac{-6}{2} = -3\text{.}\) Next, \(\fn{half}(5) = \frac{5}{2}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Find a value of \(n\) such that \(\fn{half}(n) = 10\text{.}\)
      Solution.
      Note that \(\fn{half}(20) = \frac{20}{2} = 10\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. Does there exist a value of \(n\) such that \(\fn{half}(n)=\frac{3}{5}\text{?}\) Explain.
      Solution.
      No, if \(\fn{half}(n) = \frac{3}{5}\text{,}\) then we would have \(\frac{n}{2} = \frac{3}{5}\text{.}\) Using the definition of equal fractions Theorem 4.1.11, we would have \(5n = 6\) and so \(n = \frac{6}{5}\) which is not an integer. Since the domain is the integers, we cannot find an integer \(n\) with \(\fn{half}(n)= \frac{3}{5}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    5. Describe the image of half.
      Solution.
      Any integer is in the image of half because \(\fn{half}(2a) = a\text{.}\) Any fraction of the form \(\frac{a}{2}\) where \(a\) is an integer is also in the image of half because \(\fn{half}(a) = \frac{a}{2}\text{.}\) Thus, the image of half is the set
      \begin{equation*} \left\{ \ldots, -3, ^-\frac{5}{2},-2,^-\frac{3}{2}, -1, ^-\frac{1}{2}, 0, \frac{1}{2}, 1, \frac{3}{2}, 2, \frac{5}{2}, 3, \ldots\right\} \end{equation*}

    The domain and codomain are an important part of a function. Let’s look at an example of related functions sharing a common rule but having different domain and codomain sets.
    🔗

    Example 6.1.14. Different functions with the same rules.

    Consider the following functions: \(f: \mathbb{Z} \to \mathbb{Z}\) is defined by \(f(n) = n+2\text{,}\) \(g: \mathbb{N} \to \mathbb{Z}\) is defined by \(g(n) = n+2\text{,}\) and \(h: \mathbb{N} \to \mathbb{N}\) is defined by \(h(n) = n+2\text{.}\)
    1. How are the functions \(f\text{,}\) \(g\text{,}\) and \(h\) different?
      Solution.
      One difference is their domain and codomain. The function \(f\) has domain \(\mathbb{Z}\) but the functions \(g\) and \(h\) have domain \(\mathbb{N}\text{.}\) The functions \(f\) and \(g\) have codomain \(\mathbb{Z}\) but the function \(h\) has codomain \(\mathbb{N}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate each function at \(n=3\text{.}\)
      Solution.
      We have \(f(3) = 3+2 = 5\text{,}\) \(g(3) = 3+2 = 5\text{,}\) and \(h(3) = 3+2 = 5\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Evaluate each function at \(n=-6\) or explain why that is not possible.
      Solution.
      We have \(f(-6) = -6 + 2 = -4\) but \(g(-6)\) and \(h(-6)\) are not defined because -6 is not an element of their domain \(\mathbb{N}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. Explain why we cannot define a function \(k: \mathbb{Z} \to \mathbb{N}\) by \(k(n) = n-2\text{.}\)
      Solution.
      Since 1 is in the domain \(\mathbb{Z}\text{,}\) if \(k\) were a function, then \(k(1) = 1-2=-1\) would need to be in the codomain. Since the codomain is \(\mathbb{N}\) and -1 is not an element of \(\mathbb{N}\text{,}\) we cannot define this function.
      🔗
      🔗
      🔗
      🔗
    5. Compare the images of \(f\text{,}\) \(g\text{,}\) and \(h\text{.}\)
      Solution.
      The image of \(f\) is \(\mathbb{Z}\) because given any integer \(m\text{,}\) we can find an integer \(n\) such that \(f(n) = m\text{,}\) namely \(n=m-2\text{.}\) We can check that \(f(m-2) = (m-2)+2 = m\text{.}\) On the other hand, the image of \(g\) and \(h\) are the set \(\{2, 3, 4, 5, \ldots\}\) because the smallest element of the domain \(\mathbb{N}\) is 0.

    Definition 6.1.15. Constant functions, the identity function, and fixed points.

     
    1. For sets \(X\) and \(Y\) and a specified element \(c\) of \(Y\text{,}\) a function \(f: X \to Y\) defined by \(f(x)=c\) is a constant function. For example, the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = 3\) is a constant function. No matter what the input value \(n\) is, the output is always 3. For example, \(f(15) = 3\text{,}\) \(f(-2) = 3\text{,}\) and \(f(3)=3\text{.}\)
      🔗
      🔗
    2. For a set \(X\text{,}\) the identity function is the function \(i: X \to X\) defined by \(i\) is \(i(x) = x\text{.}\) For example, the function \(i: \{1,2,3,4\}\to \{1,2,3,4\}\) defined by \(i(x) = x\) is the identity function on \(\{1,2,3,4\}\text{.}\) We can evaluate to get \(i(1)=1\text{,}\) \(i(2)=2\text{,}\) \(i(3)=3\text{,}\) and \(i(4)=4\text{.}\)
      🔗
      🔗
    3. For a function \(f:X\to Y\text{,}\) an element \(a\) of the domain \(X\) is a fixed point of the function \(f\) if \(f(a) = a\text{.}\) Note that \(a\) must also be an element of the codomain \(Y\text{.}\) For example, the function \(\fn{sq}: \mathbb{Z} \to \mathbb{N}\) defined by \(\fn{sq}(n) = n^2\) has two fixed points: 0 and 1 because \(\fn{sq}(0)=0^2=0\) and \(\fn{sq}(1)=1^2=1\text{.}\) On the other hand, there are no fixed points of the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = n+2\text{.}\) As another example, every element of the domain is a fixed point of the identity function.
      🔗
      🔗

    The rule for a function can be defined in pieces.
    🔗

    Definition 6.1.16. Piecewise-defined function.

     
    1. A piecewise-defined function is a function in which the domain set is divided into cases and the rule for the function
       3

      depends on the case. For example, we might define a function with domain \(\mathbb{Z}\) where the rule uses one formula when we input an even integer and a different formula when we input an odd integer.
      🔗
      🔗
    2. We can write a piecewise-defined function using the notation
      \begin{equation*} f(x) = \left\{ \begin{array}{cl} \text{ formula 1 } \amp \text{ if } x \text{ is in case 1 } \\ \text{ formula 2 } \amp \text{ if } x \text{ is in case 2 } \\ \vdots \amp \vdots \\ \text{ formula } n \amp \text{ if } x \text{ is in case } n \end{array} \right\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Our next example illustrates a piecewise-defined function.
    🔗

    Example 6.1.17. Piecewise-defined function.

    Consider the function \(p: \mathbb{Z} \to \mathbb{Z}\) defined by \(p(n)=n+1\) in the case where \(n\) is even and \(p(n) = 2n\) in the case where \(n\) is odd. In computer science lingo we might say “if \(n\) is even, then \(p(n)=n+1\text{,}\) else (meaning if \(n\) is odd) \(p(n)= 2n\text{.}\)” We can write this rule as
    \begin{equation*} p(n) = \left\{ \begin{array}{cc} n+1 \amp \text{ if \(n\) is even } \\ 2n \amp \text{ if \(n\) is odd } \end{array} \right \end{equation*}
    1. Evaluate \(p(6)\text{.}\)
      Solution.
      We know that 6 is even and so we are in the first case where \(p(n) = n+1\text{.}\) Therefore \(p(6)=6+1=7\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(p(7)\text{.}\)
      Solution.
      We know that 7 is odd and so we are in the second case where \(p(n) = 2n\) and so \(p(7) = 2(7) = 14\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Does there exist an integer \(n\) such that \(p(n) = 8\text{?}\) Explain
      Solution.
      Note that if \(n\) is even, then \(p(n) = n+1\) is odd and, therefore, cannot equal eight. On the other hand, if \(n\) is odd, then \(p(n) = 2n =8\) would imply that \(n=4\) which is even. No, there does not exist an integer \(n\) such that \(p(n)=8\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. Describe the image of \(p\text{.}\)
      Solution.
      Any odd integer \(2k+1\) is in the image because \(2k\) is even and so \(p(2k) = 2k+1\text{.}\) Any even integer of the form \(2m\) where \(m\) is odd is also in the image because \(m\) is odd and so \(p(m) = 2m\text{.}\) The integers that are not in the image are the even integers of the form \(2m\) where \(m\) is even which are the multiples of 4. The image of \(p\) is the set of integers that are not multiples of 4. That is, the image of \(p\) is
      \begin{equation*} \{ \ldots,-9, -7, -6, -5, -3, -2, -1, 1, 2, 3, 5, 6, 7, 9 \ldots\} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    We can define any function on a finite domain by specifying its value at each point in the domain. Technically, we are using a piecewise-defined function where the cases each have one value. Here is an example.
    🔗

    Example 6.1.18. Function on a finite set defined by a list.

    Consider the function \(f: \{1, 2, 3, 4, 5\} \to \{a,b,c,d\}\) defined by
    \begin{equation*} f(1) = a, f(2) = d, f(3) = a, f(4) = d, f(5)= c \end{equation*}
    1. The function \(f\) is piecewise-defined. Write \(f\) in the usual piecewise notation.
      Solution.
      We can write
      \begin{equation*} f(n) = \left\{ \begin{array}{cl} a \amp \text{ if } n =1 \\ d \amp \text{ if } n =2 \\ a \amp \text{ if } n =3 \\ d \amp \text{ if } n =4 \\ c \amp \text{ if } n =5 \end{array} \right\text{.} \end{equation*}
      Alternatively, we could write
      \begin{equation*} f(n) = \left\{ \begin{array}{cl} a \amp \text{ if } n =1 \text{ or } n=3\\ d \amp \text{ if } n =2 \text{ or } n=4\\ c \amp \text{ if } n =5 \end{array} \right \end{equation*}
      🔗
      🔗
      🔗
      🔗
    2. What is the domain and codomain of \(f\text{?}\)
      Solution.
      The domain of \(f\) is the set \(\{1, 2, 3, 4, 5\}\) and the codomain of \(f\) is the set \(\{a,b,c,d\}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Find an integer \(n\) in \(\{1,2,3,4,5\}\) such that \(f(n) = a\text{.}\) How many input values of \(n\) have \(f(n) = a\text{?}\)
      Solution.
      Note that \(f(1) = a\) and so \(n=1\) is one such value. Another such value is \(n=3\) because \(f(3)=a\) as well. There are two values of \(n\) for which \(f(n) = a\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. What is the image of \(f\text{?}\)
      Solution.
      The actual outputs are \(a\text{,}\) \(c\text{,}\) and \(d\) and so the image is the set \(\{a,c,d\}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    5. Does there exist an integer \(n\) in \(\{1,2,3,4,5\}\) with \(f(n) = b\text{?}\) Explain.
      Solution.
      No, the image is \(\{a,c,d\}\) so \(b\) is not in the image.

    Subsection 6.1.D Dot Diagrams and Graphs of Functions

    How can we visually represent a function? When the domain and the codomain are subsets of \(\mathbb{R}\text{,}\) we can draw a graph of the function on the \(xy\)-plane. You have seen graphs of these types of functions in algebra or calculus. When the domain and codomain are finite sets or subsets of \(\mathbb{Z}\text{,}\) we can represent the function using a dot diagram. Let’s begin with graphs in the \(xy\)-plane.
    🔗

    Definition 6.1.19. Graph of function where the domain and codomain are subsets of \(\mathbb{R}\).

    Consider a function \(f: X \to Y\) where \(X\) and \(Y\) are subsets of \(\mathbb{R}\text{.}\) The graph of the function \(f\) is the set of points \((x,y)\) on the \(xy\)-plane such that \(y=f(x)\text{.}\) Note that each point on the graph is of the form \((x,f(x))\text{.}\) For example, if \(f:\mathbb{R} \to \mathbb{R}\) is a function with \(f(2)=5\text{,}\) then the point \((2,5)\) is on the graph of \(f\text{.}\)
