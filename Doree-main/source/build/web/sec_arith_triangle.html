    Section 9.4 The Arithmetic Triangle

    In Chapter 2, we saw three counting techniques: steps (where we multiply), cases (where we add), and subsets (where we use binomial coefficients). In Section 9.1 and Section 9.3, we worked with sums and products. In this section, we revisit the binomial coefficients, defined in Definition 2.3.4, which are
    \begin{equation*} \binom{n}{k} = \text{ the number of ways to select a subset of } k \text{ elements from a set of } n \text{ elements } \end{equation*}
    for nonnegative integers \(n\) and \(k\text{.}\) We introduce the arithmetic triangle.
     1 
    The arithmetic triangle was formerly known as Pascal’s triangle, and the generic name honors that the arithmetic triangle was known in Asia, the middle East, and Europe countries centuries before Pascal lived.
    We examine the recursion that generates the arithmetic triangle, which is useful for computation, and search for patterns among the binomial coefficients, including summations. We also explain the origin of the name “binomial coefficient” and we derive an explicit formula for the binomial coefficients which is of theoretical use.
    🔗

    Subsection 9.4.A The Arithmetic Triangle

    How do we calculate the value of \(\binom{n}{k}\text{?}\) Let’s first look at an example using the definition.

    Evaluate \(\binom{7}{4}\) without using computational technology.

    Example 9.4.3. Border values of binomial coefficients.

     
    1. Explain why \(\binom{n}{0}=1\) and \(\binom{n}{n}=1\) using the definition of the binomial coefficients.
      Solution.
      Given a set with \(n\) elements, there is only one 0-element subsets, namely the empty set \(\varnothing\text{.}\) Similarly, there is only one \(n\)-element subset, namely the set itself.

      🔗
    2. Explain why \(\binom{n}{1}=n\) using the definition of the binomial coefficients.

      🔗
      🔗
      🔗

    🔗
    Listing the \(k\)-element subsets of a set with \(n\) elements is tedious, even for small values of \(n\) and \(k\text{,}\) and it is impractical for any larger values. We would like a more efficient way to calculate the values of \(\binom{n}{k}\) by hand for small values of \(n\) and \(k\text{.}\) For larger values, we seek a recursive definition to compute the values. We begin with a way to list binomial coefficients in a triangular array.
    🔗

    Definition 9.4.4. The arithmetic triangle.

    The arithmetic triangle is an array of binomial coefficients, where each row has, in order, the values \(\binom{n}{k}\text{,}\) for \(k=0,1,2, \ldots, n\text{.}\) For example, the first row has a single value, \(\binom{0}{0}=1\text{.}\) The second row has, in order, the values \(\binom{1}{0}=1\) and \(\binom{1}{1}=1\text{.}\) The third row has, in order, the values \(\binom{2}{0}=1\text{,}\) \(\binom{2}{1}=2\text{,}\) and \(\binom{2}{2}=1\text{.}\) ENDFigure 9.4.5 shows the first eight rows of the expanded version of the arithmetic triangle that includes the binomial coefficients and their values.     Remark 9.4.8. Generating the arithmetic triangle.

    We can generate the arithmetic triangle as follows.
    1. The first row is 1.
      🔗
      🔗
    2. The entry in each subsequent row is the sum of the two entries above it in the previous row, with the understanding that a missing entry equals zero.
      🔗
      🔗
    🔗
    🔗
    We state this recursion formally.
    🔗

    Theorem 9.4.9. Recursive definition of the binomial coefficients.

    The binomial coefficients can be defined recursively by \(\binom{n}{0}=\binom{n}{n}=1\) and
    \begin{equation*} \binom{n}{k}=\binom{n-1}{k-1} + \binom{n-1}{k} \end{equation*}
    for any nonnegative integer \(n\) and integer \(k=1, \ldots, n-1\text{.}\)
    🔗
    🔗

    \begin{equation*} 35+21 = 56 21+7 = 28 7+1 = 8 1 + 0 = 1 \end{equation*}

    For nonnegative integers \(n\) and \(k\text{,}\) we have
    \begin{equation*} \binom{n}{k} = \binom{n}{n-k} \end{equation*}

    Remark 9.4.18. Special case of the binomial formula.

    For any integer \(n\) and nonnegative integer \(m\text{,}\) we have
    \begin{equation*} (n+1)^m = \sum_{k=0}^m \binom{m}{k}n^{m-k} \end{equation*}
    🔗
    🔗
    Let’s look at an example.
    🔗

    Example 9.4.19. Using the special case of the binomial formula.

    Expand \((n+1)^7\) using Remark 9.4.18.
    🔗
    Solution.
    We get
    \begin{align*} (n+1)^7 \amp = \sum_{k=0}^7n^{7-k}\\ \amp = \binom{7}{0}n^7 + \binom{7}{1}n^6 + \binom{7}{2} n^5 + \binom{7}{3}n^4 + \binom{7}{4} n^3 + \binom{7}{5}n^2+ \binom{7}{6}n + \binom{7}{7}\\ \amp = n^7 + 7n^6 + 21n^5 + 35n^4 + 35n^3 + 21 n^2 + 7n+1\text{.} \end{align*}
    🔗
    The coefficients 1, 7, 21, 35, 35, 21, 7, and 1 come from the eighth row of the arithmetic triangle Figure 9.4.6.
    🔗
    🔗
    🔗
    The pattern works for the sum of two real numbers, \(x\) and \(y\text{,}\) raised to a nonnegative integer power.
    🔗

    Theorem 9.4.20. The binomial theorem.

    For any real numbers \(x\) and \(y\) and any nonnegative integer \(m\text{,}\) we have
    \begin{equation*} (x+y)^m = \sum_{k=0}^m\binom{m}{k}x^{m-k}y^k \end{equation*}
    🔗
    🔗

    Subsection 9.4.D Explicit Formula for Binomial Coefficients

    When we count, we often leave binomial coefficients in our answers. If we need an exact value, then we can use computational technology. The fastest way to evaluate binomial coefficients by hand and the method that computational technology uses is the recursive formula Theorem 9.4.9.

    Theorem 9.4.23. Explicit formula for binomial coefficients.

    For integers \(0 \le k \le n\text{,}\) we have
    \begin{equation*} \binom{n}{k} = \frac{n!}{k!(n-k)!} \end{equation*}
    🔗
    🔗
    Let’s look at how we might prove Theorem 9.4.23 using a combinatorial proof.
    🔗

    Example 9.4.24. Combinatorial proof of the explicit formula for the binomial coefficients.

    Use a combinatorial proof [cross-reference to target(s) "pff_comb_proof" missing or not unique] to prove Theorem 9.4.23.
    🔗
    Solution.
    Proof. We use a combinatorial proof. Consider the following situation there are \(n\) movies. How many ways are there to rank our top \(k\) as movie #1, movie #2, …, movie #\(k\text{?}\)
    🔗
    First, we have \(n\) choices for movie #1, and then \(n-1\) choices for movie #2, and so on until \(n-(k-1)\) choices for movie #\(k\text{.}\) Note that \(n-0, n-1, \ldots, n-(k-1)\) is a list of \(k\) rankings. Since steps multiply Theorem 2.2.2, there are
    \begin{equation*} n(n-1)\ldots(n-(k-1)) \end{equation*}
    ways to rank our top \(k\) movies. We can write this product in terms of factorials. There are
    \begin{equation*} n(n-1)\ldots(n-(k-1)) = \frac{n(n-1)\ldots(n-(k-1))(n-k)\ldots(3)(2)(1)} {(n-k)\ldots(3)(2)(1)} = \frac{n!}{(n-k)!} \end{equation*}
    ways to rank our top \(k\) movies.
    🔗
    On the other hand, we can first pick the \(k\) movies as a set in \(\binom{n}{k}\) ways and then rank these \(k\) movies in \(k(k-1)\ldots(3)(2)(1) = k!\) ways. Since steps multiply Theorem 2.2.2, there are
    \begin{equation*} \binom{n}{k}k! \end{equation*}
    ways to rank our top \(k\) movies.
    🔗
    Since we counted the same quantity in two different ways, it follows that
    \begin{equation*} \frac{n!}{(n-k)!}=\binom{n}{k}k! \end{equation*}
    🔗
    Dividing each side of this equation by \(k!\) we get
    \begin{equation*} \binom{n}{k} = \frac{n!}{k!(n-k)!} \end{equation*}
    as desired.
    🔗
    🔗
    🔗
    This formula is primarily useful for theoretical examples.
    🔗

    Example 9.4.25. Using the explicit formula for binomial coefficients.

     
    1. Use the explicit formula for the binomial coefficients Theorem 9.4.23 to evaluate \(\binom{8}{4}\text{.}\)
      Solution.
      We have \(n=8\text{,}\) \(k=4\) and \(n-k=8-4=4\) and so
      \begin{equation*} \binom{8}{4} = \frac{8!}{4! 4!} = \frac{8\cdot 7 \cdot 6 \cdot 5 \cdot \cancel{4} \cdot \cancel{3} \cdot \cancel{2} \cdot \cancel{1}} {4 \cdot 3 \cdot 2 \cdot 1 \cdot \cancel{4} \cdot \cancel{3} \cdot \cancel{2} \cdot \cancel{1}} = \frac{\cancel{8}\cdot 7 \cdot 6 \cdot 5}{\cancel{4} \cdot 3 \cdot \cancel{2} \cdot 1} = \frac{7 \cdot 6 \cdot 5}{3} =7 \cdot 2 \cdot 5 =70 \end{equation*}
      🔗
      Looking back at Example 9.4.10 we confirm \(\binom{8}{4}=70\text{.}\) Remember that the index begins at \(k=0\) so the 5th entry corresponds to \(k=4\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Use the explicit formula for the binomial coefficients Theorem 9.4.23 to show that
      \begin{equation*} \binom{n}{2} = \frac{n(n-1)}{2}\text{.} \end{equation*}
      Solution.
      We have \(k=2\) and \(n-k = n-2\text{.}\) It is useful to note that
      \begin{equation*} n! = n(n-1)(n-2)(n-3) \cdots (3)(2)(1) = n(n-1)(n-2)! \end{equation*}
      🔗
      Thus,
      \begin{equation*} \binom{n}{2} = \frac{n!}{2!(n-2)!} = \frac{n(n-1)(n-2)!}{2(n-2)!} = \frac{n(n-1)\cancel{(n-2)!}}{2\cancel{(n-2)!}} = \frac{n(n-1)}{2}\text{.} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    3. Use the explicit formula for the binomial coefficients Theorem 9.4.23 to prove algebraically that
      \begin{equation*} \binom{2n}{2} = 2\binom{n}{2} + n^2 \end{equation*}
      Solution.
      First,
      \begin{equation*} \displaystyle \binom{2n}{2} = \frac{(2n)!}{2!(2n-2)!} = \frac{(2n)(2n-1)\cancel{(2n-2)!}}{2\cancel{(2n-2)!}} =\frac{\cancel{2}n(2n-1)}{\cancel{2}} = n(2n-1) \end{equation*}
      🔗
      Next, using (b) we have
      \begin{equation*} 2\binom{n}{2} + n^2 = \cancel{2} \frac{n(n-1)}{\cancel{2}} + n^2 = n(n-1)+ n^2 = n^2-n+n^2=2n^2-n = n(2n-1) \end{equation*}
      🔗
      Since we got the same answer, it follows that \(\displaystyle \binom{2n}{2} = 2\binom{n}{2} + n^2\text{.}\)
