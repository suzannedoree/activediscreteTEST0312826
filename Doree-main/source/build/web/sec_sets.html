    Section 7.1 Sets

    We have been using the idea of sets throughout this course. In this section, we discuss sets more formally, including how to define sets using set-builder notation. We also explore ways to combine sets through set operations, which have applications to working with databases.
    🔗

    Subsection 7.1.1 \subelements

    As in Section 2.1, a set is understood to be an unordered collection of objects called elements. There is a lot of vocabulary related to sets. We start with definitions related to the elements of a set.
    🔗

    Definition 7.1.1. Elements.

     
    1. If the object \(x\) is an element of the set \(S\text{,}\) then we use element notation and write \(x \in S\text{.}\) If \(x\) is not an element of \(S\text{,}\) then we write \(x \notin S\text{.}\) For example, if \(S=\{1,3,4\}\text{,}\) then \(3 \in S\) and then \(2 \notin S\text{.}\)
      🔗
      🔗
    2. An ellipsis is \(\ldots\) which is used to indicate missing items that follow a pattern. For an infinite set described using ellipses we need to recognize the pattern to know if an object is an element. For example, the set \(F = \{4,8,12,\ldots, 64\}\) is the set of multiples of 4 from 4 to 64. Thus, \(20 \in F\) because \(4 \mid 20\) and \(4 \le 20 \le 64\text{.}\) On the other hand, \(18 \notin F\) because \(4 \nmid 18\) and \(80 \notin F\) because \(80 >64\text{.}\) We see a more rigorous way to define such sets in Subsection 7.1.2.
      🔗
      🔗
    3. The cardinality of a finite set \(S\text{,}\) denoted \(|S|\text{,}\) is the number of (distinct) elements in \(S\text{.}\) For example, \(|\{1,3,4\}|=3\) because there are three elements in \(\{1,3,4\}\) namely 1, 3, and 4.
      🔗
      🔗
    🔗
    🔗
    Let’s look at a set of bit strings.
    🔗

    Example 7.1.2. The set of bit strings of length three.

    The set of all bit strings of length three is
    \begin{equation*} \mathbb{B}_3=\{\bs{000}, \bs{001}, \bs{010}, \bs{011}, \bs{100}, \bs{101}, \bs{110}, \bs{111}\} \end{equation*}
    1. Is \(\bs{110} \in \mathbb{B}_3\text{?}\) Is \(\bs{0111}\in \mathbb{B}_3\text{?}\)
      Solution.
      Since 110 is a bit string of length three and appears on the list of elements of \(\mathbb{B}_3\text{,}\) we have \(\bs{110} \in \mathbb{B}_3\text{.}\) Since \(\bs{0111}\) is a bit string of length 4 and does not appear on the list of elements of \(\mathbb{B}_3\text{,}\) we see that \(\bs{0111} \notin \mathbb{B}_3\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(|\mathbb{B}_3|\text{.}\)
      Solution.
      We can count the elements of \(\mathbb{B}_3\text{.}\) There are 8 elements listed so \(|\mathbb{B}_3|=8\text{.}\) Note that by Theorem 2.4.6, we knew there were \(2^3=8\) bit strings of length three so, again, \(|\mathbb{B}_3|=8\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    A set is defined by its elements.
    🔗

    Definition 7.1.3. Set equality and disjoint sets.

     
    1. Sets \(S\) and \(T\) are equal if they have the exact same set of elements. For example, \(\{1,3,4\}=\{4,4,3,1\}\) because each set has the same three elements: 1, 3, and 4.
      🔗
      🔗
    2. At the other extreme, \(S\) and \(T\) are disjoint if they do not have any elements in common. For example, \(\{1,3,4\}\) and \(\{2,7\}\) are disjoint.
      🔗
      🔗
    🔗
    🔗
    Let’s practice working with these definitions.

      🔗
      🔗
    2. Consider the empty set \(\varnothing=\{ ~\}\text{.}\) What is \(|\varnothing|\text{?}\)
      🔗
      🔗
    3. Consider the set \(B = \{1, 3, 5, \ldots, 99\}\text{.}\) Is \(13 \in B\text{?}\) Calculate \(|B|\text{.}\)
      🔗

    4. Consider the set \(X=\{3,6,0,5\}\text{.}\) Is \(A=X\text{?}\) Explain.
      🔗
      🔗
    5. Give an example of a set of integers \(Y\) that is disjoint from \(A\text{.}\) By 7.1.3, that means find a set \(Y\) that has no elements in common with \(A\text{.}\)
      🔗

    Subsection 7.1.2 \subsetbuild

    There are many ways to describe a set. We can explicitly list some of the elements of a known set, such as \(\mathbb{Z}\) or \(\mathbb{R}\text{,}\) perhaps using an ellipsis (\(\ldots\)) if the list is long. Alternatively, we can select the elements of a known set that satisfy some implicit condition or build elements of an explicit format from the elements of a known set.
    🔗

    Definition 7.1.4. Set-builder notation.

     
    1. Given a set \(S\) and a predicate
       1 
      A predicate (or Boolean) is a statement that is true or false.
      \(P(x)\) defined for all elements \(x \in S\text{,}\) the set
      \begin{equation*} A=\{ x \in S \mid P(x)\}\text{,} \end{equation*}
      pronounced “the set of all elements \(x\) in \(S\) such that \(P(x)\)”, is the set of all elements \(x\) of \(S\) that satisfy implicit condition \(P(x)\text{.}\) Note that \(A\) is a subset of \(S\text{.}\) For example, if \(S=\{1,2,3,7,8\}\) and \(P(n)\) is the statement “\(n\) is even”, then
      \begin{equation*} A = \{ n \in S \mid P(n)\} = \{ n \in A \mid n \text{ is even } \}= \{2,8\}\text{.} \end{equation*}
      For example, \(2 \in A\) because 2 is even but \(3 \notin S\) because 3 is not even.
      🔗
      🔗
    2. Given a set \(S\) and a function \(f\) where \(f(x)\) is defined for all \(x \in S\text{,}\) the set
      \begin{equation*} A=\{ f(x) \mid x \in S\}\text{,} \end{equation*}
      pronounced “the set of all elements of the form \(f(x)\) where \(x\) in an element of \(S\)”, is the set of all elements of the explicit format \(f(x)\) where \(x\in S\text{.}\) For example, if \(S=\{1,2,3,7,8\}\) and \(f(n)=n^3\text{,}\) then
      \begin{equation*} A = \{ n^3 \mid n \in S\} = \{1^3,2^3,3^3,7^3,8^3\}= \{1, 8, 27, 343, 512\}\text{.} \end{equation*}
      To show \(343 \in A\) we write \(343=7^3\text{.}\) Note that \(A\) need not be a subset of \(S\text{.}\) It is just built using the set \(S\text{.}\)
      🔗
      🔗
    3. The sets \(\{ x \in S \mid P(x)\}\) and \(\{ f(x) \mid x \in S\}\) are described in set-builder notation because the notation tells us how to build the set.
      🔗
      🔗
    🔗
    🔗
    We can also combine explicit and implicit formulas.
    🔗

    Example 7.1.5. Set of multiples of 4 up to 64.

    In 7.1.1, we saw the set \(F = \{4,8,12,\ldots, 64\}\) which represents the set of multiples of 4 from 4 to 64. Use set-builder notation to define \(F\text{.}\)
    🔗
    Solution.
    One way to define \(F\) would be implicitly:
    \begin{equation*} F = \{ n \mid n = 4k \text{ for some integer } k \text{ with } 1 \le k \le 16\} \end{equation*}
    where the 16 comes from the fact that \(4(16)=64\text{.}\) We could alternatively define \(F\) mixing implicit and explicit forms:
    \begin{equation*} F = \{ 4k \mid 1 \le k \le 16\} \end{equation*}
    🔗
    🔗
    🔗

    Remark 7.1.6. Elements of implicitly or explicitly-defined sets.

    Example 7.1.9. Writing the image of a function in set-builder notation.

    Write the image of the function \(f: X \to Y\) in set builder notation.

    \begin{equation*} \{f(x) \mid x \in X\}\text{.} \end{equation*}

    \begin{equation*} \{y \in Y \mid y = f(x) \text{ for some } x \in X\} \end{equation*}

    Subsection 7.1.3 \subsetops

    We can combine sets to form new sets.
    🔗

    Definition 7.1.10. Set operations.

    Let \(S\) and \(T\) be subsets of a set \(U\text{.}\) In this context, \(U\) is the universal set.
    1. The intersection of \(S\) and \(T\text{,}\) denoted \(S \cap T\) and pronounced “\(S\) intersect \(T\)”, is the set
      \begin{equation*} S\cap T = \{x \in U \mid x \in S \land x \in T\}\text{,} \end{equation*}
      where \(\land\) is the logical connective “and”, as introduced in Definition 5.1.1. Note that \(\cap\) looks similar to \(\land\text{.}\) For example, we might be interested in the intersection of the set of students who have completed a discrete mathematics course and the set of students who have completed a linear algebra course, because such students have the prerequisite to take an abstract algebra course.
      🔗
      🔗
    2. The union of \(S\) and \(T\text{,}\) denoted \(S \cup T\) and pronounced “\(S\) union \(T\)”, is the set
      \begin{equation*} S\cup T = \{x \in U \mid x \in S \lor x \in T\}\text{,} \end{equation*}
      where \(\lor\) is the logical connective “(inclusive) or”, as introduced in Definition 5.1.1. Note that \(\cup\) looks similar to \(\lor\text{.}\) For example, we might be interested in the union of the set of students who are math majors and the set of students who are computer science majors because we would like to invite that whole group to a talk.
      🔗
      🔗
    3. The symmetric difference of \(S\) and \(T\text{,}\) denoted \(S \oplus T\text{,}\) is the set
      \begin{equation*} S \oplus T= \{ x \in U \mid x \in S \oplus x \in T\}\text{,} \end{equation*}
      where \(\oplus\) (or xor) is the logical connective “exclusive or”, as introduced in Definition 5.1.1. For example, we might want to identify people who attended a recent performance of La Bohème or of Tosca, but not both, to offer them the opportunity to buy a season membership to the opera, noting that people who already have a season membership will likely have attended both. If \(S\) is the set of people who attended La Bohème and \(T\) is the set of people who attended Tosca, then the set we want is \(S \oplus T\text{.}\)
      🔗
      🔗
    4. The difference of \(S\) and \(T\text{,}\) denoted \(S - T\) and pronounced “\(S\) without \(T\)”, is the set
      \begin{equation*} S-T =\{x \in U \mid x \in S \text{ but } x\notin T\}\text{.} \end{equation*}
      For example, we might want to send a reminder to patients who received a flu vaccine last year but have not yet done so this year. That would be the set \(S -T\) where \(S\) is the set of people who received a flu vaccine last year and \(T\) is the set of people who received a flu vaccine this year. Note that \(T-S\) is usually different. In our example, \(T-S\) would be the patients who received their flu vaccine this year but not last year. The symbol \(-\) looks like the logical operator \(\neg\text{.}\)
      🔗
      🔗
    5. The complement of \(S\) (in a universal set \(U\)), denoted \(\overline{S}\text{,}\) is the set
      \begin{equation*} \overline{S}= \{ x \in U \mid x \notin S\}\text{.} \end{equation*}
      Yes, \(\overline{S}=U-S\text{.}\) For example, we might want to reach out to all students who are not yet registered for the fall term. If \(S\) is the set of all students who have registered for fall term and \(U\) is the set of all students, then \(S-U\) is the set we want.
      🔗
      🔗
    🔗
    🔗
