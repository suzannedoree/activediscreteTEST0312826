Remark 10.0.2. Alternative characterizations of countable.

The following statements are equivalent.
  1. The set \(T\) is countable. (There is a bijection \(f: \mathbb{N} \to T\text{.}\))
    🔗
    🔗
  2. The set \(T\) fits into and fills Hotel Infinity.
    🔗
    🔗
  3. There is a sequence that lists each element of \(T\) exactly once. (Recall that a function with domain \(\mathbb{N}\) is a sequence starting at 0.)
