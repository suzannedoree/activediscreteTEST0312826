Activity 1.4.B. Primes and composites.

 
  1. Without using any computational technology, show that each of the following integers is composite:
    \begin{equation*} 320, 321, 322, 324, 325, 326, 327, 328, 330\text{.} \end{equation*}
    🔗
    🔗
  2. Using computational technology, check that \(17 \mid 323\) and \(7 \mid 329\text{.}\) What can you conclude about the integers 323 and 329?
    🔗
    🔗
  3. Using computational technology, check that \(331\) is not divisible by \(2, 3, 5, 7, 11, 13, 17\text{,}\) and that \(\sqrt{331} \lt 19\text{.}\) What can you conclude about the integer 331?
    🔗
    🔗
  4. In the mid-17th century Marin Mersenne conjectured that If \(p\) is prime, then \(2^p-1\) is prime. Prove that he was mistaken by finding a prime \(p\) where \(2^p-1\) is a composite.
