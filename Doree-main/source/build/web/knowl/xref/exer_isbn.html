Checkpoint 4.2.19. \exerE.

The International Standard Book Number (ISBN) is a 13-digit integer used to identify a book. The last digit is calculated from the first 12 digits and is used to check whether a 13-digit number is a legitimate ISBN. This check digit is useful to avoid copying errors. Here is how. For
\begin{equation*} \text{ ISBN } = abcdefghijkmx \end{equation*}
the 13th check digit \(x\) is chosen so that
\begin{equation*} (a + 3b + c + 3d + e + 3f + g + 3h + i + 3j + k + 3m + x) \fn{ mod } 10 = 0 \end{equation*}
  1. Confirm that 9780691151649 is a valid ISBN. Note that \(a=9\text{,}\) \(b=7\text{,}\) …, \(x=9\text{.}\)
