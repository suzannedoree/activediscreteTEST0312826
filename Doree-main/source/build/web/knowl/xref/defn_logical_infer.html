Definition 5.5.14. Logical Inferences.

 
  1. For statements \(S\) and statement \(C\text{,}\) a logical inference, denoted
    \begin{equation*} S \implies C\text{,} \end{equation*}
    is a rule saying if we know that statement \(S\) is true, then we can conclude that statement \(C\) is also true. For example, in Example 5.3.6 Item 4 we proved that \((P \land Q) \to P\) is a tautology. Therefore, if we know that \(S=P \land Q\) is true, we can conclude that \(C=P\) is true. We write
    \begin{equation*} P \land Q \implies P\text{.} \end{equation*}
    (This inference is 5.5.15 Item 1.)
    🔗
    🔗
  2. An logical inference can also involve multiple statements. That is, for statements \(S_1\text{,}\) \(S_2\text{,}\) …, \(S_k\text{,}\) and \(C\text{.}\) The logical inference
    \begin{equation*} \left. \begin{array}{c} S_1 \\ S_2 \\ \vdots \\ S_k \end{array} \right\} \implies C \end{equation*}
    means that if we know that statements \(S_1\text{,}\) \(S_2\text{,}\) …, \(S_k\) are true, then we can conclude that statement \(C\) is also true. For example, if we know that \(P\) is true and \(Q\) is true, then we can conclude that \(P \land Q\) is true. We write
    \begin{equation*} \left. \begin{array}{cc} P \\ Q \end{array} \right\} \implies P \land Q\text{.} \end{equation*}
    (This inference is 5.5.15 Item 3.)
    🔗
    🔗
  3. A logical inference \(S \implies C\) is valid if the corresponding conditional statement \(S \to C\) is a tautology or, equivalently, if \((S \to C) \equiv \str{T}\text{.}\) For example, \((P \land Q) \implies P\) is a valid inference because \((P \land Q) \to P\) is a tautology.
