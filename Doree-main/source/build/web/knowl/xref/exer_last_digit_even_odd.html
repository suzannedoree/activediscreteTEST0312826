Prove that for any integer \(n\) and digit \(s\) that if \(s\) is even, then \(10n+s\) is even and if \(s\) is odd, then \(10n+s\) is odd. Use Proof 5.2.C.2, Proof 5.1.B.1, Proof 5.3.B.1, and Definition 4.1.3.
🔗
It follows from this exercise that if the last digit of an integer is even, then that integer is even and if the last digit of an integer is odd, then that integer is odd.
