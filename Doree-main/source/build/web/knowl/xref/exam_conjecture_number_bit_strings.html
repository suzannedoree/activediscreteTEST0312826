Example 2.4.5. Conjecture number of bit strings of length \(n\).

How many bit strings of length \(n\) are there? State your answer as a conjecture.
🔗
Solution.
There is one bit string of length 0 (\(\lambda\)), two bit strings of length one (0, 1) and four bit strings of length two (00, 01, 10, 11). In Example 2.4.2, we listed the eight bit strings of length three. In Activity 2.4.B, we counted 16 bit strings of length four and 32 bit strings of length five. Notice that each integer is twice the previous number, suggesting that we are multiplying by two. Table 2.4.6 shows these examples written as a product of twos.
🔗
Based on these examples, it is reasonable to conjecture that there are
\begin{equation*} \underbrace{2 \times 2 \times \ldots \times 2}_{n \text{ times } } \end{equation*}
bit strings of length \(n\text{.}\)
