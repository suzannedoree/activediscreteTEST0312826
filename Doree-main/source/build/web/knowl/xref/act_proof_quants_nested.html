    Proof.
    Let \(n\) be an integer.
    🔗
    Consider the integer \(m=100-n\text{.}\)
    🔗
    Then \(n+m=n+(100-n)=100\text{.}\)
    🔗
    Thus, there is an integer \(m\) with \(n+m=100\text{,}\) namely \(m=100-n\text{.}\)
    🔗
    Therefore, for any integer \(n\) there is an integer \(m\) such that \(n+m=100\text{.}\)

Prove that there exists an integer \(z\) such that \(zn=z\) for any integer \(n\text{.}\)

    Proof.
    Consider the integer \(z=0\text{.}\)
    🔗
    Let \(n\) be an integer.
    🔗
    Then \(zn=(0)(n)=0=z\text{.}\)
    🔗
    Thus, \(zn=z\) for any integer \(n\text{.}\)
    🔗
    Therefore, there exists an integer \(z\) such that \(zn=z\) for any integer \(n\text{,}\) namely \(z=0\text{.}\)
