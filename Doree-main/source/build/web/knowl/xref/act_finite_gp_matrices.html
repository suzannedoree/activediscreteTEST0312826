Activity 8.3.3. Finite group of matrices.

Consider the following matrices
 1 
If you have studied linear algebra, the transformations corresponding to these matrices are as follows. \(I\) is the matrix of the identity transformation, \(R\) is the matrix of the rotation by 90\(^\circ\) counterclockwise, \(S\) is the matrix of the rotation by 180\(^\circ\text{,}\) \(T\) is the matrix of rotation by 90\(^\circ\) clockwise, \(H\) is the matrix of the reflection across the horizontal \(x\)-axis, \(V\) is the matrix of the reflection across the vertical \(y\)-axis, \(P\) is the matrix of the reflection across the positive slope line \(y=x\text{,}\) and \(N\) is the matrix of the reflection across the negative slope line \(y=-x\text{.}\)
:
\begin{equation*} I = \left[ \begin{array}{cc} 1 \amp 0 \\ 0 \amp 1 \end{array} \right] R = \left[ \begin{array}{rr} 0 \amp -1 \\ 1 \amp 0 \end{array} \right] S = \left[ \begin{array}{rr} -1 \amp 0 \\ 0 \amp -1 \end{array} \right] T = \left[ \begin{array}{rr} 0 \amp 1 \\ -1 \amp 0 \end{array} \right] \end{equation*}
\begin{equation*} H = \left[ \begin{array}{rr} 1 \amp 0 \\ 0 \amp -1 \end{array} \right] V = \left[ \begin{array}{rr} -1 \amp 0 \\ 0 \amp 1 \end{array} \right] P = \left[ \begin{array}{rr} 0 \amp 1 \\ 1 \amp 0 \end{array} \right] N = \left[ \begin{array}{rr} 0 \amp -1 \\ -1 \amp 0 \end{array} \right] \end{equation*}
