Checkpoint 5.1.42. \exerE.

Use a proof by contradiction [cross-reference to target(s) "pff_contradiction" missing or not unique] to prove that an integer \(n\) cannot be even and odd. Hint: If \(n\) is even, use the definition of even to write \(n = 2k\) for some integer \(k\text{.}\) If \(n\) is odd, use the definition of odd to write \(n=2q+1\) for some integer \(q\text{.}\) Do not use \(k\) again. Put these equations together to get \(2k=2q+1\text{.}\) Next, solve for 1 to show that \(2 \mid 1\text{.}\) On the other hand, the only divisors of 1 are \(\pm1\text{.}\)
