Item (a).

Copy the following example of a proof by cases. Prove that \(n^2+n\) is even for any integer \(n\text{.}\)

Proof.
Let \(n\) be an integer. By Example 4.2.9, \(n\) is even or \(n\) is odd. We consider two cases.
🔗
Case 1: Assume \(n\) is even. By the definition of even, \(n = 2k\) for some integer \(k\text{.}\) Thus
\begin{equation*} n^2+n=(2k)^2+(2k) = 4k^2+2k = 2(2k^2+k)\text{,} \end{equation*}
so \(n^2+n\) is even.
🔗
Case 2: Assume \(n\) is odd. By the definition of odd, \(n=2k+1\) for some integer \(k\text{.}\) Thus
\begin{equation*} n^2+n= (2k+1)^2 +(2k+1) = 4k^2 + 4k + 1 + 2k + 1 = 4k^2 + 6k + 2 = 2(2k^2 + 3k + 1)\text{,} \end{equation*}
so \(n^2+n\) is even.
🔗
In either case, \(n^2+n\) is even.
