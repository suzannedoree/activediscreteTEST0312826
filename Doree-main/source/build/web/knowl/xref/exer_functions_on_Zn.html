Checkpoint 6.3.52. \exerU.

Recall from Definition 4.3.5 that the integers mod \(n\text{,}\) \(\mathbb{Z}_n\text{,}\) is the set \(\{0,1,2,\ldots, n-1\}\) with addition and multiplication defined by
\begin{equation*} a \oplus b = a + b \text{ (mod } n) \text{ and } a \otimes b = ab \text{ (mod } n) \end{equation*}
  1. Consider the function \(f: \mathbb{Z} \to \mathbb{Z}_{10}\) defined by \(f(a) = a \text{ mod } 10\text{.}\) Is \(f\) one-to-one? Is \(f\) onto? Explain briefly.

    🔗
  2. Consider the function \(g: \mathbb{Z}_{10} \to \mathbb{Z}_{10}\) defined by \(g(a) = 3 \otimes a\text{.}\) Is \(g\) one-to-one? Is \(g\) onto? Explain briefly.
    🔗
    🔗
