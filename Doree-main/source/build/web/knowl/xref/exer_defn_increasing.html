Consider a function \(f: X \to Y\) where \(X\) and \(Y\) are subsets of \(\mathbb{R}\text{.}\) The function \(f\) is increasing if for every number \(a\) and \(b\text{,}\) if \(a \lt b\text{,}\) then \(f(a) \lt f(b)\text{.}\)
  1. Use Proof 5.3.B.1 to prove that the function \(f: \mathbb{Z} \to \mathbb{Z}\) defined by \(f(n) = 3n\) is increasing.
