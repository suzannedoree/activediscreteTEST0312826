Item (c).

Describe all bit strings \(b\) such that \(\fn{wgt}(b)=0\text{.}\)
Solution.
For a bit string to have weight 0, it cannot contain any 1 s. That is, it must be empty or entirely 0 s. We can list such strings as \(\lambda, \bs{0}, \bs{00}, \bs{000}, \bs{0000}, \ldots\text{.}\)
