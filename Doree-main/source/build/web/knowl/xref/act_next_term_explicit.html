Activity 6.5.B. Modeling with explicitly-defined sequences.

Write a simple explicit rule that generates each sequence. It might help to write the terms in a table. Make sure you say where the index starts.
  1. The sequence \(a\) begins \(4,4,4,4,4,4,4,4,\ldots\text{.}\) Hint: Start the index at 0.
    🔗
    🔗
  2. The sequence \(b\) begins \(5,-5,5,-5,5,-5,5,-5,\ldots\text{.}\) Hint: Start the index at 0. Use \((-1)^n\) to get the alternation.
    🔗
    🔗
  3. The sequence \(c\) begins \(5, 7, 9, 11, 13,\ldots\text{.}\) Hint: Start the index at 0. We add two to get from each term to the next, so the answer likely involves \(2+2+\ldots +2 = 2n\text{.}\) Make a table comparing \(n\text{,}\) \(2n\text{,}\) and the terms of the sequence.
    🔗
    🔗
  4. The sequence \(d\) begins \(2, -3, 4, -5, 6, -7,\ldots\text{.}\) Note: Start the index at 0 or 1 (your choice).
    🔗
    🔗
  5. The sequence \(e\) begins \(5,10,20,40,80, \ldots\text{.}\) Hint: Start the index at 0. We multiply by two to get from each term to the next, so the answer likely involves \(2\times 2 \times \ldots \times 2 = 2^n\text{.}\) Make a table comparing \(n\text{,}\) \(2^n\text{,}\) and the terms of the sequence.
    🔗
    🔗
  6. The sequence \(f\) begins \(11, 101, 1001, 10001, 100001, \ldots\text{.}\) Note: Start the index at 0 or 1 (your choice).
    🔗
    🔗
  7. The sequence \(g\) begins \(0, \frac{1}{2}, \frac{2}{3}, \frac{3}{4}, \frac{4}{5}, \ldots\text{.}\) Hint: Find a formula for the numerator sequence (\(0,1,2,3,4,\ldots\)) and then find a different formula for the denominator sequence (\(1,2,3,4,5,\ldots\)). Note: Start the index at 0 or 1 (your choice), but the numerator and denominator need to start at the same index.
    🔗
    🔗
  8. The sequence \(s\) begins \(\frac{2}{3}, 1, \frac{6}{5}, \frac{4}{3}, \frac{10}{7}, \frac{3}{2}, \frac{14}{9}, \ldots\text{.}\) Hint: The fractions were likely reduced, so consider rewriting as equivalent fractions over more convenient denominators. Note: Start the index at 0 or 1 (your choice).
    🔗
    🔗
  9. The sequence \(t\) begins \(5, 10, 30, 120, 600, \ldots\text{.}\) Hint: Start the index at 1. To get from each term to the next we multiply by 2, then multiply by 3, then by multiply by 4, then multiply by 5, so the answer likely involves \(1 \times 2 \times 3 \times \cdots \times n = n!\text{.}\) Make a table comparing \(n\text{,}\) \(n!\text{,}\) and the terms of the sequence.
    🔗
    🔗
  10. The sequence \(u\) begins \(5, 6, 8, 11, 15, 20, \ldots\text{.}\) Hint: Start the index at 1. To get from each term to the next we add 1, then add 2, then we add 3, then we add 4, then we add 5, so the answer likely involves \(1+2+3+ \ldots n-1=\frac{n(n-1)}{2}\) or \(1+2+3+ \ldots n = \frac{n(n+1)}{2}\text{,}\) which we first saw in the Handshakes Puzzle Activity 1.1.A. Make a table comparing \(n\text{,}\) \(\frac{n(n-1)}{2}\text{,}\) and the terms of the sequence.
    🔗
    🔗
  11. The sequence \(v\) begins \(3, 10, 21, 36, 55, \ldots\text{.}\) Hint: Start the index at 1. Make a table comparing \(n\) and the terms of the sequence. Factor out \(n\text{.}\)
    🔗
    🔗
  12. The sequence \(w\) begins \(1,1,1,2,2,2,3,3,3,4,4,4, \ldots\text{.}\) Hint: The terms repeat so likely either floor or ceiling is involved. Note: Start the index at 0 or 1 (your choice).
    🔗
    🔗
  13. The sequence \(x\) begins \(2, 3, 6, 12, 18, 27, \ldots\text{.}\) Hint: Start the index at 1. Make a table showing the index \(n\text{,}\) \(n^2\text{,}\) and the terms.
    🔗
    🔗
