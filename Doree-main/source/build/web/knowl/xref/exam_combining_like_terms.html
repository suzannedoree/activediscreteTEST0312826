Example 2.1.19. Combining like terms.

Simplify the expression \(2n+3n\text{.}\)
🔗
Solution.
You have seen \(2x+3x=5x\text{.}\) You might have learned that this equation is analogous to saying that if I have 2 apples plus another 3 apples, then I have a total of 5 apples. In the same way, \(2n+3n=5n\text{.}\)
🔗
Alternatively, we can use the definition of the product. Since \(2n = n+n\) and \(3n = n+n+n\text{,}\) together we have
\begin{equation*} 2n + 3n = \underbrace{(n+n)}_{2 \text{ times } } +\underbrace{(n+n+n)}_{3 \text{ times } } = \underbrace{n+n+n+n+n}_{5 \text{ times } } = 5n \end{equation*}
🔗
Yet another way of thinking about this simplification is to use the distributive property to factor
\begin{equation*} 2n+3n=(2+3)n=5n \end{equation*}
🔗
Each of these approaches is useful. So, even if you favor one approach, learn the other methods as well.
