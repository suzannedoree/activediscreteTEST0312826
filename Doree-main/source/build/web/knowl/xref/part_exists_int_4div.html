Item (a).

Copy the following proof. Note that the phrase “there is” indicates an existentially quantified statement, so we use Proof 5.2.C.1. Prove that there is an integer that has exactly four positive divisors.

Proof.
Consider the integer six. The positive divisors of six are 1, 2, 3, and 6. Thus, six has exactly four positive divisors. Therefore, there is an integer that has exactly four positive divisors.
