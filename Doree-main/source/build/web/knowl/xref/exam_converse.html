  2. Give an example of a true conditional statement that has a false converse.
    Solution.
    Consider the conditional statement If \(k=3\text{,}\) then \(k^2 = 9\text{.}\) This statement is true because if \(k=3\text{,}\) then \(k^2=3^2=9\text{.}\) The converse is if \(k^2=9\text{,}\) then \(k=3\text{.}\) The converse is false because if \(k=-3\text{,}\) then \(k^2=(-3)^2=9\) is true but \(k=-3=3\) is false. That is, we have a broken promise Theorem 5.3.13.

  3. Give an example of a true conditional statement that has a true converse.
    Solution.
    Consider the conditional statement If \(n\) is odd, then \(n+1\) is even. The converse is If \(n+1\) is even, then \(n\) is odd. We proved that both statements are true in Section 4.1 Exercise 8 and again in Section 5.3 Exercise 25.
