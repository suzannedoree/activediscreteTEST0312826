Example 9.4.10. Adding another row to the arithmetic triangle.

Use 9.4.9 to write the row of the arithmetic triangle that begins with 1, 8.
🔗
Solution.
We begin with a copy of the row that begins with 1, 7 from Figure 9.4.6. We add neighboring entries to calculate the entries of the next row:
\begin{equation*} 0+1=1 1+7=8 7 +21 = 28 21+35 = 56 35+35=70 \end{equation*}
\begin{equation*} 35+21 = 56 21+7 = 28 7+1 = 8 1 + 0 = 1 \end{equation*}
🔗
The result is shown in Figure 9.4.11.
