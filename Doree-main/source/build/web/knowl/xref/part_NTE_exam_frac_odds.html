Item 4.

The sequence \(d\) begins \(\frac{2}{3}, \frac{4}{7}, \frac{6}{11}, \frac{8}{15}, \ldots\text{.}\)
Solution.
Let’s make a table comparing \(n\text{,}\) the numerator sequence, the denominator sequence, and the terms of the sequence starting at \(n=1\) in Table 6.5.10. Notice the numerator is twice the index so it equals \(2n\text{.}\) For the denominator, we add four to get from each term to the next, so the answer likely involves \(4+4+\ldots +4 = 4n\text{.}\) Let’s add a row for \(4n\) to our table. We can get from \(4n\) to the denominator by subtracting one. A possible formula is \(d_n = \frac{2n}{4n-1}\) for \(n \ge 1\text{.}\)
