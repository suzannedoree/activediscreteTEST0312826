Item 2.

Show that \(16 \in Q\) and \(16 \in P\text{.}\)
Solution.
To show \(16 \in Q\) we need to write 16 as a square, that is \(16=n^2\) for some \(n \in \mathbb{N}\text{.}\) We can write \(16=4^2\) and so \(16 \in Q\text{.}\)
🔗
Similarly, to show \(16 \in P\) we need to write 16 as a power of two, that is \(16=2^n\) for some \(n \in \mathbb{N}\text{.}\) We can write \(16=2^4\) and so \(16 \in T\text{.}\)
