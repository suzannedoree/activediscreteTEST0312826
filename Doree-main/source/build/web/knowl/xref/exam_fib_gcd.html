Example 8.5.12. Fibonaccis and the \(\fn{gcd}\).

 
  1. Use the Euclidean Algorithm Subsection 4.5.B to evaluate \(\fn{gcd}(F_{10},F_9)=\fn{gcd}(55,34)\text{.}\) What do you notice?
    Solution.
    The steps of the Euclidean Algorithm are
    \begin{equation*} 55 \fn{ mod } 34 = 21 \end{equation*}
    \begin{equation*} 34 \fn{ mod } 21 = 13 \end{equation*}
    \begin{equation*} 21 \fn{ mod } 13 = 8 \end{equation*}
    \begin{equation*} 13 \fn{ mod } 8 = 5 \end{equation*}
    🔗
    \begin{equation*} 8 \fn{ mod } 5 = 3 \end{equation*}
    \begin{equation*} 5 \fn{ mod } 3 = 2 \end{equation*}
    \begin{equation*} 3 \fn{ mod } 2 = 1 \end{equation*}
    \begin{equation*} 2 \fn{ mod } 1 = 0 \end{equation*}
    Thus, \(\fn{gcd}(55,34)=1\text{.}\) They are coprime.
    🔗
    Notice how we calculated each of the previous Fibonacci numbers. In fact, the Fibonacci are a “worst-case scenario” for the Euclidean Algorithm, meaning it takes the most steps possible relatively to the size of the integers.

  2. Use the Euclidean Algorithm Subsection 4.5.B to evaluate \(\fn{gcd}(F_{12},F_9)=\fn{gcd}(144,34)\text{.}\) What do you notice?
    Solution.
    The steps of the Euclidean Algorithm are
    \begin{equation*} 144 \fn{ mod } 34 = 8 \end{equation*}
    \begin{equation*} 34 \fn{ mod } 8 = 2 \end{equation*}
    \begin{equation*} 8 \fn{ mod } 2 = 0\text{.} \end{equation*}
    🔗
    Thus \(\fn{gcd}{144,34} = 2\text{.}\)
    🔗
    Look what happens if we write the answer in terms of the Fibonacci numbers. We get \(\fn{gcd}(F_{12},F_9)=F_3\text{.}\)
