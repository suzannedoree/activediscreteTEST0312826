Figure 3.3.42 shows drawings of perfect binary trees \(B_1\text{,}\) \(B_2\text{,}\) and \(B_3\text{.}\)
🔗
The tree \(B_1\) has a root vertex at the top. The root vertex is adjacent to two child vertices drawn below. The tree \(B_2\) starts with the tree \(B_1\) and then, for each end vertex, draws two new adjacent child vertices below. These new vertices are grandchildren of the root. The tree \(B_3\) starts with \(B_2\) and then, for each end vertex, draws two new adjacent child vertices below. These new vertices are great-grandchildren of the root. This pattern continues to give a family of perfect binary trees, denoted \(B_s\) for \(s\ge 1\text{.}\)
