Activity 6.3.3. Four functions.

In each part of this problem you are given four functions. For each function, decide if it is onto (yes/no) and decide if it is one-to-one (yes/no).
  1. Consider the following finite functions. Hint: The graphs are drawn in Figure 6.3.28.
    • The function \(f:\{1,2,3,4\} \to \{0,1,2\}\) is defined by \(f(1) = 0, f(2) =0, f(3) = 2, f(4) = 1\text{.}\)
      🔗
      🔗
    • The function \(g:\{1,2,3,4\} \to \{0,1,2\}\) is defined by \(g(1) = 0, g(2) =0, g(3) = 2, g(4) = 2\text{.}\)
      🔗
      🔗
    • The function \(h:\{1,2,3\} \to \{0,1,2\}\) is defined by \(h(1) = 0, h(2) =2, h(3) = 1\text{.}\)
      🔗
      🔗
    • The function \(k:\{1,2,3\} \to \{0,1,2,3\}\) is defined by \(k(1) = 0, k(2) =3, k(3) = 2\text{.}\)
      🔗
      🔗

  4. As usual, \(\mathbb{B}\) is the set of all bit strings, \(\mathbb{B}^*\) is the set of all nonempty bit strings, and \(\lambda\) is the empty bit string. Consider the following functions on bit strings.
    • The function \(\fn{lastbit}:\mathbb{B}^* \to \mathbb{B}\) is defined by \(\fn{lastbit}(b) =\) the last bit in the bit string \(b\text{.}\)
      🔗
      🔗
    • The function \(\fn{append}:\mathbb{B}\to \mathbb{B}^*\) is defined by \(\fn{append}(b)=b\bs{1}\text{,}\) literally the bit string \(b\) with a \(\bs{1}\) added to the right.
      🔗
      🔗
    • The function \(\fn{reverse}:\mathbb{B}\to \mathbb{B}\) is defined by \(\fn{reverse}(b)=\overleftarrow{b}\text{,}\) where \(\overleftarrow{b}\) means the bit string \(b\) written in reverse order.
      🔗
      🔗

      \begin{equation*} f(b)= \left\{ \begin{array}{ll} b \amp \text{ if the last bit of the bit string } b \text{ is } \bs{0} \\ b \text{ without its last bit } \amp \text{ if the last bit of the bit string } b \text{ is } \bs{1} \end{array} \right\text{.} \end{equation*}
