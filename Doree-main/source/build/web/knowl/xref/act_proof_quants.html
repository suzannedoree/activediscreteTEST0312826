Activity 5.2.C. Proofs of quantified statements.

 
  1. Copy the following proof. Note that the phrase “there is” indicates an existentially quantified statement, so we use Proof 5.2.C.1. Prove that there is an integer that has exactly four positive divisors.

    Proof.
    Consider the integer six. The positive divisors of six are 1, 2, 3, and 6. Thus, six has exactly four positive divisors. Therefore, there is an integer that has exactly four positive divisors.

  3. Copy the following proof. Note that the phrase “for any” indicates a universally quantified statement, so we use Proof 5.2.C.2. Prove \(n \mid n!\) for any integer \(n\text{.}\)

    Proof.
    Let \(n\) be an integer. Note that \(n!=n(n-1)!=nk\) where \(k=(n-1)!\) By the definition of divides, it follows that \(n \mid n!\) Therefore, \(n \mid n!\) for every integer \(n\text{.}\)
