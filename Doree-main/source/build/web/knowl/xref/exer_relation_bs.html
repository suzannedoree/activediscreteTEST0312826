Checkpoint 7.4.49. \exerE.

As usual, let \(\mathbb{B}^*\) denote the set of all (non-empty) bit strings. Define a relation on \(\mathbb{B}^*\) by \(b \sim c\) if \(b\) is a substring of \(c\text{;}\) that is, if the bit string \(b\) appears in consecutive order within the bit string \(c\text{.}\) For example, \(\bs{101} \sim \bs{11}\underline{\bs{101}}\bs{0}\) but \(\bs{00} \not\sim \bs{111010}\) because 111010 does not contain two consecutive 0 s.
