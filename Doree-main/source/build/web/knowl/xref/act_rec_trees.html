Activity 8.4.3. Lopsided trees.

We define the family of lopsided trees, \(T_n\text{,}\) as follows: \(T_1\) and \(T_2\) are each just a single root vertex. For \(n\ge3\text{,}\) the lopsided tree \(T_n\) is built from the trees \(T_{n-1}\) (drawn on the left) and \(T_{n-2}\) (drawn on the right) by adding a new root vertex, an edge between the new root vertex and the root vertex of \(T_{n-1}\text{,}\) and an edge between the new root vertex and the root vertex of \(T_{n-2}\text{,}\) as represented schematically in Figure 8.4.11.
