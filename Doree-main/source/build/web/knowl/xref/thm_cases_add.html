Theorem 1.2.6. Cases add.

If we can build each example by considering separate cases and if there are \(s\) ways in the first case, \(t\) ways in the second case, \(u\) ways in the third case, and so on, then there are
\begin{equation*} s + t + u + \ldots \end{equation*}
total ways to build an example.
