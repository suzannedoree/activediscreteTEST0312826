Example 9.2.15. Direct conversion between binary and hexadecimal.

 
  1. In 9.2.14 we saw that \(695 = (\bs{2B7})_{16}\text{.}\) It turns out that \(695 = (\bs{1010110111})_2\text{.}\) Explain how the hexadecimal and binary representations are related.
    Solution.
    Every four-bit binary number represents a decimal number \(0-15\) and each of those decimal numbers can be written as a single hex digit. There are four bits per hex digit because \(16=2^4\text{.}\) Let’s take the binary representation of 695 and, working from right to left, replace every group of four bits with its single hex digit to get
    \begin{equation*} \underbrace{\bs{10}}_{\bs{2}} \underbrace{\bs{1011}}_{\bs{B}} \underbrace{\bs{0111}}_{\bs{7}}\text{.} \end{equation*}
    We used that \((\bs{10})_2= 2 =(\bs{2})_{16}\text{,}\) \((\bs{1011})_2 = 8+2+1=11=(\bs{B})_{16}\text{,}\) and \((\bs{0111})_2 = (\bs{111})_2 = 4+2+1 = 7 = (\bs{7})_{16}\text{.}\)

  2. Convert \((\bs{DE})_{16}\) directly to binary.
    Solution.
    Noting that \((\bs{D})_{16}=13 = 8 + 4 + 1 = (\bs{1101})_2\) and \((\bs{E})_{16}=14 = 8 + 4 + 2 = (\bs{1110})_2\text{,}\) we replace each hex digit with its 4-bit binary representation to get
    \begin{equation*} \underbrace{\bs{D}}_{\bs{1101}} \underbrace{\bs{E}}_{\bs{1110}}\text{.} \end{equation*}
    Therefore, \((\bs{DE})_{16}=(\bs{11011110})_2\text{.}\)

  3. Convert \((41)_{16}\) directly to binary.
    Solution.
    Noting that \((4)_{16}= 4 = (0100)_2\) and \((1)_{16} = 1 = (0001)_2\text{,}\) we replace each hex digit with its 4-bit binary representation, adding 0 s in front as needed, to get
    \begin{equation*} \underbrace{\bs{4}}_{\bs{0100}} \underbrace{\bs{1}}_{\bs{0001}}\text{.} \end{equation*}
    Thus \((41)_{16}=(01000001)_2=(1000001)_2\text{.}\)
