Example 1.4.15. Prime factorization of divisors of the integer 600.

  List the positive divisors of the integer 600 using its prime factorization.
🔗
Solution.
The prime factorization of the integer 600 is
\begin{equation*} 600=2^3 \cdot 3 \cdot 5^2\text{.} \end{equation*}
🔗
Since there are three prime divisors, we would need a 3-dimensional table which we can represent using three 2-dimensional tables based on the power of 5 in the divisor, as shown in Table 1.4.16. The list of divisors of 600 is, therefore
\begin{equation*} 1, 2, 4, 8, 3, 6, 12, 24, 5, 10, 20, 40, 15, 30, 60, 120, 25, 50, 100, 200, 75, 150, 300, 600\text{.} \end{equation*}
