Example 5.3.12. Counterexamples involving conditional statements.

For each statement from Activity 5.3.C (a)-(c), find a counterexample to show the statement is false.
  1. If a graph has chromatic number four, then it must be the complete graph \(K_4\text{.}\)
    Solution.
    One possible counterexample is the wheel \(W_5\text{,}\) drawn in Figure 3.2.24. (By the way, we could not use \(W_3\) as a counterexample because \(W_3 \cong K_4\text{.}\)) Notice that our counterexample has the hypothesis true and the conclusion false.

  2. Given real numbers \(x\) and \(y\text{,}\) if \(x + y = 2\text{,}\) then \(x \le 1\) and \(y \le 1\text{.}\)
    Solution.
    One possible counterexample is \(x = 0.8\) and \(y=1.2\text{.}\) While it is true that \(x=0.8 \le 1\text{,}\) because \(y = 1.2 > 1\) it follows that the conclusion that \(x \le 1\) and \(y \le 1\) is false. Notice that our counterexample has the hypothesis true and the conclusion false. To insure that the conclusion was false, we used DeMorgan’s Laws Theorem 5.1.16 \(\neg(P \land Q) \equiv \neg P \lor \neg Q\text{.}\)

  3. For any integers \(a\) and \(b\text{,}\) if \(6 \mid ab\text{,}\) then \(6 \mid a\) or \(6 \mid b\text{.}\)
    Solution.
    One possible counterexample would be \(a = 3\) and \(b = 4\) because then \(6 \mid 12 = ab\) but \(6 \nmid 3\) and \(6 \nmid 4\text{.}\) Notice that our counterexample has the hypothesis true and the conclusion false. To insure that the conclusion was false, we used DeMorgan’s Laws Theorem 5.1.16 \(\neg(P \lor Q) \equiv \neg P \land \neg Q\text{.}\)
