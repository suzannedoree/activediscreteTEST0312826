Checkpoint 6.1.49. \exerE.

In 6.1.46 we saw the Collatz function \(c: \mathbb{Z} \to \mathbb{Z}\) defined by c(n) = \left\{
🔗
\begin{array}{cl} \frac{n}{2} \amp \text{ if } n \text{ is even } \\ 3n+1 \amp \text{ if } n \text{ is odd } \end{array}
\right\(\text{..}\) In this exercise, we are going iterate the function \(c\text{,}\) meaning we complete \(c(n)\text{,}\) then evaluate \(c\) at the answer to get \(c(c(n))\text{,}\) then evaluate \(c\) at the answer to get \(c(c(c(n)))\text{,}\) and so on.
  1. Starting with \(n=6\text{,}\) iterate the function \(c\text{.}\) This means evaluate \(c(6)\text{,}\) then \(c(c(6))\text{,}\) then \(c(c(c(6)))\text{,}\) and so on. You may stop when the pattern becomes obvious. Write down the list of values you get starting with 6.
    🔗
    🔗
  2. Repeat for \(n=7\text{.}\)
    🔗
    🔗
  3. What do you notice? State your answer as a conjecture. This conjecture is known as the Collatz conjecture.
    🔗
    🔗
