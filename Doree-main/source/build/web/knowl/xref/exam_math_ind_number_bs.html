Example 8.2.2. Number of bit strings.

 
  1. In Theorem 2.4.7, we proved that for \(n \ge 0\) there are \(2^n\) bit strings of length \(n\text{.}\) Use mathematical induction to prove that there are \(2^n\) bit strings of length \(n\text{.}\)
    Solution.
    Proof Induct on \(n\text{.}\) First, when \(n=0\text{,}\) there is exactly one bit string of length zero, namely \(\lambda\text{,}\) the empty bit string. Since \(2^0=1\text{,}\) it follows that there are \(2^0\) bit strings of length zero.
    🔗
    Next, assume there are \(2^{n-1}\) bit strings of length \(n-1\) for some integer \(n > 0\text{.}\) Let \(b\) be a bit string of length \(n\text{.}\) Since the length of \(b\) is at least 1, we can consider two cases.
    🔗
    Case 1: \(b\) starts with 0. Then \(b=\bs{0}b_0\) where \(b_0\) is a bit string of length \(n-1\text{.}\) By the inductive hypothesis, there are \(2^{n-1}\) choices for the bit string \(b_0\text{.}\) Therefore, there are \(2^{n-1}\) choices for the bit string \(b\) in this case.
    🔗
    Case 2: \(b\) starts with 1. Then \(b=\bs{1}b_1\) where \(b_1\) is a bit string of length \(n-1\text{.}\) By the inductive hypothesis, there are \(2^{n-1}\) choices for the bit string \(b_1\text{.}\) Therefore, there are also \(2^{n-1}\) choices for the bit string \(b\) in this case.
    🔗
    Then, since cases add Theorem 2.2.6, there are
    \begin{equation*} 2^{n-1}+2^{n-1}=2\cdot2^{n-1}=2^n \end{equation*}
    bit strings of length \(n\text{.}\)

  2. What was the inductive hypothesis?
    Solution.
    The inductive hypothesis was that there are \(2^{n-1}\) bit strings of length \(n-1\) for some integer \(n > 0\text{.}\)

  3. Explain step-by-step why the algebra in the final equation is correct.
    Solution.
    For any number \(x\) we have \(x+x=x(1+1)=2x\text{.}\) In particular,
    \begin{equation*} 2^{n-1}+2^{n-1}=2\cdot2^{n-1}\text{.} \end{equation*}
    Next, \(2\cdot2^{n-1}= 2 \cdot \underbrace{2 \times 2 \times \cdots \times 2}_{(n-1) \text{ times } }= \underbrace{2 \times 2 \times \cdots \times 2}_{n \text{ times } }=2^n\text{.}\)
