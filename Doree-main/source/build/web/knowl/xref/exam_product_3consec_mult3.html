Example 4.2.11. Using proof by cases to prove multiple of three.

Use a proof by cases to prove
\begin{equation*} 3 \mid n(n+1)(n+2) \end{equation*}
for any integer \(n\text{.}\)
🔗
Solution.
Let \(n\) be an integer. By the Division Algorithm Theorem 4.2.2, we can write
\begin{equation*} n=3q+r \end{equation*}
for some integers \(q\) and \(r\) with \(0 \le r \lt 3\text{.}\) The only possible values of \(r\) are \(r=0\text{,}\) \(r=1\text{,}\) and \(r=2\text{.}\) We consider three cases.
🔗
Case 1: Assume \(r=0\text{.}\) In this case, \(n=3q\) and so
\begin{equation*} n(n+1)(n+2)= (3q)(3q+1)(3q+2) = 3[q(3q+1)(3q+2)] = 3k \end{equation*}
where \(k = q(3q+1)(3q+2)\text{.}\) Thus, \(3\mid n(n+1)(n+2)\text{.}\)
🔗
Case 2: Assume \(r=1\text{.}\) In this case, \(n=3q+1\) and so
\begin{equation*} n(n+1)(n+2)= (3q+1)(3q+2)(3q+3) = (3q+1)(3q+2)3(q+1) =3[(3q+1)(3q+2)(q+1)] = 3k \end{equation*}
where \(k = (3q+1)(3q+2)(q+1)\text{.}\) Thus, \(3\mid n(n+1)(n+2)\text{.}\)
🔗
Case 3: Assume \(r=2\text{.}\) In this case, \(n=3q+2\) and so
\begin{equation*} n(n+1)(n+2)= (3q+2)(3q+3)(3q+4) = (3q+2)3(q+1)(3q+4) = 3[(3q+2)(q+1)(3q+4)] = 3k \end{equation*}
where \(k = (3q+2)(q+1)(3q+4)\text{.}\) Thus, \(3\mid n(n+1)(n+2)\text{.}\)
🔗
In all cases, \(3\mid n(n+1)(n+2)\text{.}\)
