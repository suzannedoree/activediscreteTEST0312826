Activity 8.5.3. Fibonacci patterns.

For this activity, it is useful have a list of the first twenty Fibonacci numbers, as in Table 8.5.3.
  1. Which Fibonacci numbers are even? Begin your conjecture “\(F_n\) is even if …”.
    🔗
    🔗
  2. Something interesting happens when you multiply a Fibonacci number and the Fibonacci number two later in the sequence. For example,
    \begin{equation*} F_4 \cdot F_6 = (3)(8) = 24 = 5^2 -1 = F_5^2 - 1 \end{equation*}
    and
    \begin{equation*} F_5 \cdot F_7 = (5)(13) = 65 = 8^2 + 1 = F_6^2 + 1\text{.} \end{equation*}
    What’s the general pattern? State your answer as a conjecture.
    🔗
    🔗
  3. Use the Euclidean Algorithm Subsection 4.5.2 to evaluate \(\fn{gcd}(F_8,F_7)=\fn{gcd}(21,13)\text{.}\) What do you notice? Hint: Recall that the first two steps are \(21 \fn{ mod } 13 = 8\) and then \(13 \fn{ mod } 8 = 5\text{.}\)
    🔗
    🔗
  4. Consider the \(2 \times 2\) matrix \(A= \left[ \begin{array}{cc} 1 \amp 1\\ 1 \amp 0 \end{array} \right]\text{.}\) Calculate \(A^2\text{,}\) \(A^3\text{,}\) and \(A^4\) as defined in Definition 8.3.1 and conjecture the explicit formula for \(A^n\text{.}\)
