Checkpoint 9.3.31. \exerU.

Calculate the first few partial sums and use pattern recognition to conjecture an explicit formula for the sum
\begin{equation*} \sum_{k=1}^nk(k!)\text{.} \end{equation*}
By the way, the result of this exercise is a key step in proving the uniqueness of the factorial representations introduced in Activity 9.1.2.
