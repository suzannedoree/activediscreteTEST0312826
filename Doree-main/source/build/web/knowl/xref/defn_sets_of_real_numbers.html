Definition 6.1.4. Sets of real numbers.

 
  1. The set of all rational numbers
     2 
    The letter \(Q\) comes from the word “quotient”.
    is denoted \(\mathbb{Q}\text{.}\) For example, \(\frac{3}{8}\text{,}\) \(^-\frac{7}{11} = \frac{-7}{11}\text{,}\) and \(34 = \frac{34}{1}\) are elements of \(\mathbb{Q}\text{.}\)
    🔗
    🔗
  2. The set of all real numbers is denoted \(\mathbb{R}\text{.}\) For example, each of the following real numbers is an element of \(\mathbb{R}\text{:}\) 523.7, \(34\text{,}\) \(\frac{3}{8}\text{,}\) \(^-\frac{7}{11}\text{,}\) \(-\sqrt{2}\text{,}\) and \(\pi\text{.}\)
    🔗
    🔗
  3. If \(S\) is a subset of real numbers, then the set \(S^+\) is the set of all positive numbers in \(S\) and the set \(S^*\) is the set of all nonzero numbers in \(S\text{.}\) For example,
    \begin{equation*} \mathbb{R}^+ = \text{ set of all positive real numbers } \end{equation*}
    and
    \begin{equation*} \mathbb{R}^* = \text{ set of all nonzero real numbers }\text{.} \end{equation*}
