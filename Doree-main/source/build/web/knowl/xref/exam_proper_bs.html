Example 8.4.2. Proper bit strings.

 
  1. Prove that the bit string \(\bs{1100110}\) is proper.
    Solution.
    To see why, we start with the initial condition B that tells us \(\lambda\) is proper. We can use R1 to show that \(\lambda\bs{0} = \bs{0}\) is proper, and then apply R1 again to show that \(\bs{00}\) is proper. Next, we apply R2 to show that \(\bs{1001}\) is proper, and then apply R2 again to show that \(\bs{110011}\) is proper. Finally, we apply R1 again to show that \(\bs{1100110}\) is proper.
    🔗
    We can summarize this series of steps in the diagram:
    \begin{equation*} \xrightarrow{\textbf{B}} \lambda \xrightarrow{\textbf{R1}} \bs{0} \xrightarrow{\textbf{R1}} \bs{00} \xrightarrow{\textbf{R2}} \bs{1001} \xrightarrow{\textbf{R2}} \bs{110011} \xrightarrow{\textbf{R1}} \bs{1100110} \end{equation*}

  2. Prove that the bit string \(\bs{011}\) is improper.
    Solution.
    We start with B which tells us \(\lambda\) is proper. If we first apply R1, we get that 0 is proper. To get two more 1 s we can apply R2 but that tells us \(\bs{101}\) is proper, which is not our bit string. On the other hand, if we first apply R2, we get that \(\bs{11}\) is proper. To get one 0, we can apply R1 but that tells us 110 is proper, which is also not our bit string.
