Activity 8.1.B. Evaluating recursively-defined sequences.

 
  1. Evaluate the first four terms of the sequence defined by \(t_0=3\) and \(t_i=3t_{i-1}-5\) for \(i \ge 1\text{.}\)
    🔗
    🔗
  2. Evaluate \(v_3\) for the sequence defined by \(v_0=2\) and \(v_m=v_{m-1}^2-1\) for \(m \ge 1\text{.}\)
    🔗
    🔗
  3. Evaluate \(a_5\) for the sequence defined by \(a_1 = 5\) and \(a_n=a_{n-1}+2n\) for \(n\ge 2\text{.}\) Note that the recursion involves the index \(n\text{.}\) For example, when \(n=2\) we get \(a_2=a_1+2(2)=5+4=9\) and when \(n=3\) we have \(a_3=a_2+2(3)=9+6=15\text{.}\)
    🔗
    🔗
  4. Evaluate \(b_4\) for the sequence defined by \(b_1=1\) and \(b_k=kb_{k-1}\) for \(k \ge 2\text{.}\) What do you notice? Write an explicit formula for \(b_k\text{.}\)
    🔗
    🔗
  5. Evaluate \(c_4\) for the sequence defined by \(c_0=0\) and \(c_i=c_{i-1}+i\) for \(i \ge 1\text{.}\) What do you notice? Write an explicit formula for \(c_i\text{.}\) Hint: Handshakes.
