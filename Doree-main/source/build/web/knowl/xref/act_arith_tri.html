Activity 9.4.A. The arithmetic triangle.

 
  1. Copy the first eight rows of the arithmetic triangle.
    🔗
    🔗
  2. Use the arithmetic triangle to evaluate each of the following binomial coefficients and circle the corresponding entries in the triangle.
    \begin{equation*} \binom{5}{4}, \binom{7}{5}, \binom{3}{0}, \binom{6}{1}, \binom{2}{2}\text{.} \end{equation*}
    🔗
    🔗
  3. There is a way to calculate the row that starts with 1, 7 from the row above it. Can you see how? (Do not spoil the surprise for others if you already know the answer.) Hint: Each entry of the row is calculated using two nearby entries from the previous row.
    🔗
    🔗
  4. Use the pattern from Item 3 to write the next row that starts with 1, 8.
    🔗
    🔗
  5. Use your new row to evaluate each of the following binomial coefficients:
    \begin{equation*} \binom{8}{2}, \binom{8}{4}, \binom{8}{5}\text{.} \end{equation*}
    🔗
    🔗
  6. Write a formula for how to calculate the row that stars \(1, n\) from the row above it. Your formula should be in the form \(\displaystyle \binom{n}{k} =\text{.}\) Hint: The entries from the row above will involve \(n-1\) and \(k\)s.
