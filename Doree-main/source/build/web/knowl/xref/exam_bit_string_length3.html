  2. List all bit strings of length four and weight two.
    Solution.
    We draw the possibility tree below. Each bit string has weight two, which means that it has exactly two 1 s and two 0 s. In the tree we need to be careful– any time we have two 1 s or two 0 s, we have only one branch (either to just 0 or to just 1) instead of the usual two branches (to 0 and to 1). The strings are 0011, 0101, 0110, 1001, 1010, 1100.
