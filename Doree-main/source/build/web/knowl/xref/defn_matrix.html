Definition 8.3.1. Matrix multiplication and powers.

 
  1. A \(m \times n\) matrix is an array with entries in each of \(m\) rows and \(n\) columns. For example,
    \begin{equation*} C = \left[ \begin{array}{ccc} -2 \amp 3 \amp 0 \\ -1 \amp 1 \amp 2 \end{array} \right] \end{equation*}
    is a \(2 \times 3\) matrix.
    🔗
    🔗
  2. In this textbook, we only work with square matrices where the number of rows equals the number of columns. For example,
    \begin{equation*} B = \left[ \begin{array}{rr} 2 \amp -3 \\ 1 \amp 2 \end{array} \right] \end{equation*}
    is a square \(2 \times 2\) matrix.
    🔗
    🔗
  3. Two special \(2 \times 2\) matrices are the zero matrix \(\mathbf{0} = \left[ \begin{array}{cc} 0 \amp 0\\ 0 \amp 0 \end{array} \right]\) and the identity matrix \(I = \left[ \begin{array}{cc} 1 \amp 0\\ 0 \amp 1 \end{array} \right]\text{.}\)
    🔗
    🔗
  4. For \(2 \times 2\) matrices, the complicated formula for matrix multiplication is
    \begin{equation*} \left[ \begin{array}{cc} a_1 \amp b_1 \\ c_1 \amp d_1 \end{array} \right]\left[ \begin{array}{cc} a_2 \amp b_2 \\ c_2 \amp d_2 \end{array} \right]=\left[ \begin{array}{cc} a_1a_2 + b_1c_2 \amp a_1b_2+b_1d_2\\ c_1a_2 + d_1c_2 \amp c_1b_2+d_1d_2 \end{array} \right]\text{.} \end{equation*}
    To obtain the entry in the \(i\)th row and the \(j\)th column of the matrix product, we use the \(i\)th row of the first matrix and the \(j\)th column of the second matrix. For example, the entry in the first row and second column of the matrix product is \(a_1b_2+b_1d_2\) which uses the first row (\(a_1\) and \(b_1\)) of the first matrix and the second column (\(b_2\) and \(d_2\)) of the second matrix. For example, consider the matrices \(A=\left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right]\) and \(B=\left[ \begin{array}{rr} 2 \amp -3 \\ 1 \amp 2 \end{array} \right]\text{.}\) Then
    \begin{equation*} AB=\left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right]\left[ \begin{array}{rr} 2 \amp -3 \\ 1 \amp 2 \end{array} \right] =\left[ \begin{array}{cc} (-1)(2)+(2)(1) \amp (-1)(-3)+(2)(2)\\ (0)(2)+(3)(1) \amp (0)(-3)+(3)(2) \end{array} \right] = \left[ \begin{array}{rr} 0 \amp 7 \\ 3 \amp 6 \end{array} \right]\text{.} \end{equation*}
    🔗
    🔗
  5. Matrix multiplication is associative
    \begin{equation*} A(BC)=(AB)C \end{equation*}
    but it is not commutative. For example, for those same matrices \(A\) and \(B\) we have
    \begin{equation*} BA = \left[ \begin{array}{rr} 2 \amp -3 \\ 1 \amp 2 \end{array} \right]\left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right] =\left[ \begin{array}{cc} (2)(-1)+(-3)(0) \amp (2)(2)+(-3)(3))\\ (1)(-1)+(2)(0) \amp (1)(2)+(2)(3) \end{array} \right] = \left[ \begin{array}{rr} -2 \amp -5 \\ -1 \amp 8 \end{array} \right] \end{equation*}
    🔗
    🔗
  6. For a square matrix \(A\) and a positive integer \(s\text{,}\) the matrix power is
    \begin{equation*} A^s= \underbrace{AA\cdots A}_{s \text{ times } } \end{equation*}
    For example,
    \begin{equation*} \left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right]^2 = \left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right]\left[ \begin{array}{rr} -1 \amp 2 \\ 0 \amp 3 \end{array} \right] =\left[ \begin{array}{cc} (-1)(-1)+2(0) \amp (-1)(2)+(2)(3)\\ (0)(-1)+(3)(0) \amp (0)(2)+(3)(3) \end{array} \right] = \left[ \begin{array}{rr} 1 \amp 4 \\ 0 \amp 9 \end{array} \right]\text{.} \end{equation*}
    🔗
    🔗
