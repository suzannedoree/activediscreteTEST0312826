Definition 2.4.14. LogarithmIn this textbook, we only calculate logarithms of exact powers. We do not calculate quantities such as \(\fn{log}(25)\) or \(\fn{lg}(3)\text{.}\) We have defined \(b^n\) when \(n\) is a nonnegative integer, but it is beyond the scope of this textbook to define what \(b^x\) for any real number \(x\text{.}\) With that definition, we can take evaluate logarithms of any positive real number. For example, \(\fn{log}(25) \approx 1.398\) and \(\fn{lg}(3) \approx 1.585\text{.}\).

 
  1. The logarithm base 10 of an integer \(k\text{,}\) denoted \(\fn{log}(k)\) is the exponent of the power 10 that equals \(k\text{.}\) That is, \(\fn{log}(k)=n\) if \(10^n=k\text{.}\) For example, \(\fn{log}(100 ) = 2\) because \(10^2=100\text{.}\)

  2. The logarithm base 2 of an integer \(k\text{,}\) denoted \(\fn{lg}(k)\text{,}\) is the exponent of the power of 2 that equals \(k\text{.}\) That is, \(\fn{lg}(k)=n\) if \(2^n=k\text{.}\) For example, \(\fn{lg}(32) = 5\) because \(2^5=32\text{.}\)

    🔗
  3. In this textbook, we only use base 2 and base 10, but logarithms can be defined in general. The logarithm base \(b\) of an integer \(k\text{,}\) denoted \(\fn{log}_b(k)\) is the exponent of the power of \(b\) that equals \(k\text{.}\) That is, \(\fn{log}_b(k)=n\) if \(b^n=k\text{.}\) For example, \(\fn{log}_5(125) = 3\) because \(5^3=125\text{.}\) In this notation, \(\fn{log}\) is short for \(\fn{log}_{10}\) and \(\fn{lg}\) is short for \(\fn{log}_2\text{.}\) In calculus, a noninteger base \(b=e \approx 2.718\) is important. The corresponding logarithm is named ln.
