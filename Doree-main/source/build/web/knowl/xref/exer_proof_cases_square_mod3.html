Checkpoint 4.2.30. \exerE.

Use cases Subsection 4.2.3 to prove that \(n^2\) mod \(3 = 0\) or \(n^2\) mod \(3 = 1\) for any integer \(n\text{.}\) Hint: Use 4.2.16 Item 4.2.16.1 and consider three cases. Note that in one case we get \(n^2\) mod \(3 = 0\) and in the other two cases we get \(n^2\) mod \(3 = 1\text{.}\) Officially, we are using a modified version of proof by cases that we revisit in [cross-reference to target(s) "sec_logic_connectives" missing or not unique].
