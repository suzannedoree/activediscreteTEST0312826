Theorem 5.5.1. Equivalences involving negations, tautologies, and contradictions.

For any logical statement \(P\text{,}\) tautology T, and contradiction F, we have the following logical equivalences.
  1. Idempotent

    \begin{equation*} P \land P \equiv P\text{ and } P \lor P \equiv P\text{.} \end{equation*}
