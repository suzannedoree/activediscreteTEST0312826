Example 9.3.22. Fibonacci sum conjecture.

Calculate the first six partial sums and use pattern recognition to conjecture an explicit formula for the sum
\begin{align*} \sum_{k=1}^nF_{2k} \amp = F_2+F_4+F_6+F_8+F_{10}+F_{12}+ \ldots +F_{2n}\\ \amp = 1+3+8+21+55+144 \ldots +F_{2n} \end{align*}
🔗
The first fifteen Fibonacci numbers appear in Table 9.3.21.
🔗
Solution.
We start by writing out the first six terms and their partial sums, as shown in Figure 9.3.23. For example, \(1+3 = 4\text{.}\) Next, using the previous sum (as in Remark 9.3.5) we get \(1+3+8 = (4) + 8 = 12\text{.}\) Then, \(12 + 21 = 33\text{,}\) and so on. Next, we make a table showing the index \(n\) and the partial sums, as shown in Table 9.3.24. To see the pattern, notice that each partial sum is one less than a Fibonacci number. Notice that the subscripts are odd. We conjecture
\begin{equation*} \sum_{k=1}^nF_{2k}=F_{2n+1}-1\text{.} \end{equation*}
