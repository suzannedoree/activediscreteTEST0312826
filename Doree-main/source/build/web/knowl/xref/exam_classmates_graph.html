Example 2.1.6. Classmates graph.

Abdi, Bhavika, Cara, Drew, Elle, and Filipe are all new transfer students. This semester, Abdi, Bhavika, and Cara are in a discrete mathematics class together; Bhavika, Cara, and Drew are in an algorithms class together; and Abdi and Elle are in chemistry class together. These students do not have other classes in common.
🔗
We can model these relationships with a graph. The vertex set \(\{A,B,C,D,E,F\}\) has a vertex for each student corresponding to the first letter of their name. Let’s say two vertices are connected by an edge if those two students are taking the same class. If students have any number of classes together, we will just draw a single edge. This graph might be useful for visualizing who knows each other.
  1. Explain why \(\{A,C\}\) is an edge but \(\{B,E\}\) is not.
    Solution.
    Abdi and Cara are in the discrete mathematics class, so \(\{A,C\}\) is an edge. All common classes are listed, and there is no class that Bhavika and Elle are taking, so \(\{B,E\}\) is not an edge.

  2. How many edges are in the graph?
    Solution.
    First, since Abdi, Bhavika, and Cara are in a discrete mathematics class together, we have three edges \(\{A,B\}\text{,}\) \(\{A,C\}\text{,}\) and \(\{B,C\}\text{.}\) Next, since Bhavika, Cara, and Drew are in an algorithms class, we have two more edges \(\{B,D\}\) and \(\{C,D\}\text{.}\) We already knew that \(\{B,C\}\) was an edge, so we do not draw that edge again. Lastly, since Abdi and Elle are in the same chemistry class, we have one more edge: \(\{A,E\}\text{.}\) There are a total of six edges.

  3. Draw the graph.
    Solution.
    Figure 2.1.7 shows one possible drawing of the graph. In this drawing, we chose to draw the vertices in a circle. The lines representing the edges \(\{A,C\}\) and \(\{B,D\}\) happen to cross, which is acceptable, but note that the point where those two edges cross is not a vertex. That is the sort of potential misunderstanding that we avoid by drawing our vertices as small circles instead of actual points.
