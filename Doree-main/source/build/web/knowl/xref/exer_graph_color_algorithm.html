Here is an algorithm to 4-color the vertices of graph \(G\) when the maximum degree of any vertex in \(G\) is three.
  1. Assign each color a number: red (1), blue (2), green (3), and orange (4). Label the vertices \(v_1\text{,}\) \(v_2\text{,}\) …, \(v_n\text{.}\) Color the vertex \(v_1\) red (1).
    🔗
    🔗
  2. Go to the next vertex and color it the smallest number color that is available, keeping in mind that the vertex cannot be colored the same as any adjacent vertex. Repeat this step until \(v_n\) is colored.
