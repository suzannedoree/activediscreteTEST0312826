Example 3.2.5. Checking first theorem of graph theory.

 
  1. Check Theorem 3.2.4 for the classmates graph drawn in Figure 3.1.7.
    Solution.
    The sum of the degrees is
    \begin{equation*} 3+3+3+2+1+0 = 12\text{.} \end{equation*}
    🔗
    The number of edges is \(\frac{12}{2}=6\text{,}\) as expected.

  2. In Activity 3.2.A (f), we considered whether there exists a 3-regular graph of order five. Use Theorem 3.2.4 to explain why there cannot exist such a graph.
    Solution.
    If there were such a graph, then the sum of the degrees would be
    \begin{equation*} 3+3+3+3+3 = 15 \end{equation*}
    which is an odd integer but, by Theorem 3.2.4, the sum of the degrees is twice the number of edges, which is an even integer. Since an integer cannot be even and odd (which we will formally prove in [cross-reference to target(s) "thm_div_alg" missing or not unique]), such a graph is impossible.
