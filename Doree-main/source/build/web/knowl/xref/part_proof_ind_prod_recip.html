Item (c).

Copy the following proof. Use mathematical induction to prove that \(\displaystyle \prod_{k=1}^nk=n!\) for \(n \ge 1\text{.}\)
Proof\(f(n) = n!\text{.}\)\(n\text{.}\)\(n=1\)\(\displaystyle \prod_{k=1}^1k=1=1\)\(f(1)=1!=1\text{.}\)\(\displaystyle \prod_{k=1}^{n-1}k=f(n-1)= (n-1)!\)\(n > s\text{.}\)
\begin{equation*} \prod_{k=1}^nk = \left(\prod_{k=1}^{n-1}k\right) \cdot n = f(n-1) \cdot n = \left((n-1)!\right) \cdot n = n(n-1)! =n! = f(n)\text{.} \end{equation*}
