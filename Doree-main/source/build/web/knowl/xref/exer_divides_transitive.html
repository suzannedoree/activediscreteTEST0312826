15. Understand.

  Use Proof 5.2.C.2, Proof 5.3.B.1, and Definition 4.1.6 to prove that if \(a \mid b\) and \(b \mid c\text{,}\) then \(a \mid c\) for any integers \(a\text{,}\) \(b\text{,}\) and \(c\text{.}\) Hint: Write \(b=ak_1\) and \(c=bk_2\) for some integers \(k_1\) and \(k_2\text{.}\) You cannot use the same integer \(k\) for both.
