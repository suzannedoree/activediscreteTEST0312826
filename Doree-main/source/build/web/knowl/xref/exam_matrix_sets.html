Example 8.3.4. Sets that involve matrices.

 
  1. Give two examples of elements in the set
    \begin{equation*} \left\{\left[ \begin{array}{cc} a \amp b \\ 0 \amp a \end{array} \right] \mid a, b \in \mathbb{Z} \right\} \end{equation*}
    Solution.
    We can choose any integer values of \(a\) and \(b\text{.}\) For example, when \(a = 2\) and \(b=3\text{,}\) we get the element \(\left[ \begin{array}{cc} 2 \amp 3 \\ 0 \amp 2 \end{array} \right]\text{.}\) As another example, when \(a = 1\) and \(b=0\text{,}\) we get the element \(I\text{.}\)

  2. Confirm that \(I\) and \(C = \left[ \begin{array}{cc} 0 \amp -1 \\ -1 \amp 0 \end{array} \right]\) are elements of the set \(\mathscr{B} = \left\{ B \in \mathscr{M}(\mathbb{Z}) \mid B^2=I \right\}\)
    Solution.
    We check that
    \begin{equation*} I^2 = \left[ \begin{array}{cc} 1 \amp 0 \\ 0 \amp 1 \end{array} \right] \left[ \begin{array}{cc} 1 \amp 0 \\ 0 \amp 1 \end{array} \right] = \left[ \begin{array}{cc} 1+0 \amp 0+0 \\ 0+0 \amp 0+1 \end{array} \right] = \left[ \begin{array}{cc} 1 \amp 0 \\ 0 \amp 1 \end{array} \right] = I\text{.} \end{equation*}
    Thus \(I \in \mathscr{B}\text{.}\) Next, we check that
    \begin{equation*} C^2= \left[ \begin{array}{cc} 0 \amp -1 \\ -1 \amp 0 \end{array} \right] \left[ \begin{array}{cc} 0 \amp -1 \\ -1 \amp 0 \end{array} \right] = \left[ \begin{array}{cc} 0+1 \amp 0+0 \\ 0+0 \amp 1+0 \end{array} \right] = \left[ \begin{array}{cc} 1 \amp 0 \\ 0 \amp 1 \end{array} \right] = I\text{.} \end{equation*}
    Thus \(C \in \mathscr{B}\text{.}\)

  3. Give an explicit definition of the set
    \begin{equation*} \mathscr{A}= \{ A \in \mathscr{M}(\mathbb{Z}) \mid NA = \mathbf{0}\} \end{equation*}
    where \(N = \left[ \begin{array}{cc} 1 \amp 2 \\ 1 \amp 2 \end{array} \right]\text{.}\)
    Solution.
    Suppose \(A = \left[ \begin{array}{cc} a \amp b \\ c \amp d \end{array} \right] \in \mathscr{A}\text{.}\) Then
    \begin{equation*} NA = \left[ \begin{array}{cc} 1 \amp 2 \\ 1 \amp 2 \end{array} \right] \left[ \begin{array}{cc} a \amp b \\ c \amp d \end{array} \right] = \left[ \begin{array}{cc} a+2c \amp b+2d \\ a+2c \amp b+2d \end{array} \right] = \left[ \begin{array}{cc} 0 \amp 0 \\ 0 \amp 0 \end{array} \right]\text{.} \end{equation*}
    We must have \(a+2c = 0\) which means \(a = -2c\text{.}\) We must also have \(b+2d = 0\) which means \(b = -2d\text{.}\) That is,
    \begin{equation*} A = \left[ \begin{array}{rr} -2c \amp -2d \\ c \amp d \end{array} \right]\text{.} \end{equation*}
    We can write
    \begin{equation*} \mathscr{A} = \left\{ \left[ \begin{array}{rr} -2c \amp -2d \\ c \amp d \end{array} \right] \mid c, d \in \mathbb{Z} \right\} \end{equation*}
