Definition 3.1.8. Degree of vertex.

 
  1. The degree of a vertex \(v\) in a graph \(G\text{,}\) denoted \(\fn{deg}_G(v)\) or just \(\fn{deg}(v)\text{,}\) is the number of edges of \(G\) that contain the vertex \(v\text{.}\) For example, in the graph \(G\) from Definition 3.1.2 Item 4 with vertex set \(\{1,2,3,4\}\) and edge set
    \begin{equation*} \{\{1,2\}, \{1,4\},\{2,3\},\{2,4\},\{3,4\}\}\text{,} \end{equation*}
    vertex 1 has degree two because 1 is an element of two edges: \(\{1,2\}\) and \(\{1,4\}\text{.}\) Vertex 2 has degree three because 2 is an element of three edges: \(\{1,2\}\text{,}\) \(\{2,3\}\text{,}\) and \(\{2,4\}\text{.}\) In the drawings in Figure 3.1.3, we see two edges to vertex 1 and three edges to vertex 2.
    🔗
    🔗
  2. Equivalently, the degree of a vertex is the number of neighbors of the vertex. For example, in the graph \(G\) from Definition 3.1.2 Item 4, vertex 1 has degree two because it has two neighbors, 2 and 4. Similarly, vertex 2 has degree three because it has three neighbors, 1, 3, and 4.
    🔗
    🔗
  3. An isolated vertex is a vertex with degree zero. For example, \(F\) is an isolated vertex in the classmates graph in Example 3.1.6, because Felipe was not a classmate of anyone else in the group of new transfer students. In 3.1.7 there are no edges to the vertex \(F\text{.}\)
    🔗
    🔗
  4. A end vertex (or leaf or pendant) is a vertex with degree 1. For example, in the classmates graph from Example 3.1.6, \(E\) is an end vertex because Elle was only in a class with Abdi. In 3.1.7 we see one edge to the vertex \(E\text{.}\)
