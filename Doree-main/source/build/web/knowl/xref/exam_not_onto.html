Example 6.3.24. Show functions are not onto.

Show that each function is not onto.
  1. The function \(f:\mathbb{R} \to \mathbb{R}\) is defined by \(f(x) = x^2+1\text{.}\)
    Solution.
    The function \(f\) is not onto because for any real number \(x\) we know that \(x^2 \ge 0\) and so \(f(x) \ge 1\text{.}\) For example, there is no value of \(x\) for which \(f(x) = 0\text{.}\) In the graph of \(f\text{,}\) shown in Figure 6.3.4, we can see that the lowest point on the graph is \((0,1)\) and the image of \(f\) is \([1,\infty)\) which is not all of the codomain \(\mathbb{R}\text{.}\)

  2. The function \(g: \mathbb{Z} \to \mathbb{Z}\) is defined by \(g(n) = 3n\text{.}\)
    Solution.
    The function \(g\) is not onto because the image is only multiples of 3. For example, there is no value of \(n\) for which \(g(n) = 5\text{.}\)

  3. The function \(l:\mathbb{B} \to \mathbb{Z}\) is defined by \(l(b) =\) the length of the bit string \(b\) where \(\mathbb{B}\) is the set of all bit strings.
    Solution.
    Since the length of a bit string is nonnegative, there is no bit string \(b\) with \(l(b) = -2\text{,}\) for example. Note that if we had set the codomain as \(\mathbb{N}\text{,}\) then the function would be onto.
    🔗

  4. The function \(\fn{twopart}: \mathbb{N} \to \mathbb{N}\) defined by \(\fn{twopart}(n)\) is the highest power of two that divides \(n\text{.}\) We saw this function in Activity 6.2.2.
    Solution.
    The image of twopart is the set of powers of two:
    \begin{equation*} \{1,2,4,8,16,\ldots\}\text{.} \end{equation*}
    Since the image is not all of the codomain \(\mathbb{N}\text{,}\) the function twopart is not onto. As a specific counterexample we could say \(\fn{twopart}(n) = 3\) has no solution.
