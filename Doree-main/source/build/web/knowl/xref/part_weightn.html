Item 4.

For a positive integer \(n\text{,}\) describe a bit string \(b\) such that \(\fn{wgt}(b) = n\text{.}\)
Solution.
We are looking for a bit string \(b\) that has weight \(n\) or, equivalently, that contains \(n\) 1 s. The simplest example is
\begin{equation*} b = \underbrace{\bs{11}\ldots\bs{1}}_{n}\text{,} \end{equation*}
the bit string with \(n\) 1s. Other answers are possible, such as
\begin{equation*} b = \bs{0}\underbrace{\bs{11}\ldots\bs{1}}_{n }\bs{0} \end{equation*}
