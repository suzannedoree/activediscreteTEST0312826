Definition 2.3.4. Binomial coefficient.

For non-negative integers \(k\) and \(n\text{,}\)
  1. The number of ways to select a subset of \(k\) elements from a set of \(n\) elements is the binomial coefficient \(\binom{n}{k}\) which is pronounced “\(n\) choose \(k\text{.}\)” For example, “5 choose 2” is \(\binom{5}{2} = 10\) because we saw in Activity 2.3.A that there are 10 ways to select two cats from a set of five cats.
    🔗
    🔗
  2. Note that if \(k>n\text{,}\) then \(\binom{n}{k}=0\text{.}\)
