Checkpoint 4.3.20. \exerE.

  An element \(a\) of \(\mathbb{Z}_n\) is a zero divisor if \(a \neq 0\) but there is an element \(b\) of \(\mathbb{Z}_n\) with \(b \neq 0\) also, and yet \(ab = 0\text{.}\) That is, if there is more than one 0 in the row for \(a\) in the multiplication table for \(\mathbb{Z}_n\text{.}\) ENDCheckpoint 4.3.16 asked for an example of a zero divisor in \(\mathbb{Z}_{10}\) and asked whether there were zero divisors in \(\mathbb{Z}_5\text{.}\) Conjecture which integers \(n\) have the property that \(\mathbb{Z}_n\) has zero divisors and which integers \(n\) have the property that \(\mathbb{Z}_n\) does not have zero divisors.
