Item 3.

Give an example of a true conditional statement that has a true converse.
Solution.
Consider the conditional statement If \(n\) is odd, then \(n+1\) is even. The converse is If \(n+1\) is even, then \(n\) is odd. We proved that both statements are true in Section 4.1 Checkpoint 4.1.22 and again in Section 5.3 Checkpoint 5.3.40.
