Definition 2.2.16. Factorial.

 
  1. When \(n\) is a positive integer, the factorial \(n!\) is the product of the consecutive integers \(1, 2, \ldots n\text{,}\) usually written in reverse order. For example,
    \begin{equation*} 5!=(5)(4)(3)(2)(1) = 120\text{.} \end{equation*}
    🔗
    🔗
  2. We often write
    \begin{equation*} n! = n(n-1)\cdots(3)(2)(1) \end{equation*}
    which can be misleading for small powers of \(n\text{.}\) For example, by definition,
    \begin{equation*} 2!=(2)(1) = 2 \ \ \text{ and } 1!=(1) = 1\text{.} \end{equation*}
    Neither of these factorials includes the integer 3 as a factor, even though the \(\ldots\) notation shows a factor of (3).
    🔗
    🔗
  3. It is convenient to define \(0!=1\text{.}\)
    🔗
    🔗
  4. Factorials are at the same priority in the order of operations as exponents in Definition 2.1.17. For example,
    \begin{equation*} 20+5! = 20 + 120 = 140\text{,} \end{equation*}
    while
    \begin{equation*} (20 +5)! = 25! \approx 1.55 \times 10^{25}\text{,} \end{equation*}
    definitely a different value.
    🔗
    🔗
