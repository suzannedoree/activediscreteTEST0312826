Theorem 4.5.5. Key observations for Euclidean Algorithm.

 
  1. Given positive integers \(a\) and \(n\) with \(a \ge n\text{,}\) we have
    \begin{equation*} \fn{gcd}(a,n) = \fn{gcd}(n,a ~\fn{mod}~ n)\text{.} \end{equation*}
    🔗
    🔗
  2. Since \(n \le a\) and \(a ~\fn{mod}~ n \lt n\text{,}\) the second gcd involves smaller positive integers.
    🔗
    🔗
  3. For any positive integer \(k\text{,}\) we have gcd\((k,0)=k\text{.}\)
