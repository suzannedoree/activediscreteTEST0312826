Example 7.2.7. Multiples of six are subset of evens.

Consider the sets
\begin{equation*} E=\{2k \mid k \in \mathbb{N}\} \end{equation*}
and
\begin{equation*} X = \{6k \mid k \in \mathbb{N}\} \end{equation*}
  1. Write \(E\) and \(X\) using a list and \(\ldots\) notation.
    Solution.
    We can write \(E = \{0,2,4,6, \ldots\}\) and \(X = \{0,6,12,18,\ldots\}\text{.}\)
    🔗
    🔗
    🔗
    🔗
  2. Prove that \(X\) is a subset of \(E\text{.}\)
    Solution.
    We need to prove: if \(n \in X\text{,}\) then \(n \in E\text{.}\) We use a direct proof of the conditional Proof 5.3.B.1.
    🔗
    Proof Let \(n \in X\text{.}\) By definition of \(X\) we can write \(n = 6k\) for some \(k \in \mathbb{N}\text{.}\) Note that
    \begin{equation*} n = 6k=2(3k) \end{equation*}
    and so \(n = 2k'\) where \(k'=3k \in \mathbb{N}\text{.}\) Therefore, by definition of \(X\text{,}\) it follows that \(n \in E\text{.}\)
    🔗
    🔗
    🔗
    🔗
  3. Prove that \(X\) is a proper subset of \(E\text{.}\)
    Solution.
    Since we know that \(X\) is a subset, it remains to show that \(X\) is proper. For that, all we need is an example of \(E-X\text{,}\) that is, an element of \(E\) that is not in \(X\text{.}\) Any even number that is not a multiple of 6 will do. For example, \(4 \in E\) but \(4 \notin X\text{.}\)
