Theorem 1.2.2. Steps multiply.

If we can build each example through a sequence of steps and if there are \(s\) ways to do the first step, and then for each way to do the first step there are \(t\) ways to do the second step, and then for each way to do the first two steps there are \(u\) ways to do the third step, and so on, then there are
\begin{equation*} s \times t \times u \times \ldots \end{equation*}
total ways to build an example.
