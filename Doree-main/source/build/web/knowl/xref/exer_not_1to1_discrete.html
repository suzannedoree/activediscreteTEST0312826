Checkpoint 6.3.48. \exerP.

Each of the following functions is not one-to-one. Give a specific counterexample to prove that the function is not one-to-one.
  1. As usual, let \(\mathbb{B}\) denote the set of all bit strings. The function \(\fn{runzero}: \mathbb{B} \to \mathbb{N}\) is defined by \(\fn{runzero}(b) =\) the longest number of consecutive 0 s in the bit string \(b\text{.}\)
    🔗
    🔗
  2. Let \(\mathbb{G}_{10}\) denote the set of all graphs with ten vertices. The function \(\chi: \mathbb{G}_{10} \to \mathbb{N}\) is defined by \(\chi(G)\) is the chromatic number of the graph \(G\text{.}\)
    🔗
    🔗
  3. Euler’s phi function \(\varphi: \mathbb{Z}^+ \to \mathbb{Z}^+\) is defined by \(\varphi(n)=\) the number of integers between 1 and \(n\) that are coprime to \(n\text{.}\)
