9. Understand.

We want to count ways to tile a \(1 \times n\) board using red (R), blue (B), and green (G) \(1 \times 1\) square tiles.
  1. Let \(a_n\) be the number of tilings that do not use any blue tiles. Write an explicit rule for \(a_n\text{.}\)
    🔗
    🔗
  2. Let \(b_n\) be the number of tilings that contain at least one blue tile. First, write an explicit rule for \(b_n\) and then, write a recursive definition for \(b_n\text{.}\) Hint: Break into cases based on whether the tiling starts with G, B, or R.
    🔗
    🔗
  3. Let \(c_n\) be the number of tilings where any green tile is immediately followed by a blue tile. Write a recursive definition for \(c_n\text{.}\)
