Activity 8.3.B. Matrix power proof by mathematical induction.

 
  1. For the matrix \(A = \left[ \begin{array}{cc} 1 \amp 1\\ 0 \amp 1 \end{array} \right]\text{,}\) in Example 8.3.2 we conjectured that \(A^n=\left[ \begin{array}{cc} 1 \amp n\\ 0 \amp 1 \end{array} \right]\) for \(n \ge 1\text{.}\) Copy the following proof by mathematical induction justifying our conjecture.

    Proof.
    Write \(M_n=\left[ \begin{array}{cc} 1 \amp n\\ 0 \amp 1 \end{array} \right]\text{.}\) Induct on \(n\text{.}\)
    🔗
    First, when \(n=1\) we have \(A^1 = A = \left[ \begin{array}{cc} 1 \amp 1\\ 0 \amp 1 \end{array} \right]\) and also \(M_1=\left[ \begin{array}{cc} 1 \amp 1\\ 0 \amp 1 \end{array} \right]\text{.}\)
    🔗
    Next, assume \(A^{n-1} = M_{n-1} = \left[ \begin{array}{cc} 1 \amp n-1 \\ 0 \amp 1 \end{array} \right]\) for some integer \(n \ge 2\text{.}\) Then
    \begin{equation*} A^n = AA^{n-1} =AM_{n-1} = \left[ \begin{array}{cc} 1 \amp 1\\ 0 \amp 1 \end{array} \right]\left[ \begin{array}{cc} 1 \amp n-1\\ 0 \amp 1 \end{array} \right] = \left[ \begin{array}{cc} 1+0 \amp (n-1)+1\\ 0+0 \amp 0+1 \end{array} \right] = \left[ \begin{array}{cc} 1 \amp n\\ 0 \amp 1 \end{array} \right]=M_n \end{equation*}
