Example 9.2.3. Quinary and octal conversions.

 
  1. Convert \((413)_5\) and \((1723)_8\) to decimal.
    Solution.
    First,
    \begin{align*} (413)_5 \amp =\underline{4}\cdot 5^2 +\underline{1}\cdot 5^1 +\underline{3}\cdot 5^0\\ \amp =\underline{4}\cdot 25 +\underline{1}\cdot 5 +\underline{3}\cdot 1\\ \amp = 108\text{.} \end{align*}
    🔗
    Next,
    \begin{align*} (1723)_8 \amp =\underline{1}\cdot 8^3 +\underline{7}\cdot 8^2 +\underline{2}\cdot 8^1 +\underline{3}\cdot 8^0\\ \amp =\underline{1}\cdot 512 +\underline{7}\cdot 64 +\underline{2}\cdot 8 +\underline{3}\cdot 1\\ \amp = 979\text{.} \end{align*}

  2. Convert 50 to base five and to base eight.
    Solution.
    First, since \(50 \lt 125 = 5^3\text{,}\) we only need to use 25, five, and one. Notice that \(50-25-25=0\) and so we have
    \begin{align*} 50 \amp = 25+25\\ \amp =\underline{2}\cdot 25 +\underline{0}\cdot 5 + \underline{0}\cdot 1\\ \amp = \underline{2}\cdot 5^2 + \underline{0} \cdot 5^1 + \underline{0} \cdot 5^0\\ \amp = (200)_5 \end{align*}
    🔗
    Next, since \(50 \lt 64 = 8^2\text{,}\) we only need to use eight and one. Notice that \(50-6(8) = 50-48 = 2\) and so we have
    \begin{align*} 50 \amp = 8+8+8+8+8+8+1+1\\ \amp =\underline{6}\cdot 8 + \underline{2}\cdot 1\\ \amp = \underline{6} \cdot 8^1 + \underline{2} \cdot 8^0\\ \amp = (62)_8 \end{align*}
