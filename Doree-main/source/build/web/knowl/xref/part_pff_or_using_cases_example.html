Item 3.

Copy the following example of a proof of an “or” statement using cases. Prove that \(n^2 \fn{ mod } 4 = 0\) or \(n^2 \fn{ mod } 4 = 1\) for any integer \(n\text{.}\) Yes, this proof was 4.2.29 in Section 4.2.

Proof.
Let \(n\) be an integer. Then \(n\) is either even or odd, by Example 4.2.9. We consider two cases.
🔗
Case 1: Assume that \(n\) is even. By the definition of even, we can write \(n = 2k\) for some integer \(k\text{.}\) Then
\begin{equation*} n^2=(2k)^2=4k^2=4(k^2) = 4q=4q+0 \end{equation*}
where \(q=k^2\) is an integer. Therefore, \(n^2 \fn{ mod } 4 = 0\text{.}\)
🔗
Case 2: Assume that \(n\) is odd. By the definition of odd, we can write \(n = 2k+1\) for some integer \(k\text{.}\) Then
\begin{equation*} n^2=(2k+1)^2 = (2k+1)(2k+1)=4k^2+4k+1 = 4(k^2+k) + 1 = 4q+1 \end{equation*}
where \(q =k^2+k\) is an integer. Therefore, \(n^2 \fn{ mod } 4 = 1\text{.}\)
🔗
In either case, we have \(n^2 \fn{ mod } 4 = 0\) or \(n^2 \fn{ mod } 4 = 1\text{.}\)
