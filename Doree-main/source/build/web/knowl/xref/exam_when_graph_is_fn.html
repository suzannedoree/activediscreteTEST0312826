Example 6.3.5. Determining whether a dot diagram or graph in the \(xy\)-plane is the rule for a function.

 
  1. How can we determine whether a dot diagram is the rule for a function? Give an example.
    Solution.
    Since each element of the domain is the first coordinate of one ordered pair, there must be exactly one arrow out of each element in the domain. For example, let \(X = \{1,2,3\}\) and \(Y = \{0,1,2,3,4\}\text{.}\) Consider the set of ordered pairs
    \begin{equation*} \{(1,0), (2,3), (3,3)\} \end{equation*}
    which we saw in Definition 6.3.2. This set of ordered pairs is the rule for a function. The dot diagram is drawn in Figure 6.3.6. Notice that there is exactly one arrow out the element 1 in the domain, exactly one arrow out the element 2 in the domain, and exactly one arrow out the element 3 in the domain.

  2. Give an example of a dot diagram that is not the rule for a function.
    Solution.
    Let \(X = \{1,2,3\}\) and \(Y = \{0,1,2,3,4\}\text{.}\) Consider the set of ordered pairs
    \begin{equation*} \{(2,1), (2,3), (3,2)\} \end{equation*}
    which we saw in Definition 6.3.2. This set of ordered pairs is not the rule for a function. The dot diagram is drawn in Figure 6.3.7. Notice that there are no arrows out of the element 1 in the domain. Also, there are two arrows out of the element 2.

  3. How can we determine whether a graph in the \(xy\)-plane is the rule for a function from \(\mathbb{R}\) to \(\mathbb{R}\text{?}\)
    Solution.
    Each element of the domain must be the \(x\)-coordinate of a point on the graph. That is, if we draw the vertical line \(x=a\) for any real number \(a\text{,}\) it must intersect the graph exactly once (not never and not twice or more). This result is known as the vertical line test. For example, Figure 6.3.8 shows the vertical lines \(x=-3\) and \(x=1\) each cross the parabola in exactly one point.

  4. Give an example of a graph in the \(xy\)-plane that is not the rule for a function from \(\mathbb{R}\) to \(\mathbb{R}\text{.}\)
    Solution.
    Consider the graph of the equation \(x^2+y^2=1\) which is the unit circle drawn in Figure 6.3.9. There are two reasons why the unit circle is not the graph of a rule of function. First, there are two points on the circle with \(x\)-coordinate equal 0.5, namely \(\left(\frac{1}{2},\frac{\sqrt{3}}{2}\right)\) and \(\left(\frac{1}{2},^-\frac{\sqrt{3}}{2}\right)\text{.}\) (We used a little trigonometry to get those points.) Second, there are no points on the unit circle with \(x\)-coordinate equal -1.5.
