Example 8.4.4. Proper bit strings of length up to five.

 
  1. Draw a possibility tree to list all proper bit strings of length up to five.
    Solution.
    We begin with the tree in Figure 8.4.3. Since we only want bit strings of length at most five, we can apply R1 and R2 to any bit string in that tree, but once we have a bit string of length four we can only apply R1. The tree is shown in Figure 8.4.5.

  2. How many proper bit strings of length five are there? How many improper bit strings of length five are there? Explain.
    Solution.
    We see in Figure 8.4.5 that there are eight proper bit strings of length five. They are
    \begin{equation*} \bs{00000}, \bs{10001}, \bs{10010}, \bs{10100}, \bs{11011}, \bs{11000}, \bs{11101}, \bs{11110}\text{.} \end{equation*}
    Recall from Theorem 2.4.7 that there are \(2^5=32\) bit strings of length five. Therefore, there are \(32-8 = 24\) improper bit strings of length five.

  3. Explain how we can obtain a list of proper bit strings of length five from the list of proper bit strings of length three and four.
    Solution.
    There are two ways to obtain a proper bit string of length five.
    🔗
    Case 1: Start with a proper bit string of length four and apply R1. The proper bit strings of length four are
    \begin{equation*} \bs{0000}, \bs{1001}, \bs{1010}, \bs{1100}, \bs{1111} \end{equation*}
    so we get
    \begin{equation*} \bs{0000\underline{0}}, \bs{1001\underline{0}}, \bs{1010\underline{0}}, \bs{1100\underline{0}}, \bs{1111\underline{0}} \end{equation*}
    🔗
    Case 2: Start with a proper bit string of length three and apply R2. The proper bit strings of length three are
    \begin{equation*} \bs{000}, \bs{101}, \bs{110} \end{equation*}
    so we get
    \begin{equation*} \bs{\underline{1}000\underline{1}}, \bs{\underline{1}101\underline{1}}, \bs{\underline{1}110\underline{1}} \end{equation*}
