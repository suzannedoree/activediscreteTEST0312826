Item 9.

The sequence \(u\) begins \(3, 9, 18, 30, 45, 63, \ldots\text{.}\)
Solution.
Since all the terms are multiples of three, let’s start by factoring out three from each term to get \(1, 3, 6, 10, 15, 21, \ldots\text{.}\) To get from each term to the next we add one, add two, then add three, then add four, so the answer likely involves \(1+2+3+ \ldots n-1=\frac{n(n-1)}{2}\) or \(1+2+3+ \ldots n = \frac{n(n+1)}{2}\text{,}\) which we first saw in the Handshakes Puzzle Activity 1.1.A. Let’s make a table comparing \(n\text{,}\) \(\frac{n(n-1)}{2}\text{,}\) and the terms of the sequence starting at \(n=1\text{,}\) in Table 6.5.15. Notice that we can get from the handshake numbers to the terms by multiplying by three. A possible formula is \(u_n = 3\frac{n(n-1)}{2}\) for \(n \ge 1\text{.}\)
