    Section 1.2 Quantifiers

    In Activity 1.1.A there were statements involving variables in which the truth of the statement depended on whether the statement was about all values, some values, or no values of the variables. Each of the words “all”, “some”, and “no” has a specific meaning in mathematics and computer science. In this section, we consider such quantifiers and their negations and formally introduce the idea of a counterexample. We also look at how to prove quantified statements.

    Subsection 1.2.B Quantifiers

    In the game SET\texttrademark, a set of three cards forms a SET if for each characteristic, all the cards agree or none of the cards agree. A set of three cards is not a SET if, for some characteristic, the cards have two of one kind and one of a different kind. Part of the challenge of learning the game is grappling with words like “each”, “all”, “none”, and “some” which are examples of quantifiers.
    🔗

    Definition 1.2.8. Quantifiers.

    Quantifiers can be defined on any set. Throughout this definition, our examples use the set of integers.
    1. We indicate that a statement \(P\) depends on a variable \(n\) by writing \(P(n)\) instead of \(P\text{.}\) The notation \(P(n)\) is predicate notation. For example, if \(P(n)\) means that the integer \(n\) is odd, then \(P(3)\) means that the integer \(3\) is odd, which is true, but \(P(10)\) means that the integer \(10\) is odd, which is false.
      🔗
      🔗
    2. The universal quantifier, denoted \(\forall\text{,}\) means “for all”.
      • The statement \(\forall n P(n)\) means that \(P(n)\) is true for all values of \(n\text{.}\) For example, if \(P(n)\) means that the integer \(2n\) is even, then \(\forall n ~ P(n)\) means that every integer of the form \(2n\) is even, which is true. On the other hand, if \(Q(n)\) means that \(3 \mid n\text{,}\) then \(\forall n ~ Q(n)\) means that every integer is divisible by three, which is false because, for example, 17 is not divisible by three.
        🔗
        🔗
      • The statement \(\forall n(\neg P(n))\) means \(P(n)\) is false for all values of \(n\text{.}\) For example, if \(R(n)\) means that the integer \(2n+1\) is even, then \(\forall n (\neg R(n))\) means that no integer of the form \(2n+1\) is even, which is true.
        🔗
        🔗
      🔗
      🔗
    3. The existential quantifier, denoted \(\exists\) means “there exists.”
      • The statement \(\exists n ~ P(n)\) means that \(P(n)\) is true for some value(s) of \(n\text{.}\) For example, if \(Q(n)\) means that \(3 \mid n\text{,}\) then \(\exists n ~ Q(n)\) means that some integer is divisible by three, which is true because, for example, 12 is divisible by three.
        🔗
        🔗
      • The statement \(\exists n (\neg P(n))\) means that \(P(n)\) is false for some value(s) of \(n\text{.}\) For example, if \(Q(n)\) means \(3 \mid n\text{,}\) then \(\exists n (\neg Q(n))\) means that some integer is not divisible by three, which is true because, for example, 17 is not divisible by three.
        🔗
        🔗
      🔗
      🔗
    🔗
    🔗
    There are many different English words and phrases that indicate quantifiers.
    🔗

    Remark 1.2.9. English words indicating quantifiers.

     
    1. Words and phrases that indicate a universal quantifier include: a, all, always, any, each, every, everyone, etc.
      🔗
      🔗
    2. Words and phrases that indicate a universal quantifier followed by a negation include: impossible, never, no, no one, none, nothing, etc.
      🔗
      🔗
    3. Words and phrases that indicate an existential quantifier include: at least one, can, contains, has, possible, some, someone, sometimes, there exist, there exists there is, there are, etc.
      🔗
      🔗
    4. Note that some words and phrases that indicate the existential quantifier are plural, but it takes only one value of \(n\) where \(S(n)\) is true to make the statement \(\exists n ~ S(n)\) true. For example, in mathematics, some means at least one.
      🔗
      🔗
    🔗
    🔗
    Universally quantified statements are sometimes written without an explicit quantifier. For example, we might say \(2n\) is even when we really mean \(2n\) is even for all integers \(n\text{.}\)
    🔗

    Remark 1.2.10. Default universal.

    If a statement about variables does not explicitly state a quantifier, the default assumption is that the quantifier is universal.

    Subsection 1.2.C Proof Formats: \(\forall\) and \(\exists\)

    How do we prove that a quantified statement is true?
    🔗
    To prove an existentially quantified statement, all we need to do is provide an example. Here is the proof format.
    🔗

    Proof.
    Prove: \(\exists n ~ P(n)\text{.}\)
    🔗
    Proof.
    Consider \(n=\) (example).
    🔗
    (Explain why \(P(n)\) is true.)
    🔗
    Therefore, \(P(n)\) is true for some (describe type of object) \(n\text{,}\) namely \(n=\) (example).
    🔗
    🔗
    🔗
    In the first sentence of Proof 1.2.C.1 we present an example without any explanation of how we found that example. Mathematicians sometimes explain where the example came from, but that explanation is not a required part of the proof. Let’s look at a quick example.
    🔗

    Example 1.2.12. There is a graph with five vertices and five edges.

    Prove Activity 1.2.B (a) that there is a graph that has five vertices and five edges.
    🔗
    Solution.
    The phrase “there is” indicates an existentially quantified statement, so we follow Proof 1.2.C.1.
    🔗
    Proof. Consider the cycle \(C_5\text{.}\) Recall that \(C_5\) has five vertices and five edges. Therefore, there is a graph that has five vertices and five edges, namely \(C_5\text{.}\)
    🔗
    🔗
    🔗
    The proof of a universally quantified statement is more complicated because we have to prove that the statement holds for all possible examples. In some cases, we can simply check every example.
    🔗

    Example 1.2.13. Checking every example.

    In [cross-reference to target(s) "sec_mod_arith" missing or not unique], we introduced the integers mod 5, \(\mathbb{Z}_5=\{0,1,2,3,4\}\text{.}\) In \(\mathbb{Z}_5\text{,}\) multiplication is defined by \(a \otimes b = ab \fn{ mod } 5\text{.}\) Prove that there is no solution to \(x^2=2\) in \(\mathbb{Z}_5\text{.}\) Note that \(x^2 = x \otimes x\text{.}\)
    🔗
    Solution.
    We can check each element of \(\mathbb{Z}_5\) to see if it is a solution. Our work is displayed in Table 1.2.14. Since none of the elements of \(\mathbb{Z}_5\) is a solution, we can conclude that there is no solution to \(x^2=2\) in \(\mathbb{Z}_5\text{.}\)
    🔗
    🔗
    🔗
    In the previous example, we were able to check all five possible examples. But if the list of possible examples is very long or infinite, it is not reasonable or possible to check every example, and it is not enough to just check some examples. Here is the proof format.
    🔗

    Proof.
    Prove: \(\forall n ~ P(n)\text{.}\)
    🔗
    Proof.
    Let \(n\) be an (describe the type of object).
    🔗
    (Explain why \(P(n)\) is true.)
    🔗
    Therefore, \(P(n)\) is true for all (describe the type of object) \(n\text{.}\)
    🔗
    🔗
    🔗
    The proof begins by naming an arbitrary object, \(n\text{,}\) of the type described. This first sentence invites the reader to select any value of \(n\text{.}\) Next, we show that the statement is true for that particular but unknown \(n\text{.}\) Our proof must work for whatever value \(n\) the reader selected.
    🔗
    Let’s look at a quick example.
    🔗

    Example 1.2.15. \(6q-10\) is even.

    Use the definition of even to prove that for every integer \(q\text{,}\) the integer \(6q-10\) is even. (This proof was [cross-reference to target(s) "sec_even_odd_divides" missing or not unique] Exercise [cross-reference to target(s) "exer_linears_even_odd" missing or not unique] [cross-reference to target(s) "part_6qminus10_is_even" missing or not unique].)
    🔗
    Solution.
    The phrase “for every” indicates a universally quantified statement, so we follow Proof 1.2.C.2.
    🔗
    Proof. Let \(q\) be an integer. Then \(6q-10=2(3q-5)=2k\) where \(k=3q-5\) is an integer. By the definition of even, it follows that \(6q-10\) is even. Therefore, for every integer \(q\text{,}\) the integer \(6q-10\) is even.
    🔗
    🔗
    🔗
    As usual, after we introduce new proof formats, we give you the opportunity to practice.

    Subsection 1.2.D Negating Quantified Statements and Counterexamples

    How do we prove that a quantified statement is false? To answer this question, we need to recognize the negations of quantified statements. You may want to revisit Activity 1.1.A and Activity 1.2.B to see if you can state these negations for yourself before reading on.
    🔗

    Theorem 1.2.18. Negating quantified statements.

    For any statement \(P(n)\text{,}\) we have the following negations of quantified statements.
    1. Negating a universally quantified statement:
      \begin{equation*} \neg \left( \forall n ~ P(n) \right) \equiv \exists n (\neg P(n))\text{.} \end{equation*}
      🔗
      🔗
    2. Negating an existentially quantified statement:
      \begin{equation*} \neg \left( \exists n ~ P(n) \right) \equiv \forall n (\neg P(n))\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Let’s unpack this theorem a bit.
    🔗

    Example 1.2.19. Negating a universally quantified statement.

     
    1. Explain why Theorem 1.2.18 (a) is correct.
      Solution.
      The statement \(\forall n ~ P(n)\) says \(P(n)\) is always true. The negation would say \(P(n)\) is not always true which is equivalent to saying \(P(n)\) is sometimes false.
      🔗
      The statement \(\exists n (\neg P(n))\) says \(\neg P(n)\) is sometimes true which is equivalent to saying \(P(n)\) is sometimes false.
      🔗
      Thus \(\neg(\forall n ~ P(n)) \equiv \exists n (\neg P(n))\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Explain why Theorem 1.2.18 (b) is correct.
      Solution.
      The statement \(\exists n ~ P(n)\) says \(P(n)\) is sometimes true. The negation would say \(P(n)\) is never true which is equivalent to saying \(P(n)\) is always false.
      🔗
      The statement \(\forall n (\neg P(n))\) says \(\neg P(n)\) is always true which is equivalent to saying \(P(n)\) is always false.
      🔗
      Thus \(\neg(\exists n ~ P(n)) \equiv \forall n (\neg P(n))\text{.}\)
      🔗
      🔗
      🔗
      🔗
    🔗
    🔗
    By Theorem 1.2.18, to prove that a universally quantified statement is false, all it takes is one example where it is false. There is a special name for an example that shows that a universally quantified statement is false.
    🔗

    Definition 1.2.20. Counterexample.

    A counterexample is an example where a universally-quantified statement is false. For example, a counterexample to the false statement Every square integer has exactly three positive divisors. from Activity 1.1.A (d) is the integer 16 because \(16=4^2\) is a square, but 16 has five positive divisors: 1, 2, 4, 8, and 16.
    🔗
    🔗
    Practice finding counterexamples.
    🔗
