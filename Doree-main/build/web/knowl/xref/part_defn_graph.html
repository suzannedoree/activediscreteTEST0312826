Item (d).

A (simple) graph (or network) is a pair of sets: a vertex set of vertices and a edge set of edges where the elements of each edge are in the vertex set. For example, we might have the graph \(G\) with the vertex set \(\{1,2,3,4\}\) and the edge set
\begin{equation*} \{\{1,2\},\{1,4\},\{2,3\},\{2,4\},\{3,4\}\}\text{.} \end{equation*}
