Remark 9.3.17. Recursive definition of partial product.

Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\) Then
\begin{align*} \prod_{k=s}^n a_k \amp = a_s \times a_{s+1} \times \ldots \times a_{n-1} \times a_n\\ \amp = (a_s \times a_{s+1}\times \ldots \times a_{n-1}) \times a_n\\ \amp = \left(\prod_{k=s}^{n-1} a_k\right) \times a_n \end{align*}
🔗
We can remember this recursion as
\begin{equation*} \underbrace{\prod_{k=s}^n a_k}_{\text{ new product } } = \underbrace{\prod_{k=s}^{n-1} a_k}_{\text{ previous product } } \times \underbrace{a_n}_{\text{ new term } } \end{equation*}
