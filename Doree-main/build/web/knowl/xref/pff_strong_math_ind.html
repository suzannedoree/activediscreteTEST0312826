Theorem 8.5.14. Proof Format: Mathematical Induction (First-order Strong).

Assuming that \(P(n)\) can be defined by a single initial condition and a recursion, we can prove \(P(n)\) for all integers \(n \ge s\) using (first-order) strong mathematical induction by adapting the following proof format.
🔗

Proof.
Induct on \(n\text{.}\) First, when \(n=s\) (explain why \(P(s)\) is true).
🔗
Next, assume for some integer \(n > s\) that \(P(k)\) for any integer \(k\) with \(s \le k\lt n\) .
🔗
Then (explain why \(P(n)\) is true).
