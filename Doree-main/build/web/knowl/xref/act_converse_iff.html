Activity 1.4.A. The converse and biconditional statements.

 
  1. State the converse of the following statement: if the graph \(G\) has a vertex of degree five, then the graph \(G\) has at least six vertices. Is the statement true? Is the converse true?
    🔗
    🔗
  2. State the converse of the following statement: for any integer \(k\text{,}\) if \(k >10\text{,}\) then \(k > 5\text{.}\) Is the statement true? Is the converse true?
    🔗
    🔗
  3. State the converse of the following statement: for any integer \(t\text{,}\) if \(t \ge 1\text{,}\) then \(t >0\text{.}\) Is the statement true? Is the converse true? Hint: \(t\) is an integer.
    🔗
    🔗
  4. True or false? For any integer \(m\text{,}\) \(4 \mid m^2\) if and only if \(4 \mid m\text{.}\)
    🔗
    🔗
