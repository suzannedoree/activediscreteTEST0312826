Activity 1.3.B. Direct proof of a conditional statement.

 
  1. Copy the following proof of a direct proof of a conditional statement. Note that we are using Proof 1.2.C.2 because the statement is universally quantified as well as Proof 1.3.B.1. Prove for any integer \(m\text{,}\) if \(m\) is odd then \(3m\) is odd.

    Proof.
    Let \(m\) be an integer. Assume that \(m\) is odd. By the definition of odd [cross-reference to target(s) "defn_even_odd" missing or not unique] we can write \(m=2k+1\) for some integer \(k\text{.}\) Then
    \begin{equation*} 3m=3(2k+1)=6k+3\text{.} \end{equation*}
    🔗
    (Side note: to show that \(3m\) is odd, we need to write \(6k+3\) in the form \(2()+1\text{.}\))
    🔗
    Note that
    \begin{equation*} 6k+3 = 6k+2+1 = 2(3k+1) + 1\text{.} \end{equation*}
    🔗
    Since \(3k+1\) is an integer, it follows from the definition of odd that \(3m\) is odd.
