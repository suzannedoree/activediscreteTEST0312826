Item (c).

Copy the following proof. Note that we use Proof 1.2.C.1 and, within that format, we use Proof 1.2.C.2. Notice that we are nesting the quantifiers in the opposite order from (a). We have indented the lines to highlight the nesting. Prove that there exists an integer \(z\) such that \(zn=z\) for any integer \(n\text{.}\)

Proof.
Consider the integer \(z=0\text{.}\)
🔗
Let \(n\) be an integer.
🔗
Then \(zn=(0)(n)=0=z\text{.}\)
🔗
Thus, \(zn=z\) for any integer \(n\text{.}\)
🔗
Therefore, there exists an integer \(z\) such that \(zn=z\) for any integer \(n\text{,}\) namely \(z=0\text{.}\)
