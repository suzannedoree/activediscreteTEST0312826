Activity 1.1.E. Proof by contradiction: consecutive integers are coprime.

 
  1. Copy the following example of a proof by contradiction. Prove \(\fn{gcd}(n,n+1)=1\) for any integer \(n\text{.}\)
     1 
    We proved this result in Exercise [cross-reference to target(s) "exer_consec_coprime" missing or not unique] using the Euclidean Algorithm.

    Proof.
    Suppose not. Then there exists an integer \(n\) such that \(d=\fn{gcd}(n,n+1)\neq 1\text{.}\)
    🔗
    First, by the definition of the greatest common divisor [cross-reference to target(s) "defn_gcd" missing or not unique], \(d \mid n\) and \(d \mid n+1\text{.}\) By the definition of divides [cross-reference to target(s) "defn_divides" missing or not unique] we can write \(n = dk_1\) and \(n+1 = dk_2\) for some integers \(k_1\) and \(k_2\text{.}\) Observe that
    \begin{equation*} (n+1) - n = dk_2 - dk_1 = d(k_2-k_1)=dq \end{equation*}
    where \(q = k_2-k_1\) and so \(d \mid (n+1)-n\text{.}\) But, of course, \((n+1)-n=1\) so really \(d \mid 1\text{.}\) Since the only positive divisor of 1 is 1, it follows that \(d =1\text{.}\)
    🔗
    On the other hand, we assumed that \(d \neq 1\text{.}\) This is a contradiction. Thus, \(\fn{gcd}(n,n+1)=1\text{.}\)
