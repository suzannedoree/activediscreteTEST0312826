Example 6.3.31. Examples of bijections.

Explain how we know each of the following functions is a bijection.
  1. The function \(f: \mathbb{N} \to \mathbb{N}\) defined by
    \begin{equation*} f(n) = \left\{ \begin{array}{cl} n+1 \amp \text{ if } n\text{ is even } \\ n-1 \amp \text{ if } n\text{ is odd } \end{array} \right\text{.} \end{equation*}
    Solution.
    We drew the graph of this function in Figure 6.3.18. Note that each point in the bottom row has exactly one arrow pointing into it, and so the function is a bijection.

  2. The function \(h: \mathbb{R} \to \mathbb{R}\) is defined by \(h(x) = 3x\text{.}\)
    Solution.
    Given a real number \(y\text{,}\) there is exactly one real number \(x\) such that \(h(x)=y\text{.}\) As we saw in Example 6.3.25, it must be \(x = \frac{y}{3}\text{.}\)

  3. Let \(\mathbb{G}\) be the set of all graphs. The function \(\fn{comp}: \mathbb{G} \to \mathbb{G}\) defined by \(\fn{comp}(G)= \overline{G}\text{,}\) the graph-theoretic complement of \(G\text{.}\)
    Solution.
    Given a graph \(H\text{,}\) there is exactly one graph \(G\) such that \(\fn{comp}(G) = H\text{,}\) namely \(G =\overline{H}\) because \(\fn{comp}(\overline{H}) = \overline{\overline{H}}=H\text{.}\)
