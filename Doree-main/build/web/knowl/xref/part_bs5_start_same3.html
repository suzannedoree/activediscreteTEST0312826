Item (e).

Let \(\mathbb{B}_5\) be the set of all bit strings of length 5. Consider the equivalence relation on \(\mathbb{B}_5\) defined by \(b \sim c\) if the bit strings \(b\) and \(c\) start with the same three bits. For example, \(\bs{11111} \sim \bs{11100}\) and \(\bs{10111} \sim \bs{10110}\text{.}\) Calculate \([11111]\) and \([10111]\text{.}\)
