Definition 6.3.26. One-to-one.

A function \(f: X \to Y\) is one-to-one (or injective) if for each element \(y\) of \(Y\text{,}\) there is at most one element \(x \in X\) such that \(f(x) =y\text{.}\) That is, for each element \(y\) in \(y\text{,}\) there is at most one ordered pair in the rule for \(f\) with second coordinate \(y\text{.}\) For example, the functions \(f\) and \(h\) defined by the dot diagrams in Figure 6.3.22 are one-to-one, but the functions \(g\) and \(k\) are not one-to-one because, for example \(g(2)=c=g(4)\) and \(k(2)=c=k(4)\text{.}\)
