Item (a).

Copy the following proof. Note that we use Theorem 5.2.16 and, within that format, we use Theorem 5.2.12. We have indented the lines to highlight the nesting. Prove that for any integer \(n\) there is an integer \(m\) such that \(n+m=100\text{.}\)

Proof.
Let \(n\) be an integer.
🔗
Consider the integer \(m=100-n\text{.}\)
🔗
Then \(n+m=n+(100-n)=100\text{.}\)
🔗
Thus, there is an integer \(m\) with \(n+m=100\text{,}\) namely \(m=100-n\text{.}\)
🔗
🔗
Therefore, for any integer \(n\) there is an integer \(m\) such that \(n+m=100\text{.}\)
