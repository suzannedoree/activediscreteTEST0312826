Item (k).

The sequence \(w\) begins \(1,1,2,2,3,3,4,4, \ldots\text{.}\)
Solution.
Notice that the terms repeat, so floor or ceiling is likely involved. Since each term repeats twice, let’s try \(\frac{n}{2}\text{.}\) Let’s make a table comparing \(n\text{,}\) \(\frac{n}{2}\text{,}\) and the terms of the sequence starting at \(n=1\text{,}\) in Table 6.5.17. Notice that the ceiling function works. A possible formula is \(w_n = \lceil \frac{n}{2} \rceil\) for \(n \ge 1\text{.}\)
