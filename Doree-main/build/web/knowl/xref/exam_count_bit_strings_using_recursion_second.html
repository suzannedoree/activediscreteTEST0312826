Example 8.5.10. Using a recursion to count bit strings that do not contain \bs{00}.

Write a recursion that counts the number of bit strings of length \(n\) that do not contain 00, meaning they do not contain two or more consecutive zeros.
🔗
Solution.
Write \(c_n=\) the number of bit strings of length \(n\) that do not contain 00. Note that neither bit strings of length 1 contains 00 and so \(c_1=2\text{.}\) Also note that three of the bit strings of length 2 do not contain 00, namely 01, 10, and 11, and so \(c_2=3\text{.}\) Given a bit string of length \(n\) that does not include 00, we consider two cases.
🔗
Case 1: The bit string begins with 1. In this case, the other \(n-1\) bits cannot include 00. There are \(c_{n-1}\) such bit strings.
🔗
Case 2: The bit string begins with 0. In this case, the next bit must be 1 so that we avoid 00. The other \(n-2\) bits cannot include 00. There are \(c_{n-2}\) such bit strings.
🔗
Since cases add Theorem 2.2.6, we have
\begin{equation*} c_n=c_{n-1}+c_{n-2} \end{equation*}
for \(n\ge 3\) and initial conditions \(c_1=2\) and \(c_2=3\text{.}\)
