For each relation, decide whether it is transitive. Explain briefly if it is transitive and construct a counterexample if not transitive.
  1. As usual \(\mathbb{B}^*\) denotes the set of all (non-empty) bit strings. Define a relation on \(\mathbb{B}^*\) by \(b \sim c\) if \(b\) is a substring of \(c\text{;}\) that is, if the bit string \(b\) appears in consecutive order within the bit string \(c\text{.}\) For example, \(\bs{101} \sim \bs{111010}\) as we can see \(\bs{11}\underline{\bs{101}}\bs{0}\text{.}\)
