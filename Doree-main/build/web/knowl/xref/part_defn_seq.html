Item (a).

A sequence is a function whose domain is a set of the form \(\{s,s+1,s+2,s+3,\ldots\}\) where \(s\) is an integer. Note that when \(s=0\) this set is \(\mathbb{N}\) and when \(s=1\) this set is \(\mathbb{Z}^+\text{.}\) For example, the function \(f: \mathbb{N} \to \mathbb{Q}\) defined by
\begin{equation*} f(n) = \frac{n-1}{n+1} \end{equation*}
is a sequence.
