Item (c).

Use the identity from (b) and mathematical induction to prove that \(3 \mid F_{4n}\) for \(n \ge 0\text{.}\)
Solution.
Proof First, when \(n=0\) we have \(F_{4(0)}=F_0=0\) and \(3 \mid 0\) so \(3 \mid F_{4(0)}\text{.}\)
🔗
Next, assume \(3 \mid F_{4(n-1)} = F_{4n-4}\) for some integer \(n > 0\text{.}\) By the definition of divides we can write \(F_{4n-4}=3k\) for some integer \(k\text{.}\) Then using the identity from (b) we have
\begin{align*} F_{4n} \amp = 5 F_{4n-4} + 3F_{4n-5}\\ \amp = 5(3k) + 3F_{4n-5}\\ \amp = 3(5k+F_{4n-5})\text{.} \end{align*}
🔗
Thus \(3 \mid F_{4n}\text{.}\)
