    Section 6.5 Explicitly-defined Sequences

    We began our exploration of discrete mathematics by listing and counting objects. But what exactly is a “list” when the list is infinite such as
    \begin{equation*} 1,3,5,7,9,11,\ldots? \end{equation*}
    🔗
    In this section, we define such infinite lists (sequences) using functions, look at examples of evaluating sequences, and practice modeling with sequences.
    🔗

    Subsection 6.5.A The Definition of Sequence

    We begin with a formal definition.
    🔗

    Definition 6.5.1. Sequence.

     
    1. A sequence is a function whose domain is a set of the form \(\{s,s+1,s+2,s+3,\ldots\}\) where \(s\) is an integer. Note that when \(s=0\) this set is \(\mathbb{N}\) and when \(s=1\) this set is \(\mathbb{Z}^+\text{.}\) For example, the function \(f: \mathbb{N} \to \mathbb{Q}\) defined by
      \begin{equation*} f(n) = \frac{n-1}{n+1} \end{equation*}
      is a sequence.
      🔗
      🔗
    2. A sequence starts at \(s\) if its domain is \(\{s,s+1,s+2,s+3,\ldots\}\text{.}\) For example, the sequence from (a) starts at 0 because the domain is \(\mathbb{N}\text{.}\) We primarily consider sequences that start at 0 or 1.
      🔗
      🔗
    3. As a shorthand, we use sequence notation to write \(a_n=f(n)\) for \(n \ge s\text{.}\) For example, the sequence from (a) can be defined by
      \begin{equation*} a_n = \frac{n-1}{n+1} \text{ for } n \ge 0\text{.} \end{equation*}
      This notation specifies the domain and rule for the function but not the codomain and so it should only be used when the codomain is clear from the context or stated separately.
      🔗
      🔗
    4. A sequence can be described using a list of its terms:
      \begin{equation*} a_s, a_{s+1}, a_{s+2}, \ldots\text{.} \end{equation*}
      For example, in the sequence from (a) we calculate
      \begin{align*} a_0 \amp = \frac{0-1}{0+1}=\frac{-1}{1}=-1\\ a_1 \amp = \frac{1-1}{1+1}=\frac{0}{2}=0\\ a_2 \amp = \frac{2-1}{2+1}=\frac{1}{3}\\ a_3 \amp = \frac{3-1}{3+1}=\frac{2}{4}=\frac{1}{2}\\ a_4 \amp = \frac{4-1}{4+1}=\frac{3}{5}\\ a_5 \amp = \frac{5-1}{5+1}=\frac{4}{6}=\frac{2}{3} \end{align*}
      and so the sequence corresponds to the list beginning
      \begin{equation*} -1, 0, \frac{1}{3}, \frac{1}{2}, \frac{3}{5}, \ldots\text{.} \end{equation*}
      🔗
      🔗
    5. We can list the first few terms of a sequence using a table, as in Table 6.5.2. For example, we can list the first terms of \(a_n = \frac{n-1}{n+1}\) for \(n \ge 0\) in Table 6.5.3.
      🔗
      🔗
    6. The expression \(a_n\) is pronounced “\(a\) sub \(n\)”. The (input) value of \(n\) is the index of the term and the (output) value of \(a_n\) is the term of the sequence. For example, in the sequence from (a), the term \(a_3\) is \(\frac{1}{2}\) and its index is \(3\text{.}\)
      🔗
      🔗
    7. A sequence is explicitly-defined (or in closed form) if there is a rule for \(a_n\) that depends only on \(n\) and constants. For example, the sequence from (a) is explicitly-defined.
      🔗
      🔗
    🔗

      Solution.

      \begin{equation*} b_6=\pi_6+\pi_7=13+17=30\text{.} \end{equation*}
