    Subsection 3.3.B Coloring Graphs

    Let’s formalize the idea of coloring the vertices of a graph.
    🔗

    Definition 3.3.4. Chromatic number.

     
    1. A (vertex) coloring of a graph is an assignment of a color to each vertex in such a way that adjacent vertices have different colors.
      🔗
      🔗
    2. A \(k\)-coloring of a graph is a vertex coloring using \(k\) colors. For example, the graph in Figure 3.3.13 has a 3-coloring.
      🔗
      🔗
    3. A graph is \(k\)-colorable if there exists a coloring using \(k\) or fewer colors.
      🔗
      🔗
    4. The chromatic number of a graph is the smallest number of colors needed to color the graph. For example, the complete bipartite graph, \(K_{6,3}\text{,}\) shown in Figure 3.2.9 has chromatic number two because it can be colored using two colors (black and white) and one color would not work because there are adjacent vertices.
      🔗
      🔗
    🔗
    🔗
    Let’s look at a few examples.
    🔗

    Example 3.3.5. Chromatic number of complete graph and cycle.

    Determine the chromatic number \(k\) of each graph by finding a \(k\)-coloring and then explaining why all \(k\) colors are necessary.
    1. The complete graph \(K_5\text{.}\)
      Solution.
      First, we can color each vertex its own color using five colors. Since any pair of vertices in \(K_5\) are adjacent, they must be different colors and so we cannot use fewer than five colors. Thus, the chromatic number of \(K_5\) is five.
      🔗
      🔗
      🔗
      🔗
    2. The cycle \(C_5\text{.}\)
      Solution.
      If we try to color the vertices of \(C_5\) using only two colors (gray and black), as shown in Figure 3.3.6, we run into a problem. The fifth vertex cannot be gray (because it is adjacent to a vertex colored gray) and it cannot be black (because it is adjacent to a vertex colored black). It must be a third color, say white.
      🔗
      Notice that Figure 3.3.6 actually shows that three colors (gray, black, and white) work. Thus, the chromatic number of \(C_5\) is three.
      🔗
      🔗
      🔗
      🔗

    Subsection 3.3.C Graph Conjectures

    We have looked at several specific graphs and calculated quantities such as the number of vertices and edges, the degree sequence, and the chromatic number. What about families of graphs? Let’s look at an example.
    🔗

    Example 3.3.14. Graph conjectures for the complete graphs.

    Consider the complete graphs \(K_s\) for \(s \ge 1\text{.}\) Conjecture the number of vertices and edges, the degree sequence, and the chromatic number of \(K_s\text{.}\) Some of your answers should involve \(s\text{.}\)
    🔗
    Solution.
    By definition, \(K_s\) has \(s\) vertices. Recall that \(K_s\) models the number of handshakes in a group of \(s\) people. By Theorem 1.1.3, the number of edges is \(1+2+3+\ldots+(s-1) = \frac{s(s-1)}{2}\text{.}\) Alternatively, there is an edge for each pair of vertices. Thus, the number of edges is equal to the number of ways to select two out of \(s\) vertices, which is \(\binom{s}{2}\text{.}\)
    🔗
    Each vertex in \(K_s\) is adjacent to each of the other \(s-1\) vertices. Therefore, the degree sequence is
    \begin{equation*} \underbrace{s-1,s-1,s-1, \ldots, s-1}_{s \text{ times } } \end{equation*}
    🔗
    We can color the vertices of \(K_s\) with \(s\) colors by assigning each vertex its own color. Because each vertex is adjacent to every other vertex, no two vertices can be the same color. Thus, all \(s\) colors are necessary. The chromatic number of \(K_s\) is \(s\text{.}\)
    🔗
    🔗
    🔗
    We summarize the number of edges of the complete graph \(K_s\) for later reference.
    🔗

    Theorem 3.3.15. Number of edges in the complete graphs.

    For any positive integer \(s\text{,}\) the complete graph \(K_s\) has
    \begin{equation*} 1+2+3+\ldots+(s-1) = \frac{s(s-1)}{2} = \binom{s}{2} \end{equation*}
    edges.
    🔗
    🔗
