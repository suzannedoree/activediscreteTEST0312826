    Subsection 5.1.B And and Or

    In Activity 5.1.A, there are many words that indicate the logical structure of a statement. Two important such words are “and” and “or”, each of which has a specific technical meaning in mathematics and computer science.
    🔗

    Definition 5.1.1. And, or, and xor.

     
    1. A statement is a sentence that is either true or false. For example, if the statement \(P\) is “the integer six has exactly four positive divisors”, then \(P\) happens to be true because the positive divisors of six are 1, 2, 3, and 6. If the statement \(Q\) is “the cycle \(C_5\) has a vertex of degree three”, then \(Q\) is false because all the vertices of \(C_5\) have degree two.
      🔗
      🔗
    2. For statements \(P\) and \(Q\text{,}\) the statement “\(P\) and \(Q\)”, denoted \(P \land Q\text{,}\) is true if both \(P\) and \(Q\) are true and false otherwise. For example, the statement “the integer seven is positive and odd” is true because seven is positive and seven is odd. The statement “the integer six is positive and odd” is false, even though six is positive because six is not odd.
      🔗
      🔗
    3. For statements \(P\) and \(Q\text{,}\) the statement “\(P\) or \(Q\)”, denoted \(P \lor Q\text{,}\) is true if at least one of \(P\) and \(Q\) are true and false otherwise. For example, the statement “the integer six is positive or odd” is true, because six is positive. The statement “a graph with five vertices is either the cycle \(C_5\) or the complete graph \(K_5\)” from Activity 5.1.A (f) is false because, for example, the graph \(P_5\) has five vertices but it is not a cycle and it is not complete.
      🔗
      🔗
    4. Note that \(P \lor Q\) is true if both \(P\) and \(Q\) are true. For example, the statement “the integer seven is positive or odd” is true. This use of “or” is the inclusive or because it includes the possibility of both statements being true.
      🔗
      🔗
    5. When we want to exclude the possibility of both statements being true, we use the exclusive or instead. For statements \(P\) and \(Q\text{,}\) the statement “\(P\) xor \(Q\)”, denoted \(P \oplus Q\text{,}\) is true if one of \(P\) and \(Q\) is true and the other is false and false otherwise. For example, when I told my kids “you can have ice cream or brownies for dessert” they suggested brownies with ice cream (the inclusive or), but I probably meant one or the other but not both (the exclusive or). As another example, in Example 4.2.9 we showed that “every integer is either even or odd, but never both” which we could write more concisely as “every integer is even xor odd”.
      🔗
      🔗
    6. One way to summarize when a compound statement is true or false is to use a truth table which includes a column for each component of the compound statement (such as \(P\text{,}\) \(Q\)) and for the full compound statement (such as \(P \land Q\)) and a row for each possible combination of true or false for the component statements. For example, if our components are \(P\) and \(Q\text{,}\) then the truth table will have four rows corresponding to the four possibilities:
      • \(P\) is true and \(Q\) is true;
        🔗
        🔗
      • \(P\) is true and \(Q\) is false;
        🔗
        🔗
      • \(P\) is false and \(Q\) is true; and
        🔗
        🔗
      • \(P\) is false and \(Q\) is false.
        🔗
        🔗
      In this textbook we abbreviate true as \(\str{T}\) and false as \(\str{F}\text{.}\) Some computer science textbooks use \(\bs{1}\) for true and \(\bs{0}\) for false instead.

    Subsection 5.1.C Proof Formats: And and Or Using Cases

    How can we prove statements involving and and or? To prove \(P \land Q\text{,}\) we need to prove two things: \(P\) and then \(Q\text{.}\) We can summarize this idea in a proof format.
    🔗

    Theorem 5.1.9. Proof Format: And.

    We can prove \(P \land Q\) by adapting the following proof format.
    🔗
    Proof.
    First, (explain why \(P\) is true.) Therefore, \(P\text{.}\)
    🔗
    Next, (explain why \(Q\) is true.) Therefore, \(Q\text{.}\)
    🔗
    🔗
    🔗
    The format for a proof of \(P \lor Q\) is less direct. An option is to use a modified version of a proof by cases. Later in this textbook, we introduce two other options: proof by contradiction in Subsection 5.1.E and proof using the equivalent conditional in Subsection 5.3.B.
    🔗
    In Subsection 4.2.C we introduced proof by cases. In each case of the format in Subsection 4.2.C, we proved the same statement. We can modify that proof format to prove \(P \lor Q\) by proving \(P\) in one case and \(Q\) in the other case.
    🔗

    Theorem 5.1.10. Proof Format: Or Using Cases.

    We can prove \(P \lor Q\) using cases by adapting the following proof format.
    🔗
    Proof.
    (Explain why there are two cases.) We consider two cases.
    🔗
    Case 1: Assume …. (Explain why \(P\) is true in this case.) Therefore, \(P\text{.}\)
    🔗
    Case 2: Assume …. (Explain why \(Q\) is true in this case.) Therefore, \(Q\text{.}\)
    🔗
    In either case, we have \(P \lor Q\text{.}\)
    🔗
    🔗
    🔗
    We present this format with two cases, since that is often all we need. This format can be modified to have more than two cases where in some cases \(P\) is true and in other cases \(Q\) is true. Officially, this is a new proof format.
    🔗

    Theorem 5.1.11. Proof Format: Or Using Cases, Generalized.

    We can prove \(P_1 \lor P_2 \lor \cdots \lor P_k\) using cases by adapting the following proof format.
    🔗
    Proof.
    (Explain why there are \(n\) cases.) We consider \(n\) cases.
    🔗
    Case 1: Assume … (Explain why one of \(P_1, P_2, \ldots P_k\) is true in this case.)
    🔗
    Case 2: Assume … (Explain why one of \(P_1, P_2, \ldots P_k\) is true in this case.)
    🔗
    …
    🔗
    Case \(n\text{:}\) Assume … (Explain why one of \(P_1, P_2, \ldots P_k\) is true in this case.)
    🔗
    In (either case/all cases) we have \(P_1 \lor P_2 \lor \cdots \lor P_k\text{.}\)
    🔗
    🔗
    🔗

    Subsection 5.1.D Logical Equivalence and Negations

    In Activity 5.1.B, we saw that the statements \((P \lor Q) \land R\) and \((P \land R) \lor (Q \land R)\) have the same final column in their truth table. That is, in each case (row of the truth table), they are both true or both false. We have a name for the situation where two logical statements have the same truth values.
    🔗

    Definition 5.1.12. Logical equivalence.

     
    1. Statements \(S\) and \(T\) are logically equivalent, denoted \(S \equiv T\text{,}\) if \(S\) and \(T\) always have the same truth value, either both statements are true or both statements are false. For example, we saw in Activity 5.1.B that
      \begin{equation*} (P \lor Q) \land R \equiv (P \land R) \lor (Q \land R)\text{.} \end{equation*}
      🔗
      🔗
    2. Statements \(S\) and \(T\) are not logically equivalent, denoted \(S \not \equiv T\) if sometimes one of the statements is true but the other is false. For example,
      \begin{equation*} (P \lor Q) \land R \not \equiv P \lor (Q \land R) \end{equation*}
      as we check in Exercise 4 because, for example, when \(P\) is true and both \(Q\) and \(R\) are false, the left-hand side \((P \lor Q) \land R\) is false but the right-hand side \(P \lor (Q \land R)\) is true.
      🔗
      🔗
    🔗
    🔗
    Logically equivalent statements always have the same truth values. There is also a name for when two statements always have the opposite truth value as well as names for logical statements that are always true or always false.
    🔗

    Definition 5.1.13. Negation, tautology, and contradiction.

     
    1. The statements \(S\) and \(T\) are negations if \(S\) and \(T\) always have the opposite truth value. That is, \(S\) is true and \(T\) is false or \(S\) is false and \(T\) is true. The statement \(T\) is the negation of \(S\text{,}\) denoted \(\neg S\text{.}\) For example, if \(n\) is an integer and if \(S\) is the statement “\(n >2\)”, then \(\neg S\) is the statement “\(n \le 2\)”.
      🔗
      🔗
    2. A statement \(S\) is a tautology if it is always true. For example, the statement “either I will work on my homework Tuesday night or I will not work on my homework Tuesday night” is a tautology.
      🔗
      🔗
    3. A statement \(S\) is a contradiction if it is always false. For example, the statement “there is an integer \(n\) with \(n>2\) and \(n^2\lt 4\)” is a contradiction because for an integer \(n\) with \(n>2\) we know that \(n^2 > 4\text{.}\)
      🔗
      🔗
    🔗
    🔗

    Subsection 5.1.E Proof Format: Contradiction

    One method of proving that the statement \(P\) is true is to show that the assumption that \(P\) is false leads to a contradiction, such as a statement of the form \(Q \land \neg Q\text{.}\) That is, in a proof by contradiction of a statement \(P\text{,}\) we assume that \(P\) is false and deduce that both \(Q\) and \(\neg Q\) are true for some statement \(Q\text{,}\) which is impossible. That impossibility tells us that \(P\) cannot be false, and so \(P\) must be true.
    🔗
    As we start writing a proof by contradiction, we usually do not know what the statement \(Q\) will be. Sometimes it helps to do a little scratch work listing the consequences of \(P\) being false to see if we find contradictory statements \(Q\) and \(\neg Q\text{.}\)
    🔗
    A proof by contradiction follows the following proof format.
    🔗

    Theorem 5.1.20. Proof Format:Proof by Contradiction.

    We can prove \(P \) using proof by contradiction by adapting the following proof format.
    🔗
    Proof.
    Suppose not. Then (state \(\neg P\)).
    🔗
    First, (explain why \(Q\) is true.) Therefore, \(Q\text{.}\)
    🔗
    On the other hand, (explain why \(\neg Q\) is true.) Therefore, \(\neg Q\text{.}\)
    🔗
    This is a contradiction. Therefore, \(P\text{.}\)
    🔗
    🔗
    🔗
    Notice that we are proving two things (\(Q\) and \(\neg Q\)), but instead of saying “First, …. Next, ….” as we did in Theorem 5.1.9, we use the expression “First, …. On the other hand, ….” The phrase ``on the other hand`` alerts the reader that we are changing direction towards the negation of what we just proved. It is also acceptable to write ``On the one hand, …. On the other hand, …."

    🔗
    Let \(n\) be an integer. Write \(d=\fn{gcd}(n,n+1)\text{.}\) Since 1 is a common divisor of any integer, \(d\) is certainly positive.
    🔗
    First, by the definition of greatest common divisor Definition 4.5.1, \(d \mid n\) and \(d \mid n+1\text{.}\) By the definition of divides Definition 4.1.6 we can write \(n = dk_1\) and \(n+1 = dk_2\) for some integers \(k_1\) and \(k_2\text{.}\) Observe that
    \begin{equation*} (n+1) - n = dk_2 - dk_1 = d(k_2-k_1) \end{equation*}
    and so \(d \mid (n+1)-n\text{.}\) But, of course, \((n+1)-n=1\) so really \(d \mid 1\text{.}\) Since the only positive divisor of 1 is 1, it follows that \(d =1\text{.}\)
    🔗
    On the other hand, we assumed that \(d \neq 1\text{.}\) This is a contradiction. Thus \(\fn{gcd}(n,n+1)=1\text{.}\)
