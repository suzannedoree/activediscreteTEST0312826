Definition 8.4.1. Proper bit strings.

 
  1. A bit string is proper if it can be constructed from the initial condition B by applying the recursions R1 and/or R2 a finite number of times each in any order where
    🔗
    • B: The empty bit string \(\lambda\) is proper.
      🔗
      🔗
    • R1: If the bit string \(b\) is proper, then the bit string \(b\bs{0}\) is also proper.
      🔗
      🔗
    • R2: If the bit string \(b\) is proper, then the bit string \(\bs{1}b\bs{1}\) is also proper.
      🔗
      🔗
    For example, \(\bs{1100110}\) is proper, as we show in Example 8.4.2 (a).
    🔗
    🔗
  2. All other bit strings are improper. For example, \(\bs{011}\) is improper, as we show in Example 8.4.2 (b).
