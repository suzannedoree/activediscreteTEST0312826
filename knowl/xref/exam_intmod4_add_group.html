Example 8.3.6. \(\mathbb{Z}_4\) is a group under addition.

In Section 4.3 we saw that the integers mod 4 is the set \(\mathbb{Z}_4 =\{0,1,2,3\}\) with addition defined by \(a \oplus b = (a+b) \fn{ mod } 4\text{.}\)

  2. Check that \(\mathbb{Z}_4\) is a group under addition.
    Solution.
    First, every entry in table is 0, 1, 2, or 3 so \(\mathbb{Z}_4\) is closed under \(\oplus\text{.}\) Next, \(\oplus\) is associative because
    \begin{equation*} a \oplus (b \oplus c) = (a+(b+c)) \fn{ mod } 4 = ((a+b)+c) \fn{ mod } 4 = (a \oplus b) \oplus c \end{equation*}
    where we used that addition in \(\mathbb{Z}\) is associative. The identity element is 0, as you can check in the table. Note that \(0\oplus0 = 0\text{,}\) \(1 \oplus 3 = 0\text{,}\) \(2 \oplus 2 = 0\text{,}\) and \(3 \oplus 1 = 0\text{.}\) Therefore, the inverse of 0 is 0, the inverse of 1 is 3, the inverse of 2 is 2, and the inverse of 3 is 1. Sometimes we say the additive identity or the additive inverse to emphasis the operation is addition.
