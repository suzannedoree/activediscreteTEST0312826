Definition 2.3.2. Subsets.

 
  1. A subset of the set \(A\) is a set consisting of some of the elements of \(A\text{,}\) where the word “some” is understood to be any number of elements– from none to all. That is, the set \(T\) is a subset of the set \(A\text{,}\) denoted \(T \subseteq A\) if every element of \(T\) is also an element of \(A\text{.}\) For example, \(\{2,8\} \subseteq \{1,2,3,7,8\}\) and \(\{3\} \subseteq \{1,2,3,7,8\}\text{.}\) Note that the set \(A\) is a subset of itself. For example, \(\{1,2,3,7,8\} \subseteq \{1,2,3,7,8\}\text{.}\)

  2. The empty set \(\varnothing\) is the set with no elements. That is \(\varnothing=\{ ~\}\text{.}\) Note that \(\varnothing\) is a subset of any set. Imagine corralling no elements or drawing a shaded shape within \(A\) that contains none of the elements of \(A\text{.}\) For example, \(\varnothing \subseteq \{1,2,3,7,8\}\text{.}\)
