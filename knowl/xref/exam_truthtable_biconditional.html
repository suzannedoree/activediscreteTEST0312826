  2. Use this truth table to explain when the biconditional \(P \leftrightarrow Q\) is true and when it is false.
    Solution.
    The biconditional \(P \leftrightarrow Q\) is true when \(P\) and \(Q\) are both true (row 1) or \(P\) and \(Q\) are both false (row 4). That is, \(P \leftrightarrow Q\) is true when \(P\) and \(Q\) have the same truth value meaning \(P \equiv Q\text{.}\) On the other hand, the biconditional \(P \leftrightarrow Q\) is false when \(P\) is true but \(Q\) is false (row 2) or when \(P\) is false but \(Q\) is true (row 3). That is, \(P \leftrightarrow Q\) is false when \(P\) and \(Q\) have the opposite truth value meaning \(Q \equiv \neg P\text{.}\)
