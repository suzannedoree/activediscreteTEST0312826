Remark 9.3.5. Recursive definition of partial sums.

Consider a list of numbers \(a_s, a_{s+1}, a_{s+2}, \ldots, a_n\) for some integers \(s\) and \(n\text{.}\) Then
\begin{align*} \sum_{k=s}^n a_k \amp = a_s + a_{s+1} + \ldots + a_{n-1} + a_n\\ \amp = (a_s + a_{s+1} + \ldots + a_{n-1}) + a_n\\ \amp = \left(\sum_{k=s}^{n-1} a_k\right) + a_n \end{align*}
🔗
We can remember this recursion as
\begin{equation*} \underbrace{\sum_{k=s}^n a_k}_{\text{ new sum } } = \underbrace{\sum_{k=s}^{n-1} a_k}_{\text{ previous sum } } + \underbrace{a_n}_{\text{ new term } } \end{equation*}
