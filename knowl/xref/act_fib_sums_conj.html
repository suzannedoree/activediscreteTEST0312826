Activity 9.3.C. Fibonacci sums conjectures.

Recall that the Fibonacci numbers are defined by \(F_0=0\text{,}\) \(F_1=1\text{,}\) and \(F_n = F_{n-1}+F_{n-2}\) for \(n \ge 2\text{.}\) The first few Fibonacci numbers are listed in Table 9.3.21.

  1. Calculate the first six partial sums and use pattern recognition to conjecture an explicit formula for the sum
    \begin{align*} \sum_{k=1}^nF_{2k} \amp = F_2+F_4+F_6+F_8+F_{10}+F_{12}+\ldots +F_{2n}\\ \amp = 1+3+8+21+55+144+ \ldots +F_{2n} \end{align*}
    Hint: Add one to each partial sum to see the pattern.
