Item (e).

Copy the following proof. Use mathematical induction to prove that \(\displaystyle \sum_{k=1}^nF_{2k}=F_{2n+1}-1\) for \(n \ge 1\) where, as usual, the Fibonacci numbers are defined by \(F_0=0\text{,}\) \(F_1=1\text{,}\) and \(F_n=F_{n-1} + F_{n-2}\) for \(n \ge 2\text{.}\) “Proof Write \(f(n) = F_{2n+1}-1\text{.}\) Induct on \(n\text{.}\) First, when \(n=1\) we have \(\displaystyle\sum_{k=1}^1F_{2k}=F_{2(1)}=F_2=1\) and also
\begin{equation*} f(1) = F_{2(1)+1}-1=F_3-1=2-1=1\text{.} \end{equation*}
Next, assume
\begin{equation*} \sum_{k=1}^{n-1}F_{2k} = f(n-1) = F_{2(n-1)+1}-1 = F_{2n-1}-1 \end{equation*}
for some integer \(n > 1\text{.}\) Then
\begin{align*} \sum_{k=1}^nF_{2k} \amp = \left( \sum_{k=1}^{n-1}F_{2k} \right) + F_{2n} = f(n-1) + F_{2n} = \left(F_{2n-1}-1\right)+F_{2n}\\ \amp = \left(F_{2n} + F_{2n-1}\right) -1 = F_{2n+1}-1 = f(n) \end{align*}
The next-to-last equality uses the recursive definition the Fibonacci numbers to conclude that the sum of the consecutive terms \(F_{2n}\) and \(F_{2n-1}\) equals the next term, \(F_{2n+1}\text{.}\)” Note: We saw this summation in Activity 9.3.C (a) and Example 9.3.22.
