Example 6.1.26. Dot diagram for \(\fn{lshift}\).

Draw the dot diagram for the function \(\fn{lshift}: \mathbb{Z} \to \mathbb{Z}\) defined by \(\fn{lshift}(m) = m-1\text{.}\)
🔗
Solution.
Since the domain and codomain are the set \(\mathbb{Z}\) which is infinite, let’s draw the points in two horizontal lines. Figure 6.1.27 shows a portion of the dot diagram, along with … on each end to indicate that the pattern continues in both directions. We have drawn arrows from each integer \(m\) to \(\fn{lshift}(m)\text{,}\) that is from \(m\) to \(m-1\text{.}\) Many arrows are missing. For example, the diagram does not show the arrow from -3 in the top row to -4 in the bottom row and does not show the arrow from 4 in the top row to 3 in the bottom row.
