Example 4.2.8. Multiplying polynomials.

 
  1. Expand \(n^2(2n+1)\text{.}\)
    Solution.
    By the distributive rule,
    \begin{equation*} n^2(2n+1) = n^2(2n) + n^2(1) = 2n^3+n^2\text{.} \end{equation*}

  2. Expand \((n+2)(n+3)\text{.}\)
    Solution.
    By the distributive rule (repeatedly),
    🔗
    \((n+3)(n+2)\) = \(n(n+2) + 3(n+2)\)
    = \(\underbrace{(n)(n)}_{\text{ First } } +\underbrace{(n)(2)}_{\text{ Outside } } + \underbrace{(3)(n)}_{\text{ Inside } } + \underbrace{(3)(2)}_{\text{ Last } }\)
    = \(n^2 + 2n + 3n + 6\)
    = \(n^2+5n + 6\)
    The words under each product indicate the original location of the two integers that are multiplied. This method is First, Outside, Inside, Last or FOIL.
