Example 2.3.6. Four choose \(k\).

Evaluate \(\binom{4}{k}\) for each nonnegative integer \(k\) by listing the \(k\)-element subsets of \(\{1,2,3,4\}\text{.}\)
🔗
Solution.
When \(k=0\text{,}\) the only 0-element subset is \(\varnothing\) and so \(\binom{4}{0}=1\text{.}\)
🔗
When \(k=1\text{,}\) the 1-element subsets are \(\{1\}, \{2\}, \{3\}, \{4\}\) and so \(\binom{4}{1}=4\text{.}\)
🔗
When \(k=2\text{,}\) the 2-element subsets are \(\{1,2\}, \{1,3\}, \{1,4\}, \{2,3\}, \{2,4\}, \{3,4\}\) and so \(\binom{4}{2}=6\text{.}\)
🔗
When \(k=3\text{,}\) the 3-element subsets are \(\{1,2,3\}, \{1,2,4\}, \{1,3, 4\}, \{2,3,4\}\) and so \(\binom{4}{3}=4\text{.}\)
🔗
When \(k=4\text{,}\) the only 4-element subset is \(\{1,2,3,4\}\) and so \(\binom{4}{4}=1\text{.}\)
🔗
When \(k >4\) we have \(\binom{4}{k}=0 \text{ for } k>4\text{.}\)
