Definition 2.4.1. Bit string.

 
  1. A character that is \(\bs{0}\) or \(\bs{1}\) is a bit.
    🔗
    🔗
  2. A bit string is a string where each character is a bit. For example, \(\bs{1101}\) is a bit string.
    🔗
    🔗
  3. The weight of a bit string is the number of \(\bs{1}\) s in the bit string. For example, the bit string \(\bs{1101}\) has length four and weight three.
    🔗
    🔗
  4. The empty bit string \(\lambda\text{,}\) pronounced “lambda”, is the unique bit string of length zero. The symbol \(\lambda\) is a place holder. If we had just a blank space, you would not know that we meant the empty bit string. In computer science, the empty bit string is used as a start to build a new bit string. If we start with \(\lambda\) and write \(\bs{1}\) at the end of the string, the resulting bit string is \(\bs{1}\) (and we no longer write \(\lambda\)).
    🔗
