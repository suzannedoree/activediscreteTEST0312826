Theorem 5.4.13. Proof Format:Conditional Using the Contrapositive.

We can prove \(P \to Q\) using the contrapositive by adapting the following proof format.
🔗

Proof.
We will prove the contrapositive, namely (fill in \(\neg Q \to \neg P\)).
🔗
Assume \(\neg Q\) is true.
🔗
(Explain why it follows that \(\neg P\) is true.)
🔗
Thus \(\neg P\) is true.
