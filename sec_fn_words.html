    Nearly all of the functions we have seen so far have had sets of numbers for their domain and codomain and have had rules defined by formulas. In this section, which include functions whose domain and codomain are sets of other discrete objects such as graphs and bit strings.

    Subsection 6.2.A Floor and Ceiling

    As a first example of functions with rules described in words, we consider the floor and ceiling functions which take a real (decimal) number input and find a nearby integer to output.
    🔗

    Definition 6.2.1. Floor and ceiling.

     
    1. For a real number \(x\text{,}\) the floor of \(x\text{,}\) denoted \(\lfloor x \rfloor\text{,}\) is the result of rounding \(x\) down to the nearest integer less than or equal to \(x\text{.}\) Officially, \(\lfloor x \rfloor=k\) where \(k\) is the greatest integer such that \(k\le x\text{.}\) For example, \(\lfloor 2.4 \rfloor = 2\) and \(\lfloor -2.4 \rfloor = -3\text{.}\) This name comes from the fact that we look down to see the floor of a room. Notice that the floor is the first integer at or to the left of the number on the real number line.
      🔗
      🔗
    2. For a real number \(x\text{,}\) the ceiling of \(x\text{,}\) denoted \(\lceil x \rceil\text{,}\) is the result of rounding \(x\) up to the nearest integer greater than or equal to \(x\text{.}\) Officially, \(\lceil x \rceil =k\) where \(k\) is the least integer such that \(k\ge x\text{.}\) For example, \(\lceil 2.4 \rceil = 3\) and \(\lceil -2.4 \rceil = -2\text{.}\) This name comes from the fact that we look up to see the ceiling of a room. Notice that the ceiling is the first integer at or to the right of the number on the real number line.
      🔗
      🔗
    🔗
    🔗
    Note that floor and ceiling are in the same level as parentheses in the order of operations Definition 2.1.17. Let’s look at an example.
    🔗

    Example 6.2.4. Floor and ceiling calculations.

     
    1. Evaluate \(\lfloor \frac{10}{3} \rfloor\) and \(\lfloor ^-\frac{10}{3} \rfloor\text{.}\)
      Solution.
      Since \(\frac{10}{3} = 3.333\ldots\text{,}\) we round down to get \(\lfloor \frac{10}{3} \rfloor=3\text{.}\)
      🔗
      Since \(^-\frac{10}{3} = -3.333\ldots\text{,}\) we round down (to a more negative number) to get -4.
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(\lfloor 17 \rfloor\) and \(\lceil 17 \rceil\text{.}\)
      Solution.
      Because 17 is an integer, we do not have to round at all. Therefore, \(\lfloor 17 \rfloor = 17\) and \(\lceil 17 \rceil = 17\text{.}\)
      🔗
      🔗
      🔗
      🔗

    Subsection 6.2.B Number-theoretic Functions

    Let’s look at examples of functions with rules defined in words that come from number theory Chapter 4. Here is a first example.
    🔗

    Example 6.2.6. Number of divisors.

    The function
    \begin{equation*} \fn{countdiv}: \mathbb{Z}^+ \to \mathbb{Z}^+ \end{equation*}
    is defined by \(\fn{countdiv}(n)=\) the number of (positive) divisors of \(n\text{.}\)
    1. Evaluate \(\fn{countdiv}(4)\text{.}\)
      Solution.
      The divisors of four are: 1, 2, and 4. Since there are three divisors, \(\fn{countdiv}(4)=3\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Find an integer \(n\) such that \(\fn{countdiv}(n) = 4\text{.}\) Is it unique? Explain.
      Solution.
      The integer six has four divisors: 1, 2, 3, and 6. Therefore \(\fn{coundiv}(6)=4\text{.}\) It is not unique because, for example, the integer ten also has four divisors: 1, 2, 5, and 10 and so \(\fn{countdiv}(10)=4\) as well.
      🔗
      🔗
      🔗
      🔗
    3. Describe all integers with \(\fn{countdiv}(n) = 4\text{.}\)
      Solution.
      By our work in Subsection 4.4.B, there are two possible prime factorizations of a number having four positive divisors: \(p^3\) or \(pq\) where \(p\) and \(q\) are distinct primes. (If we made a divisor table, it would be \(1 \times 4\) or \(2 \times 2\text{.}\))
      🔗
      🔗
      🔗
      🔗
    4. Give a counterexample to the statement: for every positive integer \(a\) and \(b\text{,}\) if \(a\lt b\text{,}\) then \(\fn{countdiv}(a) \lt \fn{countdiv}(b)\text{.}\) It follows that the function \(\fn{countdiv}\) is not increasing.
      Solution.
      We want an example that shows the statement is false, meaning it is a broken promise. A counterexample is \(a=6\) and \(b=7\) because \(6 \lt 7\) but \(\fn{countdiv}(6)=4\) and \(\fn{countdiv}(7) = 2\text{,}\) so \(\fn{countdiv}(6) \ge \fn{countdiv}(7)\text{.}\)

    Subsection 6.2.D Functions Involving Bit Strings

    Next, let’s look at functions defined on bit strings. We defined bit strings, the length of a bit string, and the weight of a bit string in Definition 2.4.1. We start by establishing the notation for the empty string and for sets of bit strings.
    🔗

    Definition 6.2.9. Sets of bit strings.

     
    1. The symbol
       1 
      The lowercase Greek letter lambda, denoted \(\lambda\text{,}\) is similar to the English letter \(\str{l}\text{.}\)
      \(\lambda\) represents the empty bit string. It has length and weight 0.
      🔗
      🔗
    2. The set of all bit strings is the set
      \begin{equation*} \mathbb{B} = \{ \lambda, \bs{0}, \bs{1}, \bs{00}, \bs{01}, \bs{10}, \bs{11}, \bs{000}, \bs{001}, \bs{010}, \bs{011}, \bs{100}, \bs{101}, \bs{110}, \bs{111}, \bs{0000}, \bs{0001}, \bs{0010}, \bs{0011}, \ldots \}\text{.} \end{equation*}
      🔗
      🔗
    3. The set of all non-empty bit strings is the set \(\mathbb{B}\) without \(\lambda\text{,}\) namely
      \begin{equation*} \mathbb{B}^* = \{\bs{0}, \bs{1}, \bs{00}, \bs{01}, \bs{10}, \bs{11}, \bs{000}, \bs{001}, \bs{010}, \bs{011}, \bs{100}, \bs{101}, \bs{110}, \bs{111}, \bs{0000}, \bs{0001}, \bs{0010}, \bs{0011}, \ldots \}\text{.} \end{equation*}
      🔗
      🔗
    4. For any non-negative integer \(n\text{,}\) the set of all bit strings of length \(n\) is \(\mathbb{B}_n\text{.}\) For example, \(\mathbb{B}_0 = \{\lambda\}\text{,}\) \(\mathbb{B}_1 = \{\bs{0}, \bs{1}\}\text{,}\) \(\mathbb{B}_2 = \{\bs{00}, \bs{01}, \bs{10}, \bs{11}\}\) and
      \begin{equation*} \mathbb{B}_3 = \{\bs{000}, \bs{001}, \bs{010}, \bs{011},\bs{100}, \bs{101}, \bs{110}, \bs{111}\}\text{.} \end{equation*}
      🔗
      🔗
    🔗
    🔗
    Let’s look at an example of a function on bit strings.
    🔗

    Example 6.2.10. Weight function on bit strings.

    Consider the function
    \begin{equation*} \fn{wgt}: \mathbb{B} \to \mathbb{Z} \end{equation*}
    defined by \(\fn{wgt}(b) =\) weight of the bit string \(b\text{.}\)
    1. What are the domain and codomain of the function \(\fn{wgt}\text{?}\)
      Solution.
      The domain is the set of all bit strings, \(\mathbb{B}\text{,}\) and the codomain is the set of all integers, \(\mathbb{Z}\text{.}\)
      🔗
      🔗
      🔗
      🔗
    2. Evaluate \(\fn{wgt}(\bs{001})\text{,}\) \(\fn{wgt}(\bs{1111})\text{,}\) and \(\fn{wgt}(\lambda)\text{.}\)
      Solution.
      The weight of a bit string is the number of \(\bs{1}\) s in the bit string. Since \(\bs{001}\) has one \(\bs{1}\text{,}\) \(\fn{wgt}(\bs{001})=1\text{.}\) Since \(\bs{1111}\) has four \(\bs{1}\) s, \(\fn{wgt}(\bs{1111})=4\text{.}\) Since \(\lambda\) has no \(\bs{1}\) s, \(\fn{wgt}(\lambda)=0\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Describe all bit strings \(b\) such that \(\fn{wgt}(b)=0\text{.}\)
      Solution.
      For a bit string to have weight 0, it cannot contain any \(\bs{1}\) s. That is, it must be empty or entirely \(\bs{0}\) s. We can list such strings as \(\lambda, \bs{0}, \bs{00}, \bs{000}, \bs{0000}, \ldots\text{.}\)
      🔗
      🔗
      🔗
      🔗
    4. For a positive integer \(n\text{,}\) describe a bit string \(b\) such that \(\fn{wgt}(b) = n\text{.}\)
      Solution.
      We are looking for a bit string \(b\) that has weight \(n\) or, equivalently, that contains \(n\) \(\bs{1}\) s. The simplest example is
      \begin{equation*} b = \underbrace{\bs{11}\ldots\bs{1}}_{n}\text{,} \end{equation*}
      the bit string with \(n\) 1s. Other answers are possible, such as
      \begin{equation*} b = \bs{0}\underbrace{\bs{11}\ldots\bs{1}}_{n }\bs{0} \end{equation*}
      🔗
      🔗
      🔗
      🔗
    5. What is the image of the function \(\fn{wgt}\text{?}\)
      Solution.
      It is not possible to have a negative weight. We saw in (d) and (c) that any non-negative integer is the weight of some bit strings. Therefore, the image of \(\str{wgt}\) is \(\mathbb{N}\text{.}\)
