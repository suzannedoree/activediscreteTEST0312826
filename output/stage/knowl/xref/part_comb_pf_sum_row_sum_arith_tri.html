Item (a).

Copy the following combinatorial proof to that
\begin{equation*} \displaystyle \sum_{k=0}^n\binom{n}{k} =2^n \end{equation*}
for any natural number \(n\text{.}\) We made this conjecture about the row sums of the arithmetic triangle in Activity 9.4.B (b).

Proof.
We use a combinatorial proof. Consider the following situation: we have the set \(T = \{1,2,\ldots, n\}\text{.}\) How many ways are there to choose a subset of \(T\text{?}\)
🔗
First, condition on \(k=\) the number of elements in the subset. There are \(\binom{n}{k}\) subsets with \(k\) elements for \(k = 0, 1, 2, \ldots, n\text{.}\) Since cases add Theorem 2.2.6, there are a total of \(\displaystyle \sum_{k=0}^n\binom{n}{k}\) subsets.
🔗
On the other hand, for each element of \(T\) we can decide whether it will be in the subset or not (2 choices). There are two choices for whether 1 is in the subset, two choices for whether 2 is in the subset, and so on up to two choices for whether \(n\) is in the subset. Since steps multiply Theorem 2.2.2, there are \(\underbrace{2\cdot 2 \cdots \cdots 2}_{n \text{ times } } = 2^n\) subsets.
🔗
Since we counted the same quantity in two different ways, it follows that
\begin{equation*} \sum_{k=0}^n\binom{n}{k} =2^n\text{.} \end{equation*}
