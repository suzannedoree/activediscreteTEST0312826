Item (c).

Multiply \((n+s)(n-s)\) and write the answer as a polynomial in the variable \(n\text{.}\)
Solution.
Multiplying we get
🔗
\((n+s)(n-s)\) = \(\underbrace{(n)(n)}_{\text{ First } } +\underbrace{(n)(-s)}_{\text{ Outside } } + \underbrace{(s)(n)}_{\text{ Inside } } + \underbrace{(s)(-s)}_{\text{ Last } }\)
= \(n^2 - sn + sn - s^2\)
= \(n^2-s^2\)
