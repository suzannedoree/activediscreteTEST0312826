Activity 2.4.C. From point \(a_1\) to point \(c_4\).

In this activity we are interested in direct paths from \(a_1\) to \(c_4\) in Figure 2.4.11. We begin each direct path at \(a_1\) and then walk one unit to the right or one unit down at each step until we reach \(c_4\text{.}\) We are not allowed to walk to the left or up.
🔗
  1. Give an example of a direct path from \(a_1\) to \(c_4\text{.}\) How many steps did you take?
    🔗
    🔗
  2. Draw a possibility tree to list all possible direct paths. Hint: The original node is \(a_1\) which has branches to \(a_2\) and to \(b_1\text{.}\)
    🔗
    🔗
  3. How many direct paths from \(a_1\) to \(c_4\) are there?
    🔗
    🔗
  4. We can represent each path by a bit string where \(\bs{1}\) represents walking one unit to the right and \(\bs{0}\) represents walking one unit down. What is the bit string whose path is \(a_1a_2b_2b_3c_3c_4\text{?}\)
    🔗
    🔗
  5. What is the path whose bit string is \(\bs{00111}\text{?}\)
    🔗
    🔗
  6. Explain how to use Theorem 2.4.9 to count the number of paths. You should get the same answer as in (c).
    🔗
    🔗
  7. We can describe the grid in Figure 2.4.11 as being \(3 \times 4\) because it has 3 rows of letters and 4 columns of letters. Conjecture the number of direct paths from the upper left corner to the lower right corner in a \(5 \times 7\) grid.
    🔗
    🔗
  8. Generalize. That means conjecturing the number of direct paths from the upper left corner to the lower right corner in a \(r \times c\) grid.
