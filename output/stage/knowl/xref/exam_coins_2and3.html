Example 8.4.10. Additive set.

Consider the set \(M\) constructed recursively in Activity 8.4.B.
  1. Explain why \(M = \{n \in \mathbb{Z} \mid n \ge 2\}\text{.}\)
    Solution.
    We can show any even integer \(n \in M\) as follows. Write \(n = 2k\) for some integer \(k\text{.}\) By B1 we know \(2 \in M\text{.}\) Applying R \((k-1)\) times we get
    \begin{equation*} 2 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } \in M\text{.} \end{equation*}
    But
    \begin{equation*} 2 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } = 2+ 2(k-1) = 2k =n\text{.} \end{equation*}
    Thus \(n \in M\text{.}\)
    🔗
    We can show any odd integer \(n \in M\) for \(n \ge 3\) as follows. Write \(n = 2k+1\) for some integer \(k\text{.}\) Since \(n \ge 3\text{,}\) it follows that \(k \ge 1\text{.}\) By B2 we know \(3 \in M\text{.}\) Applying R \((k-1)\) times we get
    \begin{equation*} 3 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } \in M\text{.} \end{equation*}
    But
    \begin{equation*} 3 + \underbrace{2+2+\cdots +2}_{k-1 \text{ times } } = 3 + 2(k-1) = 2k + 1=n\text{.} \end{equation*}
    Thus \(n \in M\text{.}\)
    🔗
    🔗
    🔗
    🔗
  2. Use mathematical induction to verify that \(n \in M\) for any integer \(n \ge 2\text{.}\)
    Solution.
    Proof. Induct on \(n\text{.}\)
    🔗
    First, when \(n = 2\text{,}\) we know \(2 \in M\) by B.
    🔗
    Next, assume \(n-1 \in M\) for some \(n >1\text{.}\) We consider two cases.
    🔗
    Case 1: Somewhere in the process of constructing \(n-1\) we used B1. That is, \(n-1=2+m\) for some \(m \in M\text{.}\) Adding one to each side of the equation we get \(n = 3 + m\text{,}\) and so \(n\) can be constructed from \(m\) using B2 and R.
    🔗
    Case 2: Nowhere in the process of constructing \(n-1\) did we use B1. It follows that somewhere in the process of constructing \(n-1\) we used B2. That is, \(n-1 = 3+m\) for some \(m \in M\text{.}\) Adding one to each side of the equation we get \(n = 4 + m\text{,}\) and so \(n\) can be constructed from \(m\) using B1 twice and R.
    🔗
