Definition 3.1.2. Graph.

 
  1. A vertex (or node) is an object. For example, a vertex could be a piece of land in the city from Activity 3.1.A or perhaps a student at the university. The plural of “vertex” is “vertices” and so we refer to one vertex, two vertices, three vertices, and so on.
    🔗
    🔗
  2. An edge is a set of two vertices. For example, if \(A\) and \(B\) are distinct vertices in a graph, then \(\{A,B\}\) is an example of a possible edge. When we model a situation using a graph, each edge represents a connection between two objects. For example, in the Bridges Puzzle Activity 3.1.A, we might want an edge between two vertices to indicate that those two pieces of land are connected by a bridge.
     1 
    We are ignoring, for the moment, that there are two bridges between the big island and the north shore. Technically we need a slightly more general definition of an edge and what we get is a multigraph, not a simple graph.
    As another example, in a graph where each vertex is a student at the university, we might want an edge between two vertices to indicate that those two students have a class together this semester.
    🔗
    🔗
  3. Two vertices are adjacent (or neighbors) if they are connected by an edge. That is, if \(A\) and \(B\) are distinct vertices and \(\{A,B\}\) is an edge, then the vertices \(A\) and \(B\) are adjacent. We also say that \(A\) is adjacent to \(B\) or that \(B\) is adjacent to \(A\text{.}\) So, for example, if Camilla and Quang are both in discrete mathematics class this semester, then Camilla is adjacent to Quang (and vice versa) in the student graph.
    🔗
    🔗
  4. A (simple) graph (or network) is a pair of sets: a vertex set of vertices and a edge set of edges where the elements of each edge are in the vertex set. For example, we might have the graph \(G\) with the vertex set \(\{1,2,3,4\}\) and the edge set
    \begin{equation*} \{\{1,2\},\{1,4\},\{2,3\},\{2,4\},\{3,4\}\}\text{.} \end{equation*}
    🔗
    🔗
  5. A graph drawing of a graph has a point for each vertex and a line (or curve) for each edge connecting its two vertices. In this textbook, we draw each vertex as a small, open circle instead of a point. The placement of the vertices and edges is at our convenience– none of the geometry such as position, length, or angle matters. For example, Figure 3.1.3 shows four different drawings of the graph \(G\) from (d).
