Example 6.2.10. Weight function on bit strings.

Consider the function
\begin{equation*} \fn{wgt}: \mathbb{B} \to \mathbb{Z} \end{equation*}
defined by \(\fn{wgt}(b) =\) weight of the bit string \(b\text{.}\)
  1. What are the domain and codomain of the function \(\fn{wgt}\text{?}\)
    Solution.
    The domain is the set of all bit strings, \(\mathbb{B}\text{,}\) and the codomain is the set of all integers, \(\mathbb{Z}\text{.}\)
    🔗
    🔗
    🔗
    🔗
  2. Evaluate \(\fn{wgt}(\bs{001})\text{,}\) \(\fn{wgt}(\bs{1111})\text{,}\) and \(\fn{wgt}(\lambda)\text{.}\)
    Solution.
    The weight of a bit string is the number of \(\bs{1}\) s in the bit string. Since \(\bs{001}\) has one \(\bs{1}\text{,}\) \(\fn{wgt}(\bs{001})=1\text{.}\) Since \(\bs{1111}\) has four \(\bs{1}\) s, \(\fn{wgt}(\bs{1111})=4\text{.}\) Since \(\lambda\) has no \(\bs{1}\) s, \(\fn{wgt}(\lambda)=0\text{.}\)
    🔗
    🔗
    🔗
    🔗
  3. Describe all bit strings \(b\) such that \(\fn{wgt}(b)=0\text{.}\)
    Solution.
    For a bit string to have weight 0, it cannot contain any \(\bs{1}\) s. That is, it must be empty or entirely \(\bs{0}\) s. We can list such strings as \(\lambda, \bs{0}, \bs{00}, \bs{000}, \bs{0000}, \ldots\text{.}\)
    🔗
    🔗
    🔗
    🔗
  4. For a positive integer \(n\text{,}\) describe a bit string \(b\) such that \(\fn{wgt}(b) = n\text{.}\)
    Solution.
    We are looking for a bit string \(b\) that has weight \(n\) or, equivalently, that contains \(n\) \(\bs{1}\) s. The simplest example is
    \begin{equation*} b = \underbrace{\bs{11}\ldots\bs{1}}_{n}\text{,} \end{equation*}
    the bit string with \(n\) 1s. Other answers are possible, such as
    \begin{equation*} b = \bs{0}\underbrace{\bs{11}\ldots\bs{1}}_{n }\bs{0} \end{equation*}
    🔗
    🔗
    🔗
    🔗
  5. What is the image of the function \(\fn{wgt}\text{?}\)
    Solution.
    It is not possible to have a negative weight. We saw in (d) and (c) that any non-negative integer is the weight of some bit strings. Therefore, the image of \(\str{wgt}\) is \(\mathbb{N}\text{.}\)
