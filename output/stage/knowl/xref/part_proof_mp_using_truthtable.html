Prove modus ponens is valid using a truth table.
Solution.
To prove modus ponens is valid, we need to prove that \((P \land (P \to Q)) \to Q\) is a tautology. The truth table is shown in Table 5.5.11. Notice that the last column is all \(\str{T}\text{,}\) so \((P \land (P \to Q)) \to Q\) is a tautology. Therefore, modus ponens is valid.
