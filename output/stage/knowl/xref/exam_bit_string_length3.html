Example 2.4.2. Listing bit strings in a possibility tree.

 
  1. List all bit strings of length three by drawing a possibility tree.
    Solution.
    We draw the possibility tree in Figure 2.4.3. The list is \(\bs{000}\text{,}\) \(\bs{001}\text{,}\) \(\bs{010}\text{,}\) \(\bs{011}\text{,}\) \(\bs{100}\text{,}\) \(\bs{101}\text{,}\)\(\bs{110}\text{,}\) \(\bs{111}\text{.}\)

  2. List all bit strings of length four and weight two.
    Solution.
    We draw the possibility tree below. Each bit string has weight two, which means that it has exactly two \(\bs{1}\) s and two \(\bs{0}\) s. In the tree we need to be careful– any time we have two \(\bs{1}\) s or two \(\bs{0}\) s, we have only one branch (either to just \(\bs{0}\) or to just \(\bs{1}\)) instead of the usual two branches (to \(\bs{0}\) and to \(\bs{1}\)). The strings are \(\bs{0011}\text{,}\) \(\bs{0101}\text{,}\) \(\bs{0110}\text{,}\) \(\bs{1001}\text{,}\) \(\bs{1010}\text{,}\) \(\bs{1100}\text{.}\)
