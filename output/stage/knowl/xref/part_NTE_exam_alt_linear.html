Item (c).

The sequence \(c\) begins \(2, -3, 4, -5, 6, -7,\ldots\text{.}\)
Solution.
We can use \((-1)^n\) to get the alternation, so let’s make a table comparing \(n\text{,}\) \((-1)^n\text{,}\) and the absolute value of the terms of the sequence starting at \(n=0\text{,}\) in Table 6.5.9. Notice that the absolute value of the terms of the sequence are two more than the index \(n\text{.}\) A possible formula is \(c_n = (-1)^n(n+2)\) for \(n \ge 0\text{.}\)
