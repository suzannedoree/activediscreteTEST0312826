Theorem 8.5.16. Proof Format: Mathematical Induction (Second-order Sequence).

Given the sequence \(a\) defined recursively by \(a_s=\) and \(a_{s+1}=\) (initial conditions) and \(a_n=\) (recursive rule)for \(n \ge s+2\text{,}\) we can prove \(a_n=\) (explicit rule) for \(n \ge s\) using mathematical induction by adapting the following proof format.
🔗

Proof.
Write \(f(n) =\)(explicit rule). Induct on \(n\text{.}\)
🔗
First, when \(n=s\) we know that \(a_s=\) (first initial condition) and also \(f(s)=\) (evaluate and simplify to get the same answer).
🔗
Similarly, when \(n=s+1\) we know that \(a_{s+1}=\) (second initial condition) and also \(f(s+1)=\) (evaluate and simplify to get the same answer).
🔗
Next, assume \(a_{n-1}=f(n-1)=\) (evaluate and simplify) and \(a_{n-2} = f(n-2) =\) (evaluate and simplify), for some integer \(n > s+1\text{.}\)
🔗
Then
\begin{align*} a_n \amp = \text{ (recursive rule) }\\ \amp = \cdots \text{ (use the inductive hypothesis to replace } a_{n-1} \text{ by } f(n-1) \text{ and } a_{n-2} \text{ by } f(n-2)\text{)} \cdots\\ \amp = \cdots \text{ (use algebra) } \cdots\\ \amp = f(n)\text{.} \end{align*}
