    Section 2.4 Counting Bit Strings

    Strings consisting only of \(\bs{0}\) s and \(\bs{1}\) s, or bit strings, play a central role in computer science. All numbers, data, logical commands, and computer programs are encoded in a computer as bit strings. Similarly, every text message or email message is encoded as a bit string. In fact, we might say that
    🔗
    Bit strings are a fundamental structure of computer science because all of computer science can be defined using bit strings.
    🔗
    🔗
    In this section, we count bit strings, demonstrate clever ways to count by modeling using bit strings, and discuss exponential notation and logarithms.
    🔗

    Subsection 2.4.A Bit Strings

    We start with a definition.
    🔗

    Definition 2.4.1. Bit string.

     
    1. A character that is \(\bs{0}\) or \(\bs{1}\) is a bit.
      🔗
      🔗
    2. A bit string is a string where each character is a bit. For example, \(\bs{1101}\) is a bit string.
      🔗
      🔗
    3. The weight of a bit string is the number of \(\bs{1}\) s in the bit string. For example, the bit string \(\bs{1101}\) has length four and weight three.
      🔗
      🔗
    4. The empty bit string \(\lambda\text{,}\) pronounced “lambda”, is the unique bit string of length zero. The symbol \(\lambda\) is a place holder. If we had just a blank space, you would not know that we meant the empty bit string. In computer science, the empty bit string is used as a start to build a new bit string. If we start with \(\lambda\) and write \(\bs{1}\) at the end of the string, the resulting bit string is \(\bs{1}\) (and we no longer write \(\lambda\)).
      🔗
      🔗
    🔗
    🔗

    Subsection 2.4.B Number of Bit Strings

    One special situation that is counted using steps is the number of bit strings of length \(n\text{.}\) Make sure that you have completed Activity 2.4.A because we are about to reveal the answers.
    🔗

    Example 2.4.5. Conjecture number of bit strings of length \(n\).

    How many bit strings of length \(n\) are there? State your answer as a conjecture.
    🔗
    Solution.
    There is one bit string of length 0 (\(\lambda\)), two bit strings of length one (\(\bs{0}\text{,}\) \(\bs{1}\)) and four bit strings of length two (\(\bs{00}\text{,}\) \(\bs{01}\text{,}\) \(\bs{10}\text{,}\) \(\bs{11}\)). In Example 2.4.2, we listed the eight bit strings of length three. In Activity 2.4.B, we counted 16 bit strings of length four and 32 bit strings of length five. Notice that each integer is twice the previous number, suggesting that we are multiplying by two. Table 2.4.6 shows these examples written as a product of twos.
    🔗
    Based on these examples, it is reasonable to conjecture that there are
    \begin{equation*} \underbrace{2 \times 2 \times \ldots \times 2}_{n \text{ times } } \end{equation*}
    bit strings of length \(n\text{.}\)
    🔗
    🔗
    🔗
    Products in the format of the answer to Example 2.4.5 occur often enough that they have a name and notation. For example, our product is 2 to the power of \(n\) which is denoted
    \begin{equation*} 2^n= \underbrace{2\times 2 \times \ldots \times 2} _{n \text{ times } } \end{equation*}
    🔗
    We can prove our conjecture from Example 2.4.5 using steps.
    🔗

    Theorem 2.4.7. Number of bit strings of length \(n\).

      There are \(2^n\) bit strings of length \(n\text{.}\)
    🔗
    🔗

    Proof.
    Imagine building each bit string of length \(n\) by filling in the \(n\) spaces:
    \begin{equation*} \underline{}~\underline{} ~\underline{}~\ldots ~\underline{}~ \end{equation*}
    🔗
    There are two ways to fill in each space: either \(\bs{0}\) or \(\bs{1}\text{.}\) We fill in the spaces in a sequence of steps.
    🔗
    Step 1: Fill in the first space (2 ways).
    🔗
    Step 2: Fill in the second space (2 ways).
    🔗
    Step 3: Fill in the third space (2 ways).
    🔗
    We continue to fill spaces until Step \(n\text{:}\) Fill in the last space (2 ways).
    🔗
    Since steps multiply Theorem 2.2.2, the total number of bit strings of length \(n\) is
    \begin{equation*} \underbrace{ 2 \times 2 \times \ldots \times 2} _{n \text{ times } } = 2^n \end{equation*}

    Subsection 2.4.D Algebra: Exponential Notation and Logarithms

    In Theorem 2.4.7, we proved that there are \(2^n\) bit strings of length \(n\) where
    \begin{equation*} 2^n=\underbrace{2\times 2 \times \ldots \times 2}_{n \text{ times } } \end{equation*}
    🔗
    This exponential notation is a shorthand for a product of the same number multiplied by itself repeatedly.
    🔗

    Definition 2.4.12. Exponential notation.

     
    1. When \(n\) is a positive integer, \(b\) raised to the power of \(n\) (or just \(b\) to the \(n\)) is
      \begin{equation*} b^n = \underbrace{b\times b \times \ldots \times b}_{n \text{ times } } \end{equation*}
      For example,
      \begin{equation*} 2^5 = \underbrace{2 \times 2 \times 2 \times 2 \times 2}_{5 \text{ times } } = 32 \end{equation*}
      and
      \begin{equation*} (-2)^5 = \underbrace{(-2) \times (-2) \times (-2) \times (-2) \times (-2)}_{5 \text{ times } } = -32\text{.} \end{equation*}
      Note that exponentiation is not commutative. For example, \(2^5=32\) but \(5^2 = 5 \times 5 = 25\text{.}\) We practice evaluating powers without using technology to understand the definition, but, of course, you can use technology to check. Many computational tools, such as calculators, spreadsheet programs, or an Internet search, use the notation \(\land\) to indicate a power.
      🔗
      🔗
    2. In the expression \(b^n\text{,}\) the integer \(b\) is the base, the number that we are repeatedly multiplying. The integer \(n\) is the exponent, the number of times we multiply the base. The quantity \(b^n\) is the power of \(b\text{,}\) the final product. For example, in \(2^5\text{,}\) the base is 2, the exponent is 5, and the power of 2 is 32.
      🔗
      🔗
    3. For \(b\neq 0\text{,}\) it is convenient to define \(b^0=1\text{.}\) For example, \(2^0=1\) is the number of bit strings of length zero.
      🔗
      🔗
    4. The expression \(b^2\) is \(s\) squared. For example, \(10^2 = 10 \times 10 = 100\text{.}\) This name comes from the fact that the area of a square with sides of length \(b\) is \(b^2\text{.}\)
      🔗
      🔗
    5. The expression \(b^3\) is \(b\) cubed. For example, \(4^3 = 4 \times 4 \times 4 = 64\text{.}\) This name comes from the fact that the volume of a cube with sides of length \(b\) is \(b^3\text{.}\)
      🔗
      🔗

    Definition 2.4.14. Logarithm.

     
    1. The logarithm base 10 of an integer \(k\text{,}\) denoted \(\fn{log}(k)\) is the exponent of the power 10 that equals \(k\text{.}\) That is, \(\fn{log}(k)=n\) if \(10^n=k\text{.}\) For example, \(\fn{log}(100 ) = 2\) because \(10^2=100\text{.}\)

      \begin{align*} (10^2)^3 \amp = (\underbrace{10^2\times 10^2\times 10^2}_{3 \text{ times } })\\ \amp = (\underbrace{(10 \times 10)\times (10 \times 10)\times (10 \times 10)}_{3 \text{ times } })\\ \amp = \underbrace{10\times 10\times 10\times 10\times 10 \times 10}_{6 \text{ times } })\\ \amp = 10^6\text{.} \end{align*}
      🔗
      Notice that the exponents multiplied: \(2 \times 3=6\text{.}\)
      🔗
      🔗
      🔗
      🔗
    3. Write \(8^2\) as a power of 2.
      Solution.
      First, write \(8 = 2^3\text{.}\) Then, using what we learned in (b) we get
      \begin{equation*} 8^2=\left(2^3\right)^2 = 2^{2\times 3}=2^6\text{.} \end{equation*}
      🔗
      You can check that \(8^2=64\) and \(2^6=64\text{.}\)

    For any integer \(b\) and positive integers \(n\) and \(m\) we have the following rules.
    1. Simplifying a product of powers (of the same base): \(b^mb^n=b^{m+n}\text{.}\)

      🔗
    2. Simplifying a power of a power: \(\left(b^m\right)^n=b^{mn}\text{.}\)
