Definition 2.1.17. Integer algebra and the order of operations.

 
  1. When several operations are involved in a single calculation, we need to know the order of operations (PEMDAS), the priority ranking for arithmetic operations. The order is
    First, calculate anything inside Parentheses.
    Next, calculate Exponents \(\wedge\text{,}\) in order from left to right.
    Then, Multiply × and Divide \(\div\text{,}\) in order from left to right.
    Last, Add \(+\) and Subtract \(-\text{,}\) in order from left to right.
    🔗
    🔗
  2. The commutative properties of the integers tell us that
    \begin{equation*} n+s=s+n \ \ \text{ and } sn=ns\text{.} \end{equation*}
    We often use the commutative property to rewrite sums or products in standard order. For example, products are usually written alphabetically (\(ns\) is standard, not \(sn\)) and in products numbers come before letters (\(2k\) is standard, not \(k2\)). In sums, numbers often come after letters (\(n+1\) is common, although \(1+n\) is also acceptable).
    🔗
    🔗
  3. The associative properties of the integers tells us that
    \begin{equation*} (n+s)+t = n+(s+t) \ \ \text{ and } (ns)t = n(st)\text{.} \end{equation*}
    We often use the associative property to write an expression such as \(n+3k+2\) without parentheses, since the location of parentheses would not change the sum.
    🔗
    🔗
  4. We factor an integer by writing it as a product of two integers. For example, we can factor \(6\) as \(2 \times 3\) which we could write as \(6=2 \times 3\) or \(6=(2)(3)\text{.}\) Although it is correct to factor \(6\) as \(1 \times 6\text{,}\) if an activity or exercise asks you to “factor,” the answer should not use the factor \(1\text{.}\) Notice that “factor” can be a noun, which means the quantity we are multiplying, or a verb, which means write as a product.
    🔗
    🔗
  5. The distributive property of the integers tells us that
    \begin{equation*} n(s+t)=ns+nt\text{.} \end{equation*}
    Reading this equation from left to right tells us how to expand (or distribute or multiply out). For example,
    \begin{equation*} 2(n+4) = (2)(n) + (2)(4) = 2n + 8\text{.} \end{equation*}
    Equations tell us that two things are equal, so we can equally well read this equation from right to left
    \begin{equation*} ns+nt=n(s+t) \end{equation*}
    which tells us how to factor. For example,
    \begin{equation*} 5n-10 = (5)(n) + (5)(-2) = 5(n+(-2)) = 5(n-2)\text{.} \end{equation*}
    🔗
    🔗
