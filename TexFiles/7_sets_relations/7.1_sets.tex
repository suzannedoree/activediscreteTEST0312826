\section{\secsets}
\label{sec_sets}

We have been using the idea of sets throughout this course.  In this section, we discuss sets more formally, including how to define sets using set-builder notation. We also explore ways to combine sets through set operations, which have applications to working with databases.

\newcommand{\subelements}{Elements of a Set}
\subsection{\subelements}
\label{sub_elements}

As in \Cref{sec_listing}, a \vocab{set} is understood to be an unordered collection of objects called \vocab{elements}.  There is a lot of vocabulary related to sets.  We start with definitions related to the elements of a set.

\begin{defn}[Elements]
\label{defn_element}
~
    \begin{apart}
        \item If the object $x$ is an element of the set $S$, then we use \vocab{element notation} and write $x \in S$.  If $x$ is not an element of $S$, then we write $x \notin S$. For example, if $S=\{1,3,4\}$, then $3 \in S$ and then $2 \notin S$.
        \item An \vocab{ellipsis} is $\ldots$ which is used to indicate missing items that follow a pattern.  For an infinite set described using \vocab{ellipses} we  need to recognize the pattern to know if an object is an element.  For example, the set $F = \{4,8,12,\ldots, 64\}$ is the set of multiples of 4 from 4 to 64.  Thus, $20 \in F$ because $4 \mid 20$ and $4 \le 20 \le 64$.  On the other hand, $18 \notin F$ because $4 \nmid 18$ and $80 \notin F$ because $80 >64$.  We see a more rigorous way to define such sets in \Cref{sub_setbuild}.
        \item The \vocab{cardinality} of a finite set $S$, denoted $|S|$, is the number of (distinct) elements in $S$.  For example, $|\{1,3,4\}|=3$ because there are three elements in $\{1,3,4\}$ namely 1, 3, and 4.  
    \end{apart}
\end{defn}

Let's look at a set of bit strings.

\begin{exam}[The set of bit strings of length three]
\label{exam_set_bs_length3}   
    The set of all bit strings of length three is $$\mathbb{B}_3=\{\bs{000}, \bs{001}, \bs{010}, \bs{011}, \bs{100}, \bs{101}, \bs{110}, \bs{111}\}.$$
        \begin{apart}
            \item Is $\bs{110} \in \mathbb{B}_3$?  Is $\bs{0111}\in \mathbb{B}_3$?
                \begin{soln}
                    Since \bs{110} is a bit string of length three and appears on the list of elements of $\mathbb{B}_3$, we have $\bs{110} \in \mathbb{B}_3$.  Since $\bs{0111}$ is a bit string of length 4 and does not appear on the list of elements of $\mathbb{B}_3$, we see that $\bs{0111} \notin \mathbb{B}_3$.
                \end{soln}
            \item Evaluate $|\mathbb{B}_3|$.
                \begin{soln}
                    We can count the elements of $\mathbb{B}_3$. There are 8 elements listed so $|\mathbb{B}_3|=8$.  Note that by \Cref{thm_number_bit_strings}, we knew there were $2^3=8$ bit strings of length three so, again, $|\mathbb{B}_3|=8$.
                \end{soln}
        \end{apart}
\end{exam}

A set is defined by its elements.

\begin{defn}[Set equality and disjoint sets]
\label{defn_set_equal_disjoint}
~
    \begin{apart}
        \item Sets $S$ and $T$ are \vocab{equal} if they have the exact same set of elements.  For example, $\{1,3,4\}=\{4,4,3,1\}$ because each set has the same three elements: 1, 3, and 4.
        \item At the other extreme, $S$ and $T$ are \vocab{disjoint} if they do not have any elements in common. For example, $\{1,3,4\}$ and $\{2,7\}$ are disjoint.
    \end{apart}
\end{defn}

Let's practice working with these definitions.

\begin{act}[Elements of a set]
\label{act_set_elements}
~
    \begin{actpart}
        \item Consider the set $A = \{0,3,5,6\}$.  Is $0 \in A$?  Is $1 \in A$?  Calculate $|A|$, the number of elements in $A$.
        \item Consider the empty set $\varnothing=\{ ~\}$. What is $|\varnothing|$?
        \item Consider the set $B = \{1, 3, 5, \ldots, 99\}$. Is $13 \in B$?  Calculate $|B|$.
        \item Consider the set $X=\{3,6,0,5\}$.  Is $A=X$?  Explain.
        \item Give an example of a set of integers $Y$ that is disjoint from $A$.  By \Cref{defn_set_equal_disjoint}, that means find a set $Y$ that has no elements in common with $A$.
    \end{actpart}
\end{act}

\newcommand{\subsetbuild}{Set-Builder Notation}
\subsection{\subsetbuild}
\label{sub_setbuild}

There are many ways to describe a set.  We can explicitly list some of the elements of a known set, such as $\mathbb{Z}$ or $\mathbb{R}$, perhaps using an ellipsis ($\ldots$) if the list is long.  Alternatively, we can select the elements of a known set that satisfy some implicit condition or build elements of an explicit format from the elements of a known set. 

\begin{defn}[Set-builder notation]
\label{defn_set_builder_notation}
~
    \begin{apart}
        \item Given a set $S$ and a predicate\footnote{A \vocab{predicate} (or \vocab{Boolean}) is a statement that is true or false.}  $P(x)$ defined for all elements $x \in S$, the set 
            $$A=\{ x \in S \mid P(x)\},$$ 
            pronounced ``the set of all elements $x$ in $S$ such that $P(x)$'', is the set of all elements $x$ of $S$ that satisfy \vocab{implicit condition} $P(x)$.  Note that $A$ is a subset of $S$. For example, if $S=\{1,2,3,7,8\}$ and $P(n)$ is the statement ``$n$ is even'', then
            $$A = \{ n \in S \mid P(n)\} = \{ n \in A \mid n \text{ is even}\}= \{2,8\}.$$  For example, $2 \in A$ because 2 is even but $3 \notin S$ because 3 is not even.
        \item Given a set $S$ and a function $f$ where $f(x)$ is defined for all $x \in S$, the set 
            $$A=\{ f(x) \mid x \in S\},$$ 
            pronounced ``the set of all elements of the form $f(x)$ where $x$ in an element of $S$'', is the set of all elements of the \vocab{explicit format} $f(x)$ where $x\in S$. For example, if $S=\{1,2,3,7,8\}$ and $f(n)=n^3$, then 
            $$A = \{ n^3 \mid n \in S\} = \{1^3,2^3,3^3,7^3,8^3\}= \{1, 8, 27, 343, 512\}.$$ To show $343 \in A$ we write $343=7^3$. Note that $A$ need not be a subset of $S$.  It is just built using the set $S$.
        \item The sets $\{ x \in S \mid P(x)\}$ and $\{ f(x) \mid x \in S\}$ are described in \vocab{set-builder notation} because the notation tells us how to build the set.
    \end{apart}
\end{defn}

We can also combine explicit and implicit formulas.

\begin{exam}[Set of multiples of 4 up to 64]
\label{exam_set_mult4}
    In \Cref{defn_element}, we saw the set $F = \{4,8,12,\ldots, 64\}$ which represents the set of multiples of 4 from 4 to 64.  Use set-builder notation to define $F$.
        \begin{soln}
            One way to define $F$ would be implicitly:
                $$F = \{ n \mid n = 4k \text{ for some integer } k \text{ with } 1 \le k \le 16\}$$
            where the 16  comes from the fact that $4(16)=64$.
            We could alternatively define $F$ mixing implicit and explicit forms:
                $$F = \{ 4k \mid 1 \le k \le 16\}$$
        \end{soln}
\end{exam}

How we show $x \in A$ and what we know when $x \in A$ depends on how the set $A$ is defined.

\begin{rem}[Elements of implicitly or explicitly-defined sets]
\label{rem_implicit_explicit_sets}
~
    \begin{apart}
        \item Given a set $S$, a predicate $P(x)$ defined for all elements $x \in S$, and the set $A=\{ x \in S \mid P(x)\}$,
            \begin{itemize}
                \item To show $x \in A$, we check that $x \in S$ and that $P(x)$ is true.  
                \item If we know $x \in A$, then we can conclude that $x \in S$ and $P(x)$ is true.
            \end{itemize}
        \item Given a set $S$, a function $f$ defined on $S$, and the set $A=\{ f(x) \mid x \in S\}$, 
            \begin{itemize}
                \item To show $y \in A$, we write $y=f(x)$ for some $x \in S$.  
                \item If we know $y \in A$, then we can conclude that $y=f(x)$ for some $x \in S$.
            \end{itemize}
    \end{apart}
\end{rem}

Let's look at another example.

\begin{exam}[Listing elements of implicit and explicitly-defined sets of bit strings]
\label{exam_implicit_explicit_bs}
    As usual, let $\mathbb{B}_3$ denote the set of all bit strings of length three.
        \begin{apart}
            \item List all elements of the implicitly-defined set $$A= \{b \in \mathbb{B}_3 \mid b \text{ has weight two}\}.$$ Recall from \Cref{defn_bit_string} that the weight of a bit string is the number of \bs{1}s in the bit string.
                \begin{soln}
                    There are bit strings of length three and weight two are: \bs{011}, \bs{101}, and \bs{110} and so $A = \{\bs{011}, \bs{101}, \bs{110}\}.$
                \end{soln}
            \item List all elements of the explicitly-defined set $$B = \{ b\bs{1} \mid b \in \mathbb{B}_3\}.$$
                \begin{soln}
                    For each bit string $b$ in $\mathbb{B}_3$ we get a new bit string $b\bs{1}$ in $B$. Thus,
                        $$B = \{\bs{0001}, \bs{0011}, \bs{0101}, \bs{0111}, \bs{1001}, \bs{1011}, \bs{1101}, \bs{1111}\}.$$
                    Note that the elements of $B$ are bit strings of length 4, in $\mathbb{B}_4$.
                \end{soln}
        \end{apart}
\end{exam}

Let's look at some implicitly and explicitly-defined infinite sets.

\begin{exam}[Squares and powers of two]
\label{exam_sq_powers2} 
    Consider the explicitly-defined sets of integers
        $$Q = \{ n^2 \mid n \in \mathbb{N}\}$$
    and
        $$P = \{ 2^n \mid n \in \mathbb{N}\}.$$
        \begin{apart}
            \item Describe the sets $Q$ and $P$ in words.
                \begin{soln}
                    The set $Q$ is the set of all square integers and $P$ is the set of all powers of two.
                \end{soln}
            \item \label{part_16is_sq_and_power2} Show that $16 \in Q$ and $16 \in P$.
                \begin{soln}
                    To show $16 \in Q$ we need to write 16 as a square, that is $16=n^2$ for some $n \in \mathbb{N}$.  We can write $16=4^2$ and so $16 \in Q$.

                    Similarly, to show $16 \in P$ we need to write 16 as a power of two, that is $16=2^n$ for some $n \in \mathbb{N}$.  We can write $16=2^4$ and so $16 \in T$.
                \end{soln}
            \item Write implicit definitions for $Q$ and $P$.
                \begin{soln}
                    As in (\ref{part_16is_sq_and_power2}), to check that an integer $m$ is an element of $Q$ we need to find a nonnegative integer $n$ such that $m=n^2$.  Thus 
                        $$Q = \{ m \in \mathbb{Z} \mid m=n^2 \text{ for some } n \in \mathbb{N}\}.$$

                    Similarly, as in (\ref{part_16is_sq_and_power2}), to check that an integer $m$ is an element of $P$ we need to find a nonnegative integer $n$ such that $m=2^n$.  Thus 
                        $$P = \{ m \in \mathbb{Z} \mid m=2^n \text{ for some } n \in \mathbb{N}\}.$$
                \end{soln}
        \end{apart}
\end{exam}

We can use set-builder notation to write the image of a function.

\begin{exam}[Writing the image of a function in set-builder notation]
\label{exam_image_setbuilder}
    Write the image of the function $f: X \to Y$ in set builder notation.
        \begin{soln}
            The image of $f$ is all the actual output values $f(x)$.  We can write the image explicitly as     $$\{f(x) \mid x \in X\}.$$
            We can also write the image implicitly as
                $$\{y \in Y \mid y = f(x) \text{ for some }x \in X\}$$
        \end{soln}
\end{exam}

\newcommand{\subsetops}{Set Operations}
\subsection{\subsetops}
\label{sub_set_operations}

We can combine sets to form new sets.

\begin{defn}[Set operations]
\label{defn_set_ops}
    Let $S$ and $T$ be subsets of a set $U$.  In this context, $U$ is the \vocab{universal} set.
        \begin{apart}
            \item The \vocab{intersection} of $S$ and $T$, denoted $S \cap T$ and pronounced ``$S$ intersect $T$'', is the set 
                $$S\cap T = \{x \in U \mid x \in S \land x \in T\},$$
            where $\land$ is the logical connective ``and'', as introduced in \Cref{defn_and_or_xor}.  Note that $\cap$ looks similar to $\land$.
            For example, we might be interested in the intersection of the set of students who have completed a discrete mathematics course and the set of students who have completed a linear algebra course, because such students have the prerequisite to take an abstract algebra course.

            \item The \vocab{union} of $S$ and $T$, denoted $S \cup T$ and pronounced ``$S$ union $T$'', is the set 
                $$S\cup T = \{x \in U \mid x \in S \lor x \in T\},$$
            where $\lor$ is the logical connective ``(inclusive) or'', as introduced in \Cref{defn_and_or_xor}.  Note that $\cup$ looks similar to $\lor$.
            For example, we might be interested in the union of the set of students who are math majors and the set of students who are computer science majors because we would like to invite that whole group to a talk.

            \item The \vocab{symmetric difference} of $S$ and $T$, denoted $S \oplus T$, is the set
                $$S \oplus T= \{ x \in U \mid x \in S  \oplus x \in T\},$$
            where $\oplus$ (or xor) is the logical connective ``exclusive or'', as introduced in \Cref{defn_and_or_xor}. For example, we might want to identify people who attended a recent performance of La Boh\`eme or of Tosca, but not both, to offer them the opportunity to buy a season membership to the opera, noting that people who already have a season membership will likely have attended both.  If $S$ is the set of people who attended La Boh\`eme and $T$ is the set of people who attended Tosca, then the set we want is $S \oplus T$.
            
            \item The \vocab{difference} of $S$ and $T$, denoted $S - T$ and pronounced ``$S$ without $T$'', is the set
                $$S-T =\{x \in U \mid x \in S \text{ but } x\notin T\}.$$
            For example, we might want to send a reminder to patients who received a flu vaccine last year but have not yet done so this year. That would be the set $S -T$ where $S$ is the set of people who received a flu vaccine last year and $T$ is the set of people who received a flu vaccine this year.  Note that $T-S$ is usually different. In our example, $T-S$ would be the patients who received their flu vaccine this year but not last year. The symbol $-$ looks like the logical operator $\neg$.

            \item The \vocab{complement} of $S$ (in a universal set $U$), denoted $\overline{S}$, is the set
                $$\overline{S}= \{ x \in U \mid x \notin S\}.$$
            Yes, $\overline{S}=U-S$.  For example, we might want to reach out to all students who are not yet registered for the fall term. If $S$ is the set of all students who have registered for fall term and $U$ is the set of all students, then $S-U$ is the set we want.
        \end{apart}
\end{defn}

Let's use the Venn diagrams to visualize specific examples and we work with these definitions.

\begin{exam}[Set operations]
\label{exam_setops}
    For sets $S = \{2,3,5\}$ and $T = \{1,2,3,4\}$ calculate the following sets.  You might want to look back at \Cref{fig_venn_specific}.
        \begin{apart}
            \item The union $S \cap T$ and the intersection $S \cup T$.
                \begin{soln}
                    The intersection includes the elements in the overlap of $S$ and $T$ so $S \cap T = \{2,3\}$. The union includes all elements in $S$ or $T$ or both so $S \cup T = \{1,2,3,4,5\}$.
                \end{soln}
            \item The symmetric difference $S \oplus T$ and each difference $S-T$ and $T-S$.
                \begin{soln}
                    The symmetric difference includes the elements in exactly one of $S$ or $T$ but not both so $S \oplus T = \{1,4,5\}$. The difference $S-T$ includes the elements of $S$ that are not also in $T$ so $S-T = \{5\}$. Similarly, the difference $T-S$ includes the elements of $T$ that are not also in $S$ so $T-S = \{1,4\}$.
                \end{soln}
        \end{apart}
\end{exam}

Let's calculate some complements.

\begin{exam}[Set complements]
\label{exam_set_complement}
~
    \begin{apart}
        \item Evaluate $\overline{S}$ for the set $S = \{2, 3,5\}$ in the universal set $U= \{1, 2, 3, 4, 5, 6, 7\}$.
           \begin{soln}
               The complement includes all elements (of $U$) that are not in $S$ so $\overline{S} = \{1, 4, 6,7\}$.
           \end{soln}
        \item In the set of all bit strings $\mathbb{B}$, consider the set $$Z = \{b \in \mathbb{B} \mid b \text{ has at least one } \bs{0}\}.$$  Evaluate $\overline{Z}$.
            \begin{soln}
                The complement includes all bit strings that do not have at least one \bs{0}, that is all bit strings consisting solely of \bs{1}, and the empty string $\lambda$.  That is
                $$\overline{Z} = \{\lambda, 1, 11, 111, 1111, \ldots\}.$$ 
            \end{soln}
    \end{apart}
\end{exam}

Let's consider an example with three sets.

\begin{exam}[Set operations with three sets]
\label{exam_set_ops_3sets}
    Consider the sets $S = \{2,3,5\}$, $T = \{1,2,3,4\}$, and $Y =  \{2,4,5,6\}$ as drawn in \Cref{fig_venn_3sets_specific}.

    \begin{figure}[hbtp]
        \centering
        \input{Tikz/venn_3sets_specific}
        \caption{The standard Venn diagram for the three sets $S = \{2,3,5\}$, $T = \{1,2,3,4\}$, and $Y =  \{2,4,5,6\}$.}
        \label{fig_venn_3sets_specific}
    \end{figure}

    In this example, every element of $S$ happens to already lie within $T \cup Y$, but in other examples there might be some element in that part of the diagram. 
        \begin{apart}
            \item Calculate $(S\cap Y) \cup T$.
                \begin{soln}
                    Note that $S\cap Y=\{2,5\}$.  Thus, 
                        $$(S\cap Y) \cup T = \{2,5\} \cup \{1,2,3,4\}=\{1,2,3,4,5\}.$$
                \end{soln}
            \item Calculate $S\cap (Y \cup T)$.
                \begin{soln}
                    Note that $Y \cup T=\{1,2,3,4,5,6\}$. Thus,
                        $$S\cap (Y \cup T)=S \cap \{1,2,3,4,5,6\}=\{2,3,5\}.$$

                    Notice that we got different answers because the placement of the parentheses matters.
                \end{soln}
        \end{apart}
\end{exam}
