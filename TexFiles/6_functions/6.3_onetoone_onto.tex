\newcommand{\suborderedpair}{Ordered Pairs and the Definition of Function}
\subsection{\suborderedpair}
\label{sub_ordered pairs}

The formal definition of function uses the concept of an ordered pair.  We have used ordered pairs, for example, in discussing points in the $xy$-plane.  There is a clever way of defining an ordered pair using sets. We begin with that definition.

\begin{defn}[Ordered pairs]
\label{defn_ordered_pairs}
~
    \begin{apart}
        \item For sets $X$ and  $Y$ and elements $x$ in $X$ and $y$ in $Y$, the \vocab{ordered pair} $(x,y)$ is defined by $$(x,y) = \{\{x\}, \{x,y\}\}.$$  For example, if $X = \mathbb{Z}$ and $Y = \mathbb{Z}$, then
        $$(3,7) = \{\{3\}, \{3,7\}\}$$ whereas $$(7,3) = \{\{7\}, \{3,7\}\}$$
        which are different.  Note that the same element may be used.  For example, 
        $$(5,5) = \{\{5\}, \{5,5\}\}=\{\{5\},\{5\}\}=\{\{5\}\}. $$
        
        \item In the ordered pair $(x,y)$, we say that $x$ is the \vocab{first coordinate} and $y$ is the \vocab{second coordinate}.  For example, in $(3,7)$ the first coordinate is 3 and the second coordinate is 7.
    \end{apart}  
\end{defn}

In \Cref{defn_function}, we define a \vocab{function}, $f$, as consisting of three parts: a domain set, a codomain set, and a rule that for each element $x$ in the domain of $f$ uniquely determines a corresponding element $y$ in the codomain of $f$.  In that definition, the term ``rule'' was undefined.  As we have seen, examples of rules include formulas, piecewise-defined formulas, or even rules described in words.  We are ready to provide a formal modern definition of a rule for a function.

\begin{defn}[Formal definition of rule for a function]
\label{defn_fn_rule}
~
    \begin{apart}
        \item Given a domain set $X$ and a codomain set $Y$, a \vocab{rule for a function} $f$ is a set of ordered pairs $(x,y)$ where the first coordinate of each ordered pair, $x$, is an element of the set $X$, the second coordinate of each ordered pair, $y$, is an element of the set $Y$, and the set satisfies the property that each element of the domain is the first coordinate of exactly one ordered pair in the set. For example, if $X = \{1,2,3\}$ and $Y=\{0,1,2,3,4\}$, then the set $$\{(1,0),(2,3),(3,3)\}$$ is the rule for a function because $(1,0)$ is the unique ordered pair with first coordinate 1, $(2,3)$ is the unique ordered pair with first coordinate 2, and $(3,3)$ is the unique ordered pair with first coordinate 3.  On the other hand, the set $\{(2,1), (2,3), (3,2)\}$
        is not the rule for a function for two reasons.  First, there is no ordered pair with 1 as the first coordinate.  Second, there are two different ordered pairs with 2 as the first coordinate. Either of these reasons justifies that the set is not the rule for a function.
        \item We use \vocab{function notation} and write $f(x) =y$ to indicate that the ordered pair $(x,y)$ is in the rule for $f$.  For example, if $(2,3)$ is in the rule for a function $f$, then we write $f(2)= 3$.
    \end{apart}
    
\end{defn}

                \end{soln}

\newcommand{\subpairing}{Pairings}
\subsection{\subpairing}
\label{sub_pairings}

How can we determine whether two sets are the same size?  For finite sets, we can pair the elements, just as a child might count objects by pairing each object with one of their fingers.  Consider the following example.

\begin{exam}[Pairing finite sets]
\label{exam_pairing_finite_sets}
    Give an example of a pairing of the sets $X=\{1,2,3,4\}$ and $Y=\{a,b,c,d\}$.
        \begin{soln}
            A possible pairing is 
            $$1 \leftrightarrow a, \quad 2 \leftrightarrow b, \quad 3 \leftrightarrow c, \quad 4 \leftrightarrow d.$$
            Another pairing is
            $$1 \leftrightarrow b, \quad 2 \leftrightarrow c, \quad 3 \leftrightarrow d, \quad 4 \leftrightarrow a.$$
            We verify this example satisfies the definition of a pairing in \Cref{defn_pairing}.
        \end{soln}
\end{exam}

In defining a pairing, we want to capture the idea that each element of the first set and each element of the second set are paired exactly once.
    
\begin{defn}[Pairing]
\label{defn_pairing}
    A \vocab{pairing}, $P$, between sets $X$ and $Y$ is a set of ordered pairs $(x,y)$ where the first coordinate, $x$, is an element of the set $X$, the second coordinate, $y$, is an element of the set $Y$ and the set $P$ satisfies the following properties. 
        \begin{apart}
            \item \label{part_pairing_first_coord} Each element of $X$ is the first coordinate of exactly one ordered pair in $P$.
            \item \label{part_pairing_second_coord} Each element of $Y$ is the second coordinate of exactly one ordered pair in $P$.
        \end{apart}  
    When we have a pairing, we write $x \leftrightarrow y$ to denote that $(x,y)$ is in the set. 

    For example, in \Cref{exam_pairing_finite_sets} we saw that if $X=\{1,2,3,4\}$ and $Y=\{a,b,c,d\}$, then the set $$\{(1,b),(2,c),(3,d),(4,a)\}$$ is a pairing because 1 is the first coordinate of exactly one ordered pair, namely $(1,b)$, 2 is the first coordinate of exactly one ordered pair, namely $(2,c)$, 3 is the first coordinate of exactly one ordered pair, namely $(3,d)$, and 4 is the first coordinate of exactly one ordered pair, namely $(4,a)$.  Similarly, $a$ is the second coordinate of exactly one ordered pair, namely $(4,a)$, $b$ is the second coordinate of exactly one ordered pair, namely $(1,b)$, $c$ is the second coordinate of exactly one ordered pair, namely $(2,c)$, and $d$ is the second coordinate of exactly one ordered pair, namely $(3,d)$.                
     
\end{defn}

\begin{exam}[Counting the number of pairings between a set and itself]
\label{exam_count_pairings_self} 
    How many different pairings between the set $\{0,1,2,3,4\}$ and itself are there?
        \begin{soln}
            The question ``how many'' suggests that we should count.  There are five elements in the set, so there are five choices for which element is paired with 0.  Next, there are four elements we have not used yet, so there are four choices for which element is paired with 1.  Similarly, there are three choices for which element is paired with 2 and then two choices for which element is paired with 3 and then one choice for which element is paired with 4.  Since steps multiply (\Cref{thm_steps_multiply}), there are $(5)(4)(3)(2)(1) = 5!$ pairings between the set $\{0,1,2,3,4\}$ and itself.
        \end{soln}
\end{exam}

\newcommand{\subonetooneonto}{One-to-one and Onto}
\subsection{\subonetooneonto}
\label{sub_onetoone_onto}

Every pairing defines a rule of a function because the definition of function (\Cref{defn_fn_rule}) includes the first property of the definition of a pairing (\Cref{defn_pairing} (\ref{part_pairing_first_coord})).  Therefore, we can describe pairings using function notation. 

\begin{rem} [Function notation for pairings]
\label{rem_fn_notation_pairing}
    For sets $X$ and $Y$, a pairing, $P$, between $X$ and $Y$ defines a function $f:X \to Y$ by $f(x)=y$ when $(x,y)$ is in $P$.  In this context, we write $x \leftrightarrow f(x)$. 
\end{rem}

In this section, we explore the second property \Cref{defn_pairing} (\ref{part_pairing_second_coord}), which the rule of a function needs to satisfy to be a pairing.  For that purpose, it is helpful to separate \Cref{defn_pairing} (\ref{part_pairing_second_coord}) into two parts. 

\begin{rem}[When the rule of a function is a pairing]
\label{rem_pairings_as_fns}
    For sets $X$ and $Y$, a rule, $P$, for a function $f:X \to Y$ is a pairing if it satisfies the following properties.
        \begin{apart}
            \item \label{part_existence_onto} Existence:  Each element of $Y$ is the second coordinate of at least one ordered pair in $P$. That is, for each element $y$ in $Y$, there is at least one element $x$ in $X$ such that $f(x) = y$.  (Onto property)
            \item \label{part_uniqueness_1to1} Uniqueness: Each element of $Y$ is the second coordinate of at most one ordered pair in $P$. That is, or each element $y \in Y$, there is at most one element $x \in X$ such that $f(x)=y$.  (One-to-one property)
        \end{apart} 
\end{rem}

Let's take a closer look at the existence and uniqueness properties of a pairing. We start with existence.

\begin{defn}[Onto]
\label{defn_onto}
    A function $f: X \to Y$ is \vocab{onto} (or \vocab{surjective}) if for each element $y$ of $Y$, there is at least one element $x \in X$ such that $f(x) =y$. That is, for each element $y$ in $Y$, there is at least one ordered pair in the rule for $f$ with second coordinate $y$. For example, the functions $f$ and $k$ defined by the dot diagrams in \Cref{fig_finite_functions} are onto, but the function $g$ is not onto because nothing maps to $b$ and the function $h$ is not onto because nothing maps to $a$.
        \begin{figure}[hbtp]
            \centering
            \input{Tikz/finite_function_examples}
            \caption{Finite functions}
            \label{fig_finite_functions}
        \end{figure}
\end{defn}

We can determine whether a function is onto by identifying its image.

\begin{exam}[Onto in terms of image]
\label{exam_onto_image}
~
    \begin{apart}
        \item Restate the definition of onto in terms of the image of a function.
            \begin{soln}
                A function $f:X \to Y$ is onto if the image of $f$ is the entire codomain $Y$.
            \end{soln}
        \item Use the image to determine which of the functions in \Cref{fig_finite_functions}. are onto.
            \begin{soln}
                 The image and codomain of $f$ are $\{a,b,c,d\}$ and so $f$ is onto.  The image of $g$ is $\{a,c,d\}$ which is not all of its codomain $\{a,b,c,d\}$ and so $g$ is not onto. The image of $h$ is $\{b,c,d\}$ which is not all of its codomain $\{a,b,c,d\}$ and so $h$ is not onto.  Notice that the function $k$ has the same rule and the same domain as $g$, but the codomain of $k$ is $\{a,c,d\}$ which equals the image of $k$ and so $k$ is onto.
            \end{soln}
    \end{apart}
\end{exam}

Let's look at some additional examples.

\begin{exam}[Show functions are not onto]
\label{exam_not_onto}
    Show that each function is not onto.
    \begin{apart}
        \item The function $f:\mathbb{R} \to \mathbb{R}$ is defined by $f(x) = x^2+1$.
            \begin{soln}
                The function $f$ is not onto because for any real number $x$ we know that $x^2 \ge 0$ and so $f(x) \ge 1$. For example, there is no value of $x$ for which $f(x) = 0$.  In the graph of $f$, shown in \Cref{fig_parabola_graph}, we can see that the lowest point on the graph is $(0,1)$ and the image of $f$ is $[1,\infty)$ which is not all of the codomain $\mathbb{R}$.  
            \end{soln}
        \item The function $g: \mathbb{Z} \to \mathbb{Z}$ is defined by $g(n) = 3n$.
            \begin{soln}
                The function $g$ is not onto because the image is only multiples of 3.  For example, there is no value of $n$ for which $g(n) = 5$.
            \end{soln}    
        \item The function $l:\mathbb{B} \to \mathbb{Z}$ is defined by $l(b) =$ the length of the bit string $b$ where $\mathbb{B}$ is the set of all bit strings. 
           \begin{soln}
               Since the length of a bit string is nonnegative, there is no bit string $b$ with $l(b) = -2$, for example.  Note that if we had set the codomain as $\mathbb{N}$, then the function would be onto.
           \end{soln}
        \item The function $\fn{twopart}: \mathbb{N} \to \mathbb{N}$ defined by $\fn{twopart}(n)$ is the highest power of two that divides $n$.  We saw this function in \Cref{act_number_functions}.
            \begin{soln}
                The image of \fn{twopart} is the set of powers of two:
                    $$\{1,2,4,8,16,\ldots\}.$$
                Since the image is not all of the codomain $\mathbb{N}$, the function \fn{twopart} is not onto.  As a specific counterexample we could say $\fn{twopart}(n) = 3$ has no solution.
            \end{soln}
    \end{apart}
\end{exam} 

Since the onto property says $\forall $y~$ \exists $x$~ f(x)=y$, we can prove that a function is onto using proof formats for universally and existentially quantified statements.

\begin{exam}[Proof that a function is onto]
\label{exam_proof_onto}
    Use the proof formats for universally and existentially quantified statements (\Cref{pff_forall} and \Cref{pff_exists}) to prove that the function $h: \mathbb{R} \to \mathbb{R}$ defined by $h(x) = 3x$ is onto.
        \begin{soln}
            \emph{Proof.} Let $y$ be a real number.  Consider $x = \frac{y}{3}$ which is also a real number. Then
                $$h(x) = 3x = 3\left(\frac{y}{3}\right) = y.$$
            Thus, there exists a real number $x$ such that $h(x) = y$, namely $x = \frac{y}{3}$. \hfill $\Box$

            Note that we nested \Cref{pff_exists} inside \Cref{pff_forall}.  For another example of a similar proof, see \Cref{act_proof_quants_nested} in \Cref{sec_quant_cex}.
        \end{soln}
\end{exam}

Now, let's look at the uniqueness property of a pairing.

\begin{defn}[One-to-one]
\label{defn_onetoone}
    A function $f: X \to Y$ is \vocab{one-to-one} (or \vocab{injective}) if for each element $y$ of $Y$, there is at most one element $x \in X$ such that $f(x) =y$. That is, for each element $y$ in $y$, there is at most one ordered pair in the rule for $f$ with second coordinate $y$. For example, the functions $f$ and $h$ defined by the dot diagrams in \Cref{fig_finite_functions} are one-to-one, but the functions $g$ and $k$ are not one-to-one because, for example $g(2)=c=g(4)$ and $k(2)=c=k(4)$.
\end{defn}

Let's look at some additional examples.

\begin{exam}[Show functions are not one-to-one]
\label{exam_onetoone}
    Show that each function is not one-to-one.
    \begin{apart}
        \item The function $f:\mathbb{R} \to \mathbb{R}$ is defined by $f(x) = x^2+1$.
            \begin{soln}
                The function $f$ is not one-to-one because $f(2) = (2)^2+1 = 5$  and $f(-2) = (-2)^2+1 =5$.
            \end{soln}    
        \item The function $\fn{countdiv}: \mathbb{Z}^+ \to \mathbb{Z}^+$ is defined by $\fn{countdiv}(n)=$ the number of positive divisors of $n$.
            \begin{soln}
                The positive divisors of six are 1, 2, 3, and 6 and the positive divisors of 10 are 1, 2, 5, and 10.  Therefore, the function $\fn{countdiv}$ is not one-to-one because $\fn{countdiv}(6) = 4$ and $\fn{countdiv}(10) = 4$ 
                (because ).
            \end{soln}

A function that is onto and one-to-one has a special name.

\begin{defn}[Bijection]
\label{defn_bijection}
    A function $f: X \to Y$ is a \vocab{bijection} if it is one-to-one and onto.  Note that $f$ is a bijection exactly when $x \leftrightarrow f(x)$ is a pairing.  For example, the function $f$ defined by the dot diagrams in \Cref{fig_finite_functions} is a bijection. It corresponds to the pairing 
        $$1 \leftrightarrow b, \quad 2 \leftrightarrow c, \quad 3 \leftrightarrow d, \quad 4 \leftrightarrow a$$
    which we saw in \Cref{defn_pairing}.
\end{defn}

Let's look at some additional examples.

\begin{exam}[Examples of bijections]
\label{exam_bijections}
    Explain how we know each of the following functions is a bijection.
    \begin{apart}
        \item The function $f: \mathbb{N} \to \mathbb{N}$ defined by 
            $$f(n) = \left\{ \begin{array} {cl} 
                n+1 & \text{if }n\text{ is even} \\
                n-1 & \text{if }n\text{ is odd} \\
            \end{array} \right.$$
                \begin{soln}
                    We drew the graph of this function in \Cref{fig_nonid_pair_naturals}.  Note that each point in the bottom row has exactly one arrow pointing into it, and so the function is a bijection.
                \end{soln}
        \item \label{part_bijection_RtoR} The function $h: \mathbb{R} \to \mathbb{R}$ is defined by $h(x) = 3x$.
            \begin{soln}
                Given a real number $y$, there is exactly one real number $x$ such that $h(x)=y$.  As we saw in \Cref{exam_proof_onto}, it must be $x = \frac{y}{3}$.
            \end{soln}
        \item \label{part_graph_comp_bijection} Let $\mathbb{G}$ be the set of all graphs. The function $\fn{comp}: \mathbb{G} \to \mathbb{G}$ defined by $\fn{comp}(G)= \overline{G}$, the graph-theoretic complement of $G$. 
            \begin{soln}
                Given a graph $H$, there is exactly one graph $G$ such that $\fn{comp}(G) = H$, namely $G =\overline{H}$ because $\fn{comp}(\overline{H}) = \overline{\overline{H}}=H$.
            \end{soln}
    \end{apart}
\end{exam}
